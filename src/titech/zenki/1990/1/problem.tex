$x$，$y$，$z$，$w$を正数とする．
任意の正の整数$m$，$n$に対して
\begin{align}
  {(x^\dfrac{1}{m}+y^\dfrac{1}{m})}^n+{(z^\dfrac{1}{m}+w^\dfrac{1}{m})}^n=
{ \{ {(x^\dfrac{n}{m}+z^\dfrac{n}{m})}^\dfrac{1}{n}+{(y^\dfrac{n}{m}+w^\dfrac{n}{m})}^\dfrac{1}{n} \} }^n
\end{align}
が成り立つための必要十分条件を求めよ．
