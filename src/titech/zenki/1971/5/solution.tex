{\bf [解]}
(1)
$f(x)=e^{-x}+x-1$ とおくと，$x>0$ で $f(x)>0$ であることを示せば良い．
一階微分を計算すると
\begin{align}
 f'(x)=-e^{-x}+1>0 (\because x>0)
\end{align}
だから $0<x$ で $f(x)$ は単調増加であり，
\begin{align}
  f(x)>f(0)=0
\end{align}
である．よって題意は示された．

(2)
簡単のため
\begin{align}
 A_n = \displaystyle\prod_{k=1}^n\left(1-\frac{1}{\sqrt{k}+\sqrt{k+1}}\right) \label{eq:1}
\end{align}
および
\begin{align}
 p_k=\frac{1}{\sqrt{k}+\sqrt{k+1}} = \sqrt{k+1}-\sqrt{k}
\end{align}
とおく．
まず$p_k$は単調減少だから$1-p_k$を下から評価すると
\begin{align}
 1-p_k \ge 1-p_1 = 1-\dfrac{1}{1+\sqrt{2}} = 2-\sqrt{2} > 0 \label{eq:2}
\end{align}
である．従って$A_n$も正であり\cref{eq:1}の両辺の対数をとると
\begin{align}
  \log A_n = \sum_{k=1}^n \log(1-p_k) \equiv B_n \label{eq:3}
\end{align}
である．

以下$B_n$を評価しよう．(1)から$0<x<1$の時
\begin{align}
 e^{-x} > x-1 > 0
\end{align}
だから自然対数をとって
\begin{align}
  -x > \log(1-x) \label{eq:4}
\end{align}
である．
\cref{eq:2}から$0<p_k<1$ だから，$x=p_k$ として\cref{eq:4}に代入して
\begin{align}
  -p_k > \log(1-p_k)
\end{align}
  $k=1,2,\cdots,n$ として両辺足し合わせて
\begin{align}
  -\sum_{k=1}^n p_k &> B_n \\
  -\sum_{k=1}^n \left(\sqrt{k+1}-\sqrt{k}\right) &> B_n \\
  1-\sqrt{n+1} &> B_n 
\end{align}
である．\cref{eq:3}に代入して
\begin{align}
  1-\sqrt{n+1} > \log A_n 
\end{align}
である．
$n\to\infty$ の時$1-\sqrt{n+1}\to-\infty$ だから，追い出しの原理より
\begin{align}
 \lim_{n\to\infty} \log A_n = -\infty
\end{align}
である．
$y=\log x$ は連続だから
\begin{align}
 \lim_{n\to\infty} A_n = +0
\end{align}
が求める極限値である．
