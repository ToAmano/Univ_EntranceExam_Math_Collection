{\bf [解]}
$T = \displaystyle\int_0^a P(x)P'(x)dx$, $S = \displaystyle\int_0^a \{P'(x)\}^2 dx$ とおく．
$P(x)=Ax+Bx^2$ だから一階微分は$P'(x)=A+2Bx$ で，$T, S$は具体的に
\begin{align}
T &= \left[\dfrac{1}{2}\{P(x)\}^2\right]_0^a = \dfrac{1}{2}P(a)^2 \label{eq:1}\\
S &= \int_0^a (4B^2x^2+4ABx+A^2)dx \\
  &= \left[\dfrac{4}{3}B^2x^3+2ABx^2+A^2x\right]_0^a \\
  &= \dfrac{4}{3}B^2a^3+2ABa^2+A^2a \label{eq:2}
\end{align}
と書ける．
以下任意の $A,B\in\mathbb{R}$ に対して $|T|\le kS$ が成り立つ $k$ の条件を考える．\cref{eq:1,eq:2}を代入して
\begin{align}
 |T| & \le kS \\
\therefore 
 \dfrac{1}{2}(Aa+Ba^2)^2 & \le k\left(\dfrac{4}{3}B^2a^3+2ABa^2+A^2a\right)
\end{align}
である．
$a>0$ から両辺 $a$ で割って，
\begin{align}
\dfrac{1}{2}a(A^2+2aAB+a^2B^2) \le k\left(A^2+2aBA+\dfrac{4}{3}a^2B^2\right) \\
\left(\dfrac{1}{2}a-k\right)A^2 + (a^2B-2kaB)A + \dfrac{1}{2}a^3B^2 - \dfrac{4}{3}ka^2B^2 \le 0 \label{eq:3}
\end{align}
を得る．
\cref{eq:3}の左辺は$A$について二次以下の方程式だから，この不等式が任意の $A$ で成り立つには，
\begin{align}
 \dfrac{1}{2}a-k\le0 \iff \dfrac{1}{2}a\le k \label{eq:4}
\end{align}
が必要である．この等号が成立するかどうかで場合分けする．
\cref{eq:3}の左辺を$f(A)$とおく：
\begin{align}
 f(A) = \left(\dfrac{1}{2}a-k\right)A^2 + (a^2B-2kaB)A + \left(\dfrac{1}{2}a - \dfrac{4}{3}k\right)a^2B^2
\end{align}

\subparagraph{\cref{eq:4}で等号が不成立の時}

この時は$f(A)$は$A$の二次方程式だから，\cref{eq:4}が成立する条件は$f(A)=0$ の判別式 $D$ が $0$ 以下であることである．
実際に$D$を計算すると
\begin{align}
 D = (a^2B-2kaB)^2 - 4\left(\dfrac{1}{2}a-k\right)a^2B^2\left(\dfrac{1}{2}a-\dfrac{4}{3}k\right) \le 0
\end{align}
$a>0$ だから両辺 $a^2$ で割って，
\begin{align}
\left[(a-2k)^2 - 4\left(\dfrac{1}{2}a-k\right)\left(\dfrac{1}{2}a-\dfrac{4}{3}k\right)\right]B^2 \le 0
\end{align}
これが任意の $B\in\mathbb{R}$ で成立すれば良いので大括弧の中身が$0$以下であれば良い．
\begin{align}
(a-2k)^2-4\left(\dfrac{1}{2}a-k\right)\left(\dfrac{1}{2}a-\dfrac{4}{3}k\right) \le 0 \\
(a-2k)\left[(a-2k)-\left(a-\dfrac{8}{3}k\right)\right] \le 0 \\ 
(a-2k)\dfrac{2k}{3} \le 0 \quad \cdots \text{③} 
\end{align}
仮定より$a-2k<0$ だから，
\begin{align}
\dfrac{2}{3}k \ge 0 \quad \therefore k \ge 0
\end{align}
である．$a>0$よりこれは$a-2k<0$の時成り立っている．
すなわち$a-2k<0$ならば題意の不等式は常に成り立つ．


\subparagraph{\cref{eq:4}で等号が成立する時}

\cref{eq:4}で等号が成立する時，すなわち
\begin{align}
 2k = a
\end{align}
の時，$f(A)$は
\begin{align} 
f(A) = a^2B^2\left(\dfrac{1}{2}a-\dfrac{4}{3}k\right) = -\dfrac{1}{6}a^3B^2 \le 0 \quad (\because a>0, B\in\mathbb{R})
\end{align}
となる．
従って任意の $A,B\in\mathbb{R}$ に対して\cref{eq:3}は成立する．
\casesend


以上二つの場合分けから，求める最小の$k$は
\begin{align}
\min k = \dfrac{1}{2}a
\end{align}
である．
