{\bf [解]}
楕円$C:\dfrac{x^2}{a^2}+y^2=1$（$a>1$）上に点$A(a,0)$および$B(p,q)$をとる．この時
\begin{align}
 \begin{cases}
  p = a\cos\theta, q = \sin\theta \\
  0<\theta<\pi   
 \end{cases} \label{eq:1}
\end{align}
とおく．まずは接点の座標を求める．

$B$における接線は
\begin{align}
\ell:\ \dfrac{\cos\theta}{a}x+\sin\theta y=1 \label{eq:2}
\end{align}
である．

$\ell$の方向ベクトルは
\begin{align}
 \vec\ell=
   \begin{pmatrix}
    -a\sin\theta \\
    \cos\theta
   \end{pmatrix}
\end{align}
であり，直線$x=p$の方向ベクトルは
\begin{align}
 \vec{n} = 
   \begin{pmatrix}
    0 \\
    1
   \end{pmatrix}
\end{align}
である．また
\begin{align}
  \overrightarrow{BA} = 
 \begin{pmatrix}
  a(1-\cos\theta) \\
  \sin\theta
 \end{pmatrix}
\end{align}
である．

さて，ここで上図のような$3$点について
\begin{align}
 \tan\theta = \dfrac{\sin\theta}{\cos\theta} = \dfrac{|XY||XZ|\sin\theta}{|XY||XZ|\cos\theta} = \frac{2\triangle XYZ}{\overrightarrow{XY}\cdot\overrightarrow{XZ}}
\end{align}
だから，

$\ell$と$x=p$のなす角$\beta$について，角は鋭角にとるので絶対値を用いて
\begin{align}
 \tan\beta = \left|\dfrac{-a\sin\theta}{\cos\theta}\right| = \dfrac{a\sin\theta}{\left|\cos\theta\right|} \label{eq:3}
\end{align}
である．

同様に$\ell$と$BA$のなす角$\alpha$について，角は鋭角にとるので絶対値を用いて
\begin{align}
 \tan\alpha 
   &= \left|\dfrac{a\cos\theta(1-\cos\theta)-a\sin^2\theta}{-a^2\sin\theta(1-\cos\theta)-\sin\theta\cos\theta}\right| \\
   &= \left|\dfrac{a(\cos\theta-1)}{-\sin\theta\{(1-a^2)\cos\theta + a^2\}}\right| \\
   &= \dfrac{a(1-\cos\theta)}{\sin\theta\{(1-a^2)\cos\theta + a^2\}} \label{eq:4}
\end{align}
である．ただし最後の行で$a>1$, $-1 < \cos\theta < 1$より絶対値を外した．

題意の条件は鋭角$\alpha,\beta$について$\alpha=\beta$だから，$\tan\alpha=\tan\beta$と同値である．
従って\cref{eq:3,eq:4}が等しいから
\begin{align}
 \dfrac{a\sin\theta}{\left|\cos\theta\right|} = \dfrac{a(1-\cos\theta)}{\sin\theta\{(1-a^2)\cos\theta + a^2\}} \\
  a\sin^2\theta\Bigl[(1-a^2)\cos\theta + a^2\Bigr] = a(1-\cos\theta)\left|\cos\theta \right| 
\end{align}
左辺に$\sin^2\theta = 1-\cos^2\theta$を用いて
\begin{align}
 a\left(1-\cos^2\theta\right)\Bigl[(1-a^2)\cos\theta + a^2\Bigr] = a(1-\cos\theta)\left|\cos\theta \right| 
\end{align}
$a>0$および\cref{eq:1}より$\cos\theta\neq 1$だから両辺を$a(1-\cos\theta) (\neq 0)$で割って
\begin{align}
 \left(1+\cos\theta\right)\Bigl[(1-a^2)\cos\theta + a^2\Bigr] = \left|\cos\theta \right| \label{eq:5}
\end{align}
である．

まず$\cos\theta\ge 0$の時は\cref{eq:5}は
\begin{align}
 (1-a^2)\cos^2\theta + a^2 = 0 \quad \therefore \cos^2\theta=\dfrac{a^2}{a^2-1}>1
\end{align}
となり$0\le \cos\theta<1$に反して不適である．

よって$\cos\theta<0$であり，この時\cref{eq:5}は
\begin{align}
 (1-a^2)\cos^2\theta + 2\cos\theta + a^2 = 0 \\
\therefore
 \cos\theta = \dfrac{1\pm \sqrt{1+a^2(a^2-1)}}{a^2-1} 
\end{align}
である．$\cos\theta<0$より複合負が正しく，
\begin{align}
 \cos\theta = \dfrac{1 - \sqrt{1+a^2(a^2-1)}}{a^2-1} \label{eq:6}
\end{align}
となる．これは確かに以下のように$-1<\cos\theta < 0$を満たす．
同値変形していくと
\begin{align}
  & -1 < \cos\theta < 0 \\
\iff
  & -1 < \dfrac{1 - \sqrt{1+a^2(a^2-1)}}{a^2-1} < 0 \\
\iff
  & -(a^2-1) < 1 - \sqrt{1+a^2(a^2-1)} < 0 \\
\iff
  & 1 < \sqrt{1+a^2(a^2-1)} < a^2 \\
\iff
  & 1 < 1 + a^2(a^2-1) < a^4 \\
\iff
  & 0 < a^2(a^2-1) < a^4 -1 = (a^2+1)(a^2-1)\\ 
\iff
  & 0 < a^2 < a^2+1 \quad (\because a^2 > 1)
\end{align}
で，最後の行は自明だから$-1<\cos\theta<0$を満たす．


\paragraph{(1)}

求める$p$は\cref{eq:1,eq:6}より
\begin{align}
p=a\cos\theta=\dfrac{a\left\{1-\sqrt{1+a^2(a^2-1)}\right\}}{a^2-1}
\end{align}
である．

\paragraph{(2)}

まず$p$の$a\to 1$の極限を考える．
分子を有理化すると
\begin{align}
 p
  &= \dfrac{a\left\{1-\bigl(1+a^2(a^2-1)\bigr)\right\}}{(a^2-1)\left\{1+\sqrt{1+a^2(a^2-1)}\right\}} \\
  &= \dfrac{-a^3(a^2-1)}{(a^2-1)\left\{1+\sqrt{1+a^2(a^2-1)}\right\}}=\dfrac{-a^3}{1+\sqrt{1+a^2(a^2-1)}}
\end{align}
したがって極限をとって
\begin{align}
\lim_{a\to1}p=\dfrac{-1}{1+\sqrt{1}}=-\dfrac{1}{2}
\end{align}
である．

次に$\dfrac{p}{a}$の$a\to\infty$の極限を考えると
\begin{align}
 \dfrac{p}{a}
   &=\dfrac{1-\sqrt{1+a^2(a^2-1)}}{a^2-1} \\
   &=\dfrac{\dfrac{1}{a^2}-\sqrt{\dfrac{1}{a^4}+1-\dfrac{1}{a^2}}}{1-\dfrac{1}{a^2}} \\
   &\xrightarrow{a\to\infty} \dfrac{0-\sqrt{1}}{1-0}=-1
\end{align}
である．
