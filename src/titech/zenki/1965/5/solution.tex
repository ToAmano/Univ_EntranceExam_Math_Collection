{\bf [解]}

$0<h<\pi$より，$0 \le x \le \pi$ に $\sin(x+h) = \sin x$ をみたす $x$ が $1$ つあるのでそれを $\alpha$ とする．
つまり
\begin{align}
\sin(\alpha+h) - \sin\alpha = 0, \quad 0 \le \alpha \le \pi \label{eq:1}   \\
\therefore 
  \alpha + h = -\alpha + \pi \\
\therefore 
  \alpha = \dfrac{\pi - h}{2} \label{eq:2}
\end{align}
である．

この時与えられた積分は
\begin{align}
\int_0^\pi |\sin(x+h) - \sin x| \, dx 
  &= \int_0^\alpha \{ \sin(x+h) - \sin x \} \, dx - \int_\alpha^\pi \{ \sin(x+h) - \sin x \} \, dx \label{eq:2}
\end{align}
だから
\begin{align}
F(x) = \cos x - \cos(x+h) 
\end{align}
とおくと
\begin{align}
\text{\cref{eq:2}}
  &= 2F(\alpha) - F(0) - F(\pi) \\
  &= 2F(\alpha) - (1 - \cos h) - (-1 + \cos h) \\
  &= 2F(\alpha) \label{eq:3}
\end{align}
と書ける．\cref{eq:2}を代入して
\begin{align}
F(\alpha) 
  &= \cos\left(\dfrac{\pi}{2} - \dfrac{h}{2}\right) - \cos\left(\dfrac{\pi}{2} - \dfrac{h}{2} + h\right) \\
  &= 2\sin\dfrac{h}{2}
\end{align}
だから，\cref{eq:3}に代入して
\begin{align}
\int_0^\pi |\sin(x+h) - \sin x| \, dx = 2F(\alpha) = 4\sin\dfrac{h}{2} < 2h \quad (\because 0 < x \text{ の時 } \sin x < x) 
\end{align}
となり題意は示された．
