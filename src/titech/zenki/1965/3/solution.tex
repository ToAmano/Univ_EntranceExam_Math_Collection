{\bf [解]}

題意より
\begin{align}
\begin{cases}
 0 \le x < \pi, 0 \le y < \pi \\
 \sin2x+\sin2y=1  
\end{cases}\label{eq:1}
\end{align}
である．新しく
\begin{align}
 \alpha = x + y, \beta = x - y \label{eq:1.5}
\end{align}
とおくと\cref{eq:1}の条件は
\begin{align}
 \begin{cases}
  0 \le \alpha + \beta < 2\pi \\
  0 \le \alpha - \beta < 2\pi \\
 \end{cases} \label{eq:2} 
\end{align}
および
\begin{align}
\sin\alpha \cos\beta = \dfrac{1}{2} \label{eq:3}
\end{align}
と書ける．このもとで$|\beta|$の最大最小を考えれば良い．
\cref{eq:2}の領域を図示すると下図斜線部である．

この領域の$\beta=0$に関する対称性および\cref{eq:3}における$\cos(-\beta) = \cos\beta$から，
\begin{align}
 \beta \ge 0
\end{align}
で考えれば良い．この時\cref{eq:2}は
\begin{align}
\begin{cases}
 0 \le \beta < \pi \\
\beta \le \alpha < -\beta + 2\pi
\end{cases} \label{eq:4}
\end{align}
となる．

まず$|\beta|$ の最小値について考える．\cref{eq:4}で左側の等号が成立する時，すなわち$\beta=0$の時，
\cref{eq:4}は$0 \le \alpha < 2\pi$ で$\alpha = \dfrac{\pi}{6}, \dfrac{5}{6}\pi$ とすれば\cref{eq:3}を満たす．よって求める最小値は$|\beta|=0$でこの時
\begin{align}
 (x,y) =  \left(\dfrac{\pi}{12}, \dfrac{\pi}{12}\right), \left(\dfrac{5\pi}{12}, \dfrac{5\pi}{12}\right) \label{eq:5}
\end{align}
である． 

次に$|\beta|$ の最大値について考える．\cref{eq:4}の区間内では$\sin \alpha$のとりうる値は区間が$\dfrac{\pi}{2}$を含むかどうかで変化して
\begin{align} 
 \begin{cases}
  -1 \le \sin\alpha \le 1                  & \left(0 \le \beta \le \dfrac{\pi}{2} \text{ の時}\right) \\
  -\sin\beta \le \sin\alpha \le \sin\beta  & \left(\dfrac{\pi}{2} \le \beta \le \pi \text{ の時} \right)
 \end{cases}\label{eq:6}
\end{align}
のふたパターンあるから両方を順番に考える．

\subparagraph{$0 \le \beta \le \dfrac{\pi}{2}$の時}

\cref{eq:6}からこの区間では$\beta$の値によらずに$\sin\alpha$を$-1$から$1$の範囲で自由に決定できる．よって\cref{eq:3}を満たす$(\alpha,\beta)$が存在するには
\begin{align}
 \dfrac{-1}{2}\le \cos\beta \le \dfrac{1}{2}
\end{align}
であれば良い．
この範囲で$|\beta|$が最大なのは $\cos\beta = \dfrac{1}{2} \therefore \beta = \dfrac{\pi}{3}$の時で，この時 $\sin\alpha=1$ ゆえ $\alpha = \dfrac{\pi}{2}$である．

\subparagraph{$\dfrac{\pi}{2} \le \beta < \pi$の時}

\cref{eq:6}より $\sin\alpha \cos\beta$ の値域は$\cos\beta \le 0$に注意して
\begin{align}
 & \sin\beta\cos\beta \le \sin\alpha \cos\beta \le -\sin\beta\cos\beta \\
\therefore 
 & \dfrac{1}{2}\sin 2\beta \le \sin\alpha \cos\beta \le -\dfrac{1}{2}\sin 2\beta
\end{align}
である．ただし二行目で倍角公式を用いた．
\cref{eq:3}に代入して
\begin{align}
 & \dfrac{1}{2}\sin 2\beta \le \dfrac{1}{2} \le -\dfrac{1}{2}\sin 2\beta \\
\therefore
 & \sin 2\beta \le 1 \le -\sin 2\beta
\end{align}
となるが，これを満たす $\beta$ は存在しない．
\casesend

以上の場合分けおよび$\beta$についての対称性から，$|\beta|$ が最大の時 $(\alpha, \beta) = (\dfrac{\pi}{2}, \pm \dfrac{\pi}{3})$である．
この時$(x,y)$は\cref{eq:1.5}より
\begin{align}
(x, y) = \left(\dfrac{5}{12}\pi, \dfrac{1}{12}\pi\right), \left(\dfrac{1}{12}\pi, \dfrac{5}{12}\pi\right) \label{eq:7}
\end{align}
である．

以上\cref{eq:5,eq:7}から，求める$(x,y)$の組み合わせは
\begin{align}
(x, y) = \left(\dfrac{1}{12}\pi, \dfrac{1}{12}\pi\right), \left(\dfrac{5}{12}\pi, \dfrac{5}{12}\pi\right), \left(\dfrac{1}{12}\pi, \dfrac{5}{12}\pi\right), \left(\dfrac{5}{12}\pi, \dfrac{1}{12}\pi\right)
\end{align}
である．
