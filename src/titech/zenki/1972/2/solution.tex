{\bf [解]}
方程式
\begin{align}
 x^3-x+k = 0 \quad (k>0) \label{eq:1}
\end{align}
の解について考える．
簡単のため$e(\theta) = \cos\theta+i\sin\theta$ とおく．
$x=\pm 1$ が解の時，方程式に代入すると $k=0$ で題意に反する．
そこで $x=e(\theta)$ $(0<\theta<\pi)$ が解だとすると，
\cref{eq:1}から
\begin{align}
 e^3(\theta) - e(\theta) + k = 0
\end{align}
であって，両辺の複素共役をとると
\begin{align}
 e^3(-\theta) - e(-\theta) + k = 0
\end{align}
だから$x=e(-\theta)$ も解である．
そこで\cref{eq:1}の残りの解は同様の議論より実数解でないといけないから，これを$\alpha$とおく．
解と係数の関係から
\begin{align}
  \alpha+e(\theta)+e(-\theta)=0 \\
  \alpha e(\theta)+\alpha e(-\theta)+e(\theta)e(-\theta)=-1 \\
  \alpha e(\theta)e(-\theta) = -k 
\end{align}
である．$\theta$によらず$e(\theta)e(-\theta)=1$だから代入して
\begin{align}
  \alpha+e(\theta)+e(-\theta)=0  \label{eq:2}\\
  \alpha e(\theta)+\alpha e(-\theta)=-2 \label{eq:3}\\
  \alpha = -k  \label{eq:3} 
\end{align}
である．
\cref{eq:2}から $\alpha=-(e(\theta)+e(-\theta))$ だから，\cref{eq:3}に代入して
\begin{align}
 \alpha\left(e(\theta)+e(-\theta)\right) = -2 \\
 \alpha^2 = 2 \\
\therefore \alpha=\pm\sqrt2 
\end{align}
である．

一方で\cref{eq:3}から$\alpha=-k<0$だから複合負が必要で
\begin{align}
 (\alpha,k)=(-\sqrt{2},\sqrt{2})
\end{align}
となる．この時元の三次方程式\cref{eq:1}は
\begin{align}
 x^3-x+\sqrt{2} = 0
\end{align}
となり，これを解いて
\begin{align}
x=-\sqrt2,\ \frac{\sqrt2\pm\sqrt2\,i}{2}
\end{align}
が3つの根である．
