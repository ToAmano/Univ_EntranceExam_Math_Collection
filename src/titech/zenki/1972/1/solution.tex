{\bf [解答]}
$|a\omega+b|\ge 0$だから題意の式を両辺二乗した
\begin{align}
  |a\omega+b|^2 = 1 \label{eq:1}
\end{align}
を満たす整数$(a,b)$を求めれば良い．
左辺を展開すると
\begin{align}
  |a\omega+b|^2 = a^2|\omega|^2+b^2+ab(\omega+\bar\omega) = a^2+b^2-ab
\end{align}
だから\cref{eq:1}に代入して
\begin{align}
  a^2+b^2-ab=1 \label{eq:2}
\end{align}
をみたす $(a,b)\in\mathbb{Z}$ をもとめれば良い．
$a,b$の符号で場合分けして考える．

\subparagraph{$1^{\circ}$ $a,b$が異符号の時，つまり$ab < 0$の時}

$a,b$が異符号の時は$a^2,b^2,-ab > 0$だから，$a,b$が整数であることと合わせて\cref{eq:2}の左辺は
\begin{align}
  a^2 + b^2 - ab \ge 3
\end{align}
となり\cref{eq:2}に反して矛盾する．

\subparagraph{$2^{\circ}$ $a,b$の少なくとも一つが$0$の時，つまり$ab = 0$の時}

この時は$ab=0$だから\cref{eq:2}は
\begin{align}
  a^2 + b^2 = 1
\end{align}
となり，これを満たす整数の組$(a,b)$は
\begin{align}
  (a,b) = (\pm 1,0), (0, \pm 1)
\end{align}
である．

\subparagraph{$3^{\circ}$ $a,b$が同符号の時，つまり$ab > 0$の時}

$a,b$が同符号の時は\cref{eq:2}を変形して
\begin{align}
  (a-b)^2 + ab = 1
\end{align}
である．$(a-b)^2 \ge 0, ab >0$だからこれを満たす整数$a,b$は
\begin{align}
  ((a-b)^2,ab) = (0,1)
\end{align}
であり，これを解いて
\begin{align}
  (a,b) = (1,1), (-1, -1)
\end{align}
となる．
\casesend

以上まとめて
\begin{align}
  (a,b)=(0,\pm1),\ (1,1),\ (1,0),\ (-1,-1),\ (-1,0)
\end{align}
が求める答えである．
