{\bf [解]}
動点$P$は原点を出発し，$z\le0$では最大秒速$a$，$z>0$では最大秒速$1$で動ける（$a>1$）．求める領域は$z$軸のまわりに回転対称だから，$xz$平面（$X\ge0$）内での断面$E$を求め，それを$z$軸のまわりに回転すれば良い．そこで以下$E$について考える．$x=0$に関する対称性から$0 \le x$について考えれば良い．

まず$z \le 0$のとき，原点から$z\le0$の点へは，そこへ向かう直線が常に$z\le0$内にあるから，速さ$a$で直進するのが最適で$1$秒で到達できるのは半径$a$の円内である．よってこの部分は
\begin{align}
 x^2+z^2 \le a^2,\ z \le 0 \label{eq:1}
\end{align}
である．

そこで以下$z\ge 0$の部分について考える．点$Q(X,Z)$（$Z>0$）へ到達する方法としては，時刻$t$（$0\le t\le1$）まで$x$軸の正方向へ速さ$a$で進み点$(at,0)$に達し，そこから残り時間$1-t$で速さ$1$でまっすぐ$Q$へ向かうという進み方が最速である．これで$Q$に到達できる条件はある$t\in[0,1]$に対して
\begin{align}
(X-at)^2+Z^2\le(1-t)^2 \\
(a^2-1)t^2+(2-2aX)t+X^2+Z^2-1\le0 \quad\cdots\text{⑤} \label{eq:2}
\end{align}
が満たされることである．この左辺を$f(t)$とおくと，$a^2-1>0$だから$f$は下に凸な2次関数である．$Q$が到達可能である条件は$f(t)\le0$をみたす$t\in[0,1]$が存在すること，すなわち$[0,1]$上での$f$の最小値が$0$以下であることである．

端点$t=0,1$での値は\cref{eq:2}より
\begin{align}
 f(0)=X^2+Z^2-1,\qquad f(1)=(X-a)^2+Z^2\ge0 \label{eq:3}
\end{align}
であり，また軸の位置は
\begin{align}
 t_0 = \dfrac{aX-1}{a^2-1} \label{eq:4}
\end{align}
であり，これは$0 \le X \le a$より$t_0 \le 1$を満たす．

従って$f(t)\le 0$を満たす$t\in[0,1]$が存在するかどうかについて以下のように軸の位置で場合分けできる．

f(0) \le 0 \iff X^2+Z^2\le1 \quad\cdots\text{⑨} \label{eq:5}
\end{align}
である．

この時の条件は$f(t)=0$の判別式$D$として$D\ge0$であり，
\begin{align}
  D = (X-a)^2-(a^2-1)Z^2\ge0 
\iff \left(X-a+\sqrt{a^2-1}\,Z\right)\left(X-a-\sqrt{a^2-1}\,Z\right)\ge 0
\end{align}
である．$X\le a,\ Z\ge0$から第2因子は$\le0$だからこの条件は
\begin{align}
X-a+\sqrt{a^2-1}\,Z\le0 \quad\cdots\text{⑩} \label{eq:6}
\end{align}
である．
\casesend

以上から求める範囲$E$のうち$x\ge 0$の部分は$z \le 0$の時\cref{eq:1}，$z \ge 0$の時は\cref{eq:5,eq:6}つまり
\begin{align}
 \begin{cases}
  X^2+Z^2\le1 & X\le \dfrac{1}{a} \\
  X-a+\sqrt{a^2-1}\,Z\le0 & \dfrac{1}{a} \le X\le a
 \end{cases}
\end{align}
である．$x$軸に関する対称性より，これを$z$軸に折り返したものが$E$であり，図示すると下図斜線部である．

以下これを$z$軸周りに回転した領域$D$の体積$V$を求めよう．
$V$を$z$の範囲で分割して$-a\le z\le0$（A），$0\le z\le\sqrt{1-1/a^2}$（B），$\sqrt{1-1/a^2}\le z\le1$（C）の三つの領域に分けて計算する．

\subparagraph{A $-a\le z\le0$：} 

この領域は半径$a$の半球であって，その体積$V_A$は
\begin{align}
 V_A=\dfrac{4}{3}\pi a^3\cdot\dfrac{1}{2}=\dfrac{2}{3}\pi a^3 \label{eq:7}
\end{align}
である．

\subparagraph{B $0\le z\le\sqrt{1-1/a^2}$}

この領域は円錐台である．すなわち底円半径$a$，高さ$a/\sqrt{a^2-1}$の円錐から，底円半径$1/a$，高さ$\dfrac{1}{a\sqrt{a^2-1}}$の円錐を引いたもので，体積$V_B$は
\begin{align}
V_B=\dfrac{\pi}{3}\cdot\dfrac{1}{\sqrt{a^2-1}}\left(a^3-\dfrac{1}{a^3}\right) \label{eq:8}
\end{align}

\subparagraph{C $\sqrt{1-1/a^2}\le z\le1$}

この領域は半径$1$の球の一部を切り取ったもので，その体積$V_C$は
\begin{align}
V_C
 &=\int_{\sqrt{1-1/a^2}}^1\pi(1-z^2)\,dz \\
 &=\pi\left[z-\dfrac{z^3}{3}\right]_{\sqrt{1-1/a^2}}^1 \\
 &=\pi\left\{\dfrac{2}{3}-\sqrt{1-\dfrac{1}{a^2}}\left(\dfrac{2}{3}+\dfrac{1}{3a^2}\right)\right\} \label{eq:9}
\end{align}
である．
\casesend

以上\cref{eq:7,eq:8,eq:9}より求める体積$V$は
\begin{align}
 V
 &=V_A+V_B+V_C \\
 &=\dfrac{2}{3}\pi a^3+\dfrac{\pi}{3}\cdot\dfrac{1}{\sqrt{a^2-1}}\left(a^3-\dfrac{1}{a^3}\right)+\dfrac{2}{3}\pi-\dfrac{\sqrt{a^2-1}}{a}\pi\left(\dfrac{2}{3}+\dfrac{1}{3a^2}\right) \\
 &=\dfrac{\pi}{3}\left(2a^3+2+\dfrac{(a^2-1)\sqrt{a^2-1}}{a}\right)
\end{align}
である．

{\bf [解説]}
解答中では逆手流で$t$を消したが，\cref{eq:2}以下順手流でやるとどうなるかを簡単に示す．
\cref{eq:2}より
\begin{align}
 z^2 = -(a^2-1)t^2-2(1-aX)t+1-X^2
\end{align}
だから，右辺を$t$の二次関数と見て$z^2$の値域を求めれば良い．よって

\subparagraph{$t_0\le 0$の時}
この時は
\begin{align}
 z^2 \le f(0) \iff Z^2 \le 1-X^2
\end{align}
である．

\subparagraph{$0 \le t_0 \le 1$の時}

この時は
\begin{align}
 Z^2 \le f\left(t_0\right) \iff Z^2 \le \dfrac{(X-a)^2}{a^2-1}
\end{align}
である．
\casesend

これは解答中で求めた領域と同じだ．
