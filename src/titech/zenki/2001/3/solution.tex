{\bf [解]}
$N\ge3$とする．$k$回の試行で$j$回目までの和を$X_j$とし，$X_1,\dots,X_k$のいずれかが$k$となる確率を$P_N(k)$とする．

\textbf{(1)} $P_N(1)$：1回目で$1$が出れば良く，$P_N(1)=\dfrac{1}{N}$．

$P_N(2)$：$X_1=2$（1回目に2，確率$1/N$）または$X_1=1,X_2=2$（確率$1/N^2$，これらは排反）：
\begin{align}
P_N(2)=\dfrac{1}{N}+\dfrac{1}{N^2}
\end{align}

$P_N(3)$：長さ1のケース（1回目=3）：$1/N$．長さ2のケース（$X_2=3$，かつ$X_1\ne3$）：$(1,2),(2,1)$の2通り，$2/N^2$．長さ3のケース（$X_3=3$，かつ途中で3にならない）：$(1,1,1)$の1通り，$1/N^3$．
\begin{align}
P_N(3)=\dfrac{1}{N}+\dfrac{2}{N^2}+\dfrac{1}{N^3}
\end{align}

\textbf{(2)} $N=3$として，同様に和がちょうど4，5となる最初の到達までの数列を数え上げる．

\subparagraph{$P_3(4)$：} 長さ2（和4，$\{1,3\},\{2,2\}$）：$(1,3),(3,1),(2,2)$の3通り．長さ3（和4，最小値1が3つ以上必要，分割$1+1+2$）：$3$通り．長さ4（分割$1+1+1+1$）：$1$通り．
\begin{align}
P_3(4)=3\left(\dfrac{1}{3}\right)^2+3\left(\dfrac{1}{3}\right)^3+\left(\dfrac{1}{3}\right)^4=\dfrac{27+9+1}{81}=\dfrac{37}{81}
\end{align}

\subparagraph{$P_3(5)$：} 長さ2（分割$2+3$）：2通り．長さ3（分割$1+1+3$：3通り，$1+2+2$：3通り，計6通り）．長さ4（分割$1+1+1+2$）：4通り．長さ5（分割$1+1+1+1+1$）：1通り．
\begin{align}
P_3(5)=2\left(\dfrac{1}{3}\right)^2+6\left(\dfrac{1}{3}\right)^3+4\left(\dfrac{1}{3}\right)^4+\left(\dfrac{1}{3}\right)^5=\dfrac{54+54+12+1}{243}=\dfrac{121}{243}
\end{align}

\textbf{(3)} $k\le N$とする．$S_k=\displaystyle\sum_{\ell=1}^kP_N(\ell)$とおく．1回目に引いた札の値で場合分けすると，$1\le k+1\le N$の時
\begin{align}
P_N(k+1)=\dfrac{1}{N}\sum_{\ell=1}^kP_N(\ell)+\dfrac{1}{N}=\dfrac{1}{N}S_k+\dfrac{1}{N} \quad\cdots\text{①}
\end{align}
（1回目が$k+1$なら直ちに達成，1回目が$m\le k$なら残り$k$回で「$k+1-m$を達成する」確率$P_N(k+1-m)$に帰着，1回目が$m>k+1$なら達成不可能）．$k\ge2$の時，①と，①で$k$を$k-1$に置き換えた式$P_N(k)=\dfrac{1}{N}S_{k-1}+\dfrac{1}{N}$の差をとると，$S_k-S_{k-1}=P_N(k)$だから
\begin{align}
P_N(k+1)-P_N(k)=\dfrac{1}{N}P_N(k) \quad\therefore\ P_N(k+1)=\left(1+\dfrac{1}{N}\right)P_N(k) \quad(k\ge2)
\end{align}
$P_N(2)=\dfrac{1}{N}\left(1+\dfrac{1}{N}\right)$（(1)，または①に$k=1$を代入）を初項として，帰納的に
\begin{align}
P_N(k)=\left(1+\dfrac{1}{N}\right)^{k-2}P_N(2)=\dfrac{1}{N}\left(1+\dfrac{1}{N}\right)^{k-1} \quad(k\ge2)
\end{align}
これは$k=1$でも成立する（$P_N(1)=1/N$）．以上から
\begin{align}
P_N(k)=\dfrac{1}{N}\left(1+\dfrac{1}{N}\right)^{k-1}
\end{align}


\bigskip
\noindent\textbf{[別解]（(3)の別証明）}

{\bf [別解]}
$X_j=\displaystyle\sum_{\ell=1}^jx_\ell=k$となる場合を直接数える（$x_\ell$は$\ell$番目に引いた札の番号）．$k\le N$だから，札の値の上限$N$は制約として効かず，$x_1,\dots,x_j$（各々$1$以上の整数）の和が$k$となる組の数は，$k$個の○と$j-1$本の仕切りを並べる場合の数（両端に仕切りは来ない）に等しく，${}_{k-1}C_{j-1}$通り．したがって，長さ$j$の数列で和が$k$となるものが起こる確率は$\dfrac{1}{N^j}\,{}_{k-1}C_{j-1}$であり，
\begin{align}
P_N(k)=\sum_{j=1}^k\dfrac{1}{N^j}\,{}_{k-1}C_{j-1}=\sum_{j=0}^{k-1}\dfrac{1}{N^{j+1}}\,{}_{k-1}C_j=\dfrac{1}{N}\sum_{j=0}^{k-1}{}_{k-1}C_j\left(\dfrac{1}{N}\right)^j=\dfrac{1}{N}\left(1+\dfrac{1}{N}\right)^{k-1}
\end{align}
（最後は二項定理）．
