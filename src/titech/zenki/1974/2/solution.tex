{\bf [解]}

\paragraph{(1)}

$|\alpha|=k$ とおく．
$k\ne0,1$ と仮定するする．題意から $x=\alpha,\alpha^2,\alpha^4,\cdots,\alpha^{2^n},\cdots$ が $f(x)=0$ の解であり，$k\ne0,1$ から，これらは全て異なる．
これは $f(x)$ が3次であることに反し矛盾する．以上から$k=0,1$ である．


\paragraph{(2)}

$f(x)=0$ の3解を $\alpha,\beta,\gamma$ とおくと，題意よりこれらは全て異なり
\begin{align}
 \alpha\ne\beta,\beta\ne\gamma,\gamma\ne\alpha \label{eq:1}
\end{align}
である．

因数定理より
\begin{align}
 f(x) 
   &= (x-\alpha)(x-\beta)(x-\gamma) \\
   &= x^3 - (\alpha+\beta+\gamma)x^2 + (\alpha\beta+\beta\gamma+\gamma\alpha)x - \alpha\beta\gamma \label{eq:2}
\end{align}
と書けるので，この$x^2$の係数が$1$だから
\begin{align}
 \alpha+\beta+\gamma = 1 \label{eq:3}
\end{align}
である．

さて，(1)より，$\alpha,\beta,\gamma$の絶対値は$0$または$1$である．解が絶対値$0$を含むかどうかで場合分けする．

\subparagraph{解が絶対値$0$を含む場合}

絶対値$0$の解を$\alpha$とすると
\begin{align}
 \alpha = 0 \label{eq:4}
\end{align}
であり，\cref{eq:1}より$\beta,\gamma$の絶対値は$1$である．そこで
\begin{align}
 e\left(\theta\right) = \cos\theta + i\sin\theta \label{eq:5}
\end{align}
とおくと，
\begin{align}
 \beta = e\left(\theta\right) & (0 \le \theta < 2\pi) \label{eq:6}
\end{align}
とおける．まず$\beta=\pm 1$の場合を考える．$\beta=-1$ならば$\beta^2=1$も解なので$3$つの解は
\begin{align}
 \{\alpha,\beta,\gamma\} = \{0,1,-1\}
\end{align}
であり，この時の方程式は
\begin{align}
 f(x) = x^3 - x \label{eq:7}
\end{align}
である．

次に$\beta=1$の時は\cref{eq:2}および$f(x)$の係数が全て実数なことより$\gamma$も実数である必要があるから，$\gamma=-1$となり，これは先の解と合流する．

そこで以下これ以外の場合を考える．
\cref{eq:2}で全ての係数が実数だから，$\gamma=\bar{\beta}$であることが必要で，
\begin{align}
 \gamma = e\left(-\theta\right) \label{eq:8}
\end{align}
となる．
題意より$\beta^2=e(2\theta)$もまた解だからこれが$\beta,\gamma$のいずれかに等しいから
\begin{align}
 e(2\theta) = e(\theta) \quad \text{or} e(2\theta) = e(-\theta)
\end{align}
である．整数$m$を用いて
\begin{align}
 2\theta = \theta + 2m\pi \quad \text{or} 2\theta = -\theta + 2m\pi \\
\therefore 
 \theta = 2m\pi, \dfrac{2m\pi}{3}
\end{align}
だから，$0\le theta < 2\pi, \theta \neq 0,\pi$と合わせてこれを満たすのは
\begin{align}
 \theta = \dfrac{2\pi}{3}, \dfrac{4\pi}{3} \label{eq:9}
\end{align}
の$2$つである．これら二つは同じ解の組に対応するから，この時の解は
\begin{align}
 \{\alpha,\beta,\gamma\} = \left\{0,e\left(\dfrac{2\pi}{3}\right), e\left(\dfrac{4\pi}{3}\right)\right\}
\end{align}
であり，方程式は
\begin{align}
 f(x) &= x^3 + x^2 + x \label{eq:10}
\end{align}
となる．\cref{eq:7,eq:10}をまとめて
\begin{align}
 \begin{cases}
 f(x) &=  x^3 -x \\
 f(x) &= x^3 + x^2 + x  
 \end{cases} \label{eq:11}
\end{align}
である．

\subparagraph{解が絶対値$0$を含まない時}

この時全ての解は$e(\theta)$の形で表せる．
題意より\cref{eq:2}で全ての係数が実数だから，$(\alpha,\beta,\gamma)$は全て実数かまたは一つだけ実数である．
絶対値$1$で実数の数は$\pm 1$であるが，このうち$-1$は二乗した$1$も解にならなければならない．そうすると残りの解も実数になるがこれは\cref{eq:1}に矛盾する．

そこで$1$が解になるので，
\begin{align}
 \alpha = 1
\end{align}
とおく．残りの解は複素数であり，今までと同様の議論によって，
\begin{align}
 \beta = e(\theta) \quad \gamma = e(-\theta) & (0< \theta < 2\pi, \theta \neq \theta)
\end{align}
とおける．よって$\beta^2=e(2\theta)$がこれらのどちらかと等しく，
\begin{align}
 e(2\theta) = e(\theta) \quad \text{or} e(2\theta) = e(-\theta)
\end{align}
である．以下\cref{eq:9}と同様の議論によって
\begin{align}
 \theta = \dfrac{2\pi}{3}, \dfrac{4\pi}{3}
\end{align}
となって，解の組は
\begin{align}
 \{\alpha,\beta,\gamma\} = \left\{1,e\left(\dfrac{2\pi}{3}\right), e\left(\dfrac{4\pi}{3}\right)\right\}
\end{align}
である．この時の方程式は
\begin{align}
 f(x) = x^3-1 \label{eq:12}
\end{align}
である．
\casesend

以上で全ての場合がつくされた．よって\cref{eq:11,eq:12}より，
  \begin{align}
  f(x)=x^3-x,\ x^3+x^2+x,\ x^3-1
  \end{align}
が求める方程式である．
