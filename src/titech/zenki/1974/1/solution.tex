{\bf [解]}

与えられた二次関数を
\begin{align}
 f(x)
   &=\dfrac{3}{4}x^2-3x+4 \\
   &=\dfrac{3}{4}(x-2)^2+1 \label{eq:1}
\end{align}
とおく．
$y=x$ と $y=f(x)$ の交点は $x=\dfrac{4}{3},4$ だからグラフは下図のようになる．

したがって，$4<b$ の時は$f(b)>b$ となり，値域が$b$をはみ出てしまうため不適である．
従って$b \le 4$で考えれば良い．
次に $[a,b]$ に $2$ を含むかで場合分けする．

\subparagraph{$1^\circ\ a\le2\le b$ の時}

この時は$[a,b]$ での$f(x)$の最小値は軸$x=2$の時の$f(2)=1$だから，$a=1$であることが必要である．
$f(1)=\dfrac{7}{4}$ だから $b=\dfrac{7}{4}$とはできない（$2 \le b$より）ため，$b=4$のみが条件を満たして十分である．
以上より
\begin{align}
 (a,b) = \left(1,4\right) \label{eq:2}
\end{align}
である．

\subparagraph{$2^\circ\ a\ge2$ の時}

この時 $[a,b]$ では $f(a)\le f(x)\le f(b)$ だから，$f(a)=a$ かつ $f(b)=b$ となれば良いが，図からこれをみたす $(a,b)$ はない．

\subparagraph{$3^\circ\ b<2$ の時}

$[a,b]$ では $f(b)\le f(x)\le f(a)$ だから $f(b)=a$ かつ $f(a)=b$ となる．
よって\cref{eq:1}より
\begin{align}
f(b)-f(a)=\dfrac{3}{4}(b^2-a^2)-3(b-a)=(a-b)
\end{align}
である．
$a\ne b$ から両辺を$b-a \neq 0$で割ると
\begin{align}
 \dfrac{3}{4}(a+b)-3=-1 \quad\therefore\ a+b=\dfrac{8}{3}
\end{align}
となる．これを$f(a)=b$に代入すると
\begin{align}
 &\dfrac{3}{4}a^2-3a+4 = b = \dfrac{8}{3} - a \\
 &\dfrac{3}{4}a^2-2a+\dfrac{4}{3} = 0 \\
 &a^2-\dfrac{8}{3}a+\dfrac{16}{9} = 0 \\
\therefore
 &a = \dfrac{4}{3}
\end{align}
だから，
\begin{align}
 b = \dfrac{8}{3} - a = \dfrac{4}{3}
\end{align}
となり，$a=b$となるがこれは$a\neq b$に反して不適である．
\casesend

以上から，もとめるのは $(a,b)=(1,4)$ である．
