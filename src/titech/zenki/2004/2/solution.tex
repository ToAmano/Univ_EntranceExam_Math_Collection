{\bf [解]}
\paragraph{(1)}

与えられた方程式の左辺を$F$，右辺を$G$とおく：
\begin{align}
 \begin{cases}
 F=\displaystyle\int_0^{m\pi}f(\sin x)g(\cos x)dx \\
 G=m\displaystyle\int_0^\pi f(\sin x)g(\cos x)dx
 \end{cases} \label{eq:1}
\end{align}
さらに自然数$k$に対して左辺で積分区間を$[(k-1)\pi,k\pi]$に絞ったものを$I_k$とおく：
\begin{align}
 I_k=\displaystyle\int_{(k-1)\pi}^{k\pi}f(\sin x)g(\cos x)dx \label{eq:2}
\end{align}
\cref{eq:2}において$t=x-(k-1)\pi$と置換すると
\begin{align}
I_k=\int_0^\pi f\bigl(\sin(t+(k-1)\pi)\bigr)g\bigl(\cos(t+(k-1)\pi)\bigr)dt
\end{align}
$\sin(t+(k-1)\pi)=(-1)^{k-1}\sin t$，$\cos(t+(k-1)\pi)=(-1)^{k-1}\cos t$であり，$f,g$は偶関数だから
\begin{align}
I_k=\int_0^\pi f(\sin t)g(\cos t)\,dt
\end{align}
となりこれが$k$によらず一定である．
$k=1,\dots,m$について足すと
\begin{align}
F=\sum_{k=1}^mI_k=m\int_0^\pi f(\sin t)g(\cos t)dt=G
\end{align}
となり，$F=G$である．よって題意は示された．

\paragraph{(2)}
新しく
\begin{align}
 D= \int_0^\pi\dfrac{|\sin x|}{(1+\cos^2x)^2}dx
\end{align}
とおくと被積分関数は偶関数である．$[0,\pi]$で$\sin x\ge0$だから分子の絶対値ははずせて
\begin{align}
 D= \int_0^\pi\dfrac{\sin x}{(1+\cos^2x)^2}dx
\end{align}
である．

よって題意の不等式を左辺から順に$A,B,C$とおくと
\begin{align}
 \begin{cases}
 A &= \dfrac{m}{(m+1)\pi} D \\
 B &= \int_0^1\dfrac{|\sin nx|}{(1+\cos^2 nx)^2}dx \\
 C &= \dfrac{m+1}{m\pi} D
 \end{cases} \label{eq:3}
\end{align}
である．

(1)で$f(x)=|x|$，$g(x)=\dfrac{1}{(1+x^2)^2}$（ともに偶関数）とすると，積分区間を$[0,m\pi]$, $[0,(m+1)\pi]$として
\begin{align}
 D 
   &= \dfrac{1}{m}\int_0^{m\pi}f(\sin x)g(\cos x)\,dx \\
   &= \dfrac{1}{m+1}\int_0^{(m+1)\pi}f(\sin x)g(\cos x)\,dx  \label{eq:4}
\end{align}
である．

また，\cref{eq:3}の$B$において$t=nx$と置換積分して
\begin{align}
 B=\dfrac{1}{n}\int_0^nf(\sin t)g(\cos t)dt \label{eq:5} 
\end{align}
である．

さて，ここで新しい関数
\begin{align}
 P(t) = \int_0^tf(\sin x)g(\cos x)dx
\end{align}
を考えると，$f,g\ge0$だから$P(t)$は正かつ$t$について単調増加である．
\cref{eq:3,eq:4,eq:5}より$A,B,C$を$P(t)$で表すと
\begin{align}
 A = \dfrac{P(m\pi)}{(m+1)\pi}, \quad B = \dfrac{P(n)}{n}, \quad C = \dfrac{P((m+1)\pi)}{m\pi} \label{eq:6}
\end{align}
であるが，ここで題意より
\begin{align}
 m\pi \le n < (m+1)\pi
\end{align}
および$P(t)$の単調増加性より
\begin{align}
 P(m\pi) \le P(n) \le P((m+1)\pi)
\end{align}
だから\cref{eq:6}を大小で並べると
\begin{align}
 &\dfrac{P(m\pi)}{(m+1)\pi} \le \dfrac{P(n)}{n} \le \dfrac{P((m+1)\pi)}{m\pi} \\
\therefore
 & A \le B \le C
\end{align}
である．よって題意は示された．

\paragraph{(3)}

まず$D$を具体的に求めよう．$t = \cos x$と置換すると
\begin{align}
 D 
  &= \int_0^\pi\dfrac{\sin x}{(1+\cos^2x)^2}dx \\
  &= \int_1^{-1}\dfrac{1}{(1+t^2)^2}(-1)\,dt \\
  &=\int_{-1}^1\dfrac{1}{(1+t^2)^2}dt \\
  &=2\int_0^1\dfrac{1}{(1+t^2)^2}dt
\end{align}
となる．さらに$t=\tan\theta$とおくと
$dt=d\theta/\cos^2\theta$，$1+t^2=1/\cos^2\theta$，$\theta:0\to\pi/4$だから
\begin{align}
D
 &=2\int_0^{\pi/4}\cos^4\theta\cdot\dfrac{1}{\cos^2\theta}d\theta \\
 &=2\int_0^{\pi/4}\cos^2\theta\,d\theta \\
 &=2\left[\dfrac{\theta}{2}+\dfrac{\sin2\theta}{4}\right]_0^{\pi/4} \\
 &=2\left(\dfrac{\pi}{8}+\dfrac{1}{4}\right) \\
 &=\dfrac{\pi}{4}+\dfrac{1}{2} \label{eq:7}
\end{align}
である．

(2)で得られた不等式において
$n\to\infty$の時，$n < (m+1)\pi$から$m\to\infty$でもあり，
(2)の両辺は$m\to\infty$で$m/(m+1)\to1$よりともに$D/\pi$に収束する．


これと\cref{eq:7}およびはさみうちの定理から求める極限値は
\begin{align}
\lim_{n\to\infty}\int_0^1\dfrac{|\sin nx|}{(1+\cos^2nx)^2}dx
  &=\dfrac{D}{\pi} \\
  &= \dfrac{1}{4}+\dfrac{1}{2\pi}
\end{align}
である．
