{\bf [解]}
数$k$（$k=1,2,\dots,6$）の出る確率を$p_k$とおくと$\displaystyle\sum_{k=1}^6p_k=1$（①）．

\textbf{(1)} $P=\displaystyle\sum_{k=1}^6p_k^2$である．コーシー・シュワルツの不等式より
\begin{align}
\Bigl(\sum_{k=1}^6p_k\Bigr)^2\le6\sum_{k=1}^6p_k^2\quad\therefore\ P\ge\dfrac{1}{6}\Bigl(\sum_{k=1}^6p_k\Bigr)^2=\dfrac{1}{6}\quad(\because①).
\end{align}
等号成立は，コーシー・シュワルツの等号条件（$p_k$が$k$によらず一定）より$p_k=\dfrac{1}{6}$（すべての$k$）のとき．

\textbf{(2)} $Q=(p_1+p_3+p_5)(p_2+p_4+p_6)$である．$p_k\ge0$と①，および相加相乗平均の不等式より
\begin{align}
\sqrt{Q}\le\dfrac{(p_1+p_3+p_5)+(p_2+p_4+p_6)}{2}=\dfrac{1}{2}\quad\therefore\ Q\le\dfrac{1}{4}\quad(\because Q>0).\tag{②}
\end{align}
一方，$t=p_1+p_3+p_5$（$0\le t\le1$）とおくと，①より$1-t=p_2+p_4+p_6$である．コーシー・シュワルツの不等式より
\begin{align}
3(p_1^2+p_3^2+p_5^2)\ge t^2,\qquad3(p_2^2+p_4^2+p_6^2)\ge(1-t)^2
\end{align}
辺々加えて$3P\ge t^2+(1-t)^2$，すなわち$P\ge\dfrac{t^2+(1-t)^2}{3}$だから
\begin{align}
\dfrac{1}{2}-\dfrac{3}{2}P\ \le\ \dfrac{1}{2}-\dfrac{1}{2}\bigl\{t^2+(1-t)^2\bigr\}
=\dfrac{1}{2}\bigl[1-(2t^2-2t+1)\bigr]=t(1-t)=Q.\tag{③}
\end{align}
②，③より
\begin{align}
\dfrac{1}{2}-\dfrac{3}{2}P\ \le\ Q\ \le\ \dfrac{1}{4}.
\end{align}
