{\bf [解]} 

まずは方程式が二つの実数解を持つ条件を考えると判別式$D$として 
\begin{align}
 D > 0 \iff p^2 - 2q > 0 \label{eq:1}
\end{align}
だからこれが必要である．

次に与えられた数列が収束する条件は
\begin{align} 
 -1 < \dfrac{\alpha}{2\beta} \le 1, \quad -1 < \dfrac{4\beta^2}{\alpha} \le 1 \label{eq:2}
\end{align}
である．ただし解と係数の関係から
\begin{align}
 \alpha + \beta = p, \quad \alpha\beta = \dfrac{q}{2} \label{eq:3}
\end{align}
である．

これと題意で与えられた条件
\begin{align}
\begin{cases}
 p > 1 \\
 1-2p+2q \ge 0
\end{cases} \label{eq:4}
\end{align}
を満たすような$p,q$を求める．

まず\cref{eq:1,eq:4}を満たす$(p,q)$を$pq$平面上に図示すると$p, q > 0$ となり
\cref{eq:3}から
\begin{align}
 & \alpha + \beta > 0, \quad \alpha\beta > 0 \\
\therefore
 & \alpha >0, \quad \beta >0
\end{align}
である．

従って\cref{eq:2}で各辺に$\alpha, \beta$をかけて整理すると
\begin{align}
  &-2\beta < \alpha \le 2\beta, \quad -\alpha < 4\beta^2 \le \alpha \\
 \therefore 
  &0 < \alpha \le 2\beta, \quad 0 < 4\beta^2 \le \alpha \\
 \therefore 
  &4\beta^2 \le \alpha \le 2\beta \label{eq:5}
\end{align}
となる．

また\cref{eq:4}に\cref{eq:3}を代入して$(\alpha,\beta)$についての条件として書き下すと
\begin{align} 
 & 1 < \alpha + \beta, \quad 1 - 2(\alpha+\beta) + 4\alpha\beta \ge 0 \\
 \therefore
 & 1 < \alpha + \beta, \quad \left(2\alpha-1\right)\left(2\beta-1\right) \ge 0 \label{eq:6}
\end{align}
である．二つ目の不等式の解は $\alpha, \beta \ge \dfrac{1}{2}$ または$\alpha, \beta \le \dfrac{1}{2}$である．
\cref{eq:5,eq:6}を$\alpha\beta$平面上に図示すると下図のようになり，全ての条件を満たす点はただ一つ
\begin{align}
 (\alpha, \beta) = \left(1, \dfrac{1}{2}\right)
\end{align}
に定まる．この時\cref{eq:3}より
\begin{align}
 (p, q) = \left(\dfrac{3}{2}, 1\right)
\end{align}
であり，これが求める答えである．
