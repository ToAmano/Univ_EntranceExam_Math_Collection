{\bf [解]}
$l$の方向ベクトルは$\vec a=(1,1,1)$である．

\textbf{(1)} 点$\bigl(\dfrac{t}{3},\dfrac{t}{3},\dfrac{t}{3}\bigr)$を通り$l$と垂直な平面$\pi$は，法線ベクトル$(1,1,1)$を持つから
\begin{align}
\pi:\ x+y+z=\dfrac{t}{3}+\dfrac{t}{3}+\dfrac{t}{3}=t.
\end{align}
これと$xy$平面（$z=0$）との交線は
\begin{align}
x+y=t,\qquad z=0.
\end{align}

\textbf{(2)} $l$上に$\overrightarrow{OP}=\dfrac{t}{3}(1,1,1)$なる点$P$（$t\in\mathbb R$）をとる．$P$を通り$l$と垂直な平面による回転体の切り口を考える．この平面と$xy$平面の交線$x+y=t,\ z=0$は，(1)で見た通り$\pi\cap\{z=0\}$そのものである．

直線$x+y=t$と放物線$y=x(1-x)$の交点$Q$は，$x+x(1-x)=t$すなわち$x^2-2x+t=0$を解いて$x=1\pm\sqrt{1-t}$のうち$[0,1]$内の解
\begin{align}
x=1-\sqrt{1-t}\qquad(0\le t\le1)
\end{align}
に対応する点で，$Q=\bigl(1-\sqrt{1-t},\,(1-\sqrt{1-t})\sqrt{1-t},\,0\bigr)$．また直線$x+y=t$と$x$軸（$y=0$）の交点を$R=(t,0,0)$とする．

\begin{align}
\overrightarrow{PR}=\Bigl(\dfrac{2}{3}t,-\dfrac{1}{3}t,-\dfrac{1}{3}t\Bigr),\qquad|\overrightarrow{PR}|^2=\dfrac{4}{9}t^2+\dfrac{1}{9}t^2+\dfrac{1}{9}t^2=\dfrac{2}{3}t^2.
\end{align}
また
\begin{align}
\overrightarrow{PQ}=\Bigl(1-\sqrt{1-t}-\dfrac{t}{3},\ (1-\sqrt{1-t})\sqrt{1-t}-\dfrac{t}{3},\ -\dfrac{t}{3}\Bigr)
\end{align}
より，$|\overrightarrow{PQ}|^2$を計算すると
\begin{align}
|\overrightarrow{PQ}|^2=\dfrac{2}{3}t^2-4t+4-2(2-t)\sqrt{1-t}.
\end{align}
（$t=0,1$で検算すると，$t=0$で$0$，$t=1$で$\dfrac{2}{3}$となり，直接計算とも一致する．）

領域$D$の平面$\pi$による切り口は，線分$QR$（$P$を中心とする半径$|\overrightarrow{PQ}|$から$|\overrightarrow{PR}|$までの範囲；$|\overrightarrow{PQ}|\le|\overrightarrow{PR}|$）に対応し，これを$l$のまわりに回転させると，半径$|\overrightarrow{PQ}|$から$|\overrightarrow{PR}|$までの円環（アニュラス）になる．よってこの平面での立体の断面積$S(t)$は
\begin{align}
\dfrac{S(t)}{\pi}=|\overrightarrow{PR}|^2-|\overrightarrow{PQ}|^2=\dfrac{2}{3}t^2-\Bigl(\dfrac{2}{3}t^2-4t+4-2(2-t)\sqrt{1-t}\Bigr)=4t-4+2(2-t)\sqrt{1-t}.
\end{align}

$t$は平面$\pi$を指定するパラメータであり，$l$の単位方向ベクトルは$\dfrac{1}{\sqrt{3}}(1,1,1)$，$\pi$上の点$\bigl(\dfrac{t}{3},\dfrac{t}{3},\dfrac{t}{3}\bigr)$の$l$に沿った弧長は$\dfrac{t}{\sqrt{3}}=\dfrac{\sqrt{3}}{3}t$だから，もとめる体積$V$は
\begin{align}
V=\int_0^1S(t)\cdot\dfrac{\sqrt{3}}{3}\,dt=\dfrac{\sqrt{3}}{3}\pi\int_0^1\bigl\{4(t-1)+2(2-t)\sqrt{1-t}\bigr\}dt.
\end{align}
$2(2-t)\sqrt{1-t}=2(1-t)\sqrt{1-t}+2\sqrt{1-t}$と分けて，
\begin{align}
\int_0^1(t-1)dt=\Bigl[\dfrac{1}{2}t^2-t\Bigr]_0^1=-\dfrac{1}{2},\quad
\int_0^1\sqrt{1-t}\,dt=\Bigl[-\dfrac{2}{3}(1-t)^{3/2}\Bigr]_0^1=\dfrac{2}{3},\quad
\int_0^1(1-t)\sqrt{1-t}\,dt=\Bigl[-\dfrac{2}{5}(1-t)^{5/2}\Bigr]_0^1=\dfrac{2}{5}
\end{align}
を用いると
\begin{align}
V=\dfrac{\sqrt{3}}{3}\pi\Bigl[4\Bigl(-\dfrac{1}{2}\Bigr)+2\cdot\dfrac{2}{5}+2\cdot\dfrac{2}{3}\Bigr]=\dfrac{\sqrt{3}}{3}\pi\Bigl[-2+\dfrac{4}{5}+\dfrac{4}{3}\Bigr]=\dfrac{\sqrt{3}}{3}\pi\cdot\dfrac{2}{15}=\dfrac{2\sqrt{3}}{45}\pi.
\end{align}
