{\bf [解]}
$l$の方向ベクトルは$\vec a=(1,1,1)$である．

\paragraph{(1)}

点$\bigl(\dfrac{t}{3},\dfrac{t}{3},\dfrac{t}{3}\bigr)$を通り$l$と垂直な平面$\pi$は，法線ベクトル$(1,1,1)$を持つから
\begin{align}
\pi:\ x+y+z=\dfrac{t}{3}+\dfrac{t}{3}+\dfrac{t}{3}=t
\end{align}
である．これと$xy$平面（$z=0$）との交線は$z=0$を代入して
\begin{align}
x+y=t,\qquad z=0
\end{align}
である．

$l$上に$\overrightarrow{OP}=\dfrac{t}{3}(1,1,1)$なる点$P$（$t\in\mathbb R$）をとる．$P$を通り$l$と垂直な平面による回転体の切り口を考える．この平面と$xy$平面の交線は(1)から$x+y=t,\ z=0$であり，与えられた領域$D$との様子は以下のようになる．

ここで直線$x+y=t$と放物線$y=x(1-x)$が交わるためには，連立した$x$の二次方程式：
\begin{align}
 x + x(1-x) = t \\
 x^2 -2x +t = 0 \label{eq:1}
\end{align}
が実数解を持てばよく，判別式が$0$以上であれば良いから
\begin{align}
 1-t \ge 0 \quad \therefore t \le 1 \label{eq:2}
\end{align}
である．このもとで領域$D$内にある交点$Q$の$x$座標は\cref{eq:1}の解で
\begin{align}
 x = 1 \pm\sqrt{1-t}
\end{align}
だが，領域$D$は$0 \le x \le 1$なので，複合負をとって
\begin{align}
 x = 1 - \sqrt{1-t} 
\end{align}
である．これが$0 \le x \le 1$を満たすので
\begin{align}
 0 \le t \le 1 \label{eq:3}
\end{align}
である．
以上から$Q$の座標は
\begin{align}
 Q(1-\sqrt{1-t}, t-1 + \sqrt{1-t})\label{eq:4}
\end{align}
である．

次に直線$x+y=t$と直線$y=0$の交点$R$の$x$座標は連立して
\begin{align}
 x = t
\end{align}
だから$R$の座標は
\begin{align}
 R(t,0) \label{eq:5}
\end{align}
である．これが$0\le x \le 1$を満たす$t$の条件は\cref{eq:3}と全く同じである．

$t=1$で放物線と切断面が$(1,0)$で接するから，領域$D$と切断面の共有点の端点は常に$Q,R$である．
従って領域$D$を$l$周りに回転させた立体$E$の平面$\pi$による切り口は，半径半径$|\overrightarrow{PQ}|$から$|\overrightarrow{PR}|$までの円環になる．よって$|\overrightarrow{PQ}|$と$|\overrightarrow{PR}|$を\cref{eq:4,eq:5}から計算すると
\begin{align}
\overrightarrow{PQ}
 &=\Bigl(1-\sqrt{1-t}-\dfrac{t}{3},\ t-1 + \sqrt{1-t}-\dfrac{t}{3},\ -\dfrac{t}{3}\Bigr) \\
\therefore
|\overrightarrow{PQ}|^2
 &=\left[1-\dfrac{t}{3}-\sqrt{1-t}\right]^2 + \left[-1+\dfrac{2t}{3} + \sqrt{1-t}\right]^2 + \dfrac{t^2}{9} \\
 &=\left(1-\dfrac{t}{3}\right)^2 + (1-t) -2\left(1-\dfrac{t}{3}\right)\sqrt{1-t} 
   + \left(-1+\dfrac{2t}{3}\right)^2 + (1-t) + 2\left(-1+\dfrac{2t}{3}\right)\sqrt{1-t} 
   + \dfrac{t^2}{9} \\
 &=\dfrac{2t^2}{3} - 4t + 4 + 2\left(-2 + t\right)\sqrt{1-t} \label{eq:6}
\end{align}
\begin{align}
\overrightarrow{PR}
 &=\Bigl(\dfrac{2}{3}t,-\dfrac{1}{3}t,-\dfrac{1}{3}t\Bigr) \\
\therefore
|\overrightarrow{PR}|^2
 &=\dfrac{4}{9}t^2+\dfrac{1}{9}t^2+\dfrac{1}{9}t^2 \\
 &=\dfrac{2}{3}t^2 \label{eq:7}
\end{align}
である．

よってこの平面での立体の断面積$S(t)$は\cref{eq:6,eq:7}より
\begin{align}
\dfrac{S(t)}{\pi}
 &=|\overrightarrow{PR}|^2-|\overrightarrow{PQ}|^2 \\
 &=\dfrac{2}{3}t^2-\Bigl(\dfrac{2}{3}t^2-4t+4-2(2-t)\sqrt{1-t}\Bigr) \\
 &=4t-4+2(2-t)\sqrt{1-t} \label{eq:8}
\end{align}
である．

$t$は平面$\pi$を指定するパラメータであり，$l$の単位方向ベクトルは$\dfrac{1}{\sqrt{3}}(1,1,1)$なので，線素は
\begin{align}
 d \ell = \sqrt{3} dt \label{eq:9}
\end{align}
であり，$t$の範囲\cref{eq:3}に注意して求める体積$V$は
\begin{align}
 V
 &=\int_0^1S(t)\cdot d\ell  \\
 &=\int_0^1S(t)\dfrac{\sqrt{3}}{3}\,dt \quad (\because\text{\cref{eq:9}})\\
 &=\dfrac{\sqrt{3}}{3}\pi\int_0^1\bigl\{4(t-1)+2(2-t)\sqrt{1-t}\bigr\}dt \quad (\because\text{\cref{eq:8}})\\
 &=\dfrac{\sqrt{3}}{3}\pi\int_0^1\bigl\{4(t-1)+2\sqrt{1-t} + 2(1-t)\sqrt{1-t}\bigr\}dt \label{eq:10}
\end{align}
である．各項計算すると
\begin{align}
\int_0^1(t-1)dt=\Bigl[\dfrac{1}{2}t^2-t\Bigr]_0^1=-\dfrac{1}{2} \\
\int_0^1\sqrt{1-t}\,dt=\Bigl[-\dfrac{2}{3}(1-t)^{3/2}\Bigr]_0^1=\dfrac{2}{3} \\
\int_0^1(1-t)\sqrt{1-t}\,dt=\Bigl[-\dfrac{2}{5}(1-t)^{5/2}\Bigr]_0^1=\dfrac{2}{5}
\end{align}
だから\cref{eq:10}に代入して
\begin{align}
 V
  &=\dfrac{\sqrt{3}}{3}\pi\Bigl[4\Bigl(-\dfrac{1}{2}\Bigr)+2\cdot\dfrac{2}{5}+2\cdot\dfrac{2}{3}\Bigr] \\
  &=\dfrac{\sqrt{3}}{3}\pi\Bigl[-2+\dfrac{4}{5}+\dfrac{4}{3}\Bigr] \\
  &=\dfrac{\sqrt{3}}{3}\pi\cdot\dfrac{2}{15} \\
  &=\dfrac{2\sqrt{3}}{45}\pi
\end{align}
が求める体積である．
