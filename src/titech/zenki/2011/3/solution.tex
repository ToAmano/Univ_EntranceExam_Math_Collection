{\bf [解]}
$k>1$とする．$\angle AOX=\alpha$，$\angle AOY=\beta$，$\angle XOY=\theta$とおくと，$\theta=\beta-\alpha$（②）．$t=\tan\alpha$とおくと，$X=(1,t)$，$AX=t$，$AY=kt$（$k>1,\ t>0$より$AY=kAX$）だから$\tan\beta=kt$．②より
\begin{align}
\tan\theta=\tan(\beta-\alpha)=\dfrac{kt-t}{1+t\cdot kt}=\dfrac{(k-1)t}{1+kt^2}.
\end{align}
$0\le\theta<\pi/2$より$\sin\theta=\dfrac{\tan\theta}{\sqrt{1+\tan^2\theta}}$（③）であり，これは$\tan\theta\ge0$の増加関数だから，$\tan\theta$が最大のとき$\sin\theta$も最大．

$\tan\theta=\dfrac{k-1}{kt+\dfrac{1}{t}}$であり，$t>0$より相加相乗平均から$kt+\dfrac{1}{t}\ge2\sqrt{k}$（等号は$t=\dfrac{1}{\sqrt{k}}$）だから
\begin{align}
\tan\theta\le\dfrac{k-1}{2\sqrt{k}}
\end{align}
が$\tan\theta$の最大値．このとき③より
\begin{align}
\sin\theta=\dfrac{\dfrac{k-1}{2\sqrt{k}}}{\sqrt{1+\dfrac{(k-1)^2}{4k}}}=\dfrac{k-1}{2\sqrt{k}}\cdot\dfrac{2\sqrt{k}}{\sqrt{(k+1)^2}}=\dfrac{k-1}{k+1}
\end{align}
（$1+\dfrac{(k-1)^2}{4k}=\dfrac{4k+(k-1)^2}{4k}=\dfrac{(k+1)^2}{4k}$を用いた）．

$OP=OQ=1$（単位円上）だから，$\triangle OPQ$の面積は$\dfrac{1}{2}\sin\theta$であり，その最大値は
\begin{align}
\dfrac{1}{2}\cdot\dfrac{k-1}{k+1}=\dfrac{k-1}{2(k+1)}.
\end{align}
