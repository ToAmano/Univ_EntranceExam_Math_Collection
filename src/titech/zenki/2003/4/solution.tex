{\bf [解]}
与えられた漸化式
\begin{align}
 \begin{cases}
  f_1(x)=x^2 \\
  f_{n+1}(x)=f_n(x)+x^3f_n^{(2)}(x)
 \end{cases} \label{eq:1}
\end{align}
について考える．

\paragraph{(1)}

$f_n(x)$が$(n+1)$次多項式であり，その$x^{n+1}$の係数は$a_n=\dfrac{(n!)^2}{n}$とかけることを帰納的に示す．

$n=1$の時は$a_1=1$で成立するので，以下$n=k$での成立を仮定する．
\cref{eq:1}から$f_{k+1}(x)$の最高次は第二項からの寄与$(k+1)ka_kx^{k+1}$だからまず次数については成立する．係数については
\begin{align}
 a_{k+1} = (k+1)ka_k
\end{align}
だが，仮定から$a_k=\dfrac{(k!)^2}{k}$だから
\begin{align}
 a_{k+1} = \dfrac{(k!)^2(k+1)k}{k} = \dfrac{((k+1)!)^2}{k+1}
\end{align}
となり成立する．

以上から数学的帰納法により題意は示された．求めるべき係数は
\begin{align}
 a_n = \dfrac{(n!)^2}{n}
\end{align}
である．

\paragraph{(2)}

$f_n^{(k)}(0)$は$f_n^{(k)}(x)$の定数項だから
\begin{align}
 f_n^{(k)}(0)=k!\times(x^k\text{の係数}) \label{eq:2}
\end{align}
である．そこで，$f_n(x)$の$k$次の係数を$p^{k}_{n}$とおく．
\cref{eq:1}より$f_1(x)=x^2$だから
\begin{align}
 p^{1}_{1}=p^{3}_{1}=p^{4}_{1}=0,\qquad p^{2}_{1}=1 \label{eq:3}
\end{align}
である．

\cref{eq:1}で$1$から$4$次までの部分を考えると
\begin{align}
 \sum_{k=1}^{4}p^{k}_{n+1}x^{k} = \sum_{k=1}^{4}p^{k}_{n}x^{k} + \left(6p^{3}_{n}x^4+2p^{2}_{n}x^3\right)
\end{align}
だから係数を比較して
\begin{align}
 \begin{cases}
  p^{4}_{n+1} = p^{4}_{n} + 6p^{3}_{n} \\
  p^{3}_{n+1} = p^{3}_{n} + 2p^{2}_{n} \\
  p^{2}_{n+1} = p^{2}_{n} \\
  p^{1}_{n+1} = p^{1}_{n}   
 \end{cases} \label{eq:4}
\end{align} 
なる漸化式を得る．\cref{eq:3}と合わせて，まず
\begin{align}
 p^{1}_{n} = 0, p^{2}_{n} = 1 \label{eq:5}
\end{align}
である．これを\cref{eq:4}に代入して$p^{3}_{n}$について
\begin{align}
 p^{3}_{n+1} = p^{3}_{n} + 2
\end{align}
だから\cref{eq:3}より$p^{3}_{1}=0$と合わせて
\begin{align}
 p^{3}_{n} = 2(n-1) \label{eq:6}
\end{align}
である．これを\cref{eq:4}に代入して$p^{4}_{n}$について
\begin{align}
 p^{4}_{n+1} = p^{4}_{n} + 12(n-1)
\end{align}
だから\cref{eq:3}より$p^{4}_{1}=0$と合わせて
\begin{align}
 p^{4}_{n} = \sum_{k=1}^{n-1} 12(n-1) = 6(n-1)(n-2) \label{eq:7}
\end{align}
である．\cref{eq:5,eq:6,eq:7}をまとめて
\begin{align}
 \begin{cases}
  p^{1}_{n} = 0 \\
  p^{2}_{n} = 1 \\
  p^{3}_{n} = 2(n-1) \\
  p^{4}_{n} = 6(n-1)(n-2)
 \end{cases}
\end{align}
である．

従って\cref{eq:2}より求める値は
\begin{align}
\begin{cases}
 f_n^{(1)}(0)=p^{1}_{n}=0 \\
 f_n^{(2)}(0)=2p^{2}_{n}=2 \\
 f_n^{(3)}(0)=6p^{3}_{n}=12(n-1) \\
 f_n^{(4)}(0)=24p^{4}_{n}=144(n-1)(n-2)
\end{cases}
\end{align}
である．
