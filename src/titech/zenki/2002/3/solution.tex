{\bf [解]}
$A=(0,0,1)$，$L=(0,0,1+\sqrt{2})$とする．$z$軸に関する対称性から，$B,C$は$xz$平面に関して対称（$y$座標の符号のみ逆）としてよい．$\triangle ABC$は1辺1の正三角形だから，$BC$の中点を$M$とすると$AM=\sqrt{3}/2$，$BM=CM=1/2$，$AM\perp BC$．$\overrightarrow{AM}$の方向を角$\theta$（$0<\theta<\pi$）で
\begin{align}
\overrightarrow{AM}=\dfrac{\sqrt{3}}{2}(\sin\theta,\,0,\,\cos\theta)
\end{align}
とおくと（$BC$は$AM$に垂直な$y$方向），
\begin{align}
B=\left(\dfrac{\sqrt{3}}{2}\sin\theta,\ \dfrac{1}{2},\ 1+\dfrac{\sqrt{3}}{2}\cos\theta\right),\qquad
C=\left(\dfrac{\sqrt{3}}{2}\sin\theta,\ -\dfrac{1}{2},\ 1+\dfrac{\sqrt{3}}{2}\cos\theta\right)
\end{align}
（実際$AB^2=\dfrac{3}{4}\sin^2\theta+\dfrac{1}{4}+\dfrac{3}{4}\cos^2\theta=1$，$BC=1$となり正しく正三角形になる．）

光源$L$から点$P=(p_x,p_y,p_z)$を通る直線が$xy$平面（$z=0$）と交わる点$P'$は，$P'=t\,(p_x,p_y,0)$，$t=\dfrac{1+\sqrt{2}}{1+\sqrt{2}-p_z}$で与えられる．

$A$は$x,y$座標が$0$だから，$A$の影$A'$は原点$O$である．$B,C$は$x,z$座標が等しく$y$座標のみ符号が逆だから，$t_B=t_C=\dfrac{1+\sqrt{2}}{1+\sqrt{2}-\left(1+\dfrac{\sqrt{3}}{2}\cos\theta\right)}=\dfrac{1+\sqrt{2}}{\sqrt{2}-\dfrac{\sqrt{3}}{2}\cos\theta}$，
\begin{align}
B'=\left(t_B\cdot\dfrac{\sqrt{3}}{2}\sin\theta,\ \dfrac{t_B}{2}\right),\qquad C'=\left(t_B\cdot\dfrac{\sqrt{3}}{2}\sin\theta,\ -\dfrac{t_B}{2}\right)
\end{align}
影の三角形$A'B'C'$（$A'=O$）は，底辺$B'C'$（長さ$t_B$，$x=t_B\dfrac{\sqrt{3}}{2}\sin\theta$の位置）を底辺とする二等辺三角形で，面積は
\begin{align}
T=\dfrac{1}{2}\cdot t_B\cdot t_B\dfrac{\sqrt{3}}{2}\sin\theta=\dfrac{\sqrt{3}}{4}t_B^2\sin\theta
\end{align}
$c=\cos\theta,\ s=\sin\theta$とし，$D=\sqrt{2}-\dfrac{\sqrt{3}}{2}c$（$D>0$は常に成立）とおくと$t_B=\dfrac{1+\sqrt{2}}{D}$だから
\begin{align}
T=\dfrac{\sqrt{3}}{4}(1+\sqrt{2})^2\cdot\dfrac{s}{D^2}
\end{align}
$\theta\in(0,\pi)$で$T$を最大化する．$D'=dD/d\theta=\dfrac{\sqrt{3}}{2}s$に注意して，$T\propto s/D^2$を$\theta$で微分すると，その符号は
\begin{align}
cD^2-s\cdot2DD'=D(cD-\sqrt{3}s^2)
\end{align}
の符号（$D>0$だから）と一致し，$D>0$より$cD-\sqrt{3}s^2$の符号を調べれば良い．
\begin{align}
cD-\sqrt{3}s^2=c\left(\sqrt{2}-\dfrac{\sqrt{3}}{2}c\right)-\sqrt{3}(1-c^2)=\sqrt{2}c+\dfrac{\sqrt{3}}{2}c^2-\sqrt{3}
\end{align}
これが$0$になるのは，$\sqrt{3}c^2+2\sqrt{2}c-2\sqrt{3}=0$，すなわち
\begin{align}
c=\dfrac{-2\sqrt{2}\pm\sqrt{8+24}}{2\sqrt{3}}=\dfrac{-2\sqrt{2}\pm4\sqrt{2}}{2\sqrt{3}}
\end{align}
$|c|\le1$をみたすのは$c=\dfrac{2\sqrt{2}}{2\sqrt{3}}=\dfrac{\sqrt{2}}{\sqrt{3}}=\dfrac{\sqrt{6}}{3}$．$c<$この値で$cD-\sqrt{3}s^2<0$（減少），$c>$この値で$>0$（増加）と確かめられるので（$\theta$の向きに注意して），$T$はこの$c=\sqrt{6}/3$で最大となる．

この時$s=\sqrt{1-c^2}=\sqrt{1-2/3}=\sqrt{1/3}=1/\sqrt{3}$，$D=\sqrt{2}-\dfrac{\sqrt{3}}{2}\cdot\dfrac{\sqrt{6}}{3}=\sqrt{2}-\dfrac{\sqrt{18}}{6}=\sqrt{2}-\dfrac{3\sqrt{2}}{6}=\sqrt{2}-\dfrac{\sqrt{2}}{2}=\dfrac{\sqrt{2}}{2}$だから
\begin{align}
\max T=\dfrac{\sqrt{3}}{4}(1+\sqrt{2})^2\cdot\dfrac{1/\sqrt{3}}{(√2/2)^2}=\dfrac{\sqrt{3}}{4}(1+\sqrt{2})^2\cdot\dfrac{1}{\sqrt{3}}\cdot2=\dfrac{1}{2}(\sqrt{2}+1)^2
\end{align}
