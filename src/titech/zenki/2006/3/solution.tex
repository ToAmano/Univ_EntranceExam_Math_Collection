{\bf [解]}
点$P$を原点とする．3個の円板を$A,B,C$とし，回転して$A$の中心$O_A=(1,0)$に固定してよい．$B,C$の中心$O_B,O_C$は単位円上にあるので，偏角を$\theta,\alpha$として
\begin{align}
O_B=(\cos\theta,\sin\theta)\ (0\le\theta\le\pi),\qquad O_C=(\cos\alpha,\sin\alpha)\ (0\le\alpha\le2\pi)
\end{align}
とおく．条件(b)（3円板すべてが共有する点は$P$のみ）をみたす$O_C$の条件は
\begin{align}
\pi\le\alpha\le\theta+\pi\tag{①}
\end{align}
である．

中心間の偏角の差が$\theta$（$0\le\theta\le\pi$）である2つの単位円板の共通部分の面積を$S(\theta)$とする．

\end{tikzpicture}
\caption{中心角$\theta$の2円板の共通部分（斜線部）の面積が$S(\theta)$}
\end{figure}

2円の中心間距離は$2\sin\dfrac{\theta}{2}$なので，$x=\sin t$と置換して
\begin{align}
S(\theta)=4\int_{\sin\dfrac{\theta}{2}}^1\sqrt{1-x^2}\,dx=4\int_{\dfrac{\theta}{2}}^{\dfrac{\pi}{2}}\cos^2t\,dt=4\Bigl[\dfrac{t}{2}+\dfrac{\sin2t}{4}\Bigr]_{\dfrac{\theta}{2}}^{\dfrac{\pi}{2}}=\pi-\theta-\sin\theta.
\end{align}

$O_A,O_B,O_C$の偏角はそれぞれ$0,\theta,\alpha$（$0\le\theta\le\pi\le\alpha\le\theta+\pi$）なので，これらを結ぶ3つの弧の中心角は
\begin{align}
\overset{\frown}{O_AO_B}=\theta,\qquad\overset{\frown}{O_BO_C}=\alpha-\theta,\qquad\overset{\frown}{O_CO_A}=2\pi-\alpha
\end{align}
（和は$2\pi$）．3円板の和集合の面積$S$は，3円の面積の和から2円ずつの重なりを引けば得られる（3円共通部分は$P$のみで面積0だから，包除原理はここで止まる）：
\begin{align}
S=3\pi-\bigl\{S(\theta)+S(\alpha-\theta)+S(2\pi-\alpha)\bigr\}.
\end{align}
$S(\theta)+S(\alpha-\theta)+S(2\pi-\alpha)=3\pi-2\pi-\{\sin\theta+\sin(\alpha-\theta)+\sin(2\pi-\alpha)\}$であり，$\sin(2\pi-\alpha)=-\sin\alpha$だから
\begin{align}
S=2\pi+\sin\theta+\sin(\alpha-\theta)-\sin\alpha.
\end{align}
和積公式$\sin(\alpha-\theta)-\sin\alpha=-2\sin\dfrac{\theta}{2}\cos\Bigl(\alpha-\dfrac{\theta}{2}\Bigr)$を用いると
\begin{align}
S-2\pi=-2\sin\dfrac{\theta}{2}\cos\Bigl(\alpha-\dfrac{\theta}{2}\Bigr)+\sin\theta\equiv f(\alpha)\tag{②}
\end{align}

$\theta$を固定して$\alpha$を動かす．①より$\alpha-\dfrac{\theta}{2}\in\bigl[\pi-\dfrac{\theta}{2},\ \pi+\dfrac{\theta}{2}\bigr]$であり，$0\le\theta\le\pi$より$\sin\dfrac{\theta}{2}\ge0$だから，$f(\alpha)$は$\cos\bigl(\alpha-\dfrac{\theta}{2}\bigr)$が最小となるとき，すなわち$\alpha-\dfrac{\theta}{2}=\pi$（この値は許容範囲内）のとき最大となり，
\begin{align}
\max_\alpha f(\alpha)=2\sin\dfrac{\theta}{2}+\sin\theta\equiv g(\theta)\qquad(0\le\theta\le\pi).
\end{align}
次に$\theta$を動かす．$t=\cos\dfrac{\theta}{2}$とおくと
\begin{align}
g'(\theta)=\cos\dfrac{\theta}{2}+2\cos^2\dfrac{\theta}{2}-1=(2t-1)(t+1)
\end{align}
$0\le\theta\le\pi$では$t\in[0,1]$なので$t+1>0$，符号は$2t-1$で決まり，$t=\dfrac{1}{2}$すなわち$\theta=\dfrac{2\pi}{3}$を境に$g'$は$+$から$-$に変わる．よって$g$は$\theta=\dfrac{2\pi}{3}$で最大値
\begin{align}
g\Bigl(\dfrac{2\pi}{3}\Bigr)=2\sin\dfrac{\pi}{3}+\sin\dfrac{2\pi}{3}=\sqrt{3}+\dfrac{\sqrt{3}}{2}=\dfrac{3\sqrt{3}}{2}
\end{align}
をとる．したがって
\begin{align}
\max S=2\pi+\dfrac{3\sqrt{3}}{2}
\end{align}
である．このとき$\theta=\dfrac{2\pi}{3}$，$\alpha=\pi+\dfrac{\theta}{2}=\dfrac{4\pi}{3}$となるから，3つの弧の中心角は
\begin{align}
\overset{\frown}{O_AO_B}=\overset{\frown}{O_BO_C}=\overset{\frown}{O_CO_A}=\dfrac{2\pi}{3}
\end{align}
となり，3つの中心が$P$のまわりに正三角形状に等間隔配置されるときに最大値が実現される．
