{\bf [解]}
\paragraph{(1)}

題意から，複素数平面上で$45^\circ$回転を考えると
\begin{align}
x+yi&=\Bigl(\cos\dfrac{\pi}{4}+i\sin\dfrac{\pi}{4}\Bigr)(t+si)=\dfrac{\sqrt{2}}{2}(1+i)(t+si)=\dfrac{\sqrt{2}}{2}\bigl\{(t-s)+i(t+s)\bigr\}
\end{align}
であり，$x,y,s,t$は実数だから
\begin{align}
x=\dfrac{\sqrt{2}}{2}(t-s)=\dfrac{\sqrt{2}}{2}(-\sqrt{2}t^2+3t)\equiv f(t),\qquad
y=\dfrac{\sqrt{2}}{2}(s+t)=\dfrac{\sqrt{2}}{2}(\sqrt{2}t^2-t)\equiv g(t).
\end{align}

\paragraph{(2)}

$g(t)=\dfrac{\sqrt{2}}{2}\Bigl[\sqrt{2}\Bigl(t-\dfrac{1}{2\sqrt{2}}\Bigr)^2-\dfrac{\sqrt{2}}{8}\Bigr]$だから，$g$は$t=\dfrac{1}{2\sqrt{2}}=\dfrac{\sqrt{2}}{4}$で最小値
\begin{align}
\dfrac{\sqrt{2}}{2}\cdot\Bigl(-\dfrac{\sqrt{2}}{8}\Bigr)=-\dfrac{1}{8}
\end{align}
をとる．$g(t)$は$t$の2次関数（上に凸ではなく下に凸）で，直線$y=a$が曲線$C$とただ1点で交わるのは，この最小値の位置，すなわち
\begin{align}
a=-\dfrac{1}{8}
\end{align}
のときである．

\paragraph{(3)}

$g(t)=0\iff t=0,\ \dfrac{\sqrt{2}}{2}$（$\sqrt{2}t^2-t=t(\sqrt{2}t-1)=0$より）．よって$0\le t\le\dfrac{\sqrt{2}}{2}$の部分がグラフと$x$軸で囲む領域$D$の境界を与え，$t\in\bigl(0,\dfrac{\sqrt{2}}{4}\bigr)$で$x_-(y)$（左側の枝），$t\in\bigl(\dfrac{\sqrt{2}}{4},\dfrac{\sqrt{2}}{2}\bigr)$で$x_+(y)$（右側の枝）を与える．$D$を$y$軸のまわりに回転した体積$V$は
\begin{align}
\dfrac{V}{\pi}=\int_a^0\bigl(x_+^2-x_-^2\bigr)dy=\int_0^{\sqrt{2}/2}x(t)^2\dfrac{dy}{dt}dt\tag{①}
\end{align}
（両方の枝の寄与が$t=0$から$\dfrac{\sqrt{2}}{2}$までの一つの積分にまとまる）．$g'(t)=\dfrac{\sqrt{2}}{2}(2\sqrt{2}t-1)$であり，$x(t)=\dfrac{\sqrt{2}}{2}t(3-\sqrt{2}t)$だから
\begin{align}
x(t)^2g'(t)&=\dfrac{1}{2}t^2(3-\sqrt{2}t)^2\cdot\dfrac{\sqrt{2}}{2}(2\sqrt{2}t-1)=\dfrac{\sqrt{2}}{4}t^2(3-\sqrt{2}t)^2(2\sqrt{2}t-1)\\
&=\dfrac{\sqrt{2}}{4}t^2(4\sqrt{2}t^3-26t^2+24\sqrt{2}t-9)
\end{align}
（$(3-\sqrt{2}t)^2(2\sqrt{2}t-1)=4\sqrt{2}t^3-26t^2+24\sqrt{2}t-9$を展開して得た）．①に代入して
\begin{align}
\dfrac{V}{\pi}&=\dfrac{\sqrt{2}}{4}\Bigl[\dfrac{4\sqrt{2}}{6}t^6-\dfrac{26}{5}t^5+\dfrac{24\sqrt{2}}{4}t^4-\dfrac{9}{3}t^3\Bigr]_0^{\sqrt{2}/2}\\
&=\dfrac{\sqrt{2}}{4}\Bigl[\dfrac{2\sqrt{2}}{3}t^6-\dfrac{26}{5}t^5+6\sqrt{2}t^4-3t^3\Bigr]_0^{\sqrt{2}/2}
\end{align}
$t=\dfrac{\sqrt{2}}{2}$のとき$t^2=\dfrac{1}{2},t^3=\dfrac{\sqrt{2}}{4},t^4=\dfrac{1}{4},t^5=\dfrac{\sqrt{2}}{8},t^6=\dfrac{1}{8}$を代入すると
\begin{align}
\dfrac{2\sqrt{2}}{3}\cdot\dfrac{1}{8}-\dfrac{26}{5}\cdot\dfrac{\sqrt{2}}{8}+6\sqrt{2}\cdot\dfrac{1}{4}-3\cdot\dfrac{\sqrt{2}}{4}=\dfrac{\sqrt{2}}{12}-\dfrac{13\sqrt{2}}{20}+\dfrac{3\sqrt{2}}{2}-\dfrac{3\sqrt{2}}{4}=\dfrac{11\sqrt{2}}{60}
\end{align}
（通分すると$\dfrac{5-39+90-45}{60}\sqrt{2}=\dfrac{11}{60}\sqrt{2}$）．よって
\begin{align}
\dfrac{V}{\pi}=\dfrac{\sqrt{2}}{4}\cdot\dfrac{11\sqrt{2}}{60}=\dfrac{11\cdot2}{240}=\dfrac{11}{120}
\end{align}
より
\begin{align}
V=\dfrac{11}{120}\pi.
\end{align}
