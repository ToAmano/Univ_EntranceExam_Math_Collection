{\bf [解]}
$x^2+bx+b^2 = \left(x + \dfrac{1}{2}b\right)^2 + \dfrac{3}{4}b^2 > 0$ だから，与式の両辺に $x^2+bx+b^2$ をかけて整理すると
\begin{align}
 \begin{cases}
   2x^2 + (3b+a)x + (3b^2-a^2) \ge 0 \\  
   2x^2 - (3a+b)x + (3a^2-b^2) \ge 0
 \end{cases}
\end{align}
である．$\text{左辺}=0$の二次方程式の判別式が負であれば良いから
\begin{align}
\begin{cases}
(3b+a)^2 - 4 \cdot 2 (3b^2-a^2) \le 0 \\
(3a+b)^2 - 4 \cdot 2 (3a^2-b^2) \le 0
\end{cases} \\
\therefore 
\begin{cases}
9a^2 + 6ab - 15b^2 \le 0 \\
-15a^2 + 6ab + 9b^2 \le 0
\end{cases} \quad \cdots \text{①} \label{eq:1}
\end{align}

簡単のため$t = \dfrac{a}{b}$ とおく．$b \neq 0$ から\cref{eq:1}の両辺 $b^2$ でわって整理すると
\begin{align}
\begin{cases}
9t^2 + 6t - 15 \le 0 \\
-15t^2 + 6t + 9 \le 0
\end{cases} \\
\iff 
\begin{cases}
-\dfrac{5}{3} \le t \le 1 \\
t \le -\dfrac{3}{5}, \ 1 \le t
\end{cases} \\
\iff -\dfrac{5}{3} \le t \le -\dfrac{3}{5} \quad \text{or} \quad t = 1
\end{align}
であり，これが求める条件である．
