{\bf [解]}
\paragraph{(1)}
数学的帰納法で示す．まず$n=1$の時与えられた不等式は
\begin{align}
 |\sin\theta| \le \sin\theta \quad (0 \le \theta \le \pi)
\end{align}
でこれは成立する．
そこで以下 $n=k \in \mathbb{N}$ での成立を仮定して，$n=k+1$で成立することを示す．
加法定理より
\begin{align}
    |\sin(k+1)\theta| \leqq |\sin k\theta||\cos\theta| + |\cos k\theta||\sin\theta| \leqq k\sin\theta + \sin\theta = (k+1)\sin\theta
\end{align}
だから $n=k+1$ でも成立する. よって示された.

\paragraph{(2)}
$0\le\theta\le\pi$の時，(1)の不等式を下からさらに評価して
\begin{align}
 \sin n\theta \leqq |\sin n\theta| \leqq n \sin\theta
\end{align}
が成り立つ．
題意の条件より$0 \le f(\theta)$だから，各辺に$f(\theta)$をかけると
\begin{align}
 f(\theta) \sin n\theta \leqq f(\theta) |\sin n\theta| \leqq n f(\theta) \sin\theta \\
\therefore
 f(\theta) \sin n\theta \leqq n f(\theta) \sin\theta
\end{align}
だから，これを$0\le\theta\le\pi$で積分して
\begin{align}
 \int_0^\pi f(\theta) \sin n\theta \, d\theta \leqq \int_0^\pi nf(\theta) \sin\theta \, d\theta \label{eq:1}
\end{align}
である．ここで題意より
\begin{align}
    \int_0^\pi f(\theta) \sin\theta \, d\theta = 1 \quad \dots \text{\textcircled{2}} \label{eq:2}
\end{align}
だから，\cref{eq:2}を\cref{eq:1}に代入して
\begin{align}
 \int_0^\pi f(\theta) \sin n\theta \, d\theta \leqq n
\end{align}
となる．よって題意は示された．
