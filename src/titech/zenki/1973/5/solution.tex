{\bf [解]}

下図に曲線$y=(ax-b)^2$の様子を示す．題意の領域は図の斜線部である．
以下簡単のため
\begin{align}
 f(x) = (ax-b)^2
\end{align}
とおく．

\begin{figure}[htb]
\begin{center}
\begin{tikzpicture}[scale=1.2, >=stealth]
  % 1. 領域の塗りつぶし (x ∈ [0, b/a] において 曲線 y=(ax-b)^2 と xy軸で囲まれた領域)
  \begin{scope}
    \fill[pattern=north east lines, pattern color=gray!80]
      (0,0) -- (0,2.25) -- plot[domain=0:1.5, smooth] (\x, {(1.5-\x)*(1.5-\x)}) -- (1.5,0) -- cycle;
  \end{scope}

  % 2. 座標軸
  \draw[->] (-0.3,0) -- (2.0,0) node[right] {$x$};
  \draw[->] (0,-0.3) -- (0,2.6) node[above] {$y$};
  \node[below left] at (0,0) {$O$};

  % 3. 曲線 y = (ax-b)^2 の描画
  \draw[domain=0:1.6, smooth, thick] plot (\x, {(1.5-\x)*(1.5-\x)}) node[above right] {$y=f(x)$};

  % 4. 切片のプロットとラベル
  \fill (0, 2.25) circle (1.2pt);
  \fill (1.5, 0) circle (1.2pt);

  \node[left] at (0,2.25) {$b^2$};
  \node[below] at (1.5,0) {$b/a$};

\end{tikzpicture}
\end{center}
\caption{曲線 $y=(ax-b)^2$ と各軸で囲まれた領域（斜線部）}
\end{figure}

この領域を$x, y$ 軸のまわりにまわして得られる立体の体積 $V_x, V_y$ とすると

\begin{align}
  V_x &= \pi \int_0^{b/a} \left(f(x)\right)^2 dx = \pi \int_0^{b/a} (ax-b)^4 dx \\
  V_y &= 2\pi \int_0^{b/a} xf(x) dx = 2\pi \int_0^{b/a} x(ax-b)^2 dx 
\end{align}
である．これらが等しくなる時
\begin{align}
V_x = V_y 
&\iff \int_0^{b/a} \{ (ax-b)^4 - 2x(ax-b)^2 \} dx = 0 \\
&\iff \left[ \dfrac{1}{5a} (ax-b)^5 - \dfrac{2}{4}a^2 x^4 + \dfrac{4}{3}ab x^3 - b^2 x^2 \right]_0^{b/a} = 0 \\
&\iff -\dfrac{1}{5a} (-b)^5 - \dfrac{1}{2}a^2 \left(\dfrac{b}{a}\right)^4 + \dfrac{4}{3}ab \left(\dfrac{b}{a}\right)^3 - b^2 \left(\dfrac{b}{a}\right)^2 = 0 \\
&\iff \dfrac{b^5}{5a} - \dfrac{1}{2}\dfrac{b^4}{a^2} + \dfrac{4}{3}\dfrac{b^4}{a^2} - \dfrac{b^4}{a^2} = 0 \\
&\iff \dfrac{ab}{5} - \dfrac{1}{2} + \dfrac{4}{3} - 1 = 0 \qquad (\because a, b \neq 0) \\
&\iff ab = \dfrac{5}{6} 
\end{align}
となり，確かに$ab$は定数である．よって示された．
