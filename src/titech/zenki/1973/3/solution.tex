{\bf [解答]}
題意より
\begin{align}
  0 \le \alpha < \pi, \quad 0 < \beta < \dfrac{1}{2} \label{eq:1} \\
  0 \le x \le 1, \quad y \le \cos(\pi\beta) \label{eq:2}
\end{align}
である．
\cref{eq:1}より
\begin{align}
  0 \le \alpha\beta < \pi\beta < \dfrac{\pi}{2}
\end{align}
だから，
\begin{align}
  \cos(\pi\beta) > 0, \, \sin(\pi\beta) > \sin(\alpha\beta) \ge 0 \label{eq:3}
\end{align}
となる．
ここで
\begin{align}
  A(x,y,\alpha,\beta)
  = y \sin(\alpha\beta) + x \sin\{(\pi-\alpha)\beta\} - \sin(\pi\beta)\label{eq:4}
\end{align}
とおくと，$A(x,y,\alpha,\beta) \ge 0$ならば$x=1$であることを示せば良い．

そこで$A(x,y,\alpha,\beta)$を上から評価することを考える．
\cref{eq:2,eq:3}より$\sin(\alpha\beta), \sin\{(\pi-\alpha)\beta\}>0$だから$A$は$x,y$について単調増加で，$y=\cos(\pi\beta), x=1$で最大値をとる．これを$B(\alpha,\beta)$とおく：
\begin{align}
  B(\alpha,\beta) = \cos(\pi\beta) \sin(\alpha\beta) + \sin\{(\pi-\alpha)\beta\} - \sin(\pi\beta).
\end{align}
第二項を加法定理で展開すると
\begin{align}
  B(x,\alpha,\beta)
  & = \cos(\pi\beta) \sin(\alpha\beta)
  + \left[\sin(\pi\beta)\cos(\alpha\beta) - \cos(\pi\beta)\sin(\alpha\beta)\right]  - \sin(\pi\beta)  \\
  & = \sin(\pi\beta)\cos(\alpha\beta) - \sin(\pi\beta) \\
  & = \sin(\pi\beta)\left[\cos(\alpha\beta) - 1\right]
\end{align}
である．次に$\alpha$を動かすと，$\sin(\pi\beta)>0$よりこれは$\alpha=0$で最大値$0$をとる．以上から
\begin{align}
  A(x,y,\alpha,\beta) \le 0 \label{eq:5}
\end{align}
である．

従って，与式$A(x,y,\alpha,\beta) \ge 0$が成立するのは\cref{eq:5}で等号が成立する時のみ（$A$が最大の時）でこの時$x=1$である．よって題意は示された．\qed
