{\bf [解]}
題意をみたす整式を $f(x)$ とすると, 適当な整式 $Q(x), R(x)$ を用いて,
\begin{align}
f(x) &= Q(x) \cdot x^2 + x + 1 \quad \dots \text{①}\label{eq:1} \\
f(x) &= R(x) \cdot (x+1)^2 + x \quad \dots \text{②}\label{eq:2}
\end{align}
とかける.

$f(x)$ が定数又は1次の時は\cref{eq:1,eq:2}を満たすものはないので以下2次以上を考える.
\cref{eq:1}から，適当な整数係数$a_k$を用いて
\begin{align}
 f(x) = \sum_{k=2}^n a_k x^k + x + 1 \ (a_k \in \mathbb{R}, a_n \neq 0, n \in \mathbb{N}_{\ge 2}) \label{eq:3}
\end{align}
と書ける．
\cref{eq:2}より$g(x) = f(x) - x$ が $(x+1)^2$ で割りきれるので$g(-1) = g'(-1) = 0$だから，ここに\cref{eq:3}を代入して
\begin{align}
\begin{cases}
g(-1) = \sum_{k=2}^n a_k (-1)^k + 1 = 0 \\
g'(-1) = \sum_{k=2}^n k a_k (-1)^{k-1} = 0
\end{cases} \quad \dots \text{③} \label{eq:4} 
\end{align}
である．
以下，この\cref{eq:4}を満たす$a_k \ (k=2 \dots n)$ が存在する最小の $n$ をもとめれば良い.
$n$が小さい順に考える．

\subparagraph{1. $n=2$の時}
この時\cref{eq:4}より
\begin{align} 
\begin{cases}
 a_2 + 1 = 0 \\
 -2a_2 = 0
\end{cases}
\end{align}
だから$a_2=-1=0$となって矛盾する．よって$n=2$には解はない．

\subparagraph{2. $n=3$の時}
この時\cref{eq:4}より
\begin{align} 
\begin{cases} 
   -a_3 + a_2 + 1 = 0 \\ 
   3a_3 - 2a_2 = 0 
\end{cases} \\
\therefore
\begin{cases} 
  a_2 = -3 \\ 
  a_3 = -2 
\end{cases}
\end{align}
である．この時\cref{eq:3}から
\begin{align}
 f(x) = -2x^3 - 3x^2 + x + 1
\end{align}
となり，この$f(x)$は条件を満たす．
\casesend

以上からもとめるのは $f(x) = -2x^3 - 3x^2 + x + 1$ である.
