{\bf [解]}
三角柱の底面（正三角形，1辺1）を$DEF$，対応する上面を$ABC$（$AD=BE=CF=2$，各々垂直な辺）とする．断面の直角三角形$PQR$の頂点は辺$AD,BE,CF$上に1つずつあり，対称性からそのうちの1つが$E$（底面の頂点）に一致する場合を考えれば良い．$P=E$，$Q$が辺$AD$上，$R$が辺$CF$上にあるとし，
\begin{align}
DQ=x,\qquad FR=x+t \qquad(0\le x\le x+t\le2)\ \cdots(\ast)
\end{align}
とおく（$D,E,F$は底面の3頂点で互いの距離は1）．

$P=E$は高さ$0$，$Q$は高さ$x$，$R$は高さ$x+t$にあり，$D,E,F$間の水平距離はいずれも$1$だから
\begin{align}
PQ=\sqrt{1+x^2},\qquad QR=\sqrt{1+t^2},\qquad PR=\sqrt{1+(x+t)^2}
\end{align}
$(\ast)$より$PR$が最大辺だから，$PR$が斜辺，すなわち直角は$Q$にある．$\triangle PQR$の面積$S$は
\begin{align}
S=\dfrac{1}{2}\,QP\cdot QR=\dfrac{1}{2}\sqrt{(1+x^2)(1+t^2)} \quad\cdots\text{①}
\end{align}
また，ピタゴラスの定理$PQ^2+QR^2=PR^2$から
\begin{align}
(1+x^2)+(1+t^2)=1+(x+t)^2 \iff 2+x^2+t^2=1+x^2+2xt+t^2 \iff 2xt=1
\end{align}
\begin{align}
\therefore\ xt=\dfrac{1}{2} \quad\cdots\text{②}
\end{align}

$(\ast)$，②のもとで①の値域をもとめる．$k=x+t$とおくと，②から$x,t$は2次方程式
\begin{align}
p^2-kp+\dfrac{1}{2}=0 \quad(0\le k\le2)
\end{align}
の2つの正の実解であり（$xt=1/2>0$から$x,t$は同符号，かつ$k\ge0$から正），判別式$D=k^2-2\ge0$が必要十分．$0\le k\le2$とあわせて
\begin{align}
\sqrt{2}\le k\le2 \quad\cdots\text{③}
\end{align}
①より
\begin{align}
S=\dfrac{1}{2}\sqrt{1+x^2+t^2+x^2t^2}=\dfrac{1}{2}\sqrt{1+\{(x+t)^2-2xt\}+x^2t^2}=\dfrac{1}{2}\sqrt{1+(k^2-1)+\dfrac{1}{4}}=\dfrac{1}{2}\sqrt{k^2+\dfrac{1}{4}}
\end{align}
これは$k>0$で単調増加だから，③より$k=\sqrt{2}$で最小，$k=2$で最大：
\begin{align}
S_{\min}=\dfrac{1}{2}\sqrt{2+\dfrac{1}{4}}=\dfrac{1}{2}\cdot\dfrac{3}{2}=\dfrac{3}{4},\qquad
S_{\max}=\dfrac{1}{2}\sqrt{4+\dfrac{1}{4}}=\dfrac{1}{2}\cdot\dfrac{\sqrt{17}}{2}=\dfrac{\sqrt{17}}{4}
\end{align}
したがって，もとめる面積の範囲は
\begin{align}
\dfrac{3}{4}\le S\le\dfrac{\sqrt{17}}{4}
\end{align}
