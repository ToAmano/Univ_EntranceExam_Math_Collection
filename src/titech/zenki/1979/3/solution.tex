{\bf [解答]}
簡単のため$c=\cos x, s=\sin x$とおく．

\paragraph{(1)}
新しく
\begin{align}
  F(x)=p(x)\cos x-q(x)\sin x \label{eq:1}
\end{align}
とおくと，全ての$x$について$F(x)=0$である場合を考えれば良い．
$k$を整数として$x=k\pi, k\pi+\dfrac{\pi}{2}$での成立が必要だから，
\begin{align}
  \begin{dcases}
    F(k\pi) = (-1)^{k}p(k\pi) = 0 \\
    F(k\pi+\pi/2) = (-1)^{k}q(k\pi+\pi/2) = 0
  \end{dcases} \label{eq:2}
\end{align}
である．ところが$p(x), q(x)$は$3$次以下の関数だから高々$3$個の$x$でしか$p(x)=q(x)=0$とならない．これは無限個の点で\cref{eq:2}で成立することと反して矛盾する．よって背理法により $p(x), q(x)$ は恒等的に$0$ である．

\paragraph{(2)}
与えられた方程式
\begin{align}
  P(x)\cdot c+\int_0^xQ(t)\sin t\,dt=(x^2+2x+3)s \label{eq:3}
\end{align}
を考える．まず$x=0$を\cref{eq:3}に代入すると
\begin{align}
  P(0) = 0 \label{eq:4}
\end{align}
である．次に\cref{eq:3}の両辺を $x$ で微分して
\begin{align}
  \begin{split}
    -P(x)s+P'(x)c+Q(x)\cdot s&=(2x+2)s+(x^2+2x+3)c \\
    \therefore
    [Q(x)-P(x)-(2x+2)]s&=(x^2+2x+3-P'(x))c
  \end{split}
\end{align}
を得る．ここで$P(x), Q(x)$が$3$次以下なので$Q(x)-P(x)-(2x+2)$，$x^2+2x+3-P'(x)$も$3$次以下である．
よって(1)の結果が使えて
\begin{align}
  \begin{dcases}\displaystyle
    Q(x)-P(x)=2x+2 \\
    P'(x)=x^2+2x+3
  \end{dcases} \label{eq:5}
\end{align}
である．
\cref{eq:5}の第二式の両辺を積分して\cref{eq:4}と合わせて
\begin{align}
  P(x)=\dfrac{1}{3}x^3+x^2+3x  \label{eq:6}
\end{align}
となる．\cref{eq:5}の第一式にこれを代入して
\begin{align}
  Q(x)=\dfrac{1}{3}x^3+x^2+5x+2 \label{eq:7}
\end{align}
となる．\cref{eq:6,eq:7}はいずれも$3$次以下の多項式でかつ\cref{eq:3}を満たしており，よって求める関数は
\begin{align}
  \begin{dcases}
    P(x)=\dfrac{1}{3}x^3+x^2+3x \\
    Q(x)=\dfrac{1}{3}x^3+x^2+5x+2
  \end{dcases}
\end{align}
である．
