{\bf [解]}
(1)
与えられた式に$f(x)$の具体的な形を代入すると，まず第一項は
\begin{align}
 \int_0^1 f(x) \, dx = \frac{1}{4} + \frac{a}{3} + \frac{b}{2} + c \label{eq:1}
\end{align}
である．第二項は
\begin{align}
    \sum_{k=1}^n f\left(\frac{k}{n}\right) 
     &= \sum_{k=1}^n \left[ \frac{1}{n^3} k^3 + \frac{a}{n^2} k^2 + \frac{b}{n} k + c \right] \\
     &= \frac{1}{n^3} \left\{ \frac{n(n+1)}{2} \right\}^2 + \frac{a}{n^2} \frac{1}{6} n(n+1)(2n+1) + \frac{b}{n} \frac{1}{2} n(n+1) + cn \\
     &= \frac{(n+1)^2}{4n} + \frac{a}{6} \frac{(n+1)(2n+1)}{n} + \frac{b}{2}(n+1) + cn \\
     &= \frac{1}{4}\left(n + 2 + \frac{1}{n}\right) + \frac{a}{6}\left(2n + 3 + \frac{1}{n}\right) + \frac{b}{2}(n+1) + cn \\
     &= \left(\frac{1}{4} + \frac{a}{3} + \frac{b}{2} + c\right) n + \left(\frac{1}{2} + \frac{a}{2} + \frac{b}{2}\right) + \left(\frac{1}{4} + \frac{a}{6}\right) \frac{1}{n} \label{eq:2}
\end{align}
だから，\cref{eq:1,eq:2}より
\begin{align}
 n \int_0^1 f(x) \, dx - \sum_{k=1}^n f\left(\frac{k}{n}\right) 
  &= -\left(\frac{1}{2} + \frac{a}{2} + \frac{b}{2}\right) - \left(\frac{1}{4} + \frac{a}{6}\right) \frac{1}{n}\\
  & \xrightarrow{n \to \infty} -\frac{a+b+1}{2} 
\end{align}
である．

(2)
与えられた式に$f(x)$の具体的な形を代入すると，まず第一項は
\begin{align}
 f(1+h) - f(1) 
   &= \{(1+h)^3 - 1\} + a\{(1+h)^2 - 1\} + b\{(1+h) - 1\} \\
   &= (h^3 + 3h^2 + 3h) + a(h^2 + 2h) + bh \label{eq:3}
\end{align}
である．次に第二項は
\begin{align}
    f'(x) &= 3x^2 + 2ax + b \\
 \therefore
    f'(1) &= 3+2a+b \label{eq:4}
\end{align}
である．従って求める極限値は
\begin{align}
    \frac{f(1+h) - f(1)}{h^2} - \frac{f'(1)}{h} 
    &= h + (3+a) + \frac{3+2a+b}{h} - \frac{3+2a+b}{h} \\
    &= h + (3+a) \\
    &\xrightarrow{h \to 0} 3+a
\end{align}
である．

 
{\bf [解説]}
通常の微分で求められるより一つ高いオーダーの評価が求められる問題．(1)は区分求積計算のさらに一つ上のオーダーの評価で，(2)は微分の一つ上のオーダーの評価だ．
とはいえ$f$が単純な三次関数として与えられているので単純計算で求まるので難易度は高くない．

(2)は(1)のようには解けないが，Taylor展開を知っていれば検算できる．$f(1+h)$を$x=1$の周りで展開すると
\begin{align}
 f(1+h) = f(1) + f'(1)h + \frac{f''(1)}{2}h^2 +\mathcal{O}(h^3)
\end{align}
だから
\begin{align}
 \frac{f(1+h) - f(1)}{h^2} - \frac{f'(1)}{h}
   &= \frac{f''(1)}{2} + \mathcal{O}(h) \\
   &\xrightarrow{h \to 0} \frac{f''(1)}{2} \\
   &= 3+a
\end{align}
となり答えが正しいことがわかる．
