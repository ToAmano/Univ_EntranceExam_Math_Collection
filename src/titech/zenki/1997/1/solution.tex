{\bf [解]}
与えられた二つの領域
\begin{align}
 & a^2x^2 + b^2y^2 \le 1 \label{eq:1} \\
 & a(x-1) + b(y-1) \le 0 \label{eq:2}
\end{align}
について考える．

まず$ab=0$の場合を考える．この場合は$(a,b)=(0,0)$, $a=0,b\neq 0$, $a\neq 0, b=0$のいずれかである．

\subparagraph{$1^\circ$ $(a,b)=(0,0)$の時}

この時は題意の不等式は$0 \le 0$という自明なものになって題意は成立する．

\subparagraph{$2^\circ$ $a=0,\ b\ne0$の時}

\cref{eq:1,eq:2}は
\begin{align}
 \begin{cases}
  b^2y^2 \le 1 \\
  b(y-1) \le 0
 \end{cases}
\therefore
 \begin{cases}
  |y| \le \dfrac{1}{|b|} \\
  b(y-1) \le 0
 \end{cases}
\end{align}
となるから，$b<0$の時は第二式を満たす$y$は$y \ge 1$となりこれは$y=0$の時に満たされず不適である．
そこで$b>0$であることが必要で，この時第二式は$y \le 1$となるから，$|y| \le \dfrac{1}{b}$なる$y$が常にこれを満たすのは$1\le b$の時である．

\subparagraph{$3^\circ$ $a\ne0,\ b=0$}

$2^\circ$と同様に$1\le a$であれば良い．

\subparagraph{$4^{\circ}$ $ab\neq 0$の時}
そこで以下，$ab\ne0$のもとで考える．
この時，$xy$平面上で楕円$a^2x^2+b^2y^2\le1$の領域が常に$\ell: a(x-1)+b(y-1)\le0$をみたすような$(a,b)$の範囲をもとめれば良い．

楕円内の点$P(x,y)$の座標は
\begin{align}
 (x,y)=\left(\dfrac{r}{a}\cos\theta,\dfrac{r}{b}\sin\theta\right) \quad (0\le\theta<2\pi,\ 0\le r\le1)
\end{align}
とおける．$\ell$に代入して
\begin{align}
\begin{split}
r\cos\theta-a+r\sin\theta-b&\le0 \\
r\sqrt{2}\sin\left(\theta+\dfrac{\pi}{4}\right)&\le a+b
\end{split}
\end{align}
が任意の$\theta,r$で成立すれば良く，その条件は
\begin{align}
a+b\ge\sqrt{2}
\end{align}
である．
\casesend


以上で全ての場合が尽くされたから求める条件は
\begin{align}
a=b=0 \ \text{or}\ (ab\ne0\wedge a+b\ge\sqrt{2})\ \text{or}\ (a=0\wedge b\ge1)\ \text{or}\ (b=0\wedge a\ge1)
\end{align}
である．これを$ab$平面上に図示して下図斜線部である．ただし境界と$\bullet$を含む．

{\bf [別解]}
$ab\neq 0$の場合には以下の方がより直接的で良いかもしれない．

$a\ne0,b\ne0$の時に$X=ax,\ Y=by$とおくと，$x^2+y^2\le1$をみたす全ての$X,Y$が$X+Y\le a+b$をみたせば良く，この条件は円と直線の距離を考えて
\begin{align}
a+b\ge\sqrt{2}
\end{align}
である．
