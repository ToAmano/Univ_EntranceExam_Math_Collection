{\bf [解]}

対称性からまず 
\begin{align}
 0 \leqq x \leqq \dfrac{\pi}{2} \label{eq:1}
\end{align}
で考える．この時$\cos x, \sin x\ge 0$より題意の式は
\begin{align}
 \sin^n x + \cos^n x = 1 \label{eq:2}
\end{align}
となる．$n$の値に応じて場合分けして考える．

\subparagraph{$n \geqq 3$の時}

\cref{eq:2}より
\begin{align}
  \sin^2 x \cdot \sin^{n-2} x + \cos^2 x \cdot \cos^{n-2} x = 1
\end{align}
とかける．\cref{eq:1}では$0 \le \sin^{n-2} x, \cos^{n-2} x \le 0$だから
\begin{align}
 1 = \sin^2 x \cdot \sin^{n-2} x + \cos^2 x \cdot \cos^{n-2} x \le \sin^2 x + \cos^2 x = 1
\end{align}
となる．左辺と右辺が等しいから，等号が成立している必要があり，$x = 0 \text{ or } \pi/2$が解となる．
よって\cref{eq:1}以外の区間も同様に考えて
\begin{align}
 x = \frac{n\pi}{2} \; (n \in \mathbb{Z}) \label{eq:3}
\end{align}
が解である．

\subparagraph{$n=2$の時}
この時は三角関数の性質から任意の$x$が\cref{eq:2}を満たす．

\subparagraph{$n=1$の時}
\cref{eq:2}を三角関数の合成で書き直して
\begin{align}
 & \sin x + \cos x = 1 \\
\therefore
 & \sqrt{2}\sin(x+\pi/4) = 1 \\
\therefore 
 x = 0, \pi/2
\end{align}
が解である．従って，\cref{eq:1}以外の区間も同様に考えて
\begin{align}
 x = \frac{n\pi}{2} \; (n \in \mathbb{Z}) \label{eq:4}
\end{align}
である．

以上$3$つの場合分けをまとめて，求める解は
\begin{align}
\begin{cases}
  n \neq 2 \text{ の時 } x = \frac{n\pi}{2} \; (n \in \mathbb{Z}) \\
  n = 2 \text{ の時 } \text{任意}
\end{cases}
\end{align}
である．
