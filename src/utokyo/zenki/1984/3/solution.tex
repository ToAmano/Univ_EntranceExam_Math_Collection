{\bf [解]}

与えられた関数
\begin{align}
  f_k(x) = x^k - 1 - k(x-1) \label{eq:1}
\end{align}
について考える．
$g(x)$を$f_n(x),f_{n-1}(x),\cdots,f_2(x)$で割っていくことを考えれば
任意の $n$ 次多項式 $g(x)$ は，実数$a_k$を用いて
\begin{align}
  g(x) = \sum_{k=2}^n a_k f_k(x) + a_1 x + a_0 \label{eq:2}
\end{align}
とおける．

\subparagraph{(1)}

$g(x)$ が $(x-1)^2$ で割り切れるには，$g(1)=g'(1)=0$ が必要十分であるが，
\cref{eq:1}から$f_k(1)=f'_k(1)=0$ を\cref{eq:2}に代入してこの条件は
\begin{align}
  &
  \begin{cases}
    a_1 + a_0 = 0 \\
    a_1 = 0
  \end{cases}
  \iff
  & a_1 = a_0 = 0
\end{align}
である．よって\cref{eq:2}に代入して
\begin{align}
  g(x) = \sum_{k=2}^n a_k f_k(x) \label{eq:3}
\end{align}
と書ける．よって必要性は示された．

次に$g(x)$が\cref{eq:3}と書ける時，$g(1)=g'(1)=0$となるから$g(x)$は$(x-1)^2$で割り切れて十分である．以上から題意は示された．

\subparagraph{(2)}

$g(x)$ が $(x-1)^3$ で割り切れるには，$g(1)=g'(1)=g''(1)=0$ が必要十分である．\cref{eq:1}より$f_k(1)=f'_k(1)=0, f''_k(1)=k(k-1)$ だから
\cref{eq:2}に代入して
\begin{align}
  \begin{cases} a_1 = a_0 = 0 \\ \sum_{k=2}^n k(k-1) a_k = 0
  \end{cases}
\end{align}
だから，たしかに $g(x) = \sum_{k=2}^n a_k f_k(x)$ ($\sum_{k=2}^n \dfrac{k(k-1)}{2} a_k = 0$) を書けることが必要である．逆に，このように書ける時，(1)と同様にして十分である．以上から題意は示された．

{\bf [解2]}

少し本解とは異なる方向性の証明を(1),(2)で示す．

\subparagraph{(1)}

まずは十分性について考える．\cref{eq:1}を$(x-1)$をベースに展開すると，二項定理より
\begin{align}
  f_k(x)
  &= \{(x-1)+1\}^k - k(x-1) - 1 \\
  &= \sum_{i=0}^{k}{}_{k}C_{i}(x-1)^{i} - k(x-1) - 1 \\
  &= \sum_{i=2}^{k}{}_{k}C_{i}(x-1)^{i} \label{eq:4}
\end{align}
である．従って$f_k(x)$は$(x-1)^2$以上の項しか持たないから$(x-1)^2$ で割り切れる．
よって十分である．

次に必要性について，数学的帰納法で証明する．
$n=1,2$ の時は自明である．
$n \le m$ の時に題意が真だと仮定して，$n=m+1$について考える．
$m+1$ 次の $g(x)$ は $m$ 次以下の整式 $h(x)$ として
\begin{align}
  g(x) = a_{m+1} f_{m+1}(x) + h(x)
\end{align}
と表せる．この時，$f_{m+1}(x), g(x)$ が共に $(x-1)^2$ で割り切れるので，$h(x)$ も$(x-1)^2$で割り切れる．よって仮定から
\begin{align}
  g(x)
  &= a_{m+1} f_{m+1}(x) \sum_{i=2}^{m}a_kf_{k}(x) \\
  &= \sum_{i=2}^{m+1}a_kf_{k}(x)
\end{align}
と表せるので$n=m+1$でも成立する．よって数学的帰納法により示された．

\subparagraph{(2)}

(1)とほぼ同じなので十分性についてだけ考える．
\cref{eq:4}を$g(x)$の展開式に代入して
\begin{align}
  \sum_{k=2}^n a_k f_k(x)
  &= \sum_{k=2}^n a_k \Bigl[ \sum_{i=2}^k {}_k\mathrm{C}_i (x-1)^i \Bigr] \\
  &=\sum_{k=2}^n\sum_{i=2}^k a_k{}_k\mathrm{C}_i (x-1)^i
\end{align}
だから，これを$(x-1)^3$ でわったあまりは，$i=2$の時の項だけが残って
\begin{align}
  \sum_{k=2}^n a_k{}_k\mathrm{C}_2 (x-1)^2
  = \sum_{k=2}^n a_k\dfrac{k(k-1)}{2} (x-1)^2
\end{align}
である．これが$0$であるので
\begin{align}
  \sum_{k=2}^n a_k\dfrac{k(k-1)}{2} = 0
\end{align}
だから，十分性は示された．
