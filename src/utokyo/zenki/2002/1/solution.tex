{\bf [解答]}

与えられた放物線
\begin{align}
  \begin{cases}
    y=2\sqrt{3}(x-\cos\theta)^2+\sin\theta \\
    y=-2\sqrt{3}(x+\cos\theta)^2-\sin\theta
  \end{cases} \label{eq:1}
\end{align}
について考える．
これらは$\theta$ について $2\pi$ 周期だから，
\begin{align}
  0 \le \theta < 2\pi \label{eq:2}
\end{align}
で考える．

以下簡単のため $c = \cos\theta, s = \sin\theta$ とおく．
\cref{eq:1}が異なる二つの交点を持つので，$y$を消去して連立した二次方程式が二つの解を持つ．実際に連立して
\begin{align}
  & 2\sqrt{3}(x-c)^2 + s + 2\sqrt{3}(x+c)^2 + s = 0 \\
  & 4\sqrt{3}(x^2 + c^2) + 2s = 0 \\
  & 2\sqrt{3}x^2 + 2\sqrt{3}c^2 + s = 0
\end{align}
である．これが異なる2実解をもつ条件は
\begin{align}
  & 2\sqrt{3}c^2 + s < 0 \\
  & 2\sqrt{3}(1-s^2) + s < 0 \\
  & 2\sqrt{3}s^2 - s - 2\sqrt{3} > 0 \label{eq:3}
\end{align}
である．この左辺を$f(s)$とおいて：
\begin{align}
  f(s) = 2\sqrt{3}s^2 - s - 2\sqrt{3} \label{eq:4}
\end{align}
$(s)$が正となる条件を調べよう．
$y=f(s)$のグラフは下図のようになる．

$-1 \le s \le 1$ も考えて，\cref{eq:3}をみたす条件は
\begin{align}
  -1 \le s < -\dfrac{\sqrt{3}}{2}
  \therefore \quad
  \dfrac{4}{3}\pi < \theta < \dfrac{5}{3}\pi
\end{align}
である．

したがって一般角でまとめると，
\begin{align}
  \dfrac{4}{3}\pi + 2n\pi < \theta < \dfrac{5}{3}\pi + 2n\pi \quad (n \in \mathbb{Z})
\end{align}
である．
