{\bf [解答]}
\paragraph{(1)}

最初$\{1,2,3,4,5,6,7,8\}$からスタートすると，
具体的に$3$回シャッフルした時の並び替えは
\begin{align}
  1\text{回シャッフル}&\ \cdots\ \{5,1,6,2,7,3,8,4\}\\
  2\text{回シャッフル}&\ \cdots\ \{7,5,3,1,8,6,4,2\}\\
  3\text{回シャッフル}&\ \cdots\ \{8,7,6,5,4,3,2,1\}
\end{align}
である．よって$3$回シャッフルした結果は$\{8,7,6,5,4,3,2,1\}$である．

\paragraph{(2)}

$\{1,2,\ldots,2N\}$を$t$回シャッフルした後における数$k$（$1\le k\le 2N$）の位置を$f_t(k)$と表す．また最初の配置は$f_0(k)$とする．
$k, k+1$回目での遷移を考えると以下の漸化式を得る．
\begin{align}
  \begin{cases}
    1\le f_t(k)  \le N \text{の時，}&\ f_{t+1}(k)=2f_t(k)\\
    N+1\le f_t(k)\le 2N\text{の時，}&\ f_{t+1}(k)=2f_t(k)-(2N+1)
  \end{cases} \label{eq:1}
\end{align}
題意から最初シャッフルする前は$f_0(k)=k$，一回シャッフルすると$f_1(k)=f(k)$だから，
\cref{eq:1}において$t=0$として
\begin{align}
  \begin{cases}
    1\le k\le N\text{の時，}&\   f_1(k) = 2k \\
    N+1\le k\le2N\text{の時，}&\ f_1(k)  = 2k - (2N+1)
  \end{cases}
\end{align}
となり，$f(k)-2k$を計算すると
\begin{align}
  \begin{cases}
    1\le k\le N\text{の時，}  &\ f(k)-2k=(2k-2k)=0\\
    N+1\le k\le2N\text{の時，}&\ f(k)-2k=(2k-2k)-(2N+1)=-(2N+1)
  \end{cases}
\end{align}
だから，いずれも$f(k)-2k$は$2N+1$で割り切れる．$\blacksquare$

\paragraph{(3)}

以下合同式の法を$2N+1=2^n+1$とする．
\cref{eq:1}から，$1\le f_t(k)\le N$，$N+1\le f_t(k)\le2N$いずれの場合も
\begin{align}
  f_{t+1}(k) \equiv 2f_t(k) \pmod{2N+1} \label{eq:2}
\end{align}
だから，くり返し用いて初項は(2)より$f_0(k)=k$だから
\begin{align}
  f_t(k) \equiv 2^t \cdot k \pmod{2N+1}
\end{align}
である．$2n$回シャッフルした時のことを考えるから，$t=2n$として
\begin{align}
  f_{2n}(k) \equiv 2^{2n}k = \left(2^n\right)^2k \equiv \left((2^n+1)-1\right)^2k \equiv (-1)^2k=k\pmod{2N+1}
\end{align}
である．

ここで$1\le k\le 2N, 1\le f_{2n}(k)\le 2N$だから，
法が$2N+1$であること（区間の幅$2N$が法より小さいこと）より，合同から等号が従い
\begin{align}
  f_{2n}(k)=k
\end{align}
である．よって題意は示された．$\blacksquare$
