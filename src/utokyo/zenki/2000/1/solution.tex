BCの中点$O(0,0)$を原点とする座標系をおき，$A(0,1),B(1,0),C(-1,0)$とする．
対称性から楕円の中心は$y$軸上にあるのでこれを $D(0,a)$ とすると，$b>0$ として楕円の方程式は
\begin{align}
  \dfrac{x^2}{b^2} + \dfrac{(y-a)^2}{a^2} &= 1
\end{align}
とかける．ただし
\begin{align}
  0 < a < 1 \label{eq:1}
\end{align}

ここで$X=\dfrac{x}{b}$，$Y=\dfrac{y}{a}$ なる変換を行うと楕円の方程式は
\begin{align}
  P : X^2 + (Y-1)^2 = 1
\end{align}
へ，直線AB: $x+y=1$ は，
\begin{align}
  l : bX + aY = 1
\end{align}
へ各々うつる．

以下，直線ABと楕円が接する条件をかんがえる．対称性から，この時ACと楕円が接する条件も同じである．
変換後の座標で$l$ と $(0,1)$ の距離が $1$ なら良いので，
\begin{align}
  \dfrac{|a-1|}{\sqrt{a^2+b^2}} = 1
\end{align}
を得る．両辺 $0$ 以上だから2乗して，
\begin{align}
  b^2 &= 1 - 2a \label{eq:2}
\end{align}
である．

ここで\cref{eq:1}より$b^2<1$だから$b>0$と合わせて
\begin{align}
  0<b<1 \label{eq:3}
\end{align}
である．

楕円の面積 $S$ は\cref{eq:3}より
\begin{align}
  S = \pi a b &= \pi b \dfrac{1-b^2}{2}
\end{align}
である．一階微分は
\begin{align}
  \dfrac{dS}{db} = \pi\left(1-3b^2\right)
\end{align}
だから，増減表は以下のようになる．

したがって，$S$ は $b = \dfrac{1}{\sqrt{3}}$ で最大値
\begin{align}
  \max S = \dfrac{\pi}{2} \cdot \dfrac{1}{\sqrt{3}} \cdot \dfrac{2}{3} = \dfrac{\sqrt{3}}{9}\pi
\end{align}
をとる．
