{\bf [解]}

与えられた漸化式
\begin{align}
  \begin{cases}
    z_{n+1}=(3+4i)z_n+1
    z_1=1
  \end{cases} \label{eq:1}
\end{align}
について考える．ここで
\begin{align}
  \alpha = \dfrac{-1}{2+4i}
\end{align}
とすると，$\alpha$ は
\begin{align}
  \alpha = (3+4i)\alpha + 1 \label{eq:2}
\end{align}
をみたすので，\cref{eq:1,eq:2}を辺々引いて
\begin{align}
  z_{n+1} - \alpha &= (3+4i)(z_n - \alpha)
\end{align}
$z_1 = 1$ とあわせて，くり返し用いると
\begin{align}
  z_n
  &= (3+4i)^{n-1}(1 - \alpha) + \alpha \\
  &= \dfrac{1}{2+4i}(3+4i)^{n-1} - \dfrac{1}{2+4i} \\
  &= \dfrac{1-2i}{10}\{(3+4i)^{n-1} - 1\} \label{eq:3}
\end{align}
である．

\paragraph{(1)}

与えれた不等式の各辺は$0$以上だから，二乗して
\begin{align}
  \dfrac{9}{16} \cdot 5^{2n-2} < |z_n|^2 < \dfrac{1}{16} \cdot 5^{2n} \label{eq:4}
\end{align}
であるから，これを示す．

\cref{eq:3}の両辺で絶対値を取って
\begin{align}
  |z_n|
  &= \left|\dfrac{1-2i}{10}\right| |(3+4i)^{n-1} - 1| \\
  &= \dfrac{\sqrt{5}}{10} |(3+4i)^{n-1} - 1|
\end{align}
である．
三角不等式より
\begin{align}
  \begin{cases}
    |z_n| \le \dfrac{\sqrt{5}}{10} \{ |3+4i|^{n-1} + |-1| \} = \dfrac{\sqrt{5}}{10} (5^{n-1} + 1) \\
    |z_n| \ge \dfrac{\sqrt{5}}{10} \{ |3+4i|^{n-1} - |-1| \} = \dfrac{\sqrt{5}}{10} (5^{n-1} - 1)
  \end{cases}
\end{align}
だからまとめて
\begin{align}
  \dfrac{1}{20}(5^n-1)^2 \le |z_n|^2 \le \dfrac{1}{20}(5^n+1)^2 \label{eq:5}
\end{align}
である．

\subparagraph{\cref{eq:4}の右側について}
まず\cref{eq:4}の右側について $5^n>0$ より
\begin{align}
  \dfrac{1}{20}(5^n+1)^2 < \dfrac{1}{16} 5^{2n} &\iff 5^{2n} > 4(2\cdot 5^n+1) \\
  &\iff 5^n > 8 + \dfrac{4}{5^n} \label{eq:6}
\end{align}
であり，$n \ge 2$ の時には $5^n \ge 25 > 8 + \dfrac{4}{25} \ge 8 + \dfrac{4}{5^n}$ から \cref{eq:6} は成立する．

\subparagraph{\cref{eq:4}の左側について}
次に \cref{eq:4}の左側について，
\begin{align}
  \dfrac{1}{20}(5^n-1)^2 > \dfrac{9}{25 \cdot 16} 5^{2n} &\iff 11\cdot 5^{2n} - 40\cdot 5^{n} + 20 > 0 \\
  &\iff \left( 5^n - \dfrac{20 + 6\sqrt{5}}{11} \right) \left( 5^n + \dfrac{20 - 6\sqrt{5}}{11} \right) > 0 \label{eq:7}
\end{align}
であり，$A \ge 25 > \dfrac{20 + 6\sqrt{5}}{11} > \dfrac{20 - 6\sqrt{5}}{11}$ から \cref{eq:7} は常に成立する．
\casesend

以上\cref{eq:4,eq:5,eq:6,eq:7}から$n \ge 2$ の時，
\begin{align}
  \dfrac{9}{16} \cdot 5^{2n-2} < \dfrac{1}{20}(5^n-1)^2 \le |z_n|^2 \le \dfrac{1}{20}(5^n+1)^2 < \dfrac{1}{16} \cdot 5^{2n}
\end{align}
で，両辺平方根をとって
\begin{align}
  \dfrac{3}{4} \cdot 5^{n-1} < |z_n| < \dfrac{1}{4} \cdot 5^n
\end{align}
である．また$n=1$ の時は$|z_1|=1$ から題意は成立するから，以上より不等式は成立する． \hfill $\qed$

\paragraph{(2)}

(1)から数列 $\{|z_n|\}$ は単調増加である．

したがって，$r = \dfrac{5^n}{4}$ の時には $f(r) = n$ であり，
\begin{align}
  \dfrac{5^{n-1}}{4} < r \le \dfrac{5^n}{4} \label{eq:8}
\end{align}
に対して
\begin{align}
  n-1 \le f(r) \le n \label{eq:9}
\end{align}
が成立する．

この時\cref{eq:8}の両辺自然対数を取って
\begin{align}
  (n-1)\log 5 - \log 4 < \log r \le n\log 5 - \log 4
\end{align}
が成立する．\cref{eq:9}の両辺をこれで割って，
\begin{align}
  \dfrac{n-1}{n\log 5 - \log 4} < \dfrac{f(r)}{\log r} < \dfrac{n}{(n-1)\log 5 - \log 4}
\end{align}
が成立する．
$r \to \infty$ の時 $n \to \infty$ で，この両辺は共に $\dfrac{1}{\log 5}$ に収束するから，はさみうちの定理より求める極限は
\begin{align}
  \lim_{r\to\infty} \dfrac{f(r)}{\log r} \longrightarrow \dfrac{1}{\log 5} \hfill \qed
\end{align}
である．
