{\bf [解]}

\paragraph{(1)}

実数$x$が
\begin{align}
  -1 < x < 1, \ x \ne 0 \label{eq:1}
\end{align}
を満たすとする．与えられた不等式
\begin{align}
  {(1-x)}^{1-\frac{1}{x}}<{(1+x)}^{\frac{1}{x}} \label{eq:2}
\end{align}
の両辺は\cref{eq:1}の元で正だから自然対数を取って
\begin{align}
  & (1 - \dfrac{1}{x}) \log(1-x) < \dfrac{1}{x} \log(1+x) \label{eq:3}
\end{align}
である．
\begin{align}
  f(x) = \log(1+x) - (x-1)\log(1-x) \label{eq:4}
\end{align}
とおくと\cref{eq:1}の元で
\begin{align}
  \begin{cases}
    f(x)>0 & (0<x<1) \\
    f(x)<0 & (-1<x<0)
  \end{cases} \label{eq:5}
\end{align}
を示せば良い．$f(x)$の微分は
\begin{align}
  \begin{cases}
    f'(x) = \dfrac{1}{x+1} - \log(1-x) - 1 \\
    f''(x) = \dfrac{1}{1-x} - \dfrac{1}{(x+1)^2} = \dfrac{x(x+3)}{(x+1)^2(1-x)}
  \end{cases} \label{eq:6}
\end{align}
である．\cref{eq:1}の区間では$f''(x)$の符号は$x$と等しい．

\subparagraph{$1^\circ \ 0 < x < 1$の時}

この時は\cref{eq:6}より $f''(x) > 0$ だから $f'(x)$ は単調増加である．
よって $f'(x) > f'(0) = 0$ となって $f(x)$ も単調増加である．よって，
\begin{align}
  f(x) > \lim_{x \to +0} f(x) = 0
\end{align}
だから\cref{eq:4}は示された．

\subparagraph{$2^\circ \ -1 < x < 0$の時}

この時は\cref{eq:6}より $f''(x) < 0$となり，$f'(x)$ は単調減少である．
よって $f'(x) > f'(0) = 0$ となって $f(x)$ は単調増加である．よって
したがって
\begin{align}
  f(x) < \lim_{x \to -0} f(x) = 0
\end{align}
だから\cref{eq:4}は示された．

\paragraph{(2)}

\cref{eq:2}の両辺に$(1-x)^{1/x}, (1+x)^{1-1/x}$をかけると
\begin{align}
  \begin{cases}
    1-x < \left(1-x^2\right)^{\frac{1}{x}} \\
    (1-x^2)^{1-\frac{1}{x}} < 1 + x
  \end{cases}
\end{align}
だから，第一式に$x=\dfrac{1}{100}$，第二式に$x = -\dfrac{1}{100}$を代入すると
\begin{align}
  &
  \begin{cases}
    0.99 < 0.9999^{100} \\
    0.9999^{101} < 0.99
  \end{cases} \\
  \therefore
  & 0.9999^{101} < 0.99 < 0.9999^{100}
\end{align}
だから題意は示された．
