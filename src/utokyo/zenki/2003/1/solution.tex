(A)から，$g(x)=f(x)-x$ とすると $g(1)=g(-1)=0$ かつ $g$は2次関数だから，
因数定理から
\begin{align}
  g(x) = a(x+1)(x-1)
\end{align}
とおける．従って
\begin{align}
  f(x) = a(x+1)(x-1)+x \label{eq:1}
\end{align}
である．

よってBの条件は
\begin{align}
  f(x) &\le 3x^2-1 \\
  \therefore
  a(x^2-1) &\le 3x^2-x-1 \quad (-1 \le x \le 1) \label{eq:2}
\end{align}
である．
$x=\pm 1$ の時は明らかに成立するので，以下 $|x| < 1$ とすると $x^2-1 < 0$ から，
\begin{align}
  a \ge \dfrac{3x^2-x-1}{x^2-1} \label{eq:3}
\end{align}
となる．この右辺を$h(x)$とおくと
\begin{align}
  h(x) = \dfrac{3x^2-x-1}{x^2-1} = 3 + \dfrac{-x+2}{x^2-1} \label{eq:4}
\end{align}
だから，一階微分すると
\begin{align}
  h'(x) = \dfrac{-(x^2-1) - 2x(-x+2)}{(x^2-1)^2} = \dfrac{x^2-4x+1}{(x^2-1)^2}
\end{align}
となり下表をうる．

したがって，\cref{eq:4}が任意の $|x|<1$ で成立する $a$ の条件は
\begin{align}
  a \ge h(2-\sqrt{3}) = 2-\dfrac{\sqrt{3}}{2} \label{eq:5}
\end{align}
である．

以下，このもとで定積分 $I$ の最小値をもとめれば良い．
\cref{eq:1}から$f'(x) = 2ax+1$ だから，
\begin{align}
  I
  &= \int_{-1}^1 (2ax+1)^2 dx \\
  &= 2 \int_0^1 (4a^2 x^2 + 1) dx \\
  &= 2 \left[ \dfrac{4}{3}a^2 x^3 + x \right]_0^1 \\
  &= 2 \left( \dfrac{4}{3}a^2 + 1 \right) \label{eq:6}
\end{align}
である．

\cref{eq:5}から $a^2 \ge \dfrac{19-8\sqrt{3}}{4}$ だから，\cref{eq:6}に代入して
\begin{align}
  I \ge \dfrac{4}{3}(11-4\sqrt{3})
\end{align}
である．

{\bf [別解]}

\cref{eq:2}以下，$a$を求めるところは以下のように二次方程式を用いても良い．
\begin{align}
  h(x) = (3-a)x^2 - x + a - 1 \label{eq:7}
\end{align}
とおいて，$h(x) \ge 0$となる条件を考える．

$a=3$ の時 $h(x) = -x + 2$ となり，$-1 \le x \le 1$ では $h(x) \ge 0$ だから不成立である．
以下$a\neq 3$を考える．$f(1) = 1, f(-1) = 3$ に注意する．$h(x) = 0$ の判別式を $D$ とする．

\subparagraph{$1^\circ \ 3 > a$ の時}

この時の条件は判別式が$0$以下か，軸の位置は$-1$以下か$1$以上かのどちらかであって，
\begin{align}
  D \le 0 \quad \text{or} \quad \left\{ \dfrac{1}{2(3-a)} \le -1, \ 1 \le \dfrac{1}{2(3-a)} \right\} \iff \dfrac{4-\sqrt{3}}{2} \le a < 3
\end{align}

\subparagraph{$2^\circ \ 3 < a$ の時}

この時は$f(1) > 0, f(-1) > 0$ から$h(x) \ge 0$は成立する．
\casesend

以上から $a$については$\dfrac{4-\sqrt{3}}{2} \le a$ である．
