\paragraph{(1)}

$a-p = \dfrac{6\alpha - 14(t-3)}{\alpha} = \dfrac{2}{\alpha}[-4t-3it]$
$b-p = \dfrac{7\alpha(1+i) - 14(t-3)}{\alpha} = \dfrac{7}{\alpha}[-1-7i]$

だから
$$\dfrac{b-p}{a-p} = \dfrac{\dfrac{7}{\alpha}(-1-7i)}{\dfrac{2}{\alpha}(-4-3i)t} = \dfrac{7}{2t} \dfrac{1+7i}{4+3i} = \dfrac{7}{2t} (1+i) \quad (\because t > 0)$$
となり、$\arg\left(\dfrac{b-p}{a-p}\right) = \dfrac{\pi}{4} + 2n\pi \ (n \in \mathbb{Z})$ だから、$\angle APB = \dfrac{\pi}{4}$

\paragraph{(2)}

$\dfrac{1}{OP} = \dfrac{t-3}{(t-7)-ti} = \dfrac{(t-3)\{(t-7)+ti\}}{(t-7)^2+t^2}$ だから、
$$(\dfrac{1}{14} |OP|)^2 = \left| \dfrac{(t-3)}{(t-7)^2+t^2} \right|^2 \left| (t-7)^2 + t^2 \right|$$
$$= \dfrac{(t-3)^2}{(t-7)^2+t^2} = \dfrac{s^2}{(s-4)^2+(s+3)^2} \quad (s = t-3)$$
$$= \dfrac{s^2}{2s^2-2s+25} \equiv f(s) \cdots (1)$$

$$f(s) = \dfrac{1}{25u^2-2u+2} \quad (u = 1/s)$$
$$= \dfrac{1}{25(u-\dfrac{1}{25})^2 + 2 - \dfrac{1}{25}}$$
だから、$u = \dfrac{1}{25} \therefore s=25$、つまり $t=28$ で $f(s)$ は最大で、これは $0$ より大きいので、
