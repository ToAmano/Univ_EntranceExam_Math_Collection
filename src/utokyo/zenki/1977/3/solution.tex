{\bf [解]}

円の中心を$P(X,Y)$ とおく．また，$C$の境界を与える直線を
\begin{align}
  l: y = -\sqrt{3}x + \sqrt{3}
\end{align}
とおく．$A,B,C$の各領域：
\begin{align}
  \begin{cases}
    A: x \ge 0 \\
    B: y \ge 0 \\
    C: y \ge -\sqrt{3}x + \sqrt{3}
  \end{cases}
\end{align}
は以下の斜線部である．ただし境界を含む．

\paragraph{(1)}

与えられた条件は
\begin{align}
  \begin{cases}
    Y < 0 \\
    0 \le X \\
    Y \le -\sqrt{3}X + \sqrt{3}
  \end{cases} \label{eq:1}
\end{align}
と書ける．

さて，円の中心が$B$の外側にあるから，円が含まれるのは$A$または$C$である．
この領域に円が含まれる条件は，領域の境界の直線と円の中心$P(X,Y)$の距離が円の半径$r$以下であることで
\begin{align}
  \begin{cases}
    A: r \le X \\
    C: r \le \dfrac{|\sqrt{3}X + Y - \sqrt{3}|}{\sqrt{1+3}} = \dfrac{1}{2}(-\sqrt{3}X - Y + \sqrt{3})
  \end{cases} \label{eq:2}
\end{align}
である．$r$がこのどちらかを満たせば良い．
ある実数$\alpha, \beta$ に対して小さくない方を $\max\{\alpha, \beta\}$ と表すと，
求める半径$r(P)$は
\begin{align}
  r(P) = \max\Bigl\{ X, \dfrac{1}{2}(-\sqrt{3}X - Y + \sqrt{3}) \Bigr\} \label{eq:3}
\end{align}
である．

$X$ を固定して，$Y$ をうごかして\cref{eq:3}の後者について考える．
\cref{eq:1}および$-\sqrt{3}X - Y + \sqrt{3}$ は $Y$ の単調減少関数だから，
\begin{align}
  \begin{cases}
    -\sqrt{3}X - Y + \sqrt{3} > -\sqrt{3}X + \sqrt{3} & (0 \le X \le 1) \\
    -\sqrt{3}X - Y + \sqrt{3} \ge 0 & (1 < X)
  \end{cases}
\end{align}
である．

従って$X$および$\dfrac{1}{2}(-\sqrt{3}X - Y + \sqrt{3})$の通る領域は以下の斜線部である．

\subparagraph{$1^\circ$ $P$ が $A \cap B \cap C$ をうごく時}

$P$ が $A \cap B \cap C$ をうごく時，\cref{eq:1}より
\begin{align}
  0 \le Y \le -\sqrt{3}X + \sqrt{3} \quad (0 \le X \le 1) \label{eq:5}
\end{align}
である．このもとで\cref{eq:4}を考えれば良い．点$P$が$A,B,C$のいずれにも含まれるから，
\begin{align}
  r(P) = \max\Bigl\{ X, Y, \dfrac{1}{2}(-\sqrt{3}X - Y + \sqrt{3}) \Bigr\} \label{eq:6}
\end{align}
である．\cref{eq:5}より$X$を固定して$Y$を動かした時，
\begin{align}
  \dfrac{\sqrt{3}}{3}(-X+1) \le \dfrac{1}{2}(-\sqrt{3}X - Y + \sqrt{3}) \le \dfrac{\sqrt{3}}{2}(-X+1) \quad (0 \le X \le 1)
\end{align}
だから，$X$を固定して$Y$を動かした時の$r(P)$の値は$0 \le X \le 1$において
\begin{align}
  r(P) = \max
  \begin{cases}
    X \\
    \left[0,\sqrt{3}(-X+1)\right] \\
    \left[\dfrac{\sqrt{3}}{3}(-X+1), \dfrac{\sqrt{3}}{2}(-X+1)\right]
  \end{cases}
\end{align}
である．これを$X-r$平面に図示すると下図のようになる．

\subparagraph{$2^\circ$ $P$ が $A \cap B \cap \overline{C}$ をうごく時}

$P$ が $A \cap B \cap \overline{C}$ をうごく時，$P(X,Y)$のとりうる領域は\cref{eq:1}より
\begin{align}
  \begin{cases}
    \dfrac{1}{\sqrt{3}}(-\sqrt{3}X + \sqrt{3}) \le Y & (0 \le X \le 1) \\
    0 \le Y & (1 \le X)
  \end{cases}
\end{align}
である．
この時に\cref{eq:4}において$A$または$B$の時の条件を考えれば良いから
\begin{align}
  r(P) = \max(X,Y)
\end{align}

\subparagraph{$3^\circ$ $P$ が $\overline{A} \cap B \cap C$ をうごく時}

$P$ が $\overline{A} \cap B \cap C$ をうごく時，$P(X,Y)$のとりうる領域は
\begin{align}
  0 \le Y \le \sqrt{3}(-X+1) \quad (X \le 0)
\end{align}
である．
この時に\cref{eq:4}において$B$または$C$の時の条件を考えれば良いから
\begin{align}
  r(P) = \max\left(Y, \dfrac{1}{2}(-\sqrt{3}X - Y + \sqrt{3})\right)
\end{align}
である．\cref{eq:7}よりこの大小関係は
\begin{align}
  \begin{cases}
    r(P) = \dfrac{1}{2}(-\sqrt{3}X - Y + \sqrt{3}) & \left(0 \le Y \le \dfrac{\sqrt{3}}{3}(-X+1) \right) \\
    r(P) = Y & \left(\dfrac{\sqrt{3}}{3}(-X+1) \le Y \le \sqrt{3}(-X+1) \right)
  \end{cases}
\end{align}
である．よって$X$を固定して$Y$を動かした時の$r(P)$のとりうる範囲は
\begin{align}
  &
  \begin{cases}
    \dfrac{\sqrt{3}}{3}(-X + 1) \le r(P) \le \dfrac{\sqrt{3}}{2}(-X + 1) & (X \le 0) \\
    \dfrac{\sqrt{3}}{3}(-X+1) \le r(P) \le \sqrt{3}(-X+1) & (X \le 0)
  \end{cases} \\
  \therefore
  & \dfrac{\sqrt{3}}{3}(-X+1) \le r(P) \le \sqrt{3}(-X+1) \quad (X \le 0)
\end{align}
である．これを図示して$r(P)$のグラフは下図のようになる．
