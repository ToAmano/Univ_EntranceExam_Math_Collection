対称性から$\alpha < \beta \dots$ として良い．
題意より$|PQ|^2 = |PR|^2$ だから，
\begin{align}
  & (\beta - \dfrac{1}{2})^2 + (\beta^2 - \dfrac{1}{4})^2 = (\alpha - \dfrac{1}{2})^2 + (\alpha^2 - \dfrac{1}{4})^2 \\
  & \beta^2 - \beta + \beta^4 - \dfrac{1}{2}\beta^2 = \alpha^2 - \alpha + \alpha^4 - \dfrac{1}{2}\alpha^2 \\
  & \beta^4 + \dfrac{1}{2}\beta^2 - \beta = \alpha^4 + \dfrac{1}{2}\alpha^2 - \alpha \\
  & (\beta^2 + \alpha^2)(\beta^2 - \alpha^2) + \dfrac{1}{2}(\beta^2 - \alpha^2) - (\beta - \alpha) = 0 \label{eq:1}
\end{align}
である．$\alpha \neq \beta$ から両辺を$\beta-\alpha$で割って
\begin{align}
  (\beta^2 + \alpha^2)(\beta + \alpha) + \dfrac{1}{2}(\beta + \alpha) - 1 = 0 \label{eq:2}
\end{align}
である．

ここで$p = \alpha + \beta, \ q = \alpha \beta$ とすると，$\alpha, \beta$ が相異なる実数だから，これらを解に持つ二次方程式$x^2-px+q=0$の判別式$D$が正であって，
\begin{align}
  D = p^2 - 4q > 0 \label{eq:3}
\end{align}
である．\cref{eq:2}を$\alpha,\beta$で表すと
\begin{align}
  (p^2 - 2q)p + \dfrac{1}{2}p = 1 \label{eq:4}
\end{align}
である．$p=0$は解でないから両辺$p\neq 0$で割って
\begin{align}
  q = \dfrac{1}{2} \left( p^2 - \dfrac{1}{p} + \dfrac{1}{2} \right) \label{eq:5}
\end{align}
である．\cref{eq:3}に代入して$q$を消去すると
\begin{align}
  & p^2 - 2 \left( \dfrac{1}{2}(p^2 - \dfrac{1}{p} + \dfrac{1}{2}) \right) > 0 \\
  \therefore
  & -p(p-1)(p^2+p+2) > 0
\end{align}
である．ここで$p^2+p+2 = (p+\dfrac{1}{2})^2 + \dfrac{7}{4} > 0$ に注意して
\begin{align}
  0 < p < 1 \label{eq:6}
\end{align}
である．\cref{eq:5,eq:6}を図示すると下図のようになる．

次に$\triangle PQR$の重心 $G(X,Y)$ について
\begin{align}
  \begin{cases}
    X = \dfrac{\alpha+\beta+\dfrac{1}{2}}{3} = \dfrac{1}{3}(p+\dfrac{1}{2})  \\
    Y = \dfrac{\alpha^2+\beta^2+\dfrac{1}{4}}{3} = \dfrac{1}{3}(p^2-2q+\dfrac{1}{4})
  \end{cases} \label{eq:7}
\end{align}
である．\cref{eq:5}を代入して
\begin{align}
  Y & = \dfrac{1}{3} \left( p^2 - p^2 + \dfrac{1}{p} - \dfrac{1}{2} + \dfrac{1}{4} \right) \\
  & = \dfrac{1}{3}(\dfrac{1}{p} - \dfrac{1}{4}) \label{eq:8}
\end{align}
である．\cref{eq:5}から
\begin{align}
  p = 3X - \dfrac{1}{2} \label{eq:9}
\end{align}
だから\cref{eq:6,eq:8}に代入して
\begin{align}
  &
  \begin{cases}
    0 < 3X - \dfrac{1}{2} < 1 \\
    Y = \dfrac{1}{3} \left( \dfrac{1}{3X-\dfrac{1}{2}} - \dfrac{1}{4} \right)
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    \dfrac{1}{6} < X < \dfrac{1}{2} \\
    Y = \dfrac{1}{3} \left( \dfrac{2}{6X-1} - \dfrac{1}{4} \right)
  \end{cases}
\end{align}
であり，図示すると下図の太線部（端点は含まず）となる．
