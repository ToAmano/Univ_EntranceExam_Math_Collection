点光源の座標は
\begin{align}
  P(a\cos\theta,b\sin\theta,c+1)
\end{align}
と書ける．

また，$A(a,b), B(a,-b), C(-a,b), D(-a,-b)$ とおく．
点$P$を固定した時，$PA, PB, PC, PD$と$xy$ 平面の交点を $A_{\theta}, B_{\theta}, C_{\theta}, D_{\theta}$ とおく．
点 $P$ が四角形$ABCD$に遮られてできる影は四角形 $A_{\theta}B_{\theta}C_{\theta}D_{\theta}$ になる.

相似から $K = A, B, C, D$ に対して
\begin{align}
  \overrightarrow{PK'} = (c+1)\overrightarrow{PK} \label{eq:1}
\end{align}
だから具体的な座標を代入して
\begin{align}
  \overrightarrow{PA_{\theta}} = (c+1)
  \begin{pmatrix} a - at \\ b - bs \\ c - (c+1)
  \end{pmatrix} = (c+1)
  \begin{pmatrix} a(1-t) \\ b(1-s) \\ -1
  \end{pmatrix}
\end{align}
および
\begin{align}
  \overrightarrow{PB_{\theta}} = (c+1)
  \begin{pmatrix} a(1-t) \\ -b(1+s) \\ -1
  \end{pmatrix}, \quad
  \overrightarrow{PC_{\theta}} = (c+1)
  \begin{pmatrix} -a(1+t) \\ b(1-s) \\ -1
  \end{pmatrix}, \quad
  \overrightarrow{PD_{\theta}} = (c+1)
  \begin{pmatrix} -a(1+t) \\ -b(1+s) \\ -1
  \end{pmatrix}
\end{align}
となり，各$K_{\theta}$の座標は
\begin{align}
  A_{\theta}\big( a(c+1) - act, b(c+1) - bcs, 0 \big), \quad
  C_{\theta}\big( -a(c+1) - act, b(c+1) - bcs, 0 \big) \\
  B_{\theta}\big( a(c+1) - act, -b(c+1) - bcs, 0 \big), \quad
  D_{\theta}\big( -a(c+1) - act, -b(c+1) - bcs, 0 \big)
\end{align}
である．

{\bf [別解]}

$P$の座標を設定した後は，点$Q$が領域内の点だとして$PQ$が板と共有点を持つ条件を考えても良い．

領域内の点を $Q(X, Y, 0)$ とおくと
\begin{align}
  \overrightarrow{PQ} =
  \begin{pmatrix} X \\ Y \\ 0
  \end{pmatrix} -
  \begin{pmatrix} at \\ bs \\ c+1
  \end{pmatrix}
\end{align}
だから, $PQ$ 上の点 $R$ は,
\begin{align}
  \overrightarrow{OR} =
  \begin{pmatrix} X \\ Y \\ 0
  \end{pmatrix} + \alpha
  \begin{pmatrix} -X + at \\ -Y + bs \\ c+1
  \end{pmatrix}
\end{align}
で表される．$R$は$z=c$だからこれを代入すると
\begin{align}
  \alpha = \dfrac{c}{c+1} \equiv \alpha_0
\end{align}
として，$R$の座標は
\begin{align}
  R\Big( (1-d_0)X + a d_0 t, (1-d_0)Y + b d_0 s, c \Big)
\end{align}
である. これが長方形内部なら良いので, $1-d_0 = \dfrac{1}{c+1}$, $a, b > 0$ に注意して求める条件は
\begin{align}
  \begin{cases}
    \left| \dfrac{1}{c+1} X + a d_0 t \right| \le a \\[10pt]
    \left| \dfrac{1}{c+1} Y + b d_0 s \right| \le b
  \end{cases}
  \iff
  \begin{cases}
    -a d_0 t - a \le \dfrac{1}{c+1} X \le -a d_0 t + a \\[10pt]
    -b d_0 s - b \le \dfrac{1}{c+1} Y \le -b d_0 s + b
  \end{cases}
\end{align}
である．これは$\theta$を固定した時，下図のような長方形になる．
よって$\theta$を動かせば[解答]と同様の領域を描ける．
