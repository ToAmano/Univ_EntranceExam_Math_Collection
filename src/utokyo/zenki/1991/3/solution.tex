{\bf [解]}

与えられた三次関数を
\begin{align}
  g(x) = x^3 -3x \label{eq:1}
\end{align}
とおくと，一階微分は
\begin{align}
  g'(x) = 3(x+1)(x-1) \label{eq:2}
\end{align}
である．従って増減表は以下のようになる．

\begin{table}[htb]
  \centering
  \caption{$g(x) = x^3-3x$ の増減表}
  \begin{tabular}{c|c|c|c|c|c}
    $x$ & $\dots$ & $-1$ & $\dots$ & $1$ & $\dots$ \\ \hline
    $g'$ & $+$ & $0$ & $-$ & $0$ & $+$ \\ \hline
    $g$ & $\nearrow$ & $2$ & $\searrow$ & $-2$ & $\nearrow$
  \end{tabular}
\end{table}

したがってグラフは下図のようになる．
題意の方程式の解は $y = g(x)$ と $y = p$ の共有点の $x$ 座標に等しい．

\paragraph{(1)}

$y=g(x)$は奇関数だから$f(p)$は偶関数である．よって$0 \le p$の範囲で考える．
$p$の値に応じて，$y=g(x)$と$y=p$の解の数・値は以下のように変化する．
\begin{itemize}
  \item $0<a<2$の時: $-2<x<2$に$3$つの実数解を持つ．\\
  \item $a=2$の時: 解は$x=2,-1$である． \\
  \item $2<a$の時: $2<x$に一つ解を持つ．
\end{itemize}

\subparagraph{$2<p$の時}

この時は解はただ一つあるから，これを$\alpha$とおくと
\begin{align}
  f(p) = \alpha^2 \label{eq:3}
\end{align}
である．図から$\alpha^2$ は $p$ の単調増加関数であるから，$|p| \to 2$ を考えると
\begin{align}
  f(p) > 4 \label{eq:4}
\end{align}
である．

\subparagraph{$p=2$の時}

この時は解は$x = 2, -1$ で
\begin{align}
  f(p) = -2 \label{eq:5}
\end{align}
である．

\subparagraph{$0<p<2$の時}

この時は解は 3 つあり，これを $\alpha, \beta, \gamma$ ($\alpha < \beta < \gamma$) とおく．
これらは$x^3-3x-p=0$の解だから，解と係数の関係より
\begin{align}
  \begin{cases}
    \alpha + \beta + \gamma = 0 \\
    \alpha \beta \gamma = p \\
    \beta(\alpha + \gamma) + \alpha \gamma = -3
  \end{cases}
\end{align}
である．第一式から$\beta = -(\alpha+\gamma)$だから，第二式と第三式に代入して
\begin{align}
  \begin{cases}
    -t s = p \\
    s - t^2 = -3
  \end{cases}
  \quad (s = \alpha \gamma, t = \alpha + \gamma) \label{eq:6}
\end{align}
を得る．$f(p)=\alpha\gamma$だから\cref{eq:6}より
\begin{align}
  f(p) = s = t^2-3 \label{eq:7}
\end{align}
となる．
$p = 0$ の時 $t = 0$ となるから，この時
\begin{align}
  \min f(p) = -3 \label{eq:8}
\end{align}
となる．
\casesend

\cref{eq:4,eq:5,eq:8}から求める最小値は
\begin{align}
  \min f(p) = f(0) = -3
\end{align}
である．

\paragraph{(2)}

(1)に引き続き，$y=f(p)$が偶関数だから $0 \le p$ でかんがえる．
$y=f(p)$の挙動を調べるため，$f'(p), f''(p)$を求める．

\subparagraph{$1^\circ \ 2 < p$ の時}

この時は$g(x)=p$の唯一の解を $\alpha \ (\alpha > 2)$ として，
\begin{align}
  \begin{cases}
    f(p) = \alpha^2 \\
    p = \alpha^3 - 3\alpha
  \end{cases} \label{eq:9}
\end{align}
である．両辺を$p$で微分して
\begin{align}
  &
  \begin{cases}
    f'(p) = 2\alpha\dfrac{d\alpha}{dp} \\
    1 = 3\dfrac{d\alpha}{dp}\left(\alpha^2-1\right)
  \end{cases} \\
  &
  \begin{cases}
    f'(p) = 2\alpha\dfrac{d\alpha}{dp} \\
    \dfrac{d\alpha}{dp} = \dfrac{1}{3(\alpha^2-1)}
  \end{cases} \label{eq:10}
\end{align}
を得る．$2<\alpha$より第二式において$\dfrac{d\alpha}{dp}>0$だから
\begin{align}
  f'(p)>0
\end{align}
が従う．

さらに\cref{eq:10}を再度$p$で微分すると
\begin{align}
  &
  \begin{cases}
    f''(p) = 2\left[\left(\dfrac{d\alpha}{dp}\right)^2+\alpha\dfrac{d^2\alpha}{dp^2}\right] \\
    0 = 3\dfrac{d^2\alpha}{dp^2}\left(\alpha^2-1\right) + 6\alpha \left(\dfrac{d\alpha}{dp}\right)^2
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    f''(p) = 2\left[\left(\dfrac{d\alpha}{dp}\right)^2+\alpha\dfrac{d^2\alpha}{dp^2}\right] \\
    \dfrac{d^2\alpha}{dp^2} = \dfrac{-2\alpha}{\alpha^2-1} \left(\dfrac{d\alpha}{dp}\right)^2
  \end{cases}
\end{align}
を得る．第二式を第一式に代入して
\begin{align}
  f''(p)
  &= 2\left(\dfrac{d\alpha}{dp}\right)^2\left[1 + \dfrac{-2\alpha^2}{\alpha^2-1}\right] \\
  &= 2\left(\dfrac{d\alpha}{dp}\right)^2\dfrac{-(\alpha^2+1)}{\alpha^2-1} < 0
\end{align}
を得る．従って$f'(p)>0>f''(p)$だから，$p > 2$ の時は上に凸な単調増加関数である．
極限は$f(p) \to +\infty \ (p \to +\infty)$ であるから増減表は以下のようになる．

\subparagraph{$1^\circ \ 0 \le p \le 2$ の時}

$\beta = -(\alpha+\gamma)$より
\begin{align}
  t = -\beta
\end{align}
だから，\cref{eq:6}で$s,t$を消去して
\begin{align}
  p = -ts = -t (t^2-3) = -t^3 + 3t = \beta^3 - 3\beta \label{eq:11}
\end{align}
である．同様に\cref{eq:7}にも代入して
\begin{align}
  f(p) = \beta^2 -3 \label{eq:12}
\end{align}
である．

\cref{eq:11,eq:12}の両辺$p$で微分して
\begin{align}
  &
  \begin{cases}
    1 = (-3\beta^2+3)\dfrac{d\beta}{dp} \\
    f'(p) = 2\beta\dfrac{d\beta}{dp}
  \end{cases}
  \therefore
  &
  \begin{cases}
    \dfrac{d\beta}{dp} = \dfrac{1}{3(1-\beta^2)} \\
    f'(p) = 2\beta\dfrac{d\beta}{dp}
  \end{cases} \label{eq:13}
\end{align}
であり，よって第一式を第二式に代入して
\begin{align}
  f'(p) = \dfrac{2\beta}{3(1-\beta^2)} \label{eq:14}
\end{align}
である．図から
\begin{align}
  -1 < \beta \le 0 \label{eq:15}
\end{align}
だから，\cref{eq:14}より
\begin{align}
  f'(p) > 0 \label{eq:16}
\end{align}
である．つまり$f(p)$は単調増加である．

さらに\cref{eq:13}の両辺を$p$で微分して
\begin{align}
  &
  \begin{cases}
    0 = -6\beta\left(\dfrac{d\beta}{dp}\right)^2 + 3(1-\beta^2) \dfrac{d^2\beta}{dp^2} \\
    f''(p) = 2\left(\dfrac{d\beta}{dp}\right)^2 + 2\beta\dfrac{d^2\beta}{dp^2}
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    \dfrac{d^2\beta}{dp^2} = \dfrac{2\beta}{3(1-\beta^2)}\left(\dfrac{d\beta}{dp}\right)^2 \\
    f''(p) = 2\left(\dfrac{d\beta}{dp}\right)^2 + 2\beta\dfrac{d^2\beta}{dp^2}
  \end{cases}
\end{align}
を得る．ここで\cref{eq:15}と第一式から
\begin{align}
  \dfrac{d^2\beta}{dp^2} < 0
\end{align}
だから，第二式において
\begin{align}
  f''(p) >0
\end{align}
だ従う．

以上から$f'(p),f''(p)>0$で$0 \le p < 2$ では下に凸な単調増加関数である．
これと$f(0)=-3,\lim_{p\to 2}f(p)=-2$より増減表は以下のようになる．
