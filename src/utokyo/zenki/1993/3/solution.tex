{\bf [解]}

$R(X,Y)$とおく．
題意で与えられた二つの領域$l,m$
\begin{align}
  \begin{cases}
    l=\{(-5,y)|-5<y<5\} \\
    m=\{(5,y)|-5<y<5\}
  \end{cases}
\end{align}
および，二つの点$P(-9,-3). Q(9,3)$，これらと点$R$の距離$d(P,R), d(Q,R)$を図示すると下図のようになる．
ここで，$l,m$の端点を$L_1(5,5), L_2(5,-5),L_3(-5,-5),L_4(-5,5)$とした．

ここで，$A,B,C,D,e$は以下のような領域である．ただし，$A,B,C$のみ境界を含むとする．
$A,B,C,D,E$で$xy$平面上の全ての点を網羅する．

\begin{itemize}
  \item[A,B] $d(P,R),d(Q,R)$がいずれも直線となる領域
  \item[C]   $d(P,R),d(Q,R)$がいずれも折れ線となる領域
  \item[D]   $d(P,R)$は直線，$d(Q,R)$が折れ線となる領域
  \item[E]   $d(P,R)$は折れ線，$d(Q,R)$が直線となる領域
\end{itemize}

さて，まずは$D$について考えよう．この領域は$PQ$の垂直二等分線よりも左側にあるから，
常に$|PR|<|QR|$が成立する．さらに$d(Q,R)$は折れ線となるから$|QR|<d(Q,R)$であり，よって
\begin{align}
  d(P,R)=|PR|<|QR|<d(Q,R) \quad \therefore d(P,R)<d(Q,R)
\end{align}
となり，題意の条件を満たすことはない．よって考えなくて良い．
全く同様に$E$についても$d(P,R)>d(Q,R)$となって考える必要はないから，以下$A,B,C$について考える．

次に$A,B$について考える．この領域では$d(P,R),d(Q,R)$がいずれも直線だから，
\begin{align}
  d(P,R)=d(Q,R) \iff |PR| = |QR|
\end{align}
であり，これを満たすのは$PQ$の垂直二等分線$y=-3x$上の点のみである．よってこの領域で条件を満たすのは
\begin{align}
  y = -3x \quad (x\le -3,3 \le x) \label{eq:1}
\end{align}
である．

次に$C$について考える．この領域では$d(P,R),d(Q,R)$はいずれも折れ線で，折れ線は$L_k\,(k=1,2,3,4)$のいずれかを経由する．
すなわち
\begin{align}
  \begin{cases}
    d(P,R) = \min \{ |PL_3| + |L_3R|, |PL_4| + |L_4R| \} \\
    d(Q,R) = \min \{ |QL_1| + |L_1R|, |QL_2| + |L_2R| \}
  \end{cases} \label{eq:2}
\end{align}
である．
これらの要素が等しくなる境界を考えると，$|PL_3| = |QL_1| = 2\sqrt{5}$， $|PL_4| = |QL_2| = 4\sqrt{5}$ だから
\begin{align}
  |PL_3| + |L_3R| = |PL_4| + |L_4R| &\iff |L_3R| - |L_4R| = 2\sqrt{5} \label{eq:3} \\
  |QL_1| + |L_1R| = |QL_2| + |L_2R| &\iff |L_1R| - |L_2R| = 2\sqrt{5} \label{eq:4}
\end{align}
である．よってこれらを満たす点$R$の集合は点$L_3,L_4$および点$L_1,L_2$を焦点とする双曲線で，
\begin{align}
  \begin{cases}
    \dfrac{(x+5)^2}{20} - \dfrac{y^2}{5} = -1 & (|L_3R| - |L_4R| = 2\sqrt{5}) \\
    \dfrac{(x-5)^2}{20} - \dfrac{y^2}{5} = -1 & (|L_1R| - |L_2R| = 2\sqrt{5})
  \end{cases} \label{eq:5}
\end{align}
と与えられる．

そこで領域$C$をさらに\cref{eq:2}に基づく$d(P,R),d(Q,R)$の表式によって$C_1,C_2,C_3$に分割する．

      $\bullet\ C_2$: $d(P,R) = |PL_3|+|L_3R|,\quad d(Q,R) = |QL_2|+|L_2R|$\\[2pt]

  \label{fig:region_c_subdivision}
\end{figure}

ただし，各領域での$d(P,R),d(Q,R)$は
\begin{align}
  \begin{cases}
    C_1 : d(P,R) = |PL_4| + |L_4R|, \quad d(Q,R) = |QL_1| + |L_1R| \\
    C_2 : d(P,R) = |PL_3| + |L_3R|, \quad d(Q,R) = |QL_2| + |L_2R| \\
    C_3 : d(P,R) = |PL_3| + |L_3R|, \quad d(Q,R) = |QL_1| + |L_1R|
  \end{cases} \label{eq:6}
\end{align}
で与えられる．

まず $C_1, C_2$ について，対称性から $C_1$ のみ考える．
\cref{eq:6}から題意の条件は
\begin{align}
  d(P,R) = d(Q,R) \iff |PL_4| + |L_4R| = |QL_1| + |L_1R| \iff |L_1R| - |L_4R| = 2\sqrt{5}
\end{align}
であり，これを満たす点 $R$ は，双曲線
\begin{align}
  \dfrac{x^2}{5} - \dfrac{(y-5)^2}{20} = 1 \label{eq:7}
\end{align}
上にある．
対称性から$C_2$については題意を満たす点$R$は，双曲線
\begin{align}
  \dfrac{x^2}{5} - \dfrac{(y+5)^2}{20} = 1 \label{eq:8}
\end{align}
上にある．

次に$C_3$ について，\cref{eq:6}から題意の条件は
\begin{align}
  d(P,R) = d(Q,R) \iff |PL_3| + |L_3R| = |QL_1| + |L_1R| \iff |L_3R| = |L_1R|
\end{align}
であり，これを満たす点$R$は $|L_1L_3|$ の垂直二等分線 $y = -x$ 上にある．
これと$C_2$の境界\cref{eq:5}との交点を考えると$y$を消去して
\begin{align}
  \begin{cases}
    \dfrac{(x+5)^2}{20} - \dfrac{(-x)^2}{5} = -1 \\
    \dfrac{(x-5)^2}{20} - \dfrac{(-x)^2}{5} = -1
  \end{cases} \\
  \begin{cases}
    3x^2 - 10x - 45 = 0 \\
    3x^2 + 10x - 45  = 0
  \end{cases} \\
  \begin{cases}
    x = \dfrac{5 \pm 4\sqrt{10}}{3} \\
    x = \dfrac{-5 \pm 4\sqrt{10}}{3}
  \end{cases}
\end{align}
であり，$-5 \le x \le 5$であることと合わせると
\begin{align}
  x = \dfrac{5 - 4\sqrt{10}}{3}, \dfrac{-5 + 4\sqrt{10}}{3}
\end{align}
であるから領域は
\begin{align}
  y = -x \quad \left(\dfrac{5 - 4\sqrt{10}}{3} \le x \le \dfrac{-5 + 4\sqrt{10}}{3}\right) \label{eq:9}
\end{align}
である．

以上\cref{eq:1,eq:7,eq:8,eq:9}をまとめて，求める軌跡は
\begin{align}
  \begin{cases}
    y = -3x & (|x| \ge 3) \\
    y = -x & \Bigl( |x| \le \dfrac{-5+4\sqrt{10}}{3} \Bigr) \\
    \dfrac{x^2}{5} - \dfrac{(y-5)^2}{20} = 1 & (C_1 \text{内}) \\
    \dfrac{x^2}{5} - \dfrac{(y+5)^2}{20} = 1 & (C_2 \text{内})
  \end{cases}
\end{align}
だから，図示して下図太線部である．

{\bf [解説]}

楕円と双曲線の図形的定義が使える問題だ．
この機会に復習しておこう．

まず楕円について，焦点$A(-c,0),B(c,0)$に対して動点$P$が$|AP| + |BP| = 2a$ を満たす時，
その軌跡は楕円
\begin{align}
  \dfrac{x^2}{a^2} + \dfrac{y^2}{a^2-c^2} = 1
\end{align}
となる．

次に双曲線について，同じく焦点$A(-c,0),B(c,0)$に対して動点$P$が$||AP| - |BP|| = 2a$ を満たす時，
その軌跡は双曲線
\begin{align}
  \dfrac{x^2}{a^2} - \dfrac{y^2}{c^2-a^2} = 1
\end{align}
となる．漸近線は
\begin{align}
  \dfrac{x}{a} \pm \dfrac{y}{\sqrt{c^2-a^2}} = 0
\end{align}
である．
