{\bf [解答]}
\paragraph{(1)}

与えられた数列
\begin{align}
  \begin{cases}
    a_{n+2} = 3a_{n+1} - 7a_n \\
    a_1 = 1, a_2 = 3
  \end{cases} \label{eq:1}
\end{align}
について考える．

$a_n$ を 2 でわったあまりを $b_n$ とすると，
\cref{eq:1}より
\begin{align}
  \begin{cases}
    b_1 = 1, \quad b_2 = 1 \\
    b_{n+2} \equiv 3b_{n+1} - 7b_n \equiv b_{n+1} - b_n
  \end{cases} \label{eq:2}
\end{align}
である．$a_n$ が偶数，すなわち$b_n\equiv 0$ であることと $ n \equiv 0 \pmod 3$ が同値であることを帰納的に示す．

まず$n=1,2,3$ の時は\cref{eq:2}より
\begin{align}
  b_1 = 1, \quad b_2 = 1, \quad b_3 = 0
\end{align}
だから，確かに$b_n \equiv 0$と$n \equiv 0 \pmod 3$である．

そこで次に$n = 3k-2, 3k-1, 3k$ ($k \in \mathbb{N}$) の時に題意が成立とすると，
$n=3k+1,3k+2,3k+3$の時，\cref{eq:2}から
\begin{align}
  b_{3k+1} = 1, \quad b_{3k+2} = 1, \quad b_{3k+3} = 0
\end{align}
だから，$n = 3k+1 \sim 3k+3$ でも$b_n \equiv 0$と$n \equiv 0 \pmod 3$である．

以上より数学的帰納法により題意は示された．

\paragraph{(2)}

$a_n$が$10$の倍数であるということは，$a_n$が偶数かつ$5$の倍数であるということである．
(1)で$a_n$が偶数である条件を調べたので，次に$a_n$ が 5 の倍数になる条件を調べる．
$a_n$ を 5 でわったあまりを $c_n$ とおくと，\cref{eq:1}から
\begin{align}
  \begin{cases}
    c_1 = 1, \quad c_2 = 3 \\
    c_{n+2} \equiv 3c_{n+1} - 2c_n
  \end{cases} \label{eq:3}
\end{align}
より，$c_n$ は，$\{1, 3, 2, 0\}$ のくり返しであるから，
$c_n \equiv 0$であることは$n \equiv 4 \pmod 4$と同値である．
(1) と合わせて，
\begin{align}
  \text{「} a_n \text{ が 10 の倍数} \iff n \text{ が 12 の倍数} \text{」}
\end{align}
である．
