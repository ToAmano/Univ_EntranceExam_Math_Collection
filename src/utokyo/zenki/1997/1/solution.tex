題意の点$A(a,0),B(0,b)$の中点を $M$ とすると，正三角形の性質から
$|MC| = \dfrac{\sqrt{3}}{2} AB$ 及び $|MC| \perp |AB|$ だから，
$\vec{AB} =
\begin{pmatrix} -a \\ b
\end{pmatrix}$
より
\begin{align}
  \vec{MC} &= \pm \dfrac{\sqrt{3}}{2}
  \begin{pmatrix} b \\ a
  \end{pmatrix}
\end{align}
となり，
\begin{align}
  \vec{OC} &= \vec{OM} + \vec{MC} \\
  &= \dfrac{1}{2}
  \begin{pmatrix} a \\ b
  \end{pmatrix} \pm \dfrac{\sqrt{3}}{2}
  \begin{pmatrix} b \\ a
  \end{pmatrix} \\
  &= \dfrac{1}{2}
  \begin{pmatrix} a \pm \sqrt{3}b \\ b \pm \sqrt{3}a
  \end{pmatrix} \quad (\text{複号同順})
\end{align}
である．

題意より$C$ は第1象限の点だから複号正を採用して，
$C\left(\dfrac{a + \sqrt{3}b}{2}, \dfrac{b + \sqrt{3}a}{2}\right)$ である．
$\triangle ABC$ が $D$ に含まれるには， $A, B, C$ が $D$ に含まれていれば良い．
$a, b > 0$ とあわせてこのような条件は
\begin{align}
  \begin{cases}
    0 < a \le 1, \quad 0 < b \le 1 \\
    0 \le a + \sqrt{3}b \le 2, \quad 0 \le b + \sqrt{3}a \le 2
  \end{cases} \label{eq:1}
\end{align}
である．これを図示して求めるのは下図斜線部である．ただし境界は含むが軸は除く．

\paragraph{(2)}

$\triangle ABC$ の一辺は $\sqrt{a^2+b^2}$ だからこの面積は
\begin{align}
  S &= \dfrac{\sqrt{3}}{4}(a^2+b^2) \label{eq:2}
\end{align}
となり， $a^2+b^2$ ($\equiv T$ とする)が最大の時 $S$ も最大である．
$T$ は $(a,b)$ と $(0,0)$ の距離の2乗に等しく，(1)の$ab$平面の領域図から，
最大値の候補は領域の頂点 $(1, 2-\sqrt{3})$， $(2-\sqrt{3}, 1)$， $(\sqrt{3}-1, \sqrt{3}-1)$ である．
各々について $T$ を計算すると， 順に $8-4\sqrt{3}$， $8-4\sqrt{3}$， $8-4\sqrt{3}$ で全て等しいので\cref{eq:2}に代入して求める最大値は
\begin{align}
  \max S &= -3 + 2\sqrt{3}
\end{align}
である．この時 $(a,b) = (1, 2-\sqrt{3}), (2-\sqrt{3}, 1), (\sqrt{3}-1, \sqrt{3}-1)$ である．
