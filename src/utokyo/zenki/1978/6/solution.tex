{\bf [解]}

\paragraph{(1)}

$P(t, t^2)$ とおく．ただし$0 \le t \le 1$とする．
点 $P$ での $y=x^2$ の接線は $y = 2tx - t^2$ だから，この接線と$y=0,x=1$の交点$A,B$の座標は
\begin{align}
  A\Bigl(\dfrac{t}{2}, 0\Bigr), \quad B(1, 2t-t^2) \label{eq:1}
\end{align}
となる．また，簡単のため$P$から$x$軸，および$BC$に下ろした垂足を$P',P''$とする．

したがって，$\triangle PAC, \triangle PCB$の面積$g(t), h(t)$はそれぞれ
\begin{align}
  \begin{cases}
    g(t) = \dfrac{1}{2}|AC||PP'| = \dfrac{1}{2}\Bigl(1 - \dfrac{t}{2}\Bigr) t^2 = \dfrac{1}{4}(2-t)t^2 \\[1ex]
    h(t) = \dfrac{1}{2}|BC||PP''| = \dfrac{1}{2}(2t - t^2)(1-t)
  \end{cases}
\end{align}
となる．$0 < t \le 1$ のとき，これらの大小関係は
\begin{align}
  g(t) \le h(t)
  &\iff \dfrac{1}{2}(2t - t^2)(1-t) - \dfrac{1}{4}(2-t)t^2 \ge 0 \\
  &\iff 2(2-t)(1-t)t - (2-t)t^2 \ge 0 \\
  &\iff (2-t)t(2-3t) \ge 0 \\
  &\iff 0 \le t \le \dfrac{2}{3}
\end{align}
だから，$t$ を $x$ に置き換えて，$g(t)\le h(t)$となるのは
\begin{align}
  0 < x \le \dfrac{2}{3}
\end{align}
の時である．

放物線$y=x^2$ が下に凸だから，線分$P\alpha,P\beta$が$M$の内部にあるためには$\alpha,\beta$が$P$での接線よりも下側になければならない．従って\cref{eq:1}より
\begin{align}
  \dfrac{t}{2} \le a \le 1, \quad 0 \le b \le 2t - t^2 \label{eq:2}
\end{align}
である．以下 $t$ の値を固定して考える．
