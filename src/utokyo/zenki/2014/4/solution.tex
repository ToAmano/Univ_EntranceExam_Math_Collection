\paragraph{(1)}

\cref{eq:1}及び$0<x<1$から$0<e^{-qx}<1$だから，
\begin{align}
  0<(1-p)x<x,\qquad 0<(1-x)(1-e^{-qx})<1-x
\end{align}
が成り立つ．辺々加えて
\begin{align}
  0<f(x)<1
\end{align}
を得る．

\paragraph{(2)}

(1)及び$0<x_0<1$から，帰納的に任意の$n\ge0$に対して
\begin{align}
  0<x_n<1 \label{eq:2}
\end{align}
である．従って\cref{eq:1}と合わせて
\begin{align}
  1-qx_n \le e^{-qx_n} < 1 \label{eq:3}
\end{align}
が成立することに注意する．
$0<x_{n+1}=f(x_n)$を上から評価すると
\begin{align}
  0 < x_{n+1}
  &=(e^{-qx_n}-p)x_n+1-e^{-qx_n}\\
  &\le(e^{-qx_n}-p)x_n+qx_n \quad (\because\text{\cref{eq:3}}) \\
  &=(e^{-qx_n}-p+q)x_n\\
  &<(1-p+q)x_n \quad (\because\text{\cref{eq:3}})
\end{align}
である．両辺絶対値をとってくり返し用いると，
\begin{align}
  |x_n|<|1-p+q|^nx_0 \label{eq:4}
\end{align}
を得る．
ここで題意より$p>q$だから，\cref{eq:1}と合わせて
\begin{align}
  0<q<p<1 \quad \therefore 0 < 1-p+q < 1
\end{align}
だから\cref{eq:4}において$n\to\infty$とすれば右辺は$0$に収束する．
従って挟み撃ちの定理から
\begin{align}
  \lim_{n\to\infty} |x_n| = 0
\end{align}
である．よって題意は示された．

$g(x)=f(x)-x$とおくと，$0<x<1$かつ$g(x)=0$なる$x$があることを示せば良い．
この区間では\cref{eq:1}より
\begin{align}
  e^{-qx} \ge -qx + 1 \label{eq:5}
\end{align}
であることに注意して，具体的に$g(x)$を計算すると
\begin{align}
  g(x)
  &=-px+(1-x)(1-e^{-qx})\\
  &=(e^{-qx}-1-p)x+(1-e^{-qx})\\
  &\ge(-qx-p)x+(1-e^{-qx}) \quad (\because\text{\cref{eq:5}}) \label{eq:6}
\end{align}
である．この右辺を$h(x)$とおく：
\begin{align}
  h(x)=-qx^2-px+1-e^{-qx}
\end{align}
と，一階・2階微分は
\begin{align}
  h'(x)&=-2qx-p+qe^{-qx} \\
  h''(x)&=-2q-q^2e^{-qx} < 0 \quad (\because q>0,\ e^{-qx}>0)
\end{align}
となって$h'(x)$は単調減少である．
さらに$0<x<1$において
\begin{align}
  h'(0)=q-p>0 \quad (\because p<q),\qquad
  h'(1)=q(e^{-q}-2)-p<0 \quad(\because e^{-q}<1,\ p>0)
\end{align}
だから区間内で$h'(x)$は一回符号を変え，$h'(\alpha)=0$なる$\alpha$が$0<\alpha<1$に存在する．
従って$h(x)$の増減表は以下のようになる．

$h(0)=0$だから増減表より
\begin{align}
  g(x)\ge h(x)>0
\end{align}
なる$x=\beta$が$0<x<1$に存在する．これと
\begin{align}
  g(1)=f(1)-1=(1-p)-1=-p<0
\end{align}
であること，および$g$が連続であることから，$0<\beta<x<1$の間で$g(x)=0$なる$x$が存在する．$\blacksquare$
