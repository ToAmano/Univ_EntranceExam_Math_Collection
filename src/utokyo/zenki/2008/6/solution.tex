{\bf [解]}
$f(t)=\cos2t$，$g(t)=t\sin t$とおく．以下，$C=\cos t$，$S=\sin t$とする．
\begin{align}
f'(t)=-2\sin2t=-4SC,\qquad g'(t)=tC+S
\end{align}

$f'(t)=0$となるのは$t=0,\dfrac{\pi}{2},\pi,\dfrac{3\pi}{2},2\pi$の時で，$f'$の符号は$\left(0,\dfrac{\pi}{2}\right)$で負，$\left(\dfrac{\pi}{2},\pi\right)$で正，$\left(\pi,\dfrac{3\pi}{2}\right)$で負，$\left(\dfrac{3\pi}{2},2\pi\right)$で正である．

$g'(0)=0$であり，$g'\left(\dfrac{\pi}{2}\right)=1>0$，$g'(\pi)=-\pi<0$，$g'\left(\dfrac{3\pi}{2}\right)=-1<0$，$g'(2\pi)=2\pi>0$だから，$g'$は連続性より，$0<\alpha<\pi$，$\pi<\beta<2\pi$に，$g'(\alpha)=g'(\beta)=0$なる$\alpha,\beta$がそれぞれ一意に存在し，$g'$は$(0,\alpha)$で正，$(\alpha,\beta)$で負，$(\beta,2\pi)$で正である．したがって$g$は$t=\alpha$で極大，$t=\beta$で極小をとる．

ここで，$(1,0)$（$t=0,\pi,2\pi$に対応）以外にグラフの交わる点があると仮定し，対応する$t$を$t_1,t_2$とすると（$t_1\ne t_2$），
\begin{align}
\cos2t_1&=\cos2t_2\quad\cdots①\\
t_1\sin t_1&=t_2\sin t_2\quad\cdots②
\end{align}

①及びまず$0<t<\pi$で考えると，
\begin{align}
2t_2=2n\pi\pm2t_1\ (n\in\mathbb Z)\implies t_2=n\pi\pm t_1
\end{align}
であり，$0<t_1,t_2<\pi$から$t_2=\pi-t_1$（$\because t_1\ne t_2$）である．②に代入して
\begin{align}
t_1\sin t_1=(\pi-t_1)\sin t_1\quad\therefore\ t_1=\dfrac{\pi}{2}\quad(\because0<t_1<\pi\text{から}\sin t_1\ne0)
\end{align}
となるが，この時$t_2=\pi-\pi/2=\pi/2=t_1$となって矛盾．よって$0<t<\pi$では交点はない．同様に$\pi<t<2\pi$でも交点はなく，$0<t<\pi$では$g(t)>0$，$\pi<t<2\pi$では$g(t)<0$であることとあわせて，曲線の交点は$(1,0)$だけであり，グラフは図のようになる．

求める面積$S$のうち，$y\ge0$に含まれるものを$S_1$，$y\le0$に含まれるものを$S_2$とすると，
\begin{align}
S=S_1+S_2\quad\cdots③
\end{align}
である．$0\le t\le\pi$の部分は単純閉曲線であり，$x=f(t)$は$\left[0,\dfrac{\pi}{2}\right]$で単調減少，$\left[\dfrac{\pi}{2},\pi\right]$で単調増加だから，標準的な媒介変数表示による面積公式（符号に注意）から
\begin{align}
S_1=\int_0^\pi g(t)f'(t)\,dt\quad\cdots④
\end{align}
であり，同様に$\pi\le t\le2\pi$の部分（$y\le0$）から
\begin{align}
S_2=-\int_\pi^{2\pi}g(t)f'(t)\,dt\quad\cdots⑤
\end{align}
となる．ここで，
\begin{align}
g(t)f'(t)=tS\cdot(-4SC)=-4tC(1-C^2)=-4(tC-tC^3)
\end{align}
である．また，
\begin{align}
\int tC\,dt&=tS+C\\
\int tC^3\,dt&=\dfrac{3}{4}\int tC\,dt+\dfrac{1}{4}\int t\cos3t\,dt=\dfrac{3}{4}(tS+C)+\dfrac{1}{12}t\sin3t+\dfrac{1}{36}\cos3t
\end{align}
（$\because\cos^3t=\dfrac{3}{4}\cos t+\dfrac{1}{4}\cos3t$，$\int t\cos3t\,dt=\dfrac{1}{3}t\sin3t+\dfrac{1}{9}\cos3t$）だから，
\begin{align}
\int g(t)f'(t)\,dt=-4\int tC\,dt+4\int tC^3\,dt=-4(tS+C)+3(tS+C)+\dfrac{1}{3}t\sin3t+\dfrac{1}{9}\cos3t=-(tS+C)+\dfrac{1}{3}t\sin3t+\dfrac{1}{9}\cos3t
\end{align}
これを$F(t)$とおくと，$t=0,\pi,2\pi$で$S=0$，$\sin3t=0$だから，
\begin{align}
F(0)=-1+\dfrac{1}{9}=-\dfrac{8}{9},\qquad F(\pi)=1-\dfrac{1}{9}=\dfrac{8}{9},\qquad F(2\pi)=-1+\dfrac{1}{9}=-\dfrac{8}{9}
\end{align}
だから，
\begin{align}
S_1&=F(\pi)-F(0)=\dfrac{8}{9}-\left(-\dfrac{8}{9}\right)=\dfrac{16}{9}\\
S_2&=-\{F(2\pi)-F(\pi)\}=-\left(-\dfrac{8}{9}-\dfrac{8}{9}\right)=\dfrac{16}{9}
\end{align}

だから③から
\begin{align}
S=\dfrac{16}{9}+\dfrac{16}{9}=\dfrac{32}{9}
\end{align}
