正八面体は上図のように正三角形が$8$枚繋がってできた立体であり，上面$\triangle ABC$と底面$\triangle DEF$は平行である．真上から正八面体を見た時の図は従って，これらの点が作る図形になる．正三角形の一辺$1$として一般性を失わない．また$\theta=\dfrac{2\pi}{3}$として$c=\cos\theta,s=\sin\theta$とかき，$r=\dfrac{1}{\sqrt{3}}$とする．

上図のように三角形$DEF$の重心を原点$O(0,0,0)$とし，
\begin{align}
  D(r,0,0),E(rc,rs,0),F(rc,-rs,0)
\end{align}
とする．
点$C$について考えると$|BC|=|EC|$から$C$は線分$BE$の二等分面$DG_1G_2 (y=0)$の上にある．
同様に考えると$A$は平面$EG_1G_2$の，$B$は平面$FG_1G_2$の上にある．従ってその座標はこれらの点の$z$座標を$Z$として
\begin{align}
  A(-rc,-rs,Z), B(-rc,rs,Z), C(-r,0,Z)
\end{align}
と書ける．

\paragraph{(2)}

正八面体の6頂点 $A \sim F$ とし，面 ABC，面 DEF の重心を $G_1, G_2$ とする．直線 $G_1 G_2$ を $l$ とおく．$l$ は面 ABC，面 DEF と垂直である．$\vec{G_1 G_2} = \vec{a}$ とおき，$\vec{G_1 P} = t \vec{a} \; (0 \le t \le 1)$ なる点 $P$ を含み $l$ に垂直な平面で立体を切断する．この時の断面は右図である．下図のように頂点をおく．

三角形の相似から
\begin{align}
  \begin{cases}
    |LK| = |MH| = |IJ| = 1-t \\
    |HI| = |KJ| = |LM| = t
  \end{cases}
\end{align}
となり，これを回転させた面積 $S(t)$ は
\begin{align}
  S(t) = \pi \cdot |PJ|^2 \label{eq:1}
\end{align}
である．$\triangle PXJ$に三平方の定理を用いて
\begin{align}
  |PJ|^2
  &= |PX|^2+|XJ|^2
  = \left(\dfrac{1}{2}t\right)^2 + \left\{ \dfrac{\sqrt{3}}{2}(2-t) \right\}^2
  = \dfrac{1}{12}(4t^2 - 4t + 4)
  = \dfrac{1}{3}(t^2 - t + 1)
\end{align}
だから\cref{eq:1}に代入して
\begin{align}
  S(t) = \dfrac{\pi}{3}(t^2 - t + 1) \label{eq:2}
\end{align}
である．

\end{align}
である．
