\begin{align}
\begin{cases}
\dfrac{2.7}{a} \le u \le \dfrac{3.3}{a} \\

\end{cases} \quad \dots \text{①}

\paragraph{(2)}

まず $Z$ の存在条件から，判別式が 0 以上で，
\begin{align}
b^2 - ac \ge 0 \iff \Bigl(\dfrac{b}{a}\Bigr)^2 - \Bigl(\dfrac{c}{a}\Bigr) \ge 0 \quad (\because a > 0) \iff u^2 - v \ge 0 \quad \dots \text{①}
\end{align}
この領域を $(u, v)$ が動く時，①は常に満たされる．又，
\begin{align}
Z = \dfrac{b + \sqrt{b^2 - ac}}{a} = u + \sqrt{u^2 - v} \quad \dots \text{②}
\end{align}
ここで，(1) の領域は，式にすると，
\begin{align}
\begin{cases}
\dfrac{27}{11} \le u \le 3 \text{ の時，} \dfrac{45}{11} \le v \le 2u \\
3 \le u \le \dfrac{11}{3} \text{ の時，} \dfrac{15}{11}u \le v \le 6
\end{cases} \quad \dots \text{③}
\end{align}
であることに注意すると，②で $u$ を固定した時，$Z$ は $v$ の単調減少関数だから
\begin{align}
\begin{cases}
\dfrac{27}{11} \le u \le 3 \text{ の時，} \min Z = u + \sqrt{u^2 - 2u}, \quad \max Z = u + \sqrt{u^2 - \dfrac{45}{11}} \\
3 \le u \le \dfrac{11}{3} \text{ の時，} \min Z = u + \sqrt{u^2 - 6}, \quad \max Z = u + \sqrt{u^2 - \dfrac{15}{11}u}
\end{cases} \quad \dots \text{④}
\end{align}
次に $u$ を動かす．

$1^\circ$ $\min Z$ について
$u$ の候補は，$u = \dfrac{27}{11}$ の時の $Z = \dfrac{27+3\sqrt{15}}{11}$ か，$u = 3$ の時の $Z = 3+\sqrt{3}$ である．前者の方が小さいので，
\begin{align}
\min Z = \dfrac{27+3\sqrt{15}}{11}
\end{align}

$2^\circ$ $\max Z$ について
$u$ の候補は，$u = 3$ の時の $Z = 3+3\sqrt{\dfrac{2}{11}}$，$u = \dfrac{11}{3}$ の時の $Z = \dfrac{11+2\sqrt{19}}{3}$ である．後者の方が大きいので，
\begin{align}
\max Z = \dfrac{11+2\sqrt{19}}{3}
\end{align}

以上から
\begin{align}
\begin{cases}
\min Z = \dfrac{3}{11}(9 + \sqrt{15}) \\
\max Z = \dfrac{1}{3}(11 + 2\sqrt{19})
\end{cases}
\end{align}
