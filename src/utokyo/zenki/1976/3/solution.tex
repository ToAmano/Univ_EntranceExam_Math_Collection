\paragraph{【新課程】}
{\bf [解]}
$\cos\theta = c$，$s = \sin\theta$とおく．すると$P(5+rc, 5+rs)$とおけるから，
\begin{align}
  Q(13-rc, -5-rs), \quad R(-5-rs, 5+rc)
\end{align}
である．ゆえに
\begin{align}
  |QR|^2 &= \{(13-rc) - (-5-rs)\}^2 + \{(-5-rs) - (5+rc)\}^2 \nonumber\\
  &= (18-rc+rs)^2 + (-10-rs-rc)^2 \nonumber\\
  &= 18^2 + 10^2 + 2r^2 + 56rs - 16rc \nonumber\\
  &= 424 + 2r^2 + 8\sqrt{53}r\sin(\theta-\alpha)
\end{align}
である．ここで，$\alpha$は
\begin{align}
  \tan\alpha = \dfrac{2}{7}
\end{align}
を満たす数である．$0 \leqq \theta < 2\pi$から，
\begin{align}
  -\alpha \leqq \theta - \alpha < 2\pi - \alpha
\end{align}
であるから，$-1 \leqq \sin(\theta-\alpha) \leqq 1$である．ゆえに$r>0$から，
\begin{align}
  \begin{cases}
    f(r) = \sqrt{424-8\sqrt{53}r+2r^2} = \sqrt{2}|r-2\sqrt{53}| \\
    g(r) = \sqrt{424+8\sqrt{53}r+2r^2} = \sqrt{2}(r+2\sqrt{53})
  \end{cases}
\end{align}
である．また，$f(r)=0$のとき，$r=2\sqrt{53}$である．$\cdots\text{（答）}$

\paragraph{【旧課程】}
{\bf [解]}
点$P$の座標を$(x, y)$とする．
中心$K$，半径$R$の円に対して，点$P$からその円に接線が引けるための必要十分条件は，点$P$が円の外部または周上にあること，すなわち$|PK|^2 \geqq R^2$である．
このとき，接点までの距離の$2$乗は三平方の定理より$|PK|^2 - R^2$に等しい．
したがって，各円について以下の通りとなる．
\begin{itemize}
  \item 円$A$: 中心$(0, 0)$，半径$3$であるから，接線が引ける条件は$x^2 + y^2 \geqq 9$であり，
    \begin{align}
      \alpha(P)^2 = x^2 + y^2 - 9
    \end{align}
  \item 円$B$: 中心$(4, 3)$，半径$2$であるから，接線が引ける条件は$(x-4)^2 + (y-3)^2 \geqq 4$であり，
    \begin{align}
      \beta(P)^2 = (x-4)^2 + (y-3)^2 - 4
    \end{align}
  \item 円$C$: 中心$(5, -3)$，半径$1$であるから，接線が引ける条件は$(x-5)^2 + (y+3)^2 \geqq 1$であり，
    \begin{align}
      \gamma(P)^2 = (x-5)^2 + (y+3)^2 - 1
    \end{align}
\end{itemize}
条件式$\alpha(P)^2 + \beta(P)^2 + \gamma(P)^2 = 99$に代入して整理すると，
\begin{align}
  &(x^2 + y^2 - 9) + \{(x-4)^2 + (y-3)^2 - 4\} + \{(x-5)^2 + (y+3)^2 - 1\} = 99 \nonumber\\
  &\Longleftrightarrow 3x^2 + 3y^2 - 18x + 45 = 99 \nonumber\\
  &\Longleftrightarrow x^2 - 6x + y^2 = 18 \nonumber\\
  &\Longleftrightarrow (x-3)^2 + y^2 = 27
  \label{eq:1976-3old-circle}
\end{align}
を得る．この円を$\Gamma$とし，中心を$M(3, 0)$，半径を$\rho = 3\sqrt{3}$とおく．
点$P$が円$A, B, C$のすべてに接線を引くことができる条件を確認する．
\begin{itemize}
  \item 円$B$について: 中心$K_B(4, 3)$と$M(3, 0)$の距離は$|MK_B| = \sqrt{1^2 + 3^2} = \sqrt{10}$である．
    $\Gamma$上の点$P$に対し
    \begin{align}
      |PK_B| \geqq |PM| - |MK_B| = 3\sqrt{3} - \sqrt{10} > 5.19 - 3.17 = 2.02 > 2
    \end{align}
    であるから，$\Gamma$上のすべての点は円$B$の外部にある．
  \item 円$C$について: 中心$K_C(5, -3)$と$M(3, 0)$の距離は$|MK_C| = \sqrt{2^2 + (-3)^2} = \sqrt{13}$である．
    $\Gamma$上の点$P$に対し
    \begin{align}
      |PK_C| \geqq |PM| - |MK_C| = 3\sqrt{3} - \sqrt{13} > 5.19 - 3.61 = 1.58 > 1
    \end{align}
    であるから，$\Gamma$上のすべての点は円$C$の外部にある．
  \item 円$A$について: \eqref{eq:1976-3old-circle}より$x^2 + y^2 = 18 + 6x$であるから，
    \begin{align}
      x^2 + y^2 \geqq 9 \Longleftrightarrow 18 + 6x \geqq 9 \Longleftrightarrow x \geqq -\dfrac{3}{2}
    \end{align}
    である．
\end{itemize}
円$\Gamma$と円$A$の交点は，$x = -\dfrac{3}{2}$を$x^2 + y^2 = 9$に代入して
\begin{align}
  y = \pm \sqrt{9 - \dfrac{9}{4}} = \pm \dfrac{3\sqrt{3}}{2}
\end{align}
となり，$P_1\left(-\dfrac{3}{2}, \dfrac{3\sqrt{3}}{2}\right)$，$P_2\left(-\dfrac{3}{2}, -\dfrac{3\sqrt{3}}{2}\right)$である．
中心$M(3, 0)$から見た$P_1$の偏角$\theta_1$は
\begin{align}
  \cos\theta_1 &= \dfrac{-\dfrac{3}{2} - 3}{3\sqrt{3}} = -\dfrac{\sqrt{3}}{2} \nonumber\\
  \sin\theta_1 &= \dfrac{\dfrac{3\sqrt{3}}{2}}{3\sqrt{3}} = \dfrac{1}{2}
\end{align}
より$\theta_1 = \dfrac{5\pi}{6}$であり，同様に$P_2$の偏角は$\theta_2 = -\dfrac{5\pi}{6}$である．
したがって，除外される劣弧（$x < -\dfrac{3}{2}$の部分）の中心角は
\begin{align}
  2\pi - 2 \times \dfrac{5\pi}{6} = \dfrac{\pi}{3}
\end{align}
であるから，条件$x \geqq -\dfrac{3}{2}$を満たす優弧の中心角$\Theta$は
\begin{align}
  \Theta = 2\pi - \dfrac{\pi}{3} = \dfrac{5\pi}{3}
\end{align}
である．
ゆえに，求める曲線の長さ$L$は
\begin{align}
  L = 3\sqrt{3} \times \dfrac{5\pi}{3} = 5\sqrt{3}\pi \tag{答}
\end{align}
である．点$P$の全体が作る曲線は下図の太線部である（円$A$の内部に含まれる破線部は除く）．
