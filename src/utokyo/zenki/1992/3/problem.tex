$a$，$b$を正の実数とする．
座標空間の4点$P(0,0,0)$，$Q(a,0,0)$，$R(0,1,0)$，$S(0,1,b)$が半径1の同一球面上にあるとき，
$P$，$Q$，$R$，$S$を頂点とする四面体に内接する球の半径を$r$とすれば，
次の二つの不等式が成り立つことを示せ．
\begin{align*}
  { \left( \dfrac{1}{r}-\dfrac{1}{a}-\dfrac{1}{b} \right) }^2 \geqq \dfrac{20}{3} , \hspace{1\zw}
  \dfrac{1}{r} \geqq 2\sqrt{\dfrac{2}{3}}+2\sqrt{\dfrac{5}{3}}
\end{align*}
