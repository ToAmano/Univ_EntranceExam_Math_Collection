どちらの方向に$\dfrac{\pi}{2}$回転させても，$xy$平面での立体の面積$S$は半径$\sqrt{a^2+c^2}$と二辺が$a,c$の直角三角形二つの合計だから，求める体積$V$は
\begin{align}
  V = Sb = \left(ac + \dfrac{1}{4} \pi (a^2 +c^2)\right) b \label{eq:1}
\end{align}
である．

\paragraph{(2)}

与えられた条件
\begin{align}
  a + b + c = 1 \label{eq:2}
\end{align}
の元で\cref{eq:1}のとりうる範囲を示せば良い．

$\alpha = a+c$, $\beta = ac$ とおくと，$(a,c)$は二次方程式
\begin{align}
  x^2 - \alpha x + \beta = 0 \label{eq:3}
\end{align}
の解である．$a, c$ は0より大きい実数だから，条件は
\begin{align}
  \begin{cases}
    \text{判別式}: D \ge 0 \\
    \text{軸}:  0 < \alpha \\
    \text{端点}: f(0) > 0
  \end{cases} \\
  \begin{cases}
    \alpha^2 - 4\beta \ge 0 \\
    0 < \alpha, \beta
  \end{cases} \label{eq:4}
\end{align}
である．

\cref{eq:2} から
\begin{align}
  b = 1 - \alpha \label{eq:5}
\end{align}
で $0 < b$ から
\begin{align}
  \alpha < 1 \label{eq:6}
\end{align}
である．\cref{eq:4}に代入して
\begin{align}
  \begin{cases}
    \alpha^2 - 4\beta \ge 0 \\
    0 < \alpha < 1 \\
    0 < \beta
  \end{cases} \label{eq:7}
\end{align}
である．この領域を$(\alpha,\beta)$を図示すると下図の斜線部（境界は実線部のみ含む）になる．

\cref{eq:1}に代入して $V$ は $(\alpha,\beta)$ を用いて
\begin{align}
  V
  &= \left(\beta + \dfrac{1}{4}\pi (\alpha^2 - 2\beta)\right)(1-\alpha) \\
  &= (1-\alpha) \left\{ (1 - \dfrac{1}{2}\pi)\beta + \dfrac{1}{4}\pi \alpha^2 \right\} \label{eq:8}
\end{align}
である．これは図の区間内では$\beta$ の単調減少関数だから，$\alpha$ を固定すると，
\begin{align}
  & V\left(\beta = \dfrac{\alpha^2}{4}\right) \le V < V(\beta = 0) \\
  & (1-\alpha) \left\{ (1-\dfrac{1}{2}\pi)\dfrac{1}{4}\alpha^2 + \dfrac{1}{4}\pi \alpha^2 \right\} \le V < \dfrac{1}{4}\pi \alpha^2 (1-\alpha) \\
  & \left(1+\dfrac{\pi}{8}\right)\alpha^2(1-\alpha) \le V
  < \dfrac{\pi}{4}\alpha^2(1-\alpha) \label{eq:9}
\end{align}
である．ここで
\begin{align}
  f(\alpha) = \alpha^2(1-\alpha) \label{eq:10}
\end{align}
とおくと\cref{eq:9}は
\begin{align}
  \left(1+\dfrac{\pi}{8}\right) f(\alpha) \le V < \dfrac{\pi}{4} f(\alpha) \label{eq:11}
\end{align}
である．$f(\alpha)$の一階微分を計算して
\begin{align}
  f'(\alpha) = 2\alpha - 3\alpha^2 = \alpha(2-3\alpha)
\end{align}
だから$f(\alpha)$の増減表は以下のようになる．

したがって，$0 < f(\alpha) \le \dfrac{4}{27}$ だから\cref{eq:11}とあわせて，
\begin{align}
  & 0 < V < \dfrac{1}{4}\pi \dfrac{4}{27} = \dfrac{\pi}{27} \\
  \therefore
  &0 < V < \dfrac{\pi}{27}
\end{align}
である．
