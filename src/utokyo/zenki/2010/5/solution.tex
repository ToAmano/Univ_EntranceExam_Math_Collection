与えられた図形を$C: x^2+y^2=1$, $A(1, 0)$ とする．時刻 $t$ での $P, Q, R$ の位置は
\begin{align}
  P_t(\cos mt, \sin mt), Q_t(\cos t, \sin t), R_t(\cos(-2t), \sin(-2t))
\end{align}
とかける．$\angle P_tQ_tR_t = \angle R$ の時，円周角の定理より$P_t R_t$ が直径になることが必要である．ゆえに$P_t,R_t$の偏角は$n \in \mathbb{Z}$ として$\pi+2n\pi$だけ違うから
\begin{align}
  mt = -2t + (2n+1)\pi \quad \therefore (m+2)t = (2n+1)\pi \label{eq:1}
\end{align}
である．

又 $O R_t \perp O Q_t$ だから，$R_t,Q_t$の偏角は$l \in \mathbb{Z}$ として，$\dfrac{\pi}{2}+2l\pi$だけ違うから
\begin{align}
  t &= -2t + \dfrac{\pi}{2} + l\pi \\
  \therefore
  t &= \dfrac{\pi}{3}\left(\dfrac{1}{2} + l\right) \\
  &= \dfrac{\pi}{6}(1+2l) \label{eq:2}
\end{align}
である．$0 \le t \le 2\pi$より$l$として許されるのは
\begin{align}
  l = 0, 1, 2, 3, 4, 5 \label{eq:3}
\end{align}
である．

\cref{eq:1,eq:2}から$t$を消去して
\begin{align}
  \dfrac{\pi}{6}(m+2)(1+2l) = (2n+1)\pi \label{eq:4}
\end{align}
である．以下\cref{eq:3}の各$l$ごとに\cref{eq:4}を個別に考えると

\begin{itemize}
  \item $1^\circ \ l=0$: \cref{eq:3}から $(m+2) = 6(2n+1)$ だから $(m, n) = (4, 0)$
  \item $2^\circ \ l=1$: \cref{eq:3}から $(m+2) = 2(2n+1)$ だから $(m, n) = (4, 1), (8, 2)$
  \item $3^\circ \ l=2$: \cref{eq:3}から $5(m+2) = 6(2n+1)$ だから $(m, n) = (4, 2)$
  \item $4^\circ \ l=3$: \cref{eq:3}から $7(m+2) = 6(2n+1)$ だから $(m, n) = (4, 3)$
  \item $5^\circ \ l=4$: \cref{eq:3}から $3(m+2) = 2(2n+1)$ だから $(m, n) = (4, 4), (8, 7)$
  \item $6^\circ \ l=5$: \cref{eq:3}から $11(m+2) = 6(2n+1)$ だから $(m, n) = (4, 5)$
\end{itemize}

だから，以上まとめて，
\begin{align}
  (t, m) = \left(\dfrac{\pi}{6}, 4\right), \left(\dfrac{1}{2}\pi, 4\right), \left(\dfrac{1}{2}\pi, 8\right), \left(\dfrac{5}{6}\pi, 4\right), \left(\dfrac{7}{6}\pi, 4\right), \left(\dfrac{3}{2}\pi, 4\right), \left(\dfrac{3}{2}\pi, 8\right), \left(\dfrac{11}{6}\pi, 4\right)
\end{align}
である．
