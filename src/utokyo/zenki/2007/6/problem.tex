以下の問いに答えよ．
\begin{enumerate}
  \item $0<x<a$をみたす実数$x$，$a$に対し，次を示せ．
    \begin{align*}
      \dfrac{2x}{a} < \int_{a-x}^{a+x}\dfrac{1}{t}dt < x \left( \dfrac{1}{a+x}+\dfrac{1}{a-x} \right)
    \end{align*}
  \item (1)を利用して，次を示せ．
    \begin{align*}
      0.68 < \log 2 < 0.71
    \end{align*}
    ただし，$\log 2$は2の自然対数を表す．
\end{enumerate}
