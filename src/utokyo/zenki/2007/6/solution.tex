$P: y = \dfrac{1}{t}$ のグラフは $t > 0$ の時下に凸である．
従って点$(a,1/a)$での接線は$(1/t)'=-1/t^2$より
\begin{align}
  \ell: y = \dfrac{-1}{a^2}(t-a)+\dfrac{1}{a}
\end{align}
は$P$の下側にある．
$\ell$と$t=a+x,a-x$との交点をそれぞれ$C,D$, また$A(a-x,0), B(a+x,0)$とする．

また$E\left(a+x,\dfrac{1}{a+x}\right), F\left(a-x,\dfrac{1}{a-x}\right)$とすると線分$EF$は$P$の上側にある．従って上図で面積を比較して ($\because a-x > 0$)
\begin{align}
  & \text{台形} ABCD < \text{図形} ABEF < \text{台形} ABEF \\
  & \dfrac{|AB|(|BC|+|AD|)}{2} < \int_{a-x}^{a+x} \dfrac{1}{t} dt < \dfrac{|AB|(|BE|+|AF|)}{2} \\
  & \dfrac{2x}{a} < \int_{a-x}^{a+x} \dfrac{1}{t} dt < x \left( \dfrac{1}{a-x} + \dfrac{1}{a+x} \right) \label{eq:1}
\end{align}
である．よって題意は示された．

(1) と同様の評価を $[a-x, a]$，$[a, a+x]$ で行うことで以下の不等式を得る．
\begin{align}
  & \dfrac{x}{a - \dfrac{x}{2}} < \int_{a-x}^a \dfrac{1}{t} dt < \dfrac{1}{2} x \left( \dfrac{1}{a} + \dfrac{1}{a-x} \right) \\
  & \dfrac{x}{a + \dfrac{x}{2}} < \int_a^{a+x} \dfrac{1}{t} dt < \dfrac{1}{2} x \left( \dfrac{1}{a} + \dfrac{1}{a+x} \right)
\end{align}
これらの辺々足して，
\begin{align}
  2x \left( \dfrac{1}{2a-x} + \dfrac{1}{2a+x} \right) < \int_{a-x}^{a+x} \dfrac{1}{t} dt < \dfrac{1}{2} x \left( \dfrac{2}{a} + \dfrac{1}{a-x} + \dfrac{1}{a+x} \right) \label{eq:2}
\end{align}
である．この中辺の値は $\log \dfrac{a+x}{a-x}$ であることに注意して $a=3x$ ($0 < x < a$) を代入して
\begin{align}
  & \dfrac{2}{5} + \dfrac{2}{7} < \log 2 < \dfrac{1}{2} \left( \dfrac{2}{3} + \dfrac{3}{4} \right) \\
  & \dfrac{24}{35} < \log 2 < \dfrac{17}{24} \label{eq:3}
\end{align}
である．ここで，
\begin{align}
  \dfrac{24}{35} - \dfrac{68}{100}
  &= \dfrac{1}{5} \left( \dfrac{24}{7} - \dfrac{17}{5} \right)
  = \dfrac{1}{5} \cdot \dfrac{1}{35} > 0 \quad \therefore 0.68 < \dfrac{24}{35} \\
  \dfrac{71}{100} - \dfrac{17}{24}
  &= \dfrac{1}{600} (426 - 425)
  = \dfrac{1}{600} > 0 \quad \therefore 0.71 > \dfrac{17}{24}
\end{align}
だから，\cref{eq:3} とあわせて
\begin{align}
  0.68 < \log 2 < 0.71
\end{align}
である．よって示された．

\paragraph{(2)}

この問題の肝はうまいこと$a,b$を選んで(1)の評価が題意を示すのに十分正確にすることである．
積分は$\log \dfrac{a+x}{a-x}$だから，これが$\log 2$に等しいとすると自然に
\begin{align}
  \dfrac{a+x}{a-x} = \log 2 \quad \therefore a = 3x
\end{align}
となる．ところがこの問題の罠は，単にこれを用いると評価が緩すぎるということである．
[解答]では不等式の評価区間を二つに分けることで$a=3x$という自然な設定を用いながらも題意を証明できた．

別の発想としてよりよい$(a,b)$はないか？という解法が考えられる．
要するに$x=\dfrac{a}{3}$だと台形の幅が大きすぎるのだから，ここがより狭くなるような$x$を選べれば誤差が小さくなるだろうと考えられるから，例えば$\dfrac{a+x}{a-x}=\sqrt{2} \therefore x = (3-2\sqrt{2})a$だと$\log 2$が出てきつつも積分区間が狭くなるだろうと思えば以下のような解法があり得る．

$x = (3 - 2\sqrt{2})a$ とおいて\cref{eq:1}に代入すると
\begin{align}
  & 6 - 4\sqrt{2} < \dfrac{1}{2} \log 2 < \dfrac{15}{64} \\
  & 4(3 - 2\sqrt{2}) < \log 2 < \dfrac{1}{2}
\end{align}
である．$1.415 < \sqrt{2} < 1.42$ を示して用いることで，所望の不等式を得る．
