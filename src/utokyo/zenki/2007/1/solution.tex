{\bf [解答]}
$P(x)$ の $n$ 次以下の部分を $R_n(x)$，$Q_n(x) = (1+x)^k R_n(x)$ とおくと
$Q_n(x)$ の $n$ 次以下の項の係数が $\mathbb{Z}$ に属する時，$R_n(x)$ の全ての項の係数も $\mathbb{Z}$ に属することを示せば良い．そこで
\begin{align}
  \begin{cases}
    R_n(x) = \sum_{i=0}^n a_i x^i
    Q_n(x) = \sum_{i=0}^{n+k} b_i x^i \quad (b_i \text{ は } i=0,1,\dots,n+k \text{ の時整数})
  \end{cases}
\end{align}
とおくと，$Q_n(x)=(1+x)^{k}R_n(x)$に代入して二項定理で展開すると
\begin{align}
  \sum_{i=0}^{n+k} b_i x^i
  &= (1+x)^{k} \sum_{i=0}^n a_i x^i \\
  &= \sum_{p=0}^{k}\sum_{i=0}^n a_{i}x^{p+i} \label{eq:1}
\end{align}
である．

以下，題意を $i$ についての帰納法で示す．
$i=0$ の時は\cref{eq:1}より$b_0 = a_0$ となり，$a_0 \in \mathbb{Z}$ だから成立する．

そこで以下 $i \le l$ ($l=1,2,\dots,n-1$) での成立を仮定する，つまり$a_{1},\cdots,a_{l}$が整数だと仮定する．

\cref{eq:1}より$Q_n(x)$ の $l+1$ 次項は，
\begin{align}
  b_{l+1} x^{l+1}
  & = \sum_{p+i=l+1,p \le k, i \le n} a_{i} x^{l+1}
  = \sum_{i=\max{0,l+1-k}}^{l+1} a_{i}x^{l+1} \\
  \therefore
  a_{l+1} = b_{l+1} - \sum_{i=\max{0,l+1-k}}^{l} a_{i}
\end{align}
である．仮定より右辺が整数だから$a_{l+1}$も整数である．

以上から数学的帰納法により題意は示された．
