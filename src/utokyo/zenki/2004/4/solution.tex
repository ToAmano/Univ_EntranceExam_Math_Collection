\paragraph{(2)}

新しく
\begin{align}
  f(x) = x^3 - 3x
\end{align}
とおくと，題意の方程式$f_2(x)=a$は
\begin{align}
  f(f_1(x)) = a \label{eq:1}
\end{align}
である．従って$x_1=f_1(x)$とおくと
\begin{align}
  f(x_1) = a
\end{align}
だから，この解は$x_1y$平面上の$y=f(x_1)$と$y=a$の共有点に対応し，(1)の結果で$x\to x_1$とすれば解の個数とその時の解の値は
\begin{itemize}
  \item  $|a| > 2$ の時 $|x_1|>2$ に $1$ 個 \\
  \item  $|a| = 2$ の時 $x_1=-1,2$ または $x_1=-2,1$ の $2$ 個 \\
  \item  $|a| < 2$ の時 $|x_1|<2$ に $3$ 個
\end{itemize}
となる．

$f_n(x) = a \ (|a| < 2)$ を満たす実数 $x$ が $3^n$ 個であることを数学的帰納法で示す．

$n=1$ の時は(1)から成立するので，以下 $n=k \in \mathbb{N}$ での成立を仮定する．
$f_{k+1}(x) = a$ つまり $f(f_k(x))=a$ なる $f_k(x)$ は (1)のグラフより $-2 < f_k(x) < 2$ に 3 つある．それぞれを$a_1,a_2,a_3 \ (|a_1|,|a_2|,|a_3|<2)$とすると，$f_k(x)=a_1, f_k(x)=a_2, f_k(x)=a_3$はそれぞれ仮定より$3^{k}$個の解があるから，$f_{k+1}(x)=a$は$x$について合計で
\begin{align}
  3\cdot 3^{k} = 3^{k+1}
\end{align}
個の解を持つ．よって$n = k+1$ でも主張は成立し，数学的帰納法により解の数は任意の$n$に対して$3^{n}$個である．$a=0$とすれば題意の主張は示される．\qed
