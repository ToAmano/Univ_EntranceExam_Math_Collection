「白白白」から「黒白白」になるためには$A$を奇数回，かつ$B,C$を偶数回裏返せば良い．
合計の裏返す回数は$3$回だから，$A$を$1$回または$3$回裏返す場合のみである．

\subparagraph{$1^\circ$ $A$を1回裏返す時}

あとは$B$2回，または$C$2回を裏返せば良いから，これらの場合の数は
\begin{align}
  \underbrace{2}_{B\text{か}C\text{か}}\times\underbrace{{}_3C_1}_{3\text{回のならべ方}}=6\text{通り}
\end{align}
である．

\subparagraph{$2^\circ$ $A$を3回裏返す時}

この場合は場合の数は1通り．
\casesend

全事象は$3^3=27$通りで同様に確からしいから，もとめる確率は
\begin{align}
  \dfrac{6+1}{27}=\dfrac{7}{27}
\end{align}
である．

\paragraph{(2)}

$n$回目の操作後の状態を以下のように$3$つにわけ，これらが発生する確率を$a_n,b_n,c_n$とおく：
\begin{itemize}
  \item 両端が白: $a_n$ \\
  \item 両端が黒: $b_n$ \\
  \item それ以外: $c_n$
\end{itemize}
と，求める確率は$a_n$である．また，これらは排反だから
\begin{align}
  a_n+b_n+c_n=1 \label{eq:1}
\end{align}
である．

各操作で$A,B,C$はそれぞれ確率$\dfrac{1}{3}$で裏返るから遷移図は上のようになり，
漸化式は
\begin{align}
  \begin{cases}
    a_{n+1}=\dfrac{1}{3}a_n+\dfrac{1}{3}c_n\\
    b_{n+1}=\dfrac{1}{3}b_n+\dfrac{1}{3}c_n
  \end{cases}
\end{align}
である．\cref{eq:1}より$c_n$を消して，
\begin{align}
  \begin{cases}
    a_{n+1}=\dfrac{1}{3}(1-b_n)\\
    b_{n+1}=\dfrac{1}{3}(1-a_n)
  \end{cases}
\end{align}
である．

辺々足し引きして，$\alpha_n=a_n+b_n$，$\beta_n=a_n-b_n$とすると，
\begin{align}
  \begin{cases}
    \alpha_{n+1}=\dfrac{1}{3}(2-\alpha_n)\\
    \beta_{n+1}=\dfrac{1}{3}\beta_n
  \end{cases}
\end{align}
である．

最初の並びが「白白白」だから，初項は$a_0=1, b_0=0$である．
よって$d_0=\beta_0=1$に注意して漸化式をとくと，
\begin{align}
  \alpha_n&=\left(-\dfrac{1}{3}\right)^n\left(1-\dfrac{1}{2}\right)+\dfrac{1}{2}\\
  \beta_n &=\left(\dfrac{1}{3}\right)^n
\end{align}
である．
よってもとめる確率$a_n$は
\begin{align}
  a_n
  &=\dfrac{1}{2}(\alpha_n+\beta_n)\\
  &=\dfrac{1}{2}\left(\dfrac{1}{3}\right)^n+\dfrac{1}{4}\left(-\dfrac{1}{3}\right)^n+\dfrac{1}{4}
\end{align}
である．

{\bf [別解]}

漸化式を使わずに直接数えあげる方法もある．

$A,C$を裏返した回数をそれぞれ$a,c$とする．求める事象では$a,c$がともに偶数だから，$a=2a'$，$c=2c'$とおける．

二項定理から，偶数番目の二項係数の和について
\begin{align}
  \sum_{t=0}^{\lfloor m/2\rfloor}{}_{m}C_{2t}x^{2t}
  =\dfrac{(1+x)^m+(1-x)^m}{2}
\end{align}[O]
を用いる．

\subparagraph{$n=2k$の時}

この時，$a+c \le n$より$a'+c'\leqq k$である．
$n$箇所の中から$A$を裏返す位置を$2a'$個選び，残りから$C$を裏返す位置を$2c'$個選ぶと求める確率$P_{n}$は
\begin{align}
  P_{2k}
  &=\left(\dfrac{1}{3}\right)^{2k}
  \sum_{a'=0}^{k}{}_{2k}C_{2a'}
  \sum_{c'=0}^{k-a'}{}_{2k-2a'}C_{2c'}\\
  &=\left(\dfrac{1}{3}\right)^{2k}
  \left\{\sum_{a'=0}^{k-1}{}_{2k}C_{2a'}2^{2k-2a'-1}+1\right\}\\
  &=\left(\dfrac{1}{3}\right)^{2k}
  \left\{\sum_{a'=0}^{k}{}_{2k}C_{2a'}2^{2k-2a'-1}+\dfrac{1}{2}\right\}\\
  &=\left(\dfrac{1}{3}\right)^{2k}
  \left\{\dfrac{3^{2k}+1}{4}+\dfrac{1}{2}\right\}\\
  &=\dfrac{1}{4}\left\{1+3\left(\dfrac{1}{3}\right)^{2k}\right\}.
\end{align}
である．

\subparagraph{$n=2k+1$の時}

$n=2k+1$のときも$a'+c'\leqq k$である．同様に，
\begin{align}
  P_{2k+1}
  &=\left(\dfrac{1}{3}\right)^{2k+1}
  \sum_{a'=0}^{k}{}_{2k+1}C_{2a'}
  \sum_{c'=0}^{k-a'}{}_{2k+1-2a'}C_{2c'}\\
  &=\left(\dfrac{1}{3}\right)^{2k+1}
  \sum_{a'=0}^{k}{}_{2k+1}C_{2a'}2^{2k-2a'}\\
  &=\dfrac{1}{4}\left\{1+\left(\dfrac{1}{3}\right)^{2k+1}\right\}.
\end{align}
である．
\casesend

したがって求める確率は
\begin{align}
  P_n=
  \begin{cases}
    \dfrac{1}{4}\left\{1+3\left(\dfrac{1}{3}\right)^n\right\}&(n\text{が偶数}),\\
    \dfrac{1}{4}\left\{1+\left(\dfrac{1}{3}\right)^n\right\}&(n\text{が奇数}).
  \end{cases}
\end{align}
