{\bf [解]} $C, C', C_n$ と $l$ の接点を $H, H', H_n$ とする．($C' = C_0, H' = H_0$ とする)

右図から，ピタゴラスの定理より，$|HH_n|$ を2通りで表して
\begin{align}
|HH_n| &= \sqrt{(R+r_n)^2 - (R-r_n)^2} \\
|HH_n| &= |HH_{n+1}| + |H_{n+1}H_n| \\
&= \sqrt{(R+r_{n+1})^2 - (R-r_{n+1})^2} + \sqrt{(r_n+r_{n+1})^2 - (r_n-r_{n+1})^2}
\end{align}
だから，
\begin{align}
2\sqrt{Rr_n} = 2\sqrt{Rr_{n+1}} + 2\sqrt{r_n r_{n+1}} \quad \cdots \text{①}
\end{align}
$C_n = \dfrac{1}{\sqrt{r_n}}$ とする．①の両辺 $\sqrt{r_n r_{n+1}} \; (\neq 0)$ でわって，
\begin{align}
C_{n+1} = C_n + \sqrt{1/R}
\end{align}
$C_0 = \sqrt{1/R}$ とあわせて，くり返し用いて，
\begin{align}
C_n = n\sqrt{1/R} + \sqrt{1/R}
\end{align}
だから，
\begin{align}
r_n = \dfrac{1}{C_n^2} = \dfrac{1}{(n\sqrt{1/R} + \sqrt{1/R})^2}
\end{align}
より，
\begin{align}
n^2 r_n = \dfrac{1}{\Bigl(\sqrt{1/R} + \dfrac{1}{n}\sqrt{1/R}\Bigr)^2} \to R \quad (n \to +\infty)
\end{align}
