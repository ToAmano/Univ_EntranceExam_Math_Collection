{\bf [解]}

与えられた関数
\begin{align}
  f(x)=\dfrac{1}{2}x\{1+e^{-2(x-1)}\} \label{eq:1}
\end{align}
について考える．

\paragraph{(1)}

\cref{eq:1}の両辺を$x$で$2$回まで微分して
\begin{align}
  f'(x)
  &=\dfrac{1}{2}\left[(1+e^{-2(x-1)})+x(-2)e^{-2(x-1)}\right]\\
  &=\dfrac{1}{2}\left[1+(1-2x)e^{-2(x-1)}\right]
\end{align}
および
\begin{align}
  f''(x)&=\dfrac{1}{2}e^{-2(x-1)}\left[-2+(1-2x)(-2)\right]\\
  &=-e^{-2(x-1)}(2-2x)
\end{align}
だから，$f(x)$の増減表は以下のようになる．

従って$\dfrac{1}{2}<x$の範囲では
\begin{align}
  0 \le f'(x) < \dfrac{1}{2}
\end{align}
である．

\paragraph{(2)}

$f(1)=1$を\cref{eq:1}から辺々引いて
\begin{align}
  x_{n+1}-1=f(x_n)-f(1) \label{eq:2}
\end{align}
を得る．

さて，$x_n=1$なる$n$がある時は\cref{eq:2}から$n\le m$なる任意の$m$に対し，$f(x_m)=1$だから，$x_n\to1\ (n\to\infty)$である．

そこで以下すべての$n$で$x_n\ne1$の場合を考える．$(1)$の増減表から$x>\dfrac{1}{2}$の時$f(x)$は単調増加で
\begin{align}
  f\left(\dfrac{1}{2}\right)=\dfrac{1}{4}(1+e)>\dfrac{1}{2}
\end{align}
だから，題意より$x_0>\dfrac{1}{2}$の時，帰納的に任意の$n$に対し$x_n>\dfrac{1}{2}$である．

このことに注意すると平均値の定理から
\begin{align}
  f(x_n)-f(1)=f'(c)(x_n-1)\quad \left(\dfrac{1}{2}<c\text{，}1\text{と}x_n\text{の間}\right)
\end{align}
なる$c$がある．\cref{eq:2}および(1)の結果$0\le f'(x) < \dfrac{1}{2}$より
\begin{align}
  |x_{n+1}-1|=|f'(c)||x_n-1|<\dfrac{1}{2}|x_n-1|
\end{align}
である．よってこれをくり返し用いて，
\begin{align}
  |x_n-1|<\left(\dfrac{1}{2}\right)^n|x_0-1|\longrightarrow0\quad(n\to\infty)
\end{align}
だから，挟み撃ちの定理より
\begin{align}
  x_n\longrightarrow1\quad(n\to\infty)
\end{align}
である．
