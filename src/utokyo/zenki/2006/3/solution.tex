題意より点$Q$は$0<x,y=1$にあるから$Q(X, 1)$ ($0 < X$) とおける．
$Q$は$l$に関する$O$の対称点だから，$OQ \perp l$ かつ $OQ$の中点 $M(\dfrac{X}{2}, \dfrac{1}{2})$ を $l$ が通るので，
\begin{align}
  l: y &= -X\left(x - \dfrac{X}{2}\right) + \dfrac{1}{2} \\
  &= -Xx + \dfrac{1}{2}X^2 + \dfrac{1}{2}
\end{align}
とかける．
題意より$l$の傾きが $\alpha$ だから，$\alpha = -X$ となって，
\begin{align}
  l: y = \alpha x + \dfrac{1}{2}\alpha^2 + \dfrac{1}{2}, \quad \alpha < 0 \label{eq:1}
\end{align}
となる．

次に点$R$は直線$m$上の$x>0$の部分の点だから$R(\xi, \tan\theta \cdot \xi)$ ($0 < \xi$) とおける．
$R$は$l$に関する$P(0,p)$の対称点だから同様に，
\begin{align}
  \begin{dcases}
    \overrightarrow{PR} \cdot
    \begin{pmatrix} 1 \\ \alpha
    \end{pmatrix} = 0 \\
    \dfrac{1}{2}\left(\alpha \xi + \alpha^2 +1\right) = \dfrac{1}{2}\left(\xi \cdot \tan\theta + p\right)
  \end{dcases}
  \therefore
  \begin{dcases}
    (1 + \alpha \cdot \tan\theta) \cdot \xi = p\alpha \\
    (\tan\theta - \alpha) \cdot \xi = \alpha^2 + 1 - p
  \end{dcases} \label{eq:2}
\end{align}
となる．
第2式において題意の$0<\theta<\dfrac{\pi}{2}$より$\tan\theta>0$，\cref{eq:1}より$\alpha<0$だから$\tan\theta - \alpha>0$で両辺を割ると
\begin{align}
  \xi = \dfrac{\alpha^2 + 1 - p}{\tan\theta - \alpha} \label{eq:3}
\end{align}
である．\cref{eq:3}を\cref{eq:2}の第一式に代入して整理すると
\begin{align}
  & (\alpha^2 - p + 1)(1 + \alpha \tan\theta) = p\alpha(\tan\theta - \alpha) \\
  \therefore
  & (\alpha^2 + 1 - 2p)\cdot \alpha \cdot \tan\theta = - p\alpha^2 - \alpha^2 + p - 1
\end{align}
である．ここで左辺において$\alpha^2 + 1 - 2p=0$と仮定すると右辺も$0$となるが，具体的に右辺で$p$を消去すると
\begin{align}
  p(1-\alpha^2)  - (1+\alpha^2)
  = \dfrac{1+\alpha^2}{2}(1-\alpha^2) - (1+\alpha^2)
  = \dfrac{1}{2}\left[1-\alpha^4 - 2\alpha^2-2\right]
  = \dfrac{-(1+\alpha^2)^2}{2}<0
\end{align}
となって矛盾する．よって$\alpha^2 + 1 - 2p\neq 0$で両辺を割って
\begin{align}
  \tan\theta = \dfrac{-(p+1)\alpha^2 + p - 1}{\alpha(\alpha^2 + 1 - 2p)} \label{eq:4}
\end{align}
である．

\paragraph{(2)}

まず$\tan\theta$と$\tan\dfrac{\theta}{3}$の関係について，簡単のため$t=\tan\dfrac{\theta}{3}$とおくと，三倍角の公式より
\begin{align}
  \tan\theta &= \dfrac{3t - t^3}{1 - 3t^2} \label{eq:5}
\end{align}
である．$0<\theta<\dfrac{\pi}{2}$より$0<t<\dfrac{1}{\sqrt{3}}$だからこの分母は$0$でないことに注意する．

題意から，$l$の傾き$\alpha$と$y=tx$の傾き$t$の積が$-1$であり，これが$0 < \theta < \pi/2$ で常に成立する $p$ があることを言えば良い．よって
\begin{align}
  \alpha t = -1 \label{eq:6}
\end{align}
とする．

まず\cref{eq:4,eq:5}から$t$と$p,\alpha$についての関係式は
\begin{align}
  \dfrac{3t - t^3}{1 - 3t^2}
  = \dfrac{-(p+1)\alpha^2 + p - 1}{\alpha(\alpha^2 + 1 - 2p)} \label{eq:7}
\end{align}
となる．ここに\cref{eq:6}から$\alpha = -\dfrac{1}{t}$ を代入すると
\begin{align}
  \dfrac{3t - t^3}{1 - 3t^2} = \dfrac{(p-1)t^2 - (p+1)}{(1 - 2p)t^2 + 1} \cdot (-t)
\end{align}
これが $t$ についての恒等式だから，両辺 $t$ でわって分母を払うと
\begin{align}
  (3 - t^2)\{(1 - 2p)t^2 + 1\} = -(1 - 3t^2)\{(p - 1)t^2 - (p + 1)\} \label{eq:8}
\end{align}
である．さらに $s = t^2$ とすると
\begin{align}
  & (2p - 1)s^2 - (6p - 2)s + 3 = 3(p - 1)s^2 - (4p + 2)s + (p + 1) \\
  \therefore
  & (p - 2)s^2 + 2(p - 2)s + (p - 2) = 0 \label{eq:9}
\end{align}
である．これが$s$についての恒等式になるのは $p=2$ の時である．

この時$Q(X,1),R(\xi,\xi\tan\theta)$が第一象限の点であることを確認しよう．
(1)より$X=-\alpha$だから\cref{eq:6}を代入して
\begin{align}
  X = \dfrac{1}{t} > 0
\end{align}
より$Q$は第一象限にある．ついで\cref{eq:3}の分子に\cref{eq:6}を代入して
\begin{align}
  \xi
  & = \dfrac{(-1/t)^2 + 1 - 2}{\tan\theta - \alpha} \\
  & = \dfrac{1-t^2}{t^2(\tan\theta - \alpha)}
\end{align}
だが，$0<\theta<\dfrac{\pi}{2}$より$0<t=\tan\dfrac{\theta}{3}<\tan\dfrac{\pi}{6}=\dfrac{1}{\sqrt{3}}$より分子は正である．$\tan\theta>0>\alpha$より分母も正だから$\xi>0$が従い，よって$R$も第一象限にある．以上より$p=2$が条件であり題意は示された．
