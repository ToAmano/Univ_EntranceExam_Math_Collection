{\bf [解]}
\paragraph{(1)}
(ロ)から，$f(x) = a(x+1)(x-1)(x-\alpha)$ ($\alpha \in \mathbb{R}$) とおける．($a \neq 0$ の時)

$1^\circ$ $0 \le x$ の時

(イ) $\iff f(x) \ge 1 - x \iff a(x+1)(x-\alpha)(x-1) \ge -(x-1)$ で，$x=1$ で等号成立，$0 \le x < 1$ の時は $x-1 < 0$ だから
\begin{align}
a(x+1)(x-\alpha) \le -1
\end{align}
\begin{align}
a x^2 + a(1-\alpha) x + 1 - a\alpha \le 0 \quad \dots \text{①}
\end{align}
この左辺を $g(x)$ とおく．

$\text{i)}$ $a > 0$ の時

$0 \le x \le 1$ で $g(x) \le 0$ であれば良い．条件は
\begin{align}
g(0) \le 0 \land g(1) \le 0 \iff 1 - a\alpha \le 0 \land 2a - 2a\alpha + 1 \le 0
\end{align}

$\text{ii)}$ $a < 0$ の時

$g(x)$ の軸 $x = \dfrac{\alpha - 1}{2}$ で場合分け，$g(x) = 0$ の判別式を $D$ とおく．
\begin{align}
\begin{cases}
0 \le \dfrac{\alpha-1}{2} \le 1 \text{ の時}，D \le 0 \iff a^2(1-\alpha)^2 - 4a(1-a\alpha) \le 0 \iff a \Bigl[ a(\alpha+1)^2 - 4 \Bigr] \le 0 \dots \star_1 \\
\text{otherwise} \quad g(0) \le 0 \land g(1) \le 0
\end{cases}
\end{align}

$2^\circ$ $x \le 0$ の時

$f(x) \ge 1+x \iff a(x-1)(x-\alpha)(x+1) \ge (x+1)$ で，$1^\circ$ と同様に
\begin{align}
a(x-1)(x-\alpha) \ge 1
\end{align}
\begin{align}
a x^2 - a(1+\alpha) x + a\alpha - 1 \ge 0 \quad \dots \text{②}
\end{align}
この左辺を $h(x)$ とおく．

$\text{i)}$ $a > 0$ の時

軸 $x = \dfrac{\alpha+1}{2}$ で場合分け，$h(x)=0$ の判別式を $D'$ とおく．
\begin{align}
\begin{cases}
-1 \le \dfrac{\alpha+1}{2} \le 0 \text{ の時}，D' \le 0 \iff a^2(\alpha+1)^2 - 4a(a\alpha-1) \ge 0 \iff a \Bigl[ a(\alpha-1)^2 + 4 \Bigr] \ge 0 \dots \star_2 \\
\text{otherwise} \quad g(-1) \ge 0 \land g(0) \ge 0 \iff 2a + 2a\alpha - 1 \ge 0 \land a\alpha - 1 \ge 0
\end{cases}
\end{align}

$\text{ii)}$ $a < 0$ の時

条件は $g(-1) \ge 0 \land g(0) \ge 0$

ここで，$a < 0$ から $\star_1 \iff a(\alpha+1)^2 - 4 \ge 0$ (これをみたす $\alpha, a$ はない)．
同じく $a > 0$ から $\star_2 \iff a(\alpha-1)^2 + 4 \ge 0 \iff \alpha, a$ は任意．

だから，$1^\circ, 2^\circ$ をまとめて，

$a > 0$ の時
\begin{align}
\begin{cases}
1 - a\alpha \le 0 \land 2a - 2a\alpha + 1 \le 0 \land (\alpha \le -3 \text{ or } 0 \le \alpha) \land \\
a\alpha - 1 \ge 0 \land 2a + 2a\alpha - 1 \ge 0
\end{cases}
\end{align}
$a < 0$ の時
\begin{align}
\begin{cases}
a\alpha - 1 \ge 0 \land 2a + 2a\alpha - 1 \ge 0 \land (\alpha \le 1 \text{ or } 3 \le \alpha) \land \\
1 - a\alpha \le 0 \land 2a - 2a\alpha + 1 \le 0
\end{cases}
\end{align}

ここで，$f(x) = a(x^2-1)(x-\alpha) = a(x^3 - \alpha x^2 - x + \alpha)$ から
\begin{align}
b = -a\alpha, \quad d = a\alpha, \quad c = -a \quad \dots \text{③}
\end{align}
である．$\alpha$ は，$a>0$ の時 $1 < \alpha$，$a<0$ の時 $\alpha < -1$ なので条件はまとめて
\begin{align}
\begin{cases}
\alpha = \dfrac{b}{-a} + 1 \\
\alpha = \dfrac{d}{a}
\end{cases} \quad \text{で} \quad
\begin{cases}
1 - a\alpha \le 0 \land 2a - 2a\alpha + 1 \le 0 \\
2a + 2a\alpha - 1 \ge 0
\end{cases} \quad \dots \text{④}
\end{align}
一方，$a=0$ の時，$f(x)$ が $1$ 次以下で不適なので $b \neq 0$ のもとで $f(x) = b(x^2-1)$ とおける．
(ハ)の条件は $f(0) \ge 1 \iff 1+b \le 0$ である．

以上まとめて，
\begin{align}
b = -d, \quad c = -a, \quad 1 + b \le 0, \quad
\begin{cases}
2a + 2b + 1 \le 0 \\
2a - 2b - 1 \ge 0
\end{cases}
\end{align}

\paragraph{(2)}

(1)から，$f(x) = ax^3 + bx^2 - ax - d$ とおける．$f'(x) = 3ax^2 + 2bx - a$ から
\begin{align}
\{f'(x) - x\}^2 &= (3ax^2)^2 + (2b-1)^2 x^2 + a^2 + 2 \Bigl[ 3a(2b-1) x^3 - 3a^2 x^2 - (2b-1)ax \Bigr] \\
&= 9a^2 x^4 + \Bigl[ (2b-1)^2 - 6a^2 \Bigr] x^2 + a^2 + (\text{奇数次項})
\end{align}
より，
\begin{align}
\int_{-1}^1 \{f'(x) - x\}^2 \, dx &= 2 \int_0^1 \Bigl( 9a^2 x^4 + \Bigl[ (2b-1)^2 - 6a^2 \Bigr] x^2 + a^2 \Bigr) dx \\
&= 2 \Bigl[ a^2 \int_0^1 (9x^4 - 6x^2 + 1) dx + (2b-1)^2 \int_0^1 x^2 dx \Bigr] \\
&= 2 \Bigl[ \dfrac{4}{5} a^2 + \dfrac{1}{3}(2b-1)^2 \Bigr] \equiv A \quad \dots \text{⑤}
\end{align}
ここで，$(a, b)$ は領域をうごくから，
\begin{align}
\begin{cases}
0 \le a \le \dfrac{1}{2} \text{ の時}，b \le -\dfrac{1}{2} \\
\dfrac{1}{2} \le a \text{ の時}，b \le -a - \dfrac{1}{2}
\end{cases}
\end{align}
したがって
\begin{align}
|a| \le \dfrac{1}{2} \text{ の時}，A \text{ は } (a, b) = (0, -1) \text{ で } \min 6
\end{align}
\begin{align}
\dfrac{1}{2} \le |a| \text{ の時}，A \text{ は } 0 \le a \le \dfrac{1}{2} \text{ の時より大きい}
\end{align}
から，$A$ は $(a, b) = (0, -1)$ で $\min 6$ をとる．この時
\begin{align}
f(x) = -x^2 + 1
\end{align}
