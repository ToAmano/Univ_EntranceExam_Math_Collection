$k\in\mathbb{Z}_{\ge1}$とする．
与えられた曲線
\begin{align}
  \begin{cases}
    C_1:y=f(x) = \cos x \\
    C_2:y=g(x) = \dfrac{1-x^2}{1+x^2}
  \end{cases} \quad (2k\pi \le x \le (2k+1)\pi) \label{eq:1}
\end{align}
について考える．

\paragraph{(1)}

$y=\cos x$は区間$[2k\pi,(2k+1)\pi]$内で単調減少で$-1\le\cos x\le1$である．
一方で
\begin{align}
  g(x) = -1 + \dfrac{2}{1+x^2}
\end{align}
も単調減少で，$g(2\pi)=-1+\dfrac{2}{1+4\pi^2}<1,\lim_{x\to\infty}g(x)=-1$を考えると
\begin{align}
  h(x) = f(x) - g(x)
\end{align}
に対して
\begin{align}
  h(2k\pi) > 0，\qquad h((2k+1)\pi) < 0
\end{align}
となるから，$h(\alpha_k)=0\ (2k\pi < \alpha_k < (2k+1)\pi)$なる$\alpha_k$がある．
よって$C_1$，$C_2$の共有点が存在することが示された．

$x=\alpha_k$における$C_1$の接線$\ell_k$は
\begin{align}
  \ell_k: y=\ell_k(x)=-\sin\alpha_k(x-\alpha_k)+\cos\alpha_k \label{eq:2}
\end{align}
で表せる．ここで$h(\alpha_k)=0$より
\begin{align}
  \cos\alpha_k=\dfrac{1-\alpha_k^2}{\alpha_k^2+1}，
  \qquad
  \sin\alpha_k=\sqrt{1-\dfrac{(1-\alpha_k^2)^2}{(\alpha_k^2+1)^2}}=\dfrac{2\alpha_k}{\alpha_k^2+1}\ (>0)
\end{align}
であり，\cref{eq:2}に代入して
\begin{align}
  \ell_k(x)= -\dfrac{2\alpha_k}{\alpha_k^2+1}(x-\alpha_k) + \dfrac{1-\alpha_k^2}{\alpha_k^2+1} \label{eq:3}
\end{align}
である．$y=\ell_k(x)$の$y$切片は
\begin{align}
  \ell_k(0)
  =-\dfrac{2\alpha_k}{\alpha_k^2+1}(-\alpha_k)+\dfrac{1-\alpha_k^2}{\alpha_k^2+1}
  =\dfrac{\alpha_k^2+1}{\alpha_k^2+1}
  =1
\end{align}
だから，$\ell_k$は$(0,1)$を通る．$\blacksquare$

\paragraph{(2)}

$x=t$における$C_1$の接線は$y=-\sin t(x-t)+\cos t$であり，この接線の$y$切片は
\begin{align}
  Y(t)=t\sin t+\cos t
\end{align}
である．一階微分は
\begin{align}
  Y'(t)=t\cos t
\end{align}
だから，$[2k\pi,(2k+1)\pi]$での$Y(t)$の増減表は以下のようになる．
