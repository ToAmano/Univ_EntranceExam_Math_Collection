{\bf [解答]}

与えられた条件
\begin{align}
  \alpha+\beta+\gamma=\alpha^2+\beta^2+\gamma^2 = 0 \label{eq:1}
\end{align}
より
\begin{align}
  \beta\gamma+\gamma\alpha+\alpha\beta=\dfrac{1}{2}\left[(\alpha+\beta+\gamma)^2-(\alpha^2+\beta^2+\gamma^2)\right]=0
\end{align}
だから，$\alpha\beta\gamma=k^3$とおくと，$\alpha,\beta,\gamma$は，$x$の3次方程式$x^3-k^3=0$の3解である．題意より$\alpha\ne\beta, \gamma\ne\alpha$から$k\ne0$である．
この時方程式の解は
\begin{align}
  (x-k)(x^2+kx+k^2)=0
  \quad \therefore\ x=k,\ \dfrac{-1\pm\sqrt{3}i}{2}k
\end{align}
だから，$\triangle ABC$は重心を原点とする正三角形である．
