{\bf [解]}
グラフは下図である．
\begin{align}
  \dfrac{3}{4}x^2-5=x\quad&\cdots①\ \text{の2解}\ \alpha,\beta\ (\alpha<\beta)\\
  -\dfrac{3}{4}x^2+1=x\quad&\cdots②\ \text{の2解}\ \gamma,\delta\ (\gamma<\delta)
\end{align}
とおく．もとめる面積を$S$とする．

\begin{align}
  S=(\text{①を全区間で延長した放物線と直線の間の面積})+2\times(\text{②の放物線と直線の間の面積})\\
  -2\times(\text{①を延長した放物線と直線の間の，区間}[-2,2]\text{での面積})\quad\cdots③
\end{align}

であり，
\begin{align}
  &\dfrac{3}{4}\cdot\dfrac{1}{6}(\beta-\alpha)^3=\dfrac{1}{8}(\beta-\alpha)^3，\\
  &\dfrac{3}{4}\cdot\dfrac{1}{6}(\delta-\gamma)^3=\dfrac{1}{8}(\delta-\gamma)^3，\\
  &\dfrac{3}{4}\cdot\dfrac{1}{6}(2+2)^3=\dfrac{1}{8}(4)^3
\end{align}

を③に代入して
\begin{align}
  S=\dfrac{1}{8}(\beta-\alpha)^3+\dfrac{1}{4}(\delta-\gamma)^3-16\quad\cdots④
\end{align}

ここで，①，②から
\begin{align}
  \beta-\alpha=\dfrac{10}{3}+2=\dfrac{16}{3}，\qquad\delta-\gamma=\dfrac{2}{3}+2=\dfrac{8}{3}
\end{align}

を④に代入して
\begin{align}
  S&=\dfrac{1}{8}\left(\dfrac{16}{3}\right)^3+\dfrac{1}{4}\left(\dfrac{8}{3}\right)^3-16\\
  &=\dfrac{8^3}{3^3}+\dfrac{2\cdot8^2}{3^3}-\dfrac{16\cdot3^3}{3^3}\\
  &=\dfrac{16}{3^3}(32+8-27)\\
  &=\dfrac{208}{27}．
\end{align}
