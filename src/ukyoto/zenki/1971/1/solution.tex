{\bf [解答]}

\paragraph{(1)}

\begin{figure}[htb]
  \centering
  \begin{tikzpicture}[scale=0.95]
    \draw[step=1cm, gray!45, thin] (-0.3,-0.3) grid (2.3,2.3);
    \fill[blue!10] (1.47,0.48) rectangle (2.47,1.48);
    \draw[blue!75!black, very thick] (1.47,0.48) rectangle (2.47,1.48);
    \foreach \x in {0,1,2} {
      \foreach \y in {0,1,2} {
        \node[circle, fill=gray!75, inner sep=1.6pt] at (\x,\y) {};
      }
    }
    \node[circle, fill=red!75!black, inner sep=2.2pt] at (2,1) {};
  \end{tikzpicture}
  \caption{座標軸に平行な一辺 $1$ の正方形は格子点を含む．}
  \label{fig:1971_1_axis_aligned_square}
\end{figure}

1辺の長さ1の辺が座標軸に平行な時，この正方形内部(周含む)の点 $(X, Y)$ は, $\alpha, \beta \in \mathbb{R}$ として
\begin{align}
  \begin{cases}
    \alpha \le X \le \alpha + 1 \\
    \beta \le Y \le \beta + 1
  \end{cases}
\end{align}
と書ける. この時, $\alpha \le m \le \alpha + 1$, $\beta \le n \le \beta + 1$ をみたす $m, n \in \mathbb{Z}$ が必ず存在するから, $(m, n)$ は正方形内部にある. 従って常に少なくとも1つの格子点を含む.

1辺の長さ $\sqrt{2}$ の時，上図から正方形の中心(対角線の交点)からの距離 $\dfrac{\sqrt{2}}{2}$ の点は全て正方形内に含まれる.

又, 1辺1の正方形$A$の4頂点となるような4格子点をもってくる. このような正方形で格子点空間を埋め尽くせる．

この正方形は対角線の長さ $\sqrt{2}$だから，正方形内部の任意の点は少なくとも1つの格子点からの距離が $\dfrac{\sqrt{2}}{2}$ 以下である．
従って，この正方形$A$の内部に一辺$\sqrt{2}$の正方形の中心を配置すれば，辺の長さ $\sqrt{2}$ の正方形は少なくとも1つの格子点を持つ.

\begin{figure}[htb]

  \begin{tikzpicture}[scale=2.2, >=stealth, every node/.style={font=\small}]
    \coordinate (O) at (0, 0);

    \begin{scope}[rotate=25]

      \node[blue!85!black, above right] at (0.3, 0.7071) {一辺 $\sqrt{2}$};
    \end{scope}

    % 内接円（半径 sqrt{2}/2 = 0.7071）
    \draw[line width=1.1pt, teal!75!black] (O) circle (0.7071);
    \draw[dashed, teal!75!black] (O) -- (140:0.7071) node[midway, above left=-1pt, font=\footnotesize] {$\frac{\sqrt{2}}{2}$};

    % 内接円に内接する座標軸に平行な一辺 1 の正方形
    \draw[line width=1.3pt, orange!85!black] (-0.5, -0.5) rectangle (0.5, 0.5);
    \node[orange!85!black, below] at (0, -0.5) {一辺 $1$（軸に平行）};

    % 中心点
    \node[circle, fill=red!85!black, inner sep=1.4pt] at (O) {};
  \end{tikzpicture}
  \caption{一辺 $\sqrt{2}$ の正方形とその内接円，および内接円に内接する軸に平行な一辺 $1$ の正方形．}
  \label{fig:1971_1_concentric_squares}
\end{figure}

議論としては同じだが，(i)を誘導として使う形にしておくのが綺麗かもしれない．
一辺$\sqrt{2}$の正方形の内接円の半径は$\dfrac{\sqrt{2}}{2}$で，さらにこれに内接する正方形は一辺$1$である．そこでその正方形を座標軸に平行に取れば(i)が使えて，その内部には必ず格子点がある．
