\noindent
[\textbf{解}]

\noindent
$m$ は $a, b$ によって以下のようになる. (軸の位置で場合分け)

\begin{enumerate}
  \item[ア] $-\dfrac{a}{2} \le 0 \iff a \ge 0$ の時, $m = f(0) = b$
  \item[イ] $0 \le -\dfrac{a}{2} \le 1 \iff -2 \le a \le 0$ の時, $m = f\left(-\dfrac{a}{2}\right) = -\dfrac{1}{4}a^2 + b$
  \item[ウ] $1 \le -\dfrac{a}{2} \iff a \le -2$ の時, $m = f(1) = a + b + 1$
\end{enumerate}

\noindent
又, $(a, b)$ の存在領域は下図斜線部 (境界含む) である.

\begin{itemize}
  \item[アの時] $\max f(0) = 1 \quad ((a, b) = (0, 1))$
  \item[イの時] $m \le -\dfrac{1}{4}a^2 - \dfrac{1}{2}a + 1 = -\dfrac{1}{4}(a+1)^2 + \dfrac{5}{4} \le \dfrac{5}{4}$

    等号成立 $(a, b) = \left(-1, \dfrac{3}{2}\right)$
  \item[ウの時] $m \le a + 1 - \dfrac{1}{2}a + 1 = \dfrac{1}{2}a + 2 \le 1$

    等号成立 $(a, b) = (-2, 2)$
\end{itemize}

\noindent
以上から $(a, b) = \left(-1, \dfrac{3}{2}\right)$ が $m$ を最大にする.
