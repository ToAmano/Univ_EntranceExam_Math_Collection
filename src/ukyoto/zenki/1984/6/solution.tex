\paragraph{(1)}

$F(x) = f(x) - x$ とおくと条件(ハ)から$[a,b]$で
\begin{align}
  F'(x) = f'(x) - 1 < 0
\end{align}
である．よって$F(x)$は$[a,b]$で単調減少である．また条件(ロ)から
\begin{align}
  F(a) = f(a) - a \ge a - a = 0, \ F(b) = f(b) - b \le 0
\end{align}
から，$F(x) = 0$をみたす$x$が $[a,b]$の中に唯1つ存在し，これが$c_0$に他ならない．

与えられた不等式
\begin{align}
  |d_n-c_0| \leqq k^n|d_0-c_0| \quad (n=1,2,\cdots)  \label{eq:1}
\end{align}
について考える．$d_n = c_0$の時は$f(c_0)=c_0$より\cref{eq:1}は成立するから，以下$d_n \neq c_0$とする．

平均値の定理から
\begin{align}
  f(d_n) - f(c_0) = f'(p) (d_n - c_0)
\end{align}
をみたす $p$が$d_n, c_0$の間に存在する．
条件(ハ)から $|f'(p)| \le k$ だから, 両辺絶対値をとって整理して
\begin{align}
  |d_{n+1} - c_0| \le k |d_n - c_0| \quad (\because f(d_n) = d_{n+1}, f(c_0) = c_0)
\end{align}
だから，くり返し用いて
\begin{align}
  |d_n - c_0| \le k^n |d_0 - c_0|
\end{align}
である．以上より\cref{eq:1}が成立し，題意は示された．
