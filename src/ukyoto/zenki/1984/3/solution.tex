\paragraph{(1)}

$P(t+1,t), Q(t-1,-t)$より
$
\overrightarrow{PQ}=
\begin{pmatrix} 2 \\ 2t
\end{pmatrix} \parallel
\begin{pmatrix} 1 \\ t
\end{pmatrix}$だから，
\begin{align}
  PQ : \dfrac{1}{2}x - (t+1)\cdot\dfrac{1}{2}t - (y-t) = 0 \label{eq:1}
\end{align}
とおける．これを整理して
\begin{align}
  t^2 - xt + y = 0 \label{eq:2}
\end{align}
である．$t$が実数域全体を動く時，\cref{eq:2}をみたす$t \in \mathbb{R}$が存在するので, 判別式$D$として$D \ge 0$だから
\begin{align}
  D = x^2 - 4y \ge 0
\end{align}
である．これを図示すると下図斜線部（境界を含む）である．

\paragraph{(2)}

\cref{eq:2}から線分$PQ$の方程式は
\begin{align}
  y = f(t) = -t^2 + xt \quad (0 \le t \le 1, \ t-1 \le x \le t+1) \label{eq:3}
\end{align}
である．これを満たす$(x,y)$をもとめる．そこで$x=X$と固定して右辺の値域を考えよう．

$t$に関する条件
\begin{align}
  0 \le t \le 1, \ X-1 \le t \le X+1 \label{eq:4}
\end{align}
と，$f(t)$の軸$t=\dfrac{X}{2}$の大小を比較して，
\begin{align}
  &
  \begin{cases}
    f(1) \le y \le f\left(\dfrac{X}{2}\right) & (0 \le X \le 2) \\
    f(X+1) \le y \le f(0) & (-1 \le X \le 0)
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    X-1 \le y \le \dfrac{X^2}{4} & (0 \le X \le 2) \\
    -(X+1) \le y \le 0 & (-1 \le X \le 0)
  \end{cases}
\end{align}
である．

次に$X$をうごかして，求める領域は
\begin{align}
  \begin{cases}
    -x-1 \le y \le 0 & (-1 \le x \le 0) \\
    x-1 \le y \le \dfrac{1}{4}x^2 & (0 \le x \le 2)
  \end{cases}
\end{align}
である．これは下図斜線部 (境界含む) で, もとめる面積は$x\le 0$の三角形の領域と$x \ge 0$の領域に分けられて，
\begin{align}
  S &= \dfrac{1}{2} \cdot 1 \cdot 1 + \int_0^2 \left(\dfrac{1}{4}x^2 - x + 1\right) dx \\
  &= \dfrac{1}{2} + \dfrac{1}{3} \cdot \dfrac{1}{4} \cdot 2^3 \\
  &= \dfrac{7}{6}
\end{align}
である．
