$i$回目で勝負が決まるとき，$i$としてあり得るのは
\begin{align}
  1 \le i \le s+1 \label{eq:1}
\end{align}
だから以下このもとで考える.

\paragraph{(1)}

$i$回目に勝者が決まる確率は$s=0$の時は$1$回目で必ず赤玉を引くので
\begin{align}
  P_1 = 1 \quad (s=0) \label{eq:2}
\end{align}
である．そこで以下$s \ge 1$の場合を考える．

まず$i=1$の時は，$r+s$個の球の中から$r$個ある赤玉を引けば良いので
\begin{align}
  P_1 = \dfrac{r}{r+s} \quad (s \ge 1) \label{eq:3}
\end{align}
である．
ついで$i \ge 2$の時，$i-1$回目までは白玉を連続で引き，最後$i$回目で赤玉を引く確率だから
\begin{align}
  P_i
  &= \dfrac{s}{r+s} \cdot \dfrac{s-1}{r+s-1} \cdots \dfrac{s-(i-2)}{r+s-(i-2)} \cdot \dfrac{r}{r+s-(i-1)} \\
  &=\left(\prod_{k=0}^{i-2}\dfrac{s-k}{r+s-k}\right)\dfrac{r}{r+s-(i-1)} \label{eq:4}
\end{align}
である．

そこで\cref{eq:3,eq:4}よりまず$i=1$の時
\begin{align}
  P_{i}-P_{i+1}
  & = P_1-P_2
  = \dfrac{r}{r+s} - \dfrac{s}{r+s}\dfrac{r}{r+s-1}
  = \dfrac{r}{r+s}\dfrac{r-1}{r+s-1} \ge 0 \quad (\because r \ge 1) \label{eq:5}
\end{align}
である．

ついで$i=2,3,\cdots,s$の時，\cref{eq:4}より
\begin{align}
  P_i - P_{i+1}
  &= \left(\prod_{k=0}^{i-2}\dfrac{s-k}{r+s-k}\right)\dfrac{r}{r+s-(i-1)}
  - \left(\prod_{k=0}^{i-1}\dfrac{s-k}{r+s-k}\right)\dfrac{r}{r+s-i} \\
  &= \left(\prod_{k=0}^{i-2}\dfrac{s-k}{r+s-k}\right)\left[\dfrac{r}{r+s-(i-1)}- \dfrac{s-(i-1)}{r+s-(i-1)}\dfrac{r}{r+s-i}\right] \\
  &= \left(\prod_{k=0}^{i-2}\dfrac{s-k}{r+s-k}\right)\dfrac{r(r-1)}{(r+s-i)(r+s-i+1)} \ge 0 \label{eq:6}
\end{align}
である．以上\cref{eq:5,eq:6}より$P_i \ge P_{i+1}$ である.

\paragraph{(2)}

$A$からゲームを始めるので，Aが勝者となるのは $2k-1 \ (k \in \mathbb{N}, \ 1 \le 2k-1 \le s+1)$ 回目にはじめて赤玉を引く確率で, これを$P_A$, Bが勝者となる確率を$P_B$とおくと$s$の偶奇に応じて以下のようになる．

\subparagraph{$1^\circ \ s=2s'-1 \ (s' \in \mathbb{N})$の時}

この時は$2k-1 \le 2s'$なる$k$まで足し合わせるから
\begin{align}
  \begin{cases}
    P_A = P_1 + P_3 + \cdots + P_{2s'-1} \\
    P_B = P_2 + P_4 + \cdots + P_{2s'}
  \end{cases}
\end{align}
であり, (1)から $P_1 \ge P_2, \cdots, P_{2s'-1} \ge P_{2s'}$ とした式を辺々たしあわせて
\begin{align}
  P_A \ge P_B
\end{align}
である．これと$P_A + P_B = 1$から$P_A \ge \dfrac{1}{2}$が従う．

等号が成立するのは$P_1 = P_2, \cdots, P_{2s'-1} = P_{2s'}$と(1)で全ての等号が成立する時である．まず$P_1=P_2$が必要だから\cref{eq:5}で等号が成立して
\begin{align}
  \dfrac{r}{r+s}\dfrac{r-1}{r+s-1} = 0
  \therefore
  r = 1 \quad (\because r \ge 1)
\end{align}
である．この時$i=2,\cdots,s$に対して\cref{eq:6}から$P_i=P_{i+1}$が成立するから十分である．

\subparagraph{$2^\circ \ s=2s' \ (s' \in \mathbb{N})$の時}

この時は$2k-1 \le 2s'+1$なる$k$まで足し合わせるから
\begin{align}
  \begin{cases}
    P_A = P_1 + P_3 + \cdots + P_{2s'-1} + P_{2s'+1} \\
    P_B = P_2 + P_4 + \cdots + P_{2s'}
  \end{cases}
\end{align}
であり, $1^{\circ}$と同様に $P_1 \ge P_2, \dots$ などとした式と $P_{2s'+1} \ge 0$から,
\begin{align}
  P_A \ge P_B \quad \therefore P_A \ge \dfrac{1}{2} \ (\because P_A + P_B = 1)
\end{align}
である．

この時等号が成立するのは$P_1 = P_2, \cdots, P_{2s'-1} = P_{2s'}$と$P_{2s'+1}=0$が必要だが，\cref{eq:4}から $P_{2s'+1}=0$ とはならないから等号は成立しない．

\subparagraph{$3^\circ \ s=0$の時}

この時はAが1回目で勝利するから $P_A = 1$であるから，$P_A \ge \dfrac{1}{2}$であり，等号は成立しない．
\casesend

以上からいずれの場合も$P_A \ge \dfrac{1}{2}$が成立し，等号が成立するのは$1^{\circ}$の場合のみで
\begin{align}
  r=1, s \text{が奇数}
\end{align}
なる時である．
