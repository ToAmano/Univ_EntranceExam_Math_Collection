{\bf [解答]}

\paragraph{(1)}

$a_n^2 = A_n, b_n^2 =B_n$ と表すと，
$a_0<b_0, a_1<b_1$より$A_0 < B_0, A_1 < B_1$である．
与式の分母を払って $(A_0, A_1, B_0, B_1 > 0)$
\begin{align}
  B_1 (B_0 + 1) + A_1 (A_0 + 1) > A_1 (B_0 + 1) + B_1 (A_0 + 1)
\end{align}
を示せば良い．具体的に左辺と右辺の差を計算すると，
\begin{align}
  (\text{左辺}) - (\text{右辺}) &= B_1 (B_0 - A_0) + A_1 (A_0 - B_0) \\
  &= (B_1 - A_1) (B_0 - A_0) > 0 \quad (\because A_0 < B_0, A_1 < B_1)
\end{align}
だから示された．

\paragraph{(2)}

与えられた不等式
\begin{align}
  \sum_{k=1}^n\dfrac{{x_k}^2}{k^2+1}>n-\dfrac{8}{5} \label{eq:1}
\end{align}
について考え，この左辺を$T(n)$とおく．

$\{x_k\}$ は自然数列 $\{k\}$ の並びかえである．
(1) から，$i < j \in \mathbb{N}$ に対して $x_i < x_j$ なら
\begin{align}
  \dfrac{x_i^2}{i^2+1} + \dfrac{x_j^2}{j^2+1} > \dfrac{x_j^2}{i^2+1} + \dfrac{x_i^2}{j^2+1} \label{eq:2}
\end{align}
だから，$T(n)$の値は $x_i$ と $x_j$ を入れかえた方が小さくなる．
したがって，$k = 1, 2, \cdots$ の順に $x_k$ と $x_m$ $(m = k+1, \cdots, n)$ の大きさを比べ，
$x_k < x_m$ ならそのまま，$x_k > x_m$ なる $m$ があるならそのうち $x_m$ が最小のものと $x_k$ を入れかえる作業をすることで，「$x_k = k$」の時，$T(n)$ が最小であることがわかる．
よって
\begin{align}
  T(n)
  \ge \sum_{k=1}^n \dfrac{k^2}{k^2+1}
  = \sum_{k=1}^n \left( 1 - \dfrac{1}{k^2+1} \right)
  = n - \sum_{k=1}^n \dfrac{1}{k^2+1} \label{eq:3}
\end{align}
が成り立つ．

ここで上図の$y = \dfrac{1}{x^2+1}$ のグラフで面積比較して
\begin{align}
  \sum_{k=1}^n \dfrac{1}{k^2+1}
  = \dfrac{1}{2} + \sum_{k=2}^n \dfrac{1}{k^2+1}
  \le \dfrac{1}{2} + \int_1^n \dfrac{1}{x^2+1} dx \label{eq:4}
\end{align}
である．ここで$\tan \alpha_n = n$ なる $\alpha_n$ を定めると $(0 \le \alpha_n < \pi/2)$
右辺の積分は実行できて，
\begin{align}
  \sum_{k=1}^n \dfrac{1}{k^2+1} \le \dfrac{1}{2} + \alpha_n - \dfrac{\pi}{4}
\end{align}
である．\cref{eq:3}に代入して
\begin{align}
  T(n) \ge n - \dfrac{1}{2} - \alpha_n + \pi/4 > n - \dfrac{1}{2} - \pi/4 \quad (\because \alpha_n < \pi/2)
\end{align}
である．ここで，$\pi < 3.15$ だから，
\begin{align}
  T(n) > n - \dfrac{1}{2} - \dfrac{3.15}{4} > n - \dfrac{8}{5}
\end{align}
となって題意は示された．

{\bf [別解]}

\cref{eq:3}以下の$\sum \dfrac{1}{k^2+1}$の評価は，以下のような普通の代数的な変形でも得られる．$n \ge 2$の時は
\begin{align}
  \sum_{k=1}^n \dfrac{1}{k^2+1}
  &< \sum_{k=2}^n \dfrac{1}{k^2-1} + \dfrac{1}{2} \\
  & = \sum_{k=2}^n \dfrac{1}{2} \left( \dfrac{1}{k-1} - \dfrac{1}{k+1} \right) + \dfrac{1}{2} \\
  &= \dfrac{1}{2} + \dfrac{1}{2} \left( 1 + \dfrac{1}{2} - \dfrac{1}{n} - \dfrac{1}{n+1} \right) \\
  &= \dfrac{5}{4} - \dfrac{1}{2} \left( \dfrac{1}{n} + \dfrac{1}{n+1} \right) < \dfrac{5}{4}
\end{align}
だから，
\begin{align}
  T(n) > n - \dfrac{5}{4} > n - \dfrac{8}{5}
\end{align}
となって題意は示される．$n=1$の時は
\begin{align}
  \sum_{k=1}^{1} \dfrac{1}{k^2+1} = \dfrac{1}{2}
\end{align}
だから，
\begin{align}
  T(1) \ge 1 - \dfrac{1}{2} > 1-\dfrac{8}{5}
\end{align}
となって成立する．以上から示された．
