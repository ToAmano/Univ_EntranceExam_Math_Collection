{\bf [解答]}

与えられた方程式を
\begin{align}
  f(x) = x^5+x^4-x^3+x^2-(a+1)x+a \label{eq:1}
\end{align}
とおく．$f(x)=0$ が $x = pi \ (p \in \mathbb{R})$ を解に持つ時，代入して
\begin{align}
  f(pi)
  &= p^5 i + p^4 + p^3 i - p^2 - (a+1)pi + a \\
  &= (p^5+p^3-(a+1)p) i + (p^4-p^2+a) = 0
\end{align}
である．$p, a \in \mathbb{R}$より係数を比較して，
\begin{align}
  p\{p^4+p^2-(a+1)\} = 0 \land a = p^2-p^4 \label{eq:2}
\end{align}
を得る．第二式から$a$を消して第一式に代入して
\begin{align}
  & p \{ p^4+p^2-(p^2-p^4)-1 \} = 0 \\
  & p (2p^4-1) = 0 \\
  & p = 0, \pm \left(\dfrac{1}{2}\right)^{\frac{1}{4}}
\end{align}
となる．よって\cref{eq:2}に代入して$a$を求めて
\begin{align}
  a = 0, \left(\dfrac{1}{2}\right)^{\frac{1}{2}} - \dfrac{1}{2}
\end{align}
である．
