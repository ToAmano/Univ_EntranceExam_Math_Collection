{\bf [解答]}

与えられた数列
\begin{align}
  \begin{cases}
    f(n) = \dfrac{n(n-1)}{2} \\
    a_n = i^{f(n)}
  \end{cases}
\end{align}
について考える．$n=n,n+k$とすると
\begin{align}
  a_{n+k} = i^{\frac{(n+k)(n+k-1)}{2}},
  \quad
  a_n = i^{\frac{n(n-1)}{2}}
\end{align}
だからこれらが等しい時，
\begin{align}
  \dfrac{a_{n+k}}{a_n} = i^{\frac{(n+k)(n+k-1)-n(n-1)}{2}} = 1
\end{align}
である．したがって任意の $n \in \mathbb{Z}$ に対し，
\begin{align}
  g(n) = (n+k)(n+k-1)-n(n-1) \label{eq:1}
\end{align}
が$8$の倍数なら良い．
まず $n=0, 1$ での成立が必要で，以下合同式の法を $8$ として
\begin{align}
  \begin{cases}
    f(0) = k(k-1) \equiv 0 \pmod 8\\
    f(1) = k(k+1) \equiv 0 \pmod 8
  \end{cases}
\end{align}
である．$k$ と $k-1$，$k$ と $k+1$ は互いに素でこの中に $8$ の倍数は多くとも $1$ つしかないから$k \equiv 0$ が必要である．
逆にこの時\cref{eq:1}より$g(n) \equiv 0 \pmod 8$ となり十分である．
以上から求める条件は
\begin{align}
  k = 8m \ (m \in \mathbb{Z})
\end{align}
である．
