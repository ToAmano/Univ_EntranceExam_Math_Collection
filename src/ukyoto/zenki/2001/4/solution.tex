題意の正八面体の一辺を $\sqrt{2}$ とし，$P_1$ を始点とするベクトル $\vec{v}$ の終点を $V$ とする．正八面体の対称性から$k=1$の場合のみ考えれば良い．

任意の $m \ (m=2,\cdots,6)$ に対し
\begin{align}
  \overrightarrow{P_1 P_m} \cdot \vec{v} \le 0
\end{align}
を満たす $V$ の存在範囲は，これらの成す角度が$\dfrac{\pi}{2}$より大きいことと同じである．
すなわち上図で $\overrightarrow{P_1 P_m}$ を法線ベクトルとする $(m=2,3,4,5)$ 4平面で囲まれた部分（$\alpha$ とおく）である．

  \caption{正八面体の中心$O$に対する$\overrightarrow{OX}=\vec{v}$と，点$X$に最も近い頂点$P_k$}
  \label{fig:octahedron_closest_vertex}
\end{figure}

正八面体の中心を $O$ とし，$\overrightarrow{OX} = \vec{v}$ となる点 $X$ をとる．
$P_1, \cdots, P_6$ の中で点 $X$ から最も近い点を $P_k$ とする．$|P_k X| \le |P_m X|$ より
\begin{align}
  |\overrightarrow{OX} - \overrightarrow{OP_k}| \le |\overrightarrow{OX} - \overrightarrow{OP_m}|
\end{align}
である．
各辺 $0$ 以上だから $2$ 乗して
\begin{align}
  & 2 (\overrightarrow{OP_m} - \overrightarrow{OP_k}) \cdot \overrightarrow{OX} \le |\overrightarrow{OP_m}|^2 - |\overrightarrow{OP_k}|^2 = 0 \\
  \therefore
  & \overrightarrow{P_k P_m} \cdot \vec{v} \le 0
\end{align}
となる．$\overrightarrow{P_k P_m} \cdot \vec{v} \neq 0$ から
\begin{align}
  \overrightarrow{P_k P_m} \cdot \vec{v} < 0
\end{align}
