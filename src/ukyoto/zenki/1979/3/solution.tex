{\bf [解答]}

\paragraph{(i)}

$t > 0$から，AM-GM不等式を用いて
\begin{align}
  f(t) \ge 2\sqrt{t \cdot \dfrac{1}{t}} + \sqrt{2\left(t \cdot \dfrac{1}{t}\right) + 1} = 2 + \sqrt{3} \label{eq:1}
\end{align}
である．等号成立は$t=1$の時である．

次に$f(t)g(t)$について
\begin{align}
  & f(t)g(t) = \left(t+\dfrac{1}{t}+2\right) - \left(t+\dfrac{1}{t}+1\right) = 1 \\
  \therefore
  & g(t) = \dfrac{1}{f(t)} \quad (\because f(t) \ge 2+\sqrt{3} > 0)
\end{align}
だから\cref{eq:1}より$g(t)$は$f(t) = 2+\sqrt{3}$の時に最大値$2-\sqrt{3}$をとる．

\paragraph{(ii)}

$x, y > 0$から全体を$\sqrt{xy}$でスケーリングして
\begin{align}
  A = \dfrac{a}{\sqrt{xy}}, \quad
  B = \dfrac{b}{\sqrt{xy}}, \quad
  C = \dfrac{c}{\sqrt{xy}}
\end{align}
を三辺とする三角形が常に存在する$p$の条件を求めれば良い．これは三角不等式
\begin{align}
  |C-A| < B < A + C \label{eq:2}
\end{align}
が常に成り立つような$p$の条件と等しい．

$t = \dfrac{x}{y} \ (t>0)$とおくと
\begin{align}
  A = \sqrt{t+\dfrac{1}{t}+1}, \ B = p, \ C = \sqrt{t} + \dfrac{1}{\sqrt{t}}
\end{align}
だから，(i)より
\begin{align}
  \max(C-A) = 2-\sqrt{3}, \ \min(A+C) = 2+\sqrt{3} \label{eq:3}
\end{align}
である．よって\cref{eq:2}が常に成り立つような$p$の条件は
\begin{align}
  2-\sqrt{3} < p < 2+\sqrt{3}
\end{align}
である．
