{\bf [解答]}

\paragraph{(i)}

引き分けになるのは二人が同じ目を出した時で，その確率は
\begin{align}
  P = \sum_{k=1}^6 p_k^2 \label{eq:1}
\end{align}
である．

\paragraph{(ii)}

$p_k$の和は$1$であるから
\begin{align}
  1 &= p_1 + p_2 + p_3 + p_4 + p_5 + p_6 \label{eq:2}
\end{align}
である．

コーシー・シュワルツの不等式から
\begin{align}
  & (p_1+p_2+p_3+p_4+p_5+p_6)^2 \le 6P \\
  \therefore
  & P \ge \dfrac{1}{6} \ (\because \text{\cref{eq:2}})
\end{align}
が成り立つ．等号成立は$p_1 = p_2 = p_3 = p_4 = p_5 = p_6$の時で, \cref{eq:2}からこの時
\begin{align}
  p_k = \dfrac{1}{6}
\end{align}
である．以上から題意は示された．
