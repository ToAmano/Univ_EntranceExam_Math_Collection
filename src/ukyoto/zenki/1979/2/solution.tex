{\bf [解答]}

与えられた関数
\begin{align}
  f(x) = 1 + 2\cos x + 3\sin x
\end{align}
と関係式
\begin{align}
  af(x) + bf(x-c) = 1 \label{eq:1}
\end{align}
について考える．$\cos x, \sin x$の周期性から
\begin{align}
  0 \le c < 2\pi
\end{align}
として良い．

まず $x=0, \pi, \pi/2$での\cref{eq:1}の成立が必要だから
\begin{align}
  3a + b(1+2\cos c - 3\sin c) &= 1 \label{eq:2} \\
  -a + b(1-2\cos c + 3\sin c) &= 1 \label{eq:3} \\
  4a + b(1+2\sin c + 3\cos c) &= 1 \label{eq:4}
\end{align}
である．\cref{eq:2}+\cref{eq:3}から
\begin{align}
  a + b = 1 \label{eq:5}
\end{align}
となる．

次に\cref{eq:5}を\cref{eq:2,eq:4}に代入して
\begin{align}
  b(-2 + 2\cos c - 3\sin c) + 2 &= 0 \label{eq:6} \\
  b(-3 + 3\cos c + 2\sin c) + 3 &= 0 \label{eq:7}
\end{align}
である．\cref{eq:6}$\times 3$ - \cref{eq:7}$\times 2$から
\begin{align}
  b[-6 + 6\cos c - 9\sin c + 6 - 6\cos c - 4\sin c] = 0
  \quad \therefore
  b \sin c = 0
\end{align}
である．
したがって $b=0$又は$\sin c=0 \iff c=0, \pi (\because 0 \le c < 2\pi)$ である.
それぞれ個別に考える．

\subparagraph{$1^\circ \ b=0$の時}

この時\cref{eq:1}は$af(x)=1$となるが，これが任意の$x$で成立するような$a$は存在せず不適である．

\subparagraph{$2^\circ \ c=0$の時}

この時\cref{eq:6}から$2=0$となり不適である．

\subparagraph{$3^\circ \ c=\pi$の時}

\cref{eq:6}から$b=\dfrac{1}{2}$, \cref{eq:5}から$a=\dfrac{1}{2}$である.
逆にこの時\cref{eq:1}は
\begin{align}
  \dfrac{1}{2}f(x) + \dfrac{1}{2}f(x-\pi) = 1
\end{align}
となるが，\cref{eq:1}を代入すると
\begin{align}
  (1+2\cos x + 3\sin x ) + (1-2\cos x - 3\sin x ) = 2
  \quad \iff
  2 = 2
\end{align}
となってこれは任意の$x$について成立して十分である．
\casesend

以上より $c$ を一般角に直して求める条件は
\begin{align}
  (a, b, c) = \left(\dfrac{1}{2}, \dfrac{1}{2}, \pi + 2n\pi\right) \ (n \in \mathbb{Z})
\end{align}
である．
