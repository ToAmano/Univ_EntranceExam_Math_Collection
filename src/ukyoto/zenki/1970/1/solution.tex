{\bf [解答]} 題意から $y = f'(a)(x-a) + f(a)$ が $(c,0)$ を通る.
\begin{align}
  0 = f'(a)(c-a) + f(a) \quad \dots \text{①}
\end{align}
又, $g(x)$ の定義から
\begin{align}
  g'(x) = \dfrac{f'(x)(x-c) - f(x)}{(x-c)^2}
\end{align}
だから
\begin{align}
  g'(a) = \dfrac{f'(a)(a-c) - f(a)}{(a-c)^2} = 0 \quad (\because \text{①}) \quad \mathbin{/\mkern-5mu/}
\end{align}
