\begin{align}
  h(x) =
  \begin{cases}
    g(x) f\left(\dfrac{x}{a}\right) & (0 \le x) \\
    g(x) f\left(-\dfrac{x}{a}\right) & (x \le 0)
  \end{cases}
\end{align}
が条件 (イ), (ニ) を満たすことを示す. まず (ロ) から $h(0) = 0$ となって (ハ) を満たす.次に (ニ) について,
\begin{itemize}
  \item $a < x$ の時 $f\left(\dfrac{x}{a}\right) = 1$ から $h(x) = g(x)$ \\
  \item $x < -a$ の時 $f\left(-\dfrac{x}{a}\right) = 1$ から $h(x) = g(x)$
\end{itemize}
となって (ニ) も満たす. また $g, f$ 共に微分可能だから $h(x)$ も $x \ne 0$ では微分可能である. $x=0$では (イ) から $f'(0) = 0$ だから左右極限は
\begin{align}
  & \lim_{x \to +0} \dfrac{h(x) - h(0)}{x} = \left. \left( g(x) f\left(\dfrac{x}{a}\right) \right)' \right|_{x=0} = \left. \left( g'(x) f\left(\dfrac{x}{a}\right) + \dfrac{1}{a} g(x) f'\left(\dfrac{x}{a}\right) \right) \right|_{x=0} = 0 \\
  & \lim_{x \to -0} \dfrac{h(x) - h(0)}{x} = \left. \left( g(x) f\left(-\dfrac{x}{a}\right) \right)' \right|_{x=0} = \left. \left( g'(x) f\left(-\dfrac{x}{a}\right) - \dfrac{1}{a} g(x) f'\left(-\dfrac{x}{a}\right) \right) \right|_{x=0} = 0
\end{align}
となって左右極限が一致し，$x=0$ でも $h(x)$ は微分可能である．以上からこの $h(x)$ は題意を満たす．
\begin{align}
  h(x) =
  \begin{cases}
    g(x) f\left(\dfrac{x}{a}\right) & (0 \le x) \\
    g(x) f\left(-\dfrac{x}{a}\right) & (x \le 0)
  \end{cases}
\end{align}

(ロ)を満たす関数
\begin{align}
  f(x) =
  \begin{cases}
    0 & (x \le 0) \\
    2x^2 & (0 \le x \le 1/2) \\
    -2(x-1)^2 + 1 & (1/2 \le x \le 1) \\
    1 & (1 \le x)
  \end{cases}
\end{align}
が (イ) を満たすことをしめす. この関数は全区間で連続であり， $x \ne 0, 1/2, 1$ では微分可能であるから，$x=0, \dfrac{1}{2}, 1$での微分可能性を示せば良い．

簡単のため
\begin{align}
  \begin{cases}
    p(x) = 2x^2 \\
    q(x) = -2(x-1)^2 + 1
  \end{cases}
\end{align}
とおくと，$p'(x) = 4x, q'(x) = -4(x-1)$ だから
\begin{align}
  & \lim_{x \to +0} f'(x) = p'(0) = 0 = \lim_{x \to -0} f'(x) \\
  & \lim_{x \to \frac{1}{2} - 0} f'(x) = p'\left(\dfrac{1}{2}\right) = 2 = q'\left(\dfrac{1}{2}\right) = \lim_{x \to \frac{1}{2} + 0} f'(x) \\
  & \lim_{x \to 1 - 0} f'(x) = q'(1) = 0 = \lim_{x \to 1 + 0} f'(x)
\end{align}
から，$f(x)$ は $x = 0, 1/2, 1$ でも微分可能である．
以上から(イ)は示された．
