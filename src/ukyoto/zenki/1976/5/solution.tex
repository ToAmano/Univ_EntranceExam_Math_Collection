(i) $h(x) =
\begin{cases} g(x) f\left(\dfrac{x}{a}\right) & (0 \le x) \\ g(x) f\left(-\dfrac{x}{a}\right) & (x \le 0)
\end{cases}$ が (イ), (ニ) を満たすことを示す. まず (ロ) から $h(0) = 0$ となって (ハ) を満たす. 次に (ニ) について,
$a < x$ の時 $f\left(\dfrac{x}{a}\right) = 1$ から $h(x) = g(x)$
$x < -a$ の時 $f\left(-\dfrac{x}{a}\right) = 1$ から $h(x) = g(x)$
となって (ニ) も満たす. 又 $g, f$ 共に微分可能だから $h(x)$ も $x \ne 0$ では微分可能である. ここで (イ) から $f'(0) = 0$ だから
\[
  \lim_{x \to +0} \dfrac{h(x) - h(0)}{x} = \left. \left( g(x) f\left(\dfrac{x}{a}\right) \right)' \right|_{x=0} = \left. \left( g'(x) f\left(\dfrac{x}{a}\right) + \dfrac{1}{a} g(x) f'\left(\dfrac{x}{a}\right) \right) \right|_{x=0} = 0
\]
\[
  \lim_{x \to -0} \dfrac{h(x) - h(0)}{x} = \left. \left( g(x) f\left(-\dfrac{x}{a}\right) \right)' \right|_{x=0} = \left. \left( g'(x) f\left(-\dfrac{x}{a}\right) - \dfrac{1}{a} g(x) f'\left(-\dfrac{x}{a}\right) \right) \right|_{x=0} = 0
\]
となって左右極限が一致し，$x=0$ でも $h(x)$ は微分可能. 以上からこの $h(x)$ は題意を満たす.
\[
  h(x) =
  \begin{cases} g(x) f\left(\dfrac{x}{a}\right) & (0 \le x) \\ g(x) f\left(-\dfrac{x}{a}\right) & (x \le 0)
  \end{cases}
\]

(ii) $f(x) =
\begin{cases} 0 & (x \le 0) \\ 2x^2 & (0 \le x \le 1/2) \\ -2(x-1)^2 + 1 & (1/2 \le x \le 1) \\ 1 & (1 \le x)
\end{cases}$ が (イ) を満たすことをしめす. この関数は全区間で連続である. 又 $x \ne 0, 1/2, 1$ では微分可能.

まず，$g(x) = 2x^2$, $h(x) = -2(x-1)^2 + 1$ とおく. $g'(x) = 4x, h'(x) = -4(x-1)$ であり，
\[
  \lim_{x \to +0} f'(x) = g'(0) = 0 = \lim_{x \to -0} f'(x)
\]
\[
  \lim_{x \to \frac{1}{2} - 0} f'(x) = h'\left(\dfrac{1}{2}\right) = 2 = g'\left(\dfrac{1}{2}\right) = \lim_{x \to \frac{1}{2} + 0} f'(x)
\]
\[
  \lim_{x \to 1 - 0} f'(x) = h'(1) = 0 = \lim_{x \to 1 + 0} f'(x)
\]
から，$f(x)$ は $x = 0, 1/2, 1$ でも微分可能. 以上から示された.
