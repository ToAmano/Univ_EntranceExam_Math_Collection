{\bf [解答]}

題意より$f(x)$は多項式だからその次数を$n\in\mathbb{Z}_{\ge 0}$とすると
\begin{align}
  f(x) = \sum_{k=0}^{n}a_{k} x^{k} \quad (a_n \ne 0) \label{eq:1}
\end{align}
と置ける．従ってこれを微分，積分した時
\begin{align}
  \begin{cases}
    f'(x) = \sum_{k=1}^{n}k a_{k} x^{k-1} \\
    \int_1^xf(t)dt = \sum_{k=0}^{n} \dfrac{a_{k}}{k}\left(x^{k+1}-1\right)
  \end{cases}
\end{align}
である．

与えられた関係式
\begin{align}
  f(x)f'(x)+\int_1^xf(t)dt=\dfrac{4}{9}x-\dfrac{4}{9} \label{eq:2}
\end{align}
について，$f(x) \cdot f'(x)$ の最高次は $n a_n^2 x^{2n-1}$, $\int_0^x f(t) dt$ の最高次は $\dfrac{a_n}{n+1} x^{n+1}$ である．よって$2n-1$と$n+1$の大小で左辺の挙動が変わるのでこれによって場合分けする．
\begin{align}
  2n-1 \ge n+1 \quad \therefore  n \ge 2
\end{align}
だから，
\begin{align}
  \begin{cases}
    n \ge 3 \text{の時: 最高次} n a_n^2 x^{2n-1} \\
    n = 2 \text{の時: 最高次} n a_n^2 x^{3}+\dfrac{a_n}{n+1}x^{3} \\
    n \le 1 \text{の時: 最高次} \dfrac{a_n}{n+1} x^{n+1}
  \end{cases}
\end{align}
である．

\subparagraph{$1^\circ \ n \ge 3$ の時}

与式左辺の最高次 $n a_n^2 x^{2n-1}$ が右辺の最高次$\dfrac{4}{9}x$と等しいから
\begin{align}
  n \cdot a_n^2 \cdot x^{2n-1} = \dfrac{4}{9} x
\end{align}
となり，$2n-1=1 \therefore n=1$が必要だが，$n \ge 3$に反して矛盾する．
よってこの時は解はない．

\subparagraph{$2^\circ \ n \le 1$ の時}

与式左辺の最高次 $\dfrac{a_n}{n+1} x^{n+1}$ が右辺の最高次$\dfrac{4}{9}x$と等しいから
\begin{align}
  \dfrac{a_n}{n+1} x^{n+1} = \dfrac{4}{9} x
\end{align}
より，$(a_n, n) = \left(\dfrac{4}{9}, 0\right)$, つまり $f(x) = \dfrac{4}{9}$ が必要である. \cref{eq:2}に代入して
\begin{align}
  (\text{左辺}) = \dfrac{4}{9} (x - 1)
\end{align}
となり，十分である．

\subparagraph{$3^\circ \ n = 2$ の時}

与式左辺の最高次は$\left(3 a_3^2+\dfrac{a_3}{4}\right)x^3$となるから，この係数が零出なければ与式左辺の最高次は $x^3$ となり矛盾する．従って
\begin{align}
  3 a_3^2 + \dfrac{a_3}{4} = 0
  \quad \therefore
  a_n = -\dfrac{1}{6} \quad (\because a_3\neq 0)
\end{align}
が必要である．よって
\begin{align}
  f(x) = -\dfrac{1}{6} x^2 + a_1 + a_0 \label{eq:3}
\end{align}
となる．これを\cref{eq:2}に代入して
\begin{align}
  & \left( -\dfrac{1}{6} x^2 + a_1x + a_0 \right) \left( -\dfrac{1}{3} x + a_1 \right)
  - \dfrac{1}{18} x^3 + \dfrac{a_1}{2} x^2 + a_0x + \dfrac{1}{18} - \dfrac{a_1}{2} - a_0 = \dfrac{4}{9} (x - 1) \\
  \therefore
  & \left( a_1^2 + \dfrac{2}{3} a_0 \right) x + a_1a_0 - \dfrac{1}{2} a_1 - a_0 + \dfrac{1}{18} = \dfrac{4}{9} (x - 1)
\end{align}
となる．係数比較して
\begin{align}
  \begin{cases}
    a_1^2 + \dfrac{2}{3} a_0 = \dfrac{4}{9} \\
    (a_1 - 1) a_0 - \dfrac{1}{2} a_1 + \dfrac{1}{18} = -\dfrac{4}{9}
  \end{cases}
\end{align}
である．第一式より
\begin{align}
  a_0 = \dfrac{-3}{2}a_1^2 + \dfrac{2}{3}
\end{align}
だから第二式に代入して
\begin{align}
  (a_1-1)\left(\dfrac{1}{2} - a_1^2\right) = 0
  \quad \therefore
  a_1 = 1, \pm \dfrac{\sqrt{2}}{2}
\end{align}
だから，
\begin{align}
  (a_1, a_0) = \left(1, -\dfrac{5}{6}\right), \left(\pm \dfrac{1}{\sqrt{2}}, \dfrac{1}{6}\right)
\end{align}
であり，\cref{eq:3}より
\begin{align}
  f(x)
  = -\dfrac{1}{6} x^2 + x - \dfrac{5}{6},
  \quad
  -\dfrac{1}{6} x^2 \pm \dfrac{1}{\sqrt{2}} x + \dfrac{1}{6}
\end{align}
である．
\casesend

以上から求める$f(x)$は
\begin{align}
  f(x)
  = \dfrac{4}{9},
  \quad
  -\dfrac{1}{6} x^2 + x - \dfrac{5}{6},
  \quad
  -\dfrac{1}{6} x^2 \pm \dfrac{\sqrt{2}}{2} x + \dfrac{1}{6}
\end{align}
である．
