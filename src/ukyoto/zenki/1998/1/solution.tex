$\angle \text{BAC} = \angle \text{R}$ となるよう，3頂点 $\text{A}, \text{B}, \text{C}$ を定め，$|AB|=c, |AC|=b, |BC|=a$ とおく．内接円の中心 $\text{O}$ から各辺に下ろした垂線を $\text{H}_1 \sim \text{H}_3$ とする．題意から
\begin{align}
  2r + a + b + c = 2 \label{eq:1}
\end{align}
である．

\paragraph{(1)}

題意より$\square \text{AH}_1\text{OH}_3$ が正方形だから，$|AH_1|=|AH_3|=r$であり，
よって
\begin{align}
  \begin{cases}
    |BH_2| = |BH_1| = c-r \\
    |CH_2| = |CH_3| = b-r
  \end{cases}
  \quad \therefore
  a = b+c-2r \label{eq:2}
\end{align}
である．これを\cref{eq:1}に代入して
\begin{align}
  b+c = 1
\end{align}
だから\cref{eq:1}から斜辺の長さ$a$は
\begin{align}
  a = 1-2r \label{eq:3}
\end{align}
である．

\paragraph{(2)}

\cref{eq:3}と$a>0$より
\begin{align}
  r < \dfrac{1}{2} \label{eq:4}
\end{align}
である．

$\triangle \text{ABC}$ の面積を $S(r)$ とすると，
\begin{align}
  S(r) = \dfrac{1}{2}bc \label{eq:5}
\end{align}
である．以下この最大値をもとめる．
$a, b, c, r > 0$ であり，$\triangle \text{ABC}$ の存在条件から
\begin{align}
  \begin{cases}
    b+c > b+c-2r \\
    2b+c-2r > c \\
    2c+b-2r > b
  \end{cases}
  \quad \therefore
  \begin{cases}
    2r > 0 \\
    b-r > 0 \\
    c-r > 0
  \end{cases}
  \quad \therefore
  0<r, r<b, r<c \label{eq:6}
\end{align}
である．
このもとで$b, c$ は $t$ の2次方程式
\begin{align}
  f(t) = t^2 - t + 2S(r) = 0
\end{align}
の$r$ より大きい2実解である．判別式 $D$とすると$b,c$の存在条件は
\begin{align}
  \begin{cases}
    D \ge 0 \\
    f(r) > 0
  \end{cases}
  \quad \therefore
  \begin{cases}
    1 - 8S(r) \ge 0 \\
    r^2 - r + 2S(r) > 0
  \end{cases}
\end{align}
である．\cref{eq:4}と合わせてこれを図示すると下図斜線部である．
ただし境界は $S(r) = \dfrac{1}{8}$ のみ含む．
したがって求める最大値は
\begin{align}
  \max S(r) =  \dfrac{1}{8}
\end{align}
である．

{\bf [別解]}

$b,c$を完全に消去する方向性もあり得る．
内接円と三角形$ABC$の関係から，$S(r)$をふた通りで表すと
\begin{align}
  S(r) = \dfrac{|AB||AC|}{2} = \dfrac{r(|AB|+|AC|+|BC|)}{2}
\end{align}
だから，\cref{eq:1}より
\begin{align}
  & S(r) = \dfrac{1}{2}bc = \dfrac{1}{2}r(2-2r) \\
  \therefore
  & bc = 2r(1-r)
\end{align}
である．(1)より$b+c=1$だから$b,c$は
\begin{align}
  t^2-t+2r(1-r)=0
\end{align}
の二解である．よって条件は
\begin{align}
  \begin{cases}
    r < \dfrac{1}{2} \\
    1 - 8r(1-r) \ge 0 \\
    r^2 - r + 2r(1-r) > 0
  \end{cases}
\end{align}
で， $0 < r \le \dfrac{2-\sqrt{2}}{4}$ となるから$S(r)$が
\begin{align}
  \max S(r) = S\left(\dfrac{2-\sqrt{2}}{4}\right) = \dfrac{1}{8}
\end{align}
である．
