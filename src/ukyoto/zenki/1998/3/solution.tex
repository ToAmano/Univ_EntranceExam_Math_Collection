点 $\text{X}$ に対して $\overrightarrow{\text{OX}} = \vec{x}$ と定めると，
$\vec{a}, \vec{b}, \vec{c}$ は1次独立である．
題意から
\begin{align}
  \begin{cases}
    \vec{p} = p\vec{a} \\
    \vec{q} = q\vec{a} + (1-q)\vec{b} \\
    \vec{r} = r\vec{b} + (1-r)\vec{c} \\
    \vec{s} = s\vec{c}
  \end{cases} (0 < p,q,r,s < 1) \label{eq:1}
\end{align}
とおける．従って
\begin{align}
  \begin{cases}
    \overrightarrow{PQ} = (q-p)\vec{a} + (1-q)\vec{b}  \\
    \overrightarrow{PS} = -p\vec{a} + s\vec{c} \\
    \overrightarrow{PR} = -p\vec{a} + r\vec{b} + (1-r)\vec{c}
  \end{cases}  \label{eq:2}
\end{align}
である．

平行四辺形$PQRS$の2つの対角線の交点を$H$とすると，
\begin{align}
  \overrightarrow{PH}
  = \dfrac{1}{2}\overrightarrow{PR}
  = \dfrac{1}{2}(\overrightarrow{PS} + \overrightarrow{PQ}) \label{eq:3}
\end{align}
である．\cref{eq:2}を代入して
\begin{align}
  2\overrightarrow{PH}
  & = -p\vec{a} + r\vec{b} + (1-r)\vec{c} \\
  & = (q-2p)\vec{a} + (1-q)\vec{b} + s\vec{c}
\end{align}
だから，$\vec{a},\vec{b},\vec{c}$が一次独立なことから係数を比較して
\begin{align}
  \begin{cases}
    -p = q-2p \\
    r = 1-q \\
    1-r = s
  \end{cases}
  \quad \therefore
  \begin{cases}
    q = s = p \\
    r = 1-p
  \end{cases}
\end{align}
を得る．\cref{eq:3}に代入して
\begin{align}
  \overrightarrow{PH} &= \dfrac{1}{2}\left(-p\vec{a} + (1-p)\vec{b} + p \vec{c}\right) \\
  \therefore
  \vec{h}
  &= \overrightarrow{PH} + \vec{p} \\
  &= \dfrac{-p\vec{a} + (1-p)\vec{b} + p \vec{c}}{2} - \left(p\vec{a}\right) \\
  &= \dfrac{1}{2}( p\vec{a} + (1-p)\vec{b} + p\vec{c} ) \\
  &= p\dfrac{\vec{a}+\vec{c}}{2}+(1-p)\dfrac{\vec{b}}{2} \quad (0<p<1) \label{eq:4}
\end{align}
を得る．

一方で，題意で与えられた線分$AC,OB$のそれぞれの中点を結ぶ線分の点 $\text{X}$ は $\gamma$ に対して $(0 < \gamma < 1)$
\begin{align}
  \quad \vec{x} = \gamma \dfrac{\vec{a}+\vec{c}}{2} + (1-\gamma) \dfrac{\vec{b}}{2} \label{eq:5}
\end{align}
と表せる．\cref{eq:4,eq:5}より\cref{eq:5}で $\gamma = p$ としたものが\cref{eq:4}だから，
たしかに$\text{H}$ は題意の線分上にある．
