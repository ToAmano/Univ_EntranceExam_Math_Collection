以下，それぞれの場合において，直線 $SR$ が $P$ の位置によらず定点 $C$ を通ることを示す．

\subparagraph{$1^\circ$ の時}

円に内接する四角形$PQSR$の対角の和が $\pi$ であること，$AC$と$QS$が平行であることから
\begin{align}
  \begin{cases}
    \angle APB = \angle RSD = \angle BCR = \circ \\
    \angle PAB = \angle PQS = \angle BRC = \times \\
    \angle PBA = \angle RDS = \angle CBR = \triangle
  \end{cases}
\end{align}
となり，
\begin{align}
  \triangle PAB \sim \triangle CRB
\end{align}
が従う．

\subparagraph{$2^\circ$ の時}

この時は円周角の定理と$AC$と$QS$が平行であることから
\begin{align}
  \begin{cases}
    \angle APB = \angle RSD = \angle RCB \\
    \angle PAB = \angle PQD = \angle SRD \\
    \angle PBA = \angle RDS = \angle RBC
  \end{cases}
\end{align}
となり，
\begin{align}
  \triangle PAB \sim \triangle CRB
\end{align}
が従う．
\casesend

以上 $1^\circ, 2^\circ$ からいずれの場合も $\triangle PAB \sim \triangle CRB$ であり，
相似より
\begin{align}
  |BC| = \dfrac{|PB||BR|}{|AB|} \label{eq:1}
\end{align}
である．

一方，直線 $BC$ と円の交点を $E, F$ として方べきの定理から
\begin{align}
  |PB||BR| = |BF||BE| \label{eq:2}
\end{align}
である．
\cref{eq:1,eq:2}から
\begin{align}
  |BC| = \dfrac{|BF||BE|}{|AB|}
\end{align}
となる．この右辺は$P$によらない一定値だから，$|BC|$も一定であり，従って点$C$は$P$によらない定点である．

{\bf [解説]}

本問で用いた円の基本性質を確認しておく．
\begin{itemize}
  \item {\bf 円に内接する四角形の対角の和：}
    円に内接する四角形 $PQSR$ において，弧 $QSR$ に対する中心角を $2\theta_1$，弧 $QPR$ に対する中心角を $2\theta_2$ とすると，一周の角より $2\theta_1 + 2\theta_2 = 2\pi$ である．円周角の定理から $\angle QPR = \theta_1$，$\angle QSR = \theta_2$ であるため，対角の和は $\angle QPR + \angle QSR = \theta_1 + \theta_2 = \pi$ となる．
  \item {\bf 方べきの定理：}
    円の2弦 $PR, EF$ が点 $B$ で交わるとき，$\triangle PBE$ と $\triangle FBR$ に注目する．弧 $ER$ に対する円周角より $\angle BPE = \angle BFR$，対頂角より $\angle PBE = \angle FBR$ であるから，$\triangle PBE \sim \triangle FBR$ が成り立つ．したがって対応する辺の比から
    \begin{align}
      |PB| : |FB| = |BE| : |BR| \iff |PB||BR| = |BF||BE|
    \end{align}
    が得られる．
\end{itemize}
