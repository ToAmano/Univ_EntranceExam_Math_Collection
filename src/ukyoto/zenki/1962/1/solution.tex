{\bf [解答]}

座標平面で，$A(0, a)$, $B(b, 0)$, $C(c, 0)$ ($a>0, b>0, c<0$) として良い．
$PQ$ の中点 $R$ の軌跡を考える．
対称性から，まず$P, Q$ が $AC, BC$ 上を動く時を考える．
この時$P,Q$の座標はパラメータ$t,s$を用いて
\begin{align}
  P(ct, a(1-t)), \quad Q(s, 0) \quad (0 \le t \le 1, c \le s \le b)
\end{align}
とおける．$PQ$ の中点 $R(X, Y)$ とすると
\begin{align}
  \begin{pmatrix} X \\ Y
  \end{pmatrix} = \dfrac{1}{2}
  \begin{pmatrix} ct \\ a(1-t)
  \end{pmatrix} + \dfrac{1}{2}
  \begin{pmatrix} s \\ 0
  \end{pmatrix} = \dfrac{1}{2} t
  \begin{pmatrix} c \\ -a
  \end{pmatrix} + \dfrac{1}{2} s
  \begin{pmatrix} 1 \\ 0
  \end{pmatrix} + \dfrac{1}{2}
  \begin{pmatrix} 0 \\ a
  \end{pmatrix}
\end{align}
となる．これは$(0,a/2)$を始点とし，
$
\begin{pmatrix} 1 \\ 0
\end{pmatrix}$と
$
\begin{pmatrix} c \\ -a
\end{pmatrix}$の張る平行四辺形内の領域（境界含む）を動く．
これを図示すると下図のようになる．

$M$ が各々の領域をうごく時の線本数をしらべる．まず $T_3$ について考える．
$AM$ と $BC$，$BM$ と $AC$，$CM$ と $AB$ の交点を各々 $A', B', C'$ とする．
$P$ を $A$ から，$Q$ を $A'$ から，反時計回りに $PQ$ が $M$ を通るようにうごかす．
すると$P$ は $A \to C' \to B \to A'$，$Q$ は $A' \to C \to B' \to A$と動く．

この時，$M$は$AA'$の中点より$A'$側に，$CC'$の中点より$C'$側にあるから
\begin{align}
  |MA| - |MA'| > 0, \quad |MC'| - |MC| < 0
\end{align}
が成り立つ．
$P$ が $A \to C'$ とうごく時，
\begin{align}
  |MP| - |MQ|
\end{align}
は連続な値をとりながら正 $\to$ 負と変化するので，$|MP| - |MQ| = 0$ となる $(P, Q)$ の組が少なくとも1つ存在する．このような組が2つ以上あると仮定すると，これらを $(P_1, Q_1), (P_2, Q_2)$ として，この4点は平行四辺形をなすが，$AB \mathbin{/\!/} BC$ より矛盾する．よって $|MP| - |MQ| = 0$ となる $(P, Q)$ がただ1つ存在する．同様に $P$ が $C' \to B, B \to A'$ と動く時にも1つずつ，計3つある．

同様に $T_2$ のときは2つ，$T_1$ のときは1つあるので，[解答]のようになる．
