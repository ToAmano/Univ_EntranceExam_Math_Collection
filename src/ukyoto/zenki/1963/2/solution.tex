\[
  AB = \dfrac{r}{\tan \alpha} + \dfrac{r}{\tan \beta}
\]
だから正弦定理から
\[
  \dfrac{r}{\sin 2\gamma} \left( \dfrac{1}{\tan \alpha} + \dfrac{1}{\tan \beta} \right) = 2R
\]
$A = \sin \alpha \sin \beta \sin \gamma$ とおくと
\[
  \dfrac{r \sin(\alpha+\beta)}{2A \cos \gamma} = 2R
\]
$\alpha+\beta+\gamma = \pi/2$ から $\sin(\alpha+\beta) = \sin(\pi/2-\gamma) = \cos \gamma$ だから
\[
  A = \dfrac{r}{4R} \quad \dots \text{①}
\]
である．同様に $\triangle DEF$ において図のように角をおくと ($O''$ は $\triangle DEF$ の内心)
\[
  \sin \alpha' \sin \beta' \sin \gamma' = \dfrac{r}{4R} \quad \dots \text{②}
\]
である．$\{\alpha, \beta, \gamma\} = \{\alpha', \beta', \gamma'\}$ ならば $\triangle ABC$ と $\triangle DEF$ は合同である $\dots$ ③．以下，
\begin{align}
  f(x, y) &= \sin x \sin y \sin(\pi/2 - x - y) \\
  &= \sin x \sin y \cos(x+y) \quad (0 < x, y, \ x+y < \pi/2)
\end{align}
のとりうる値を考える．もし，異なる2組の $(x,y)$ に対し $f(x,y)$ が同じ値をとるなら，①, ②から $\triangle ABC$ と $\triangle DEF$ は合同とは限らない $\dots$ ④

\[
  f(x,y) = \dfrac{1}{2} \sin y \{ \sin(2x+y) - \sin y \}
\]
まず $y$ を固定して考える．$0 < x < \pi/2$ から $y < 2x+y < \pi-y$, $0 < y < \pi/2$ に注意して右辺 $g(y)$ とおくと
\[
  0 < g(y) \le \dfrac{1}{2} \sin y (1 - \sin y) \quad \dots *
\]
次に $t = \sin y \ (0 < t < 1)$ とおいて，$y$ をうごかすことにより $S = g(y)$ のとりうる領域は図の色付き部分である（境界は，斜線部のみ含む）．
