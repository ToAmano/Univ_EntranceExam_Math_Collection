{\bf [解答]}

\paragraph{(1)}

題意を背理法で示す．
$\sqrt[3]{2}$が有理数だとする．この時互いに素な自然数$a,b$を用いて
\begin{align}
  \sqrt[3]{2}=\dfrac{b}{a}\quad\therefore\ 2a^3=b^3
\end{align}
とかける．したがって$b^3$が$2$の因数を持ち，$2$は素数だから$b$は$2$の倍数である．
この時$b=2b'\ (b'\in\mathbb N)$とかけるから
\begin{align}
  a^3=4b'^3
\end{align}
となり同じく$a$も$2$の倍数となり，$a$と$b$が互いに素であることに矛盾する．
よって背理法により$\sqrt[3]{2}$は無理数である．

\paragraph{(2)}

$\alpha=\sqrt[3]{2}$とおく．$Q(x)$を有理数係数の整式，$a,b,c\in\mathbb{Q}$として
\begin{align}
  P(x)=Q(x)(x^3-2)+ax^2+bx+c \label{eq:1}
\end{align}
とおける．題意より$P(\alpha)=0$だから
\begin{align}
  a\alpha^2+b\alpha+c=0 \label{eq:2}
\end{align}
となる．さらに$x^3-2$を$ax^2+bx+c$で割った商を$R(x)$，余りを$S(x)$とするといずれも係数は有理数で，
\begin{align}
  x^3-2 = R(x)(ax^2+bx+c) + S(x) \label{eq:3}
\end{align}
となる．$S(x)$は一次以下の有理数係数の整式で$S(x)=dx+e$と書ける．
$x=\alpha$を代入すると\cref{eq:2}より
\begin{align}
  S(\alpha) = d\alpha + e = 0 \label{eq:4}
\end{align}
となる．以下$a=b=c=0$であることを示す．

\subparagraph{$1^{\circ}$ $a=0$の時}

\cref{eq:2}は
\begin{align}
  b\alpha + c = 0
\end{align}
となり，$b=c=0$または$b \neq 0, \alpha=-\dfrac{c}{b}$となる．
後者の場合$\alpha$が有理数となり(1)に矛盾するから
\begin{align}
  a = b = c = 0
\end{align}
である．

\subparagraph{$2^{\circ}$ $a\neq 0$の時}

$a\neq 0$の時，まず\cref{eq:3}で$1^{\circ}$と同様に$d=e=0$が従う．
従って\cref{eq:3}より
\begin{align}
  x^3-2 = R(x)(ax^2+bx+c)
\end{align}
となる．左辺を因数分解して
\begin{align}
  (x-\alpha)(x^2+\alpha x + \alpha^2)
\end{align}
だから，これらが一致するには
\begin{align}
  ax^2+bx+c = a(x^2+\alpha x + \alpha^2)
\end{align}
となり，$a,b,c$が有理数であることに反して矛盾する．
\casesend

以上より$a=b=c=0$となり，$P(x)$は$x^3-2$で割り切れる．$\blacksquare$

{\bf [別解]}

\paragraph{(2)}

\cref{eq:2}以下，よくあるテクニックを使う方法もある．
\cref{eq:2}の両辺に$\alpha$をかけて$\alpha^3=2$を用いると
\begin{align}
  b\alpha^2+c\alpha+2a=0 \label{eq:5}
\end{align}
である．$\text{\cref{eq:2}}\times b - \text{\cref{eq:5}}\times a$より
\begin{align}
  (b^2-ac)\alpha+bc-2a^2=0
\end{align}
である．$\alpha$が無理数だから，
\begin{align}
  b^2-ac=0，\qquad bc-2a^2=0
\end{align}
である．$a=0$ならば$b=c=0$が従うが，$a\neq 0$とすると
\begin{align}
  b^3=2a^3 \quad\therefore\ \alpha=\dfrac{b}{a}
\end{align}
となって$\alpha$が無理数であることに反して矛盾する．

以上から$a=b=c=0$となり題意は示された．$\blacksquare$
