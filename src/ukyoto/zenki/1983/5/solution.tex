{\bf [解答]} 到達時刻 $t_0$ とする．右のように点 P, Q を定める．
\[ ||OP|| = |t-a|, \quad ||OQ|| = |t_0-b|, \quad ||PQ|| = \sqrt{2}(t_0-t) \]
だから，$\triangle OPQ$ にピタゴラスの定理を用いて，
\[ 2(t_0-t)^2 = (t-a)^2 + (t_0-b)^2 \quad \cdots \text{①} \]

$S = t_0 - t$ とすると，$S$ を min にする $t$ をもとめれば良い．①に代入して
\begin{align}
  2 S^2 &= (t-a)^2 + (S + t - b)^2 \\
  &= S^2 + 2(t-b)S + (t-b)^2 + (t-a)^2
\end{align}
\[ \therefore S^2 - 2(t-b)S - (t-a)^2 - (t-b)^2 = 0 \]
\[ \therefore S = t-b + \sqrt{2(t-b)^2 + (t-a)^2} \quad (\because S > 0) \]
であるから，両辺 $t$ で微分して，
\[ \dfrac{dS}{dt} = 1 + \dfrac{2(t-b) + (t-a)}{\sqrt{2(t-b)^2 + (t-a)^2}} \]
だから，
\[ \dfrac{dS}{dt} \ge 0 \iff \sqrt{2(t-b)^2 + (t-a)^2} \ge -2(t-b) - (t-a) \]
$-2(t-b) - (t-a) \ge 0 \iff t \le \dfrac{a+2b}{3}$ のもとで2乗して解く（$t \ge \dfrac{a+2b}{3}$ のときは常に $\dfrac{dS}{dt} \ge 0$ ）
\begin{align}
  2(t-b)^2 + (t-a)^2 &\ge 4(t-b)^2 + (t-a)^2 + 4(t-a)(t-b) \\
  \iff 0 &\ge 2(t-b)^2 + 4(t-b)(t-a) \\
  &= 2(t-b) \{ 3t - (2a+b) \} \\
  \iff \dfrac{2a+b}{3} &\le t \le b \quad (\because 0 < a < b)
\end{align}
だから，下表をうる．
