到達時刻を $t_0$ とする．上図のように切り替え時刻$t$での点 P, Q を$P_t(t-a,0),Q_t(0,t-b)$，
到達時刻$t_0$での点$P,Q$を$P_{t_0}=Q_{t_0}(0,t_0-b)$とおくと点$P$の$[t,t_0]$での速さが$\sqrt{2}$だから
\begin{align}
  |P_tQ_{t_0}| = \sqrt{2}(t_0-t)
\end{align}
である．そこで$\triangle OP_tQ_{t_0}$に三平方の定理を用いて
\begin{align}
  & |P_tQ_{t_0}|^2 = |OP_t|^2 + |OQ_{t_0}|^2 \\
  \therefore
  & 2(t_0-t)^2 = (t-a)^2 + (t_0-b)^2 \label{eq:1}
\end{align}
である．

さて，$s = t_0 - t$ とすると$s$ を最小にする $t$ をもとめれば良い．\cref{eq:1}に代入して$t_0$を消去すると
\begin{align}
  2 s^2
  &= (t-a)^2 + (s + t - b)^2 \\
  &= s^2 + 2(t-b)s + (t-b)^2 + (t-a)^2 \\
  & s^2 - 2(t-b)s - (t-a)^2 - (t-b)^2 = 0 \\
  \therefore
  & s = t-b + \sqrt{2(t-b)^2 + (t-a)^2} \quad (\because s > 0) \label{eq:2}
\end{align}
だから両辺 $t$ で微分して，
\begin{align}
  \dfrac{ds}{dt} = 1 + \dfrac{2(t-b) + (t-a)}{\sqrt{2(t-b)^2 + (t-a)^2}} \label{eq:3}
\end{align}
を得る．そこでこの符号を考える．
\begin{align}
  \dfrac{ds}{dt} \ge 0 \iff \sqrt{2(t-b)^2 + (t-a)^2} \ge -2(t-b) - (t-a)
\end{align}
これは$-2(t-b) - (t-a) \ge 0 \iff t \le \dfrac{a+2b}{3}$ のもとで2乗して良い．$t \ge \dfrac{a+2b}{3}$ のときは常に $\dfrac{ds}{dt} \ge 0$ である:
\begin{align}
  2(t-b)^2 + (t-a)^2 &\ge 4(t-b)^2 + (t-a)^2 + 4(t-a)(t-b) \\
  \iff
  0 &\ge 2(t-b)^2 + 4(t-b)(t-a) \\
  &= 2(t-b) \{ 3t - (2a+b) \} \\
  \iff
  \dfrac{2a+b}{3} &\le t \le b \quad (\because 0 < a < b)
\end{align}
だから，$s$の増減表は以下のようになる．

\end{table}

したがって$s$が最小になるのは $t = \dfrac{2a+b}{3}$ の時である．
