{\bf [解答]}

与えられた不等式
\begin{align}
  4m<n^2<4m+\dfrac{a}{\sqrt{m}}+\dfrac{b}{m} \quad (m,a,b>0) \label{eq:1}
\end{align}
について，簡単のため
\begin{align}
  f(m) = \dfrac{a}{\sqrt{m}}+\dfrac{b}{m} \label{eq:2}
\end{align}
とおいて，
\begin{align}
  4m < n^2 < 4m + f(m) \label{eq:3}
\end{align}
について考える．
$f(m)$は$m,a,b>0$より $m$ について単調減少であり，$f(1)=a+b,\lim_{m\to\infty}f(m)=0$だから
$y=f(m)$のグラフは以下のようになる．

\paragraph{(イ)}

\cref{eq:3}は$f(m)$の単調減少性より
\begin{align}
  4m < n^2 < 4m + f(m) \le 4m + f(1) =4m+(a+b)
\end{align}
となるから，$f(1)=a+b$の値に応じて場合分けする．

\subparagraph{$1^\circ$ $f(1)<1$ つまり $a+b < 1$ の時}

この時\cref{eq:3}は
\begin{align}
  4m < n^2 < 4m + f(m) \le 4m + f(1) < 4m+1
  \quad\therefore
  4m < n^2 < 4m+1
\end{align}
となり，これが解を持つとすると $4m$ と $4m+1$ の間に整数が存在することになり矛盾する．
よってこの時不等式\cref{eq:3}は解なしである．

\subparagraph{$2^\circ$ $f(1)\ge 1$ つまり $a+b \ge 1$ の時}

この時，$f(m)$の単調減少性と$\lim_{m\to\infty}f(m)=0$から，
\begin{align}
  f(m_0+1) < 1 \le f(m_0)
  %  \dfrac{a}{\sqrt{m_0}} + \dfrac{b}{m_0} \ge 1 > \dfrac{a}{\sqrt{m_0+1}} + \dfrac{b}{m_0+1}
\end{align}
をみたす $m_0 \in \mathbb{N}$ が存在する．
$m \ge m_0+1$ の時は $1^\circ$ と同じく不等式\cref{eq:3}は解なしである．
したがって解答があるのは $1 \le m \le m_0$ の時である．この時，
\begin{align}
  4m < N < 4m + \dfrac{a}{\sqrt{m}} + \dfrac{b}{m}
\end{align}
をみたす $N \in \mathbb{N}$ は $\left[ \dfrac{a}{\sqrt{m}} + \dfrac{b}{m} \right]$ 個であるから，全ての $N$ に $n \in \mathbb{Z}$ が $n=\pm\sqrt{N}$で2つずつ対応していたとしても，$n$ は $2 \left[ \dfrac{a}{\sqrt{m}} + \dfrac{b}{m} \right]$ 個である．以上から，解は多くとも
\begin{align}
  \sum_{m=1}^{m_0} 2 \left[ \dfrac{a}{\sqrt{m}} + \dfrac{b}{m} \right]
\end{align}
であり，これは有限の値をとる．
\casesend

以上 $1^\circ, 2^\circ$ から題意は示された．

\subparagraph{(ロ)}

\cref{eq:3}に$a=8,b=9$を代入すると
\begin{align}
  \begin{cases}
    4m < n^2 < 4m + f(m) \quad (m \ge 9)\\
    f(m) = \dfrac{8}{\sqrt{m}} + \dfrac{9}{m}
  \end{cases} \label{eq:4}
\end{align}
である．$f(m)$は単調減少だから，$m \ge 9$において
\begin{align}
  f(m) \le f(9) = \dfrac{11}{3} = 3.6\cdots
\end{align}
である．よって\cref{eq:4}を満たす$n^2 \in\mathbb{Z}$は
\begin{align}
  n^2 = 4m+1, \, 4m+2, \, 4m+3
\end{align}
に限られる．$\bmod 4$ で考えると$n^2 \equiv 0, 1$ だから適するものは $n^2 = 4m+1$ に限られる．
よって題意は示された．

\subparagraph{(ハ)}

$n<0$なる$n$が解ならば$-n(>0)$も解だから，$n>0$で考えれば良い．
この時(ロ)から解は $n = \sqrt{4m+1}$ である．
つまり $n$ が最大の時 $m$ が最大であるから最大となる$m$を求める．

まず $n^2 = 4m+1$ が解であるには\cref{eq:4}より$f(m)>1$が必要で，
\begin{align}
  & 1 < \dfrac{8}{\sqrt{m}} + \dfrac{9}{m} \\
  \therefore
  & (m-9)^2 < 64m \quad (\because m \ge 9)
\end{align}
が必要である．これを解いて $m\ge 9$ では
\begin{align}
  9 \le m \le 80
\end{align}
となる．この時$4m+1$は
\begin{align}
  37 \le 4m+1 \le 321 \label{eq:5}
\end{align}
であり，$6^2 < 37 < 7^2$ から $6 < \sqrt{37} < 7$,
$17^2=289 < 321 < 324=18^2$ から $17 < \sqrt{321} < 18$なので，
\cref{eq:5}の両辺平方根をとって，$n \in \mathbb{N}_{>0}$ から
\begin{align}
  7 \le n \le 17
\end{align}
である．従って $n=17$ をみたす $m$ があればこれが求める値で，
$n^2 = 289 = 4m+1$ を解いて計算すると $(n, m) = (17, 72)$ が求める最大値である．
