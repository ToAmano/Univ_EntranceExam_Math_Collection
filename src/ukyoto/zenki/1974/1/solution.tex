3点 $A(\cos\alpha, \sin\alpha), B(\cos\beta, \sin\beta), C(\cos\gamma, \sin\gamma)$ を頂点とする 三角形$ABC$ を考える. この外心は $(0,0)$ で, 題意の関係式から重心も $(0,0)$ である.

外心と重心が一致するのは正三角形なので, $\Delta ABC$ は正三角形である．
従って
\begin{align}
  \beta - \alpha = \gamma - \beta = \dfrac{2\pi}{3}
\end{align}
である．

{\bf [別解]}

与えられた関係式
\begin{align}
  \begin{cases}
    \cos\alpha+\cos\beta+\cos\gamma=0 \\
    \sin\alpha+\sin\beta+\sin\gamma=0
  \end{cases}
\end{align}
を$\cos^2\gamma + \sin^2\gamma = 1$ に代入して$\gamma$を消去して
\begin{align}
  & 2 + 2\cos(\beta - \alpha) = 1 \\
  & \cos(\beta - \alpha) = -\dfrac{1}{2} \\
  \therefore
  &\beta - \alpha = \dfrac{2}{3}\pi, \, \dfrac{4}{3}\pi
\end{align}
である．

同様に$\beta$を消去すると
\begin{align}
  \gamma - \alpha = \dfrac{2}{3}\pi, \, \dfrac{4}{3}\pi
\end{align}
である．

以上と $0 \le \alpha < \beta < \gamma < 2\pi$ から
\begin{align}
  \beta - \alpha = \dfrac{2}{3}\pi,
  \quad
  \gamma - \alpha = \dfrac{4}{3}\pi
  \quad
  \gamma - \beta = \dfrac{2}{3}\pi
\end{align}
である．
