$O$ を原点，$OX$ を $x$ 軸とする上図のような座標系を考える．
$OY$ の方向ベクトルを $
\begin{pmatrix} \cos\theta \\ \sin\theta
\end{pmatrix}$
とおく ($0 < \theta < \pi$)，点 $A(\alpha, \beta)$ とおく．

題意から $P_1(t_1, 0)$, $Q_1(t_1\cos\theta, t_1\sin\theta)$, $P_2(t_2, 0)$, $Q_2(t_2\cos\theta, t_2\sin\theta)$ ($0 < t_1 < t_2$) とおける．$P_1 Q_1 \perp OA$ 又は $P_2 Q_2 \perp OA$ の時，$OP_1 = OQ_1$, $OP_2 = OQ_2$ から，$A$ は $\angle XOY$ の2等分線上にあるから良い．
そこで以下 $\angle OAP_1 \ne \pi/2$, $\angle OAP_2 \ne \pi/2$ の時を考える．

このもとで題意の条件から
\begin{align}
  \begin{cases}
    \tan \angle OAP_1 &= \tan \angle OAQ_1 \\
    \tan \angle OAP_2 &= \tan \angle OAQ_2
  \end{cases} \label{eq:1}
\end{align}
が成り立つと仮定する．

上図の3点 $P, Q, R$ に対し
\begin{align}
  \tan \theta = \dfrac{\sin\theta}{\cos\theta} = \dfrac{|PQ| \cdot |PR| \sin\theta}{|PQ| \cdot |PR| \cos\theta} = \dfrac{2 (\triangle PQR \text{の面積})}{\overrightarrow{PQ} \cdot \overrightarrow{PR}}
\end{align}
だから，$P_k,Q_k$の座標を用いて $t_1, t_2$ は方程式
\begin{equation}
  \dfrac{|\beta(t-\alpha) + \alpha\beta|}{-\alpha(t-\alpha) + \beta^2} = \dfrac{|\beta(t\cos\theta-\alpha) - \alpha(t\sin\theta-\beta)|}{-\alpha(t\cos\theta-\alpha) - \beta(t\sin\theta-\beta)} \label{eq:2}
\end{equation}
の異なる二つの実数解である．

ここでさらに$A$の座標を$(\alpha,\beta)=(r\cos p,r\sin p)$とおくと，$A$が$\angle XOY$の内部にあるから
\begin{align}
  0 < r, 0 < p < \theta \label{eq:3}
\end{align}
である．\cref{eq:2}に代入すると
\begin{align}
  &\dfrac{|r\sin p \cdot t|}{-r\cos p \cdot t + r^2}
  = \dfrac{|r(\sin p \cos \theta - \cos p \sin \theta ) t|}{-r(\cos p \cos \theta + \sin p \sin \theta) t + r^2} \\
  &\dfrac{|r\sin p \cdot t|}{-r\cos p \cdot t + r^2}
  = \dfrac{|rt\sin(p-\theta)|}{-rt\cos(\theta-p) + r^2}
\end{align}
となる．$t > 0, \sin p > 0, t > 0, \sin(\theta-p) > 0$ から両辺の$rt/|r|$を割って絶対値も外して
\begin{align}
  &\dfrac{\sin p }{-t\cos p + r}
  = \dfrac{\sin(\theta-p)}{-t\cos(\theta-p) + r} \\
  & \sin p (-t\cos(\theta-p) + r) = \sin(\theta-p)(-t\cos p + r) \\
  & \left(\sin p \cos(\theta-p) - \sin(\theta-p)\cos p\right) t + r\left(\sin p - \sin(\theta-p )\right) = 0 \\
  \therefore
  & \sin(2p - \theta) t + r\left(\sin p - \sin(\theta-p)\right) = 0 \label{eq:4}
\end{align}
である．\cref{eq:4}が$t$について異なる2つの実数解を持つ必要があるが，
$\sin(2p - \theta) \neq 0$の時は左辺は$1$次式だから不適である．そこで
\begin{align}
  \sin(2p - \theta) = 0 \label{eq:5}
\end{align}
が必要で，この時\cref{eq:4}と$r>0$から
\begin{align}
  \sin p = \sin(\theta - p) \label{eq:6}
\end{align}
である．

題意と\cref{eq:3}より$0 < p < \theta < \pi$ だから，\cref{eq:5,eq:6}を満たすのは
\begin{align}
  2p - \theta 0 \quad \therefore \theta = 2p \label{eq:7}
\end{align}
である．この時\cref{eq:4}が$t$についての恒等式になって常に\cref{eq:1}は満たされる．
\cref{eq:7}の時，$p = \dfrac{\theta}{2}$，つまり $A$ が $\angle XOY$ の2等分線上にある．

以上から題意は示された．

各図形量を上図のようにおく．
この時 $OP = OQ$ となる $\alpha$ が少なくとも2つある条件をしらべる．
ただし
\begin{align}
  0 < \theta, \alpha, \psi < \pi, 0 < \theta+\psi < \pi, a > 0 \label{eq:8}
\end{align}
とする．

$\triangle OPA, \triangle OQA$に正弦定理から
\begin{align}
  &
  \begin{cases}
    \dfrac{|OP|}{\sin\angle PAO} = \dfrac{|OA|}{\sin\angle OPA} \\
    \dfrac{|OQ|}{\sin\angle QAO} = \dfrac{|OA|}{\sin\angle OQA}
  \end{cases}\\
  &
  \begin{cases}
    |OP| = \dfrac{a \sin\alpha}{\sin(\pi - \theta - \alpha)} \\
    |OQ| = \dfrac{a \sin\alpha}{\sin(\pi - \psi - \alpha)}
  \end{cases}
\end{align}
だから，\cref{eq:8}より$|OP| = |OQ|$ の時，
\begin{align}
  & \sin(\pi - \theta - \alpha) = \sin(\pi - \psi - \alpha) \\
  & \sin(\theta - \alpha) + \sin(-\psi + \alpha) = 0 \\
  & -2 \sin\left(\dfrac{\theta - \psi}{2}\right) \cos\left(\dfrac{\theta + \psi}{2} - \alpha\right) = 0
\end{align}
である．
$0 < \dfrac{\theta + \psi}{2} < \dfrac{\pi}{2}, 0 < \alpha < \pi$ から
\begin{align}
  \theta = \psi \quad \text{or} \quad \dfrac{\theta + \psi}{2} = \alpha
\end{align}
となる．$\theta = \psi$ の時は題意を満たす．
$\dfrac{\theta + \psi}{2} = \alpha$ の時これを満たす $\alpha$ は2つはないから不適である．以上より$\theta = \psi$となり，$A$は$\angle POQ$の二等分線である．
