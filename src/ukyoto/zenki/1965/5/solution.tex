{\bf [解答]}

まず微分係数の定義を述べる．
$g(x) = \dfrac{f(x) - f(a)}{x - a}$ とおく．
$\displaystyle \lim_{x \to a+0} g(x)$ と $\displaystyle \lim_{x \to a-0} g(x)$ が一致する時，$\displaystyle \lim_{x \to a} g(x)$ を $f(x)$ の $x = a$ における微分係数という．

\paragraph{(ア)}

$f(x) = \dfrac{1}{x^3}$の時，$g(x)$を計算すると
\begin{align}
  g(x)
  & = \dfrac{\dfrac{1}{x^3} - 1}{x - 1} \\
  & = \dfrac{1 - x^3}{x^3} \dfrac{1}{x - 1} \\
  & = \dfrac{-1}{x^3}(x^2 + x + 1)
\end{align}
より，
\begin{align}
  \lim_{x \to 1+0} g(x) = \lim_{x \to 1-0} g(x) = -3
\end{align}
となり，定義から
\begin{align}
  g'(1) = -3
\end{align}
である．

\paragraph{(イ)}

$f(x) = \sqrt{x^2 + x + 1}$の時，$g(x)$を計算すると
\begin{align}
  g(x)
  & = \dfrac{\sqrt{x^2 + x + 1} - \sqrt{3}}{x - 1} \\
  & = \dfrac{1}{x - 1} \dfrac{(x^2 + x - 2)}{\sqrt{x^2 + x + 1} + \sqrt{3}} \\
  &= \dfrac{x + 2}{\sqrt{x^2 + x + 1} + \sqrt{3}}
\end{align}
だから左右極限は
\begin{align}
  \lim_{x \to 1+0} g(x) = \lim_{x \to 1-0} g(x) = \dfrac{3}{2\sqrt{3}} = \dfrac{1}{2}\sqrt{3}
\end{align}
となり，定義から
\begin{align}
  g'(1) = \dfrac{1}{2}\sqrt{3}
\end{align}
である．
