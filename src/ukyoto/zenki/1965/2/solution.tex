{\bf [解答]}

与えられた方程式
\begin{align}
  kx^2-(k+2)^2x+(ak^2+4k+b)=0 \quad (k>0) \label{eq:1}
\end{align}
について考える．この根の1つを $\alpha$ とすると，\cref{eq:1}に代入して
\begin{align}
  (\alpha - a)k^2 + (\alpha^2 - 4\alpha + 4)k + b - 4\alpha = 0 \label{eq:2}
\end{align}
となる．これが$k$によらずに成り立つためには，この式が$k$ についての恒等式である．
よって係数を比較して
\begin{align}
  & a = \alpha, \quad (\alpha - 2)^2 = 0, \quad b = 4\alpha \\
  \therefore
  & \alpha = 2,\quad a = 2, \quad b = 8 \label{eq:3}
\end{align}
である．\cref{eq:1}に代入して与えられた方程式は
\begin{align}
  & k x^2 - (k+2)^2 x + (2k^2 + 4k + 8) = 0 \\
  \therefore
  & (x - 2)\left(k x - (k^2 + 2k + 4)\right) = 0
\end{align}
となるから，もう片方の解は
\begin{align}
  x = \dfrac{k^2 + 2k + 4}{k} = k + \dfrac{4}{k} + 2 \ge 8
\end{align}
である．ただし最後の不等号では$k > 0$ から AM-GMを用いた．
等号成立は $k = \dfrac{4}{k} \ \therefore k = 2$の時である．

従って求める条件は\cref{eq:3}より
\begin{align}
  \alpha = 2,\quad a = 2, \quad b = 8
\end{align}
であり，この時もう一方の解は $k = 2$ の時に最小値 $8$ をとる．
