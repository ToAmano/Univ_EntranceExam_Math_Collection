題意の平面$H$の方程式は
\begin{align}
  H: z=y-1 \label{eq:1}
\end{align}
である．円柱の方程式は
\begin{align}
  C: x^2+y^2 \le 4 \quad (0 \le z \le 1) \label{eq:2}
\end{align}
だから，\cref{eq:1}で切り取られるうち$(0,2,0)$を含む部分は$1 \le y \le 2$を満たす．
そこで $y=2\sin\theta$ $(\dfrac{\pi}{6}\leqq\theta\leqq\dfrac{\pi}{2})$で図形を切断すると，
\begin{align}
  \begin{cases}
    x^2 \le 4-4\sin^2\theta = 4\cos^2\theta  \\
    0 \le z \le 2\sin\theta-1
  \end{cases}
\end{align}
となり，下図斜線部のような長方形になる．

この面積$S(\theta)$とすると
\begin{align}
  S(\theta)=4\cos\theta(2\sin\theta-1)
\end{align}
だから，求める体積$V$は
\begin{align}
  \begin{split}
    V
    &=\int_1^2S(\theta)\,d(2s)\\
    &=\int_{\pi/6}^{\pi/2}S(\theta)\dfrac{d(2\sin\theta)}{d\theta}\,d\theta\\
    &=\int_{\pi/6}^{\pi/2}4\cos\theta(2\sin\theta-1)\,2\cos\theta\,d\theta\\
    &=8\int_{\pi/6}^{\pi/2}(2\cos^2\theta\sin\theta-\cos^2\theta)\,d\theta\\
    &=8\left[-\dfrac{2}{3}\cos^3\theta\right]_{\pi/6}^{\pi/2}
    -8\cdot\dfrac{1}{2}\left[\theta+\dfrac{1}{2}\sin2\theta\right]_{\pi/6}^{\pi/2}\\
    &=\dfrac{16}{3}\left(\dfrac{\sqrt{3}}{2}\right)^3
    -4\left(\dfrac{\pi}{3}-\dfrac{1}{2}\cdot\dfrac{\sqrt{3}}{2}\right)\\
    &=3\sqrt{3}-\dfrac{4}{3}\pi
  \end{split}
\end{align}
である．
