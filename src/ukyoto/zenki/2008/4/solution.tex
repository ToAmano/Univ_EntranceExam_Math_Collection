\paragraph{【乙】}

{\bf [解答]}

与えられた関数の絶対値の中身を
\begin{align}
  \begin{cases}
    f(x)=x^2-2 \\
    g(x)=2x^2+ax-1
  \end{cases} \label{eq:1}
\end{align}
とおくと$f(x)=0$は$x=\pm\sqrt{2}$に解を持つ．
$g(x)=0$については$g(0)=-1<0$および$g$の2次係数が正なので2異実根を持ち，それらは
\begin{align}
  x=\dfrac{-a\pm\sqrt{a^2+8}}{4} \equiv \alpha_{\pm} \quad (\text{複合同順}) \label{eq:2}
\end{align}
とおく．題意の方程式
\begin{align}
  |f(x)| = |g(x)| \label{eq:3}
\end{align}
は$a\to -a$の入れ替えに対して$x\to -x$とすれば対称なので，
$a \ge 0$で考えれば$a <0$の場合は$-a$の時と同じだけ解が存在する．
そこで以下$a \ge 0$で考える．

\cref{eq:3}は$\alpha_{\pm}$と$\pm\sqrt{2}$の大きさに応じて解の様子が変わるので以下これによって場合分けする．上図の$y=\alpha_{\pm},y=\pm\sqrt{2}$のグラフより，$a \ge 0$であり得るのは以下のパターンである．

\begin{align}
  \begin{cases}
    -\sqrt{2}<\alpha_{-}<\alpha_{+}<\sqrt{2} \quad\therefore -\dfrac{3\sqrt{2}}{2}<a<\dfrac{3\sqrt{2}}{2}\\
    -\sqrt{2}=\alpha_{-}<\alpha_{+}<\sqrt{2} \quad\therefore a = \dfrac{3\sqrt{2}}{2}\\
    \alpha_{-}<-\sqrt{2}<\alpha_{+}<\sqrt{2} \quad\therefore \dfrac{3\sqrt{2}}{2} < a
  \end{cases}
\end{align}

この時は$-\sqrt{2}\leqq\alpha_{-}<\alpha_{+}\leqq\sqrt{2}$となるから，
$-\sqrt{2} \le x \le \alpha_{-}, \alpha_{+} \le x \le \sqrt{2}$に一つづつ解を持つ．
残りの区間については$f(x),g(x)$の符号が等しいから，与えられた方程式の解は
\begin{align}
  |f(x)|=|g(x)| \iff f(x)=g(x) \iff x^2+ax+1=0 \iff x=\dfrac{-a\pm\sqrt{a^2-4}}{2}\equiv \beta_{\pm} \label{eq:4}
\end{align}
となる．これと$\alpha_{\pm},\pm\sqrt{2}$の大きさを比べると
\begin{itemize}
  \item $a<2$ の時: $\beta_{\pm}$は虚数となり\cref{eq:4}は解なし．
  \item $a=2$ の時: $\beta_{\pm}=0$となり，$-\alpha_{-}<\beta_{\pm}<\alpha_{+}$より\cref{eq:4}は解を一つもつ．
  \item $a>2$の時: $\beta_{\pm}$は二つの異なる実数となり\cref{eq:4}は二つの実数解を持つ．
\end{itemize}

以上より\cref{eq:3}全体の解の数は
\begin{itemize}
  \item $a<2$ の時: 2個
  \item $a=2$ の時: 3個
  \item $a>2$の時:  4個
\end{itemize}
である．

{\bf [別解]}

与えられた方程式の絶対値を直接外すと，
\begin{align}
  |f(x)|=|g(x)|
  &\ \Longleftrightarrow\ 2x^2+ax-1=\pm(x^2-2)\\
  &\ \Longleftrightarrow\ a=\dfrac{-2x^2+1\pm(x^2-2)}{x}\quad(x=0\text{は解でない}),\\
  &\ \Longleftrightarrow\ a=-\left(x+\dfrac{1}{x}\right)\quad\text{又は}\quad
  a=-3x+\dfrac{3}{x}
\end{align}
である．よって$xy$平面において，$y=a$と$y=-\left(x+\dfrac{1}{x}\right), -3x+\dfrac{3}{x}$のグラフの交点の数が解の個数である．
