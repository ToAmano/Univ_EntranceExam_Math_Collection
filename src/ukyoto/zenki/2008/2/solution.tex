$n$秒の間に訪れる頂点について，
\begin{itemize}
  \item 2頂点$A,B$にしかおとずれない確率を$a_n$ \\
  \item 3頂点$A,B,C$にしかおとずれない確率を$b_n$ \\
  \item 4頂点$A,B,C,D$の全てを訪れる確率を$c_n$
\end{itemize}
とおくと，$c_n$を求めれば良い．また，頂点の対称性より
\begin{itemize}
  \item 他の2頂点のみしか訪れない場合（$AC,AD$）も確率$a_n$ \\
  \item 他の3頂点のみしか訪れない場合（$ABD,ACD$）も確率$b_n$
\end{itemize}
だから，確率の合計が$1$になることより
\begin{align}
  3a_n+3b_n+c_n = 1 \label{eq:1}
\end{align}
である．そこで$a_n,b_n$を求めることによって$c_n$を求める．

まず$a_n$について，$P$は$A\to B\to A\to B\to\cdots$の移動をくり返すので
\begin{align}
  a_n=\left(\dfrac{1}{3}\right)^n \label{eq:2}
\end{align}
である．

次に$b_n$について，常に3頂点のうち$D$をのぞく2頂点のみに移動をつづけ，かつ$A,B,C$全てに訪れることから
\begin{align}
  b_n
  =\left(\dfrac{2}{3}\right)^n-2a_n
  =\left(\dfrac{2}{3}\right)^n-2\left(\dfrac{1}{3}\right)^n \label{eq:3}
\end{align}
である．

\cref{eq:2,eq:3}を\cref{eq:1}に代入して求める確率は
\begin{align}
  c_n=1-3a_n-3b_n
  =1-3\left\{\left(\dfrac{2}{3}\right)^n-\left(\dfrac{1}{3}\right)^n\right\}
\end{align}
である．
