{\bf [解答]}

与えられた関係式
\begin{align}
  \begin{cases}
    x + y + z = a \\
    x^3+y^3+z^3 = a^3
  \end{cases} \label{eq:1}
\end{align}
について考える．
新しく$x' = x-a, y' = y-a, z' = z-a$ とおいて\cref{eq:1}に代入して
\begin{align}
  \begin{cases}
    x' + y' + z' = -2a \\
    (x'+a)^3 + (y'+a)^3 + (z'+a)^3 = a^3
  \end{cases} \label{eq:2}
\end{align}
である．第二式を展開すると
\begin{align}
  & (x'^3+y'^3+z'^3) + 3a(x'^2+y'^2+z'^2)+3a^2(x'+y'+z')+3a^3 = a^3 \\
  & (x'^3+y'^3+z'^3) + 3a(x'^2+y'^2+z'^2)-6a^3+3a^3 = a^3 \quad (\because\text{\cref{eq:2}}) \\
  \therefore
  & (x'^3+y'^3+z'^3) + 3a(x'^2+y'^2+z'^2)-4a^3 = 0 \label{eq:3}
\end{align}
だから，第一項の変形
\begin{align}
  x'^3+y'^3+z'^3
  & = (x'+y'+z')^3 - 3(x'+y'+z')(x'y'+y'z'+z'x') + 3x'y'z' \\
  & = -8a^3 + 6a(x'y'+y'z'+z'x') + 3x'y'z' \quad (\because\text{\cref{eq:2}})
\end{align}
を代入して
\begin{align}
  & -8a^3 + 6a(x'y'+y'z'+z'x') + 3x'y'z' + 3a(x'^2+y'^2+z'^2)-4a^3 = 0 \\
  & 3a(x'^2+y'^2+z'^2+2x'y'+2y'z'+2z'x') + 3x'y'z' - 12a^3 = 0 \\
  & 3a(x'+y'+z')^2 + 3x'y'z' - 12a^3 = 0 \\
  & 3a(-2a)^2 + 3x'y'z' - 12a^3 = 0  \quad (\because\text{\cref{eq:2}}) \\
  & x'y'z' = 0
\end{align}
である．よって $x', y', z'$ のうち少なくとも1つは 0, つまり $x, y, z$ のうち少なくとも1つは $a$ である．

{\bf [別解]}

\cref{eq:1}より$a$を消去すると
\begin{align}
  x^3 + y^3 + z^3 = (x+y+z)^3
\end{align}
だから，右辺を展開して整理すると
\begin{align}
  & 3x^2 y + 3x^2 z + 3y^2 x + 3y^2 z + 3z^2 x + 3z^2 y + 6xyz = 0 \\
  \therefore
  & (y+z)(z+x)(x+y) = 0
\end{align}
である．よって$z=-y,x=-z,y=-x$のいずれかが成立するが，$x+y+z=a$に代入すると，$x,y,z$のいずれかが$a$になる．よって題意は示された．
