外接円の半径を$I$とする．外心から各辺におろした垂線について，例えば辺$BC$と点$P$に着目して$\triangle OBP, \triangle OCP$に三平方の定理を用いて
\begin{align}
  |BP|^2 = |CP|^2 = \sqrt{|OP|^2-I^2}
  \quad\therefore
  |BP| = |CP|
\end{align}
だから，$P$は辺$BC$の中点である．同様に$Q,R$も各辺の中点である．
よって$O$を原点とする各点の位置ベクトルをその小文字で表すと
\begin{align}
  \vec{p} &= \dfrac{1}{2}(\vec{b} + \vec{c}) \\
  \vec{q} &= \dfrac{1}{2}(\vec{a} + \vec{c}) \\
  \vec{r} &= \dfrac{1}{2}(\vec{a} + \vec{b})
\end{align}
である．これを与えられた関係式
\begin{align}
  \vec{p} + 2\vec{q} + 3\vec{r} = \vec{0} \label{eq:1}
\end{align}
に代入して
\begin{align}
  & \dfrac{1}{2}(\vec{b} + \vec{c}) + \dfrac{2}{2}(\vec{a} + \vec{c}) + \dfrac{3}{2}(\vec{a} + \vec{b}) = 0 \\
  & 5\vec{a} + 4\vec{b} + 3\vec{c} = 0 \label{eq:2}
\end{align}
である．

\paragraph{(2)}

\cref{eq:2}を変形して
\begin{align}
  \overrightarrow{OA} = -\dfrac{4\overrightarrow{AB} + 3\overrightarrow{AC}}{12} \label{eq:3}
\end{align}
である．$\overrightarrow{AB}\perp\overrightarrow{OC}, \overrightarrow{AC}\perp\overrightarrow{OB}$より
\begin{align}
  &
  \begin{cases}
    \overrightarrow{AB} \cdot \left(\overrightarrow{AO} - \dfrac{1}{2}\overrightarrow{AB}\right) = 0 \\
    \overrightarrow{AC} \cdot \left(\overrightarrow{AO} - \dfrac{1}{2}\overrightarrow{AC}\right) = 0
  \end{cases} \\
  &
  \begin{cases}
    \overrightarrow{AB} \cdot \left(3\overrightarrow{AC} - 2\overrightarrow{AB}\right) = 0 \\
    \overrightarrow{AC} \cdot \left(-3\overrightarrow{AC} +4\overrightarrow{AB}\right) = 0
  \end{cases} \\
  &
  \begin{cases}
    3\overrightarrow{AB}\cdot\overrightarrow{AC} - 2|\overrightarrow{AB}|^2 = 0 \\
    4\overrightarrow{AB}\cdot\overrightarrow{AC} - 3|\overrightarrow{AC}|^2 = 0
  \end{cases}
\end{align}
である．$\overrightarrow{AB}$と$\overrightarrow{AC}$のなす角$\theta\ (0 < \theta < \pi)$として
\begin{align}
  \begin{cases}
    3|AC|\cos\theta - 2|AB|= 0 \\
    4|AB|\cos\theta - 3|AC|=0
  \end{cases}
\end{align}
である．第一式より$|AB|=\dfrac{3}{2}|AC|\cos\theta$だから第二式に代入して
\begin{align}
  \cos^2\theta = \dfrac{1}{2}
  \quad\therefore
  \theta = \angle BAC = \dfrac{\pi}{4}
\end{align}
である．
