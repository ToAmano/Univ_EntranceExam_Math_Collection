{\bf [解答]}

以下
\begin{align}
  0 < \theta < \dfrac{\pi}{2} \label{eq:1}
\end{align}
で考える．

\paragraph{(1)}

$0 < \theta < \dfrac{\pi}{2}$ から $0 < 2\theta < \pi, \quad 0 < 3\theta < \dfrac{3}{2}\pi$ より題意を満たす$\theta$は
\begin{align}
  \sin 3\theta = \sin 2\theta
  \Leftrightarrow
  3\theta = 2\theta,\ 3\theta = \pi - 2\theta
  \Leftrightarrow
  \theta = \dfrac{\pi}{5} \quad (\because\text{\cref{eq:1}}) \label{eq:2}
\end{align}
である．

\paragraph{(2)}

二倍角，三倍角の公式から
\begin{align}
  \begin{cases}
    \sin 3\theta = 3\sin\theta - 4\sin^3\theta \\
    \sin 2\theta = 2\sin\theta\cos\theta
  \end{cases}
\end{align}
だから，題意の方程式
\begin{align}
  \sin 3\theta = m\sin 2\theta + n\sin\theta  \label{eq:3}
\end{align}
に代入して
\begin{align}
  & 3\sin\theta - 4\sin^3\theta = 2m\sin\theta\cos\theta + n\sin\theta \\
  & \sin\theta\left[4\sin^2\theta + 2m\cos\theta - 3 + n\right] = 0
\end{align}
を得る．\cref{eq:1}より$\sin \theta \neq 0$で両辺割って
\begin{align}
  & 4(1-\cos^2\theta) + 2m\cos\theta - 3 + n = 0 \\
  \therefore
  & f(\cos\theta) = 4\cos^2\theta - 2m\cos\theta - n -1 = 0 \label{eq:4}
\end{align}
を得る．以下これを満たす$(m,n,\theta)$を求めよう．
\cref{eq:1}より$0 < \cos\theta < 1$だから，この範囲で$f(\cos\theta)$が解を持つ．
$f(0)=-1-n<0$だから，この条件は
\begin{align}
  f(1)>0 \iff 3> 2m+n  \label{eq:5}
\end{align}
である．

$m, n$ が非負整数であることから\cref{eq:5}を満たす組は
\begin{align}
  (m, n) = (0, 0), (0, 1), (0, 2), (1, 0) \label{eq:6}
\end{align}
であるから個別に検討する．

\subparagraph{$(m, n) = (0, 0)$の時}

\cref{eq:4}より
\begin{align}
  f(c) = 4c^2 - 1 = 0
  \quad \therefore
  c = \dfrac{1}{2}, \theta = \dfrac{\pi}{3}
\end{align}
である．

\subparagraph{$(m,n)=(0,1)$の時}

\cref{eq:4}より
\begin{align}
  f(c) = 4c^2-2 = 0
  \quad \therefore
  c = \dfrac{\sqrt{2}}{2}, \theta = \dfrac{\pi}{4}
\end{align}
である．

\subparagraph{$(m,n)=(0,2)$の時}

\cref{eq:4}より
\begin{align}
  f(c) = 4c^2 - 3 = 0
  \quad \therefore
  c = \dfrac{\sqrt{3}}{2}, \theta = \dfrac{\pi}{6}
\end{align}
である．

\subparagraph{$(m,n)=(1,0)$の時}

この時は\cref{eq:3}は
\begin{align}
  \sin 3\theta = \sin 2\theta
\end{align}
となるから，\cref{eq:2}から$\theta = \dfrac{\pi}{5}$である．
\casesend

以上をまとめて，求める解は
\begin{align}
  (m, n, \theta) = \left(0, 0, \dfrac{\pi}{3}\right), \left(0, 1, \dfrac{\pi}{4}\right), \left(0, 2, \dfrac{\pi}{6}\right), \left(1, 0, \dfrac{\pi}{5}\right)
\end{align}
である．
