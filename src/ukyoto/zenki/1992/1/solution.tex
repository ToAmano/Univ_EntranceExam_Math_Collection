[解] $a,b,c>0 \cdots$ \textcircled{1}
\begin{equation*}
  \pi : \dfrac{x}{a} + \dfrac{y}{b} + \dfrac{z}{c} = 0 \cdots \textcircled{2}
\end{equation*}

\textcircled{2}の表式から，$\pi$は3点$(0,0,0)$，$(a,-b,0)$，$(0,b,-c)$を通る平面で，切り口は下図のような六角形になる．従って，
$AD, AF, DE, BC, BF, CE$
との交点
\begin{align}
  AD &: z=0, y=x-1 \text{ より交点 } \left(\dfrac{a}{a+b}, \dfrac{-b}{a+b}, 0\right) \\
  AF &: y=0, z=x-1 \text{ より交点 } \left(\dfrac{a}{a+c}, 0, \dfrac{-c}{a+c}\right) \\
  DE &: x=0, z=y+1 \text{ より交点 } \left(0, \dfrac{-b}{b+c}, \dfrac{c}{b+c}\right) \\
  BC &: z=0, y=x+1 \text{ より交点 } \left(\dfrac{-a}{a+b}, \dfrac{b}{a+b}, 0\right) \\
  BF &: x=0, z=y-1 \text{ より交点 } \left(0, \dfrac{a}{b+c}, \dfrac{-c}{b+c}\right) \\
  CE &: y=0, x=z+1 \text{ より交点 } \left(\dfrac{-a}{a+c}, 0, \dfrac{c}{a+c}\right)
\end{align}
