{\bf [解答]}

以下
\begin{align}
  0 \le a < \dfrac{\pi}{4}, \ 0 \le b < \dfrac{\pi}{4} \label{eq:1}
\end{align}
で不等式
\begin{align}
  \sqrt{\tan a \cdot \tan b} \leqq \tan \left( \dfrac{a+b}{2} \right) \leqq \dfrac{1}{2}(\tan a + \tan b) \label{eq:2}
\end{align}
について考える．

\begin{lemma}[補題1]
  $0 \le x < \pi/4$ において，$f(x) = \tan x$ は下に凸である．
\end{lemma}

\begin{proof}
  $f'(x) = \dfrac{1}{\cos^2 x} > 0$, $f''(x) = 2 \dfrac{\tan x}{\cos^2 x} \ge 0$ から示された．$\square$
\end{proof}

\begin{lemma}[補題2]
  $0 < x < \pi/4$ において $g(x) = \log(\tan x)$ は上に凸である．
\end{lemma}

\begin{proof}
  $g'(x) = \dfrac{1}{\cos^2 x \cdot \tan x} > 0$, $g''(x) = - \dfrac{1}{\sin^2 x} + \dfrac{1}{\cos^2 x} = \dfrac{2\sin^2 x - 1}{\sin^2 x \cos^2 x} < 0$から示された．$\square$
\end{proof}

[補題1]から凸不等式より\cref{eq:2}の右側の不等号は示された．$\square$

次に左側については$a,b$の値で場合分けして考える．

\subparagraph{$1^\circ \ a>0, b>0$ の時}

両辺 $\log$ をとることができて，
\begin{align}
  \dfrac{1}{2} \log\left(\tan a \cdot \tan b\right)
  \leqq \log \tan \left( \dfrac{a+b}{2} \right)
\end{align}
だから，[補題2]および凸不等式から示される．

\subparagraph{$2^\circ \ ab=0$ の時}

\begin{align}
  \begin{cases}
    \sqrt{\tan 0 \cdot \tan b} = 0 \\
    \tan\left(\dfrac{0+b}{2}\right) \ge 0
  \end{cases}
\end{align}
から明らかに成立する．
\casesend

以上より\cref{eq:2}の左側の不等号も示された．$\square$
