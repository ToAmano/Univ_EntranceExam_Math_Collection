$n+1$回目の試行前に赤玉が$i$個あるのは，$n$回目の試行前に$i+1$個の赤玉があって一つ赤玉を取り出した場合か，$n$回目の試行前に$i$個の赤玉があって白玉を取り出した場合だから，
\begin{align}
  \begin{cases}
    P_{1,n+1} = \dfrac{1}{N+3}\left[ Q_{1,n} + P_{2,n}\right] \\
    P_{2,n+1} = \dfrac{2}{N+3}\left[ Q_{2,n} + P_{3,n}\right] \\
    P_{3,n+1} = \dfrac{3}{N+3} Q_{3,n}
  \end{cases} \label{eq:1}
\end{align}
と書ける．

また，$P_{i,n}$と$Q_{i,n}$について，$n$回目の試行前には$N+3-i$個の白玉と$i$個の赤玉があるから，どちらの球を取り出すかの確率を考えて
\begin{align}
  Q_{1,n} = (N+2)P_{1,n} \quad Q_{2,n} = \dfrac{N+1}{2} P_{2,n} \quad Q_{3,n} = \dfrac{N}{3} P_{3,n} \label{eq:2}
\end{align}
なる関係がある．\cref{eq:2}を\cref{eq:1}に代入して求める漸化式は
\begin{align}
  \begin{cases}
    P_{1,n+1} = \dfrac{1}{N+3} ( (N+2) P_{1,n} + P_{2,n} ) \\
    P_{2,n+1} = \dfrac{2}{N+3} ( \dfrac{N+1}{2} P_{2,n} + P_{3,n} ) \\
    P_{3,n+1} = \dfrac{3}{N+3} \cdot \dfrac{N}{3} P_{3,n} = \dfrac{N}{N+3} P_{3,n}
  \end{cases} \label{eq:3}
\end{align}
である．

\paragraph{(2)}

$P_n = P_{1,n} + P_{2,n} + P_{3,n}$ だから\cref{eq:3}を辺々足し合わせて
\begin{align}
  P_{n+1} = \dfrac{N+2}{N+3} P_n \label{eq:4}
\end{align}
である．また初期条件は$n=1$の時，$N+3$個の中から$3$個の赤玉のどれかを引く確率だから$P_1=\dfrac{3}{N+3}$である．
よって\cref{eq:4}と等比数列の公式から
\begin{align}
  P_n = \left(\dfrac{N+2}{N+3}\right)^{n-1} \dfrac{3}{N+3}
\end{align}
である．
