点$X$に対して$\overrightarrow{AX}=\vec x$とおく．
題意の点$P,Q,R$は$s,t,u$を$0<s,t,u<1$を満たす実数として
\begin{align}
  \vec p=s\vec b，\qquad\vec q=t\vec c+(1-t)\vec b，\qquad\vec r=u\vec c
\end{align}
とおける．$\triangle PQR$の重心を$G$とすると
\begin{align}
  \vec g
  = \dfrac{\vec{p}+\vec{q}+\vec{r}}{3}
  = \dfrac{(t+u)}{3}\vec c+\dfrac{(1+s-t)}{3}\vec b \label{eq:1}
\end{align}
である．

ここで，$\lambda=\dfrac{1+s-t}{3}$，$\mu=\dfrac{t+u}{3}$とおくと，$s,t,u\in(0,1)$が独立に動くことから，$(\lambda,\mu)$は頂点
\begin{align}
  (1/3,0),(2/3,0),(2/3,1/3),(1/3,2/3),(0,2/3),(0,1/3)
\end{align}
を持つ六角形の内部（境界含まず）を動く．
