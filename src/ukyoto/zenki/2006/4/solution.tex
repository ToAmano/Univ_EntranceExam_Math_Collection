{\bf [解答]}

$n$が素数で$n>3$の時を考えると，
\begin{align}
  n\not\equiv0\pmod{3},
  \quad \therefore
  n^2+2 \equiv 1+2 \equiv 0\pmod3
\end{align}
となり，$n^2+2$は素数ではないので不適である．

よって$n=2, 3$であり，それぞれの場合を考えると
\begin{itemize}
  \item $n=3$の時，$n^2+2=11$は素数である．\\
  \item $n=2$の時，$n^2+2=6$は素数でない．
\end{itemize}
以上から題意は示された．$\blacksquare$
