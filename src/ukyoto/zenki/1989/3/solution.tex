[解] $f(x)$ はモニック多項式であるとしてよく，$f(x) = x^3 + ax^2 + bx + c$ とおける．
$f'(x) = 3x^2 + 2ax + b$ より，
\begin{align}
  f(x) = \dfrac{1}{3}\left(x + \dfrac{1}{3}a\right)f'(x) + \left(\dfrac{2}{3}b - \dfrac{2}{9}a^2\right)x + (c - ab)
\end{align}
題意から，
\begin{align}
  \dfrac{2}{3}b - \dfrac{2}{9}a^2 = 0 \quad \therefore \quad b = \dfrac{1}{3}a^2
\end{align}
だから
\begin{align}
  f(x) = x^3 + ax^2 + \dfrac{1}{3}a^2 x + c
\end{align}
\begin{align}
  f'(x) = 3x^2 + 2ax + \dfrac{1}{3}a^2 = 3\left(x + \dfrac{1}{3}a\right)^2 \ge 0
\end{align}
より，$f(x)$ は単調増加．これと $f(x) \to \pm\infty \ (x \to \pm\infty)$ から，$f(x) = 0$ をみたす実数 $x$ がただ1つある．($f$ は連続) //
