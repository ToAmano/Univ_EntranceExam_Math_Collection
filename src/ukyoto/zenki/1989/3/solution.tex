{\bf [解答]}

$f(x)$ はモニック多項式であるとしてよく，
\begin{align}
  f(x) = x^3 + ax^2 + bx + c \label{eq:1}
\end{align}
とおける．一階微分は
\begin{align}
  f'(x) = 3x^2 + 2ax + b \label{eq:2}
\end{align}
だから$f(x)$を$f'(x)$で割ると
\begin{align}
  f(x) = \dfrac{1}{3}\left(x + \dfrac{1}{3}a\right)f'(x) + \left(\dfrac{2}{3}b - \dfrac{2}{9}a^2\right)x + \left(c - \dfrac{1}{9}ab\right)
\end{align}
である．題意から余りが定数なので，
\begin{align}
  \dfrac{2}{3}b - \dfrac{2}{9}a^2 = 0
  \quad \therefore
  \quad b = \dfrac{1}{3}a^2
\end{align}
だから，\cref{eq:1,eq:2}に代入して
\begin{align}
  & f(x) = x^3 + ax^2 + \dfrac{1}{3}a^2 x + c \\
  & f'(x) = 3x^2 + 2ax + \dfrac{1}{3}a^2 = 3\left(x + \dfrac{1}{3}a\right)^2 \ge 0
\end{align}
より，$f(x)$ は単調増加である．これと $f(x) \to \pm\infty \ (x \to \pm\infty)$ から，$f(x) = 0$ をみたす実数 $x$ がただ1つある．よって題意は示された．
