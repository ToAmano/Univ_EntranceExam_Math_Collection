$a$ 以外の2辺の長さを $x, y$ とすると題意より
\begin{align}
  x + y = m \label{eq:1}
\end{align}
である．ここで
\begin{align}
  s = \dfrac{1}{2}(x+y+a) = \dfrac{1}{2}(m+a) \label{eq:2}
\end{align}
とおくと，ヘロンの公式から三角形の面積 $T$ は
\begin{align}
  T
  &= \sqrt{s(s-x)(s-y)(s-a)} \\
  &\le \sqrt{s(s-a)} \cdot \dfrac{(s-x)+(s-y)}{2} \quad (\because S-x, S-y > 0 \text{ から AM-GM}) \\
  &= \sqrt{s(s-a)} \cdot \dfrac{2s-m}{2} \\
  &= a\sqrt{s(s-a)} = \text{const.}
\end{align}
となる．等号成立は $s-x = s-y \therefore x=y=\dfrac{m}{2}$ の時で，この時三角形は2等辺三角形である．よって題意は示された．

四角形 $ABCD$ とし，4辺の長さを $x, y, z, w$ とすると題意より $m$ を定数 ($>0$) として
\begin{align}
  x + y + z + w = m \label{eq:3}
\end{align}
となる．$|BC| = a\ (>0)$, $x+y = k\ (k > a)$ と固定すると$z+w=m-k$で一定である．
この時(1)より$\triangle ABC$, $\triangle BCD$ は $x=y, z=w$ で面積最大である．この面積を $S(k)$ とする．三角形$ABC, BCD$の存在条件から
\begin{align}
  0 < a < \dfrac{m}{2} \label{eq:4}
\end{align}
である．

上図で$E$ は $BC$ の中点とすると，$\triangle AEB, \triangle CDE$に三平方の定理を用いて
\begin{align}
  \begin{cases}
    |AE| = \sqrt{|AB|^2-|BE|^2} = \sqrt{\left(\dfrac{k}{2}\right)^2 - \left(\dfrac{a}{2}\right)^2} \\
    |ED| = \sqrt{|CD|^2-|CE|^2} = \sqrt{\left(\dfrac{m-k}{2}\right)^2 - \left(\dfrac{a}{2}\right)^2}
  \end{cases}
\end{align}
である．よって$S(k)$は
\begin{align}
  S(k)
  &= \dfrac{1}{2} |BC| (|AE| + |ED|) \\
  &= \dfrac{1}{2} a (|AE| + |ED|) \\
  &= \dfrac{1}{2} a \left\{ \sqrt{\left(\dfrac{k}{2}\right)^2 - \left(\dfrac{a}{2}\right)^2} + \sqrt{\left(\dfrac{m-k}{2}\right)^2 - \left(\dfrac{a}{2}\right)^2} \right\} \\
  &\le \dfrac{1}{2} a \sqrt{(1+1) \left\{ \left(\dfrac{k}{2}\right)^2 - \left(\dfrac{a}{2}\right)^2 + \left(\dfrac{m-k}{2}\right)^2 - \left(\dfrac{a}{2}\right)^2 \right\}} \quad (\because \text{コーシー・シュワルツ, 等号成立は } k = \dfrac{1}{2}m) \\
  &= \dfrac{1}{2} a \sqrt{k^2 - mk + \dfrac{1}{2}m^2 - a^2} \\
  &= \dfrac{1}{2} a \sqrt{\left(k - \dfrac{1}{2}m\right)^2 + \dfrac{1}{4}m^2 - a^2} \\
  &\le \dfrac{1}{2} a \sqrt{\dfrac{1}{4}m^2 - a^2} \quad (\text{等号成立は } k = \dfrac{1}{2}m) \label{eq:5}
\end{align}
となる．従って$a$ を固定した時は$k = \dfrac{1}{2}m$ で $S(k)$ は最大値 $\dfrac{1}{2} a \sqrt{\dfrac{1}{4}m^2 - a^2}$ をとる．

次に $a$ を$0 < a < \dfrac{1}{2}m$で動かす．\cref{eq:5}を変形して
\begin{align}
  S(k)
  &= \dfrac{1}{2} \sqrt{ -a^4 + \dfrac{1}{4}m^2 a^2 } \\
  &= \dfrac{1}{2} \sqrt{ -\left(a^2 - \dfrac{1}{8}m^2\right)^2 + \dfrac{1}{64}m^4 } \\
  &\le \dfrac{1}{16} m^2 \quad (\text{等号成立は } a = \dfrac{\sqrt{2}}{4}m \text{ のとき})
\end{align}
となる．したがって $S(k)$ は $a = \dfrac{\sqrt{2}}{4}m$ で最大となる．この$a$は$0<a<\dfrac{m}{2}$を満たし十分である．

この時 $x = y = z = w = \dfrac{1}{4}m, a = \dfrac{\sqrt{2}}{4}m$ で，たしかに $\square ABCD$ は正方形である．よって題意は示された．

$\angle BAC + \angle BDC = \theta$ とする．
ブレードシュナイダーの公式から，$S = \dfrac{1}{2}(x+y+z+w) = \dfrac{1}{2}m$ として
\begin{align}
  T &= \sqrt{(S-x)(S-y)(S-z)(S-w) - xyzw \cos^2 \dfrac{\theta}{2}} \\
  &\le \sqrt{ \left\{ \dfrac{(S-x)+(S-y)+(S-z)+(S-w)}{4} \right\}^4 } \quad (\because \text{AM-GM 及び } xyzw \cos^2 \dfrac{\theta}{2} \ge 0) \\
  &= \dfrac{m^2}{16}
\end{align}
等号成立は $x=y=z=w$ かつ $\theta=\pi$，つまり $\square ABCD$ が正方形の時である．
