{\bf [解答]}
\paragraph{(1)}

$N=5,6$について確率変数$X,Y$が独立な時に成立する式
\begin{align}
  P(X \land Y) = P(X)P(Y) \label{eq:1}
\end{align}
が成立するか個別に検討する．

$i=j=0$での成立が必要である．$X=0 \land Y=0$となるのは$1,2$回目とも$5$の目を出した時で
\begin{align}
  P(X=0 \land Y=0) = \dfrac{1}{36}
\end{align}
である．一方$X=0$となるのは$5$の目を出した時で
\begin{align}
  P(X=0) = \dfrac{1}{6}
\end{align}
である．$Y=0$となるのは，$1,2$回目に出る目の和が$5$または$10$の時だから
\begin{align}
  P(Y=0) = \dfrac{7}{36}
\end{align}
である．以上から $P(X=0 \land Y=0) = P(X=0)P(Y=0)$ は不成立で$X, Y$は独立ではない．

確率変数$X, Y$に対して$P(X=k)=P(Y=k)=\dfrac{1}{6} \quad (k=0 \sim 5)$であり，また任意の$i,j$について$(X,Y)=(i,j)$となるのは常に一通りだから
\begin{align}
  P(X=i \land Y=j) = \dfrac{1}{36}
\end{align}
である．よって任意の$i, j$に対し $P(X=i \land Y=j) = P(X=i)P(Y=j)$ が成立するので，$X$と$Y$は独立である．

\paragraph{(2)}

$N=5,6$について(1)で調べたので，残りの$N \ge 3$について個別に検討する．

\subparagraph{$1^{\circ} \ N=3$の時}

$P(X=k)=P(Y=k)=\dfrac{1}{3} \quad (k=0 \sim 2)$ であり (1)と同じく，
$P(X=i \land Y=j) = \dfrac{1}{9}$ だから，$X, Y$は独立である．

\subparagraph{$2^{\circ} \ N=4$の時}

$i=j=0$での成立が必要である．$P(X=0) = \dfrac{1}{6}, \quad P(Y=0) = \dfrac{9}{36}, \quad P(X=0 \land Y=0) = \dfrac{1}{36}$ から$X, Y$は非独立である．

\subparagraph{$3^{\circ} \ 7 \le N$の時}

この時は2周まわって6にいくことはないので，1回目に出た目を$A$，2回目を$B$とすると，$Y=6$となるのは $A+B=6$ の5通りである．従って
\begin{align}
  P(Y=6) = \dfrac{5}{36}
\end{align}
であり，また$P(X=6)=\dfrac{1}{6}, \quad P(X=6 \land Y=6)=0$ だから
\begin{align}
  P(X=6)P(Y=6) \neq P(X=6 \land Y=6)
\end{align}
となり，$X$と$Y$は独立ではない．
\casesend

以上から，$X, Y$が独立なのは
\begin{align}
  N=3, 6
\end{align}
の時である．
