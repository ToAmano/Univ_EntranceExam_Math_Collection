まず$1>1-2r$より内側の円の半径が$1-2r$，外側の円の半径が$1$である．
内側の円の半径が$0$以上だから
\begin{align}
  0 < r < \dfrac{1}{2} \label{eq:1}
\end{align}
である．

\paragraph{(1)}

半径$1-2r,1$のドーナツ状の領域に半径$r$の円を入れていく時，上図のように半径$r$の円を順に$C_1, C_2, \cdots, C_n$とし，その中心を$O_1, O_2, \cdots, O_n$とする．$C_1$から始めて$C_1, C_2,C_3,\cdots, C_n$がお互い接するように配置するのがもっとも効率が良いため以下この場合を考える．$C_n$と$C_1$は接する必要はないが，お互い重なる場合は不適である．

上図のように，$O$から$C_i$に引いた接線の接点を$T_i$とし，$\angle T_iOO_i=\theta$とおくと，
\begin{align}
  \sin \theta = \dfrac{r}{1-r} \label{eq:2}
\end{align}
である．円が$n$個あることから全ての円が見込む角度$2n\theta$が$2\pi$以下でないとならず，
\begin{align}
  2n\theta \le 2\pi
  \quad\therefore
  \theta &\le \dfrac{\pi}{n} \label{eq:3}
\end{align}
である．
$n \ge 2$から $\dfrac{\pi}{n} \le \dfrac{\pi}{2}$ であり $0 \le \theta \le \pi/2$ で $\sin \theta$ が単調増加することから，\cref{eq:2,eq:3}より
\begin{align}
  & \dfrac{r}{1-r} \le \sin \dfrac{\pi}{n} \\
  \therefore
  & 0 < r \le \dfrac{\sin \dfrac{\pi}{n}}{1+\sin \dfrac{\pi}{n}} \label{eq:4}
\end{align}
である．これは\cref{eq:1}を満たして十分である．

\paragraph{(2)}

$n+2$個の円の面積の総和$S_n(r)$とおくと
\begin{align}
  \dfrac{S_n(r)}{\pi} &= 1 + (1-2r)^2 + nr^2  \label{eq:5}
\end{align}
だから，両辺$r$で微分して
\begin{align}
  \dfrac{S'_n(r)}{\pi} &= 2 \{(n+4)r - 2\} \label{eq:6}
\end{align}
である．よって$S'_n(r)=0$は唯一の零点を$r=\dfrac{2}{n+4}$に持つ．
これと\cref{eq:4}の上端$r_0= \dfrac{\sin \dfrac{\pi}{n}}{1+\sin \dfrac{\pi}{n}}$を比較する．
\begin{align}
  f(n) & = r_0 - \dfrac{2}{n+4} \\
  & = \dfrac{\sin \dfrac{\pi}{n}}{1+\sin \dfrac{\pi}{n}} - \dfrac{2}{n+4} \\
  & =   1 - \dfrac{1}{1+\sin \dfrac{\pi}{n}} - \dfrac{2}{n+4}
\end{align}
とおくと，$0 \le x \le \dfrac{\pi}{2}$で$\dfrac{2}{\pi}x \le \sin x$だから第二項を評価して
\begin{align}
  f(n) & \ge 1 - \dfrac{1}{1+(2/\pi)(\pi/n)} - \dfrac{2}{n+4} \\
  & = 1 - \dfrac{1}{1+2/n} - \dfrac{2}{n+4} \\
  & = \dfrac{2}{n+2} - \dfrac{2}{n+4} \\
  & = \dfrac{4}{(n+2)(n+4)} > 0
\end{align}
だから，$r_0 > \dfrac{2}{n+4}$となり，常に$S'_n(r)$の零点は\cref{eq:4}の区間内にある．
従って$S_n(r)$の増減表は以下のようになる．

よって$S_n(r)$を最小にする$r$は
\begin{align}
  r = \dfrac{2}{n+4}
\end{align}
である．

{\bf [解説]}

零点については，以下のように愚直に微分してもすぐ計算できる．
\begin{align}
  g(x) = \dfrac{\sin x}{1+\sin x}, \quad h(x) = \dfrac{2x}{\pi+4x} \text{について} \left(0 < x \le \dfrac{\pi}{2}\right)
\end{align}
とおいて
\begin{align}
  g(x) > h(x)
\end{align}
を示せば良い．
$g(x) = 1 - \dfrac{1}{1+\sin x}, \quad h(x) = \dfrac{1}{2} - \dfrac{\pi}{2(\pi+4x)}$ より
$F(x) = g(x) - h(x)$ とおくと
\begin{align}
  F'(x) = - \dfrac{\cos x}{(1+\sin x)^2} + \dfrac{\pi}{2} \dfrac{-4}{(4x+\pi)^2} \le 0 \quad \left(\because 0 < x \le \dfrac{\pi}{2}\right)
\end{align}
より $F(x)$ は単調減少である．これと $F(\pi/2) = \dfrac{1}{2} > 0$ から $F(x) > 0$ なので示された．
