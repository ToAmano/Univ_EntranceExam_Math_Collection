与えられた関数
\begin{align}
  \begin{cases}
    y = 4-x^2 \\
    y = 3x
  \end{cases}
\end{align}
の交点の$x$座標はこれらを連立した二次方程式の解で
\begin{align}
  x^2 + 3x - 4 = 0 \quad
  \therefore
  (x+4)(x-1) = 0 \quad
  \therefore
  x = 1, -4
\end{align}
となる．よって交点は$A(1,3), B(-4,-12)$である．

\paragraph{(1)}

曲線$y=4-x^2$上の点を$P(t, 4-t^2) \ (-4 \le t \le 1)$ とおく．
$P$から直線$AB$におろした垂線の足を$H$とすると，
\begin{align}
  \triangle PAB = \dfrac{1}{2} |AB||PH| \label{eq:1}
\end{align}
だから，$P$ と $AB$ の距離 $|PH|$ が最大の時に$\triangle PAB$ の面積も最大になる．

\begin{align}
  |PH|
  = \dfrac{|3t - (4-t^2)|}{\sqrt{9+1}}
  = \dfrac{|t^2 + 3t - 4|}{\sqrt{10}}
  = \dfrac{\sqrt{10}}{10} \left| \left(t+\dfrac{3}{2}\right)^2 - \dfrac{25}{4} \right|
\end{align}
より，これは$t=-\dfrac{3}{2}$の時に最大値
\begin{align}
  \max |PH| = \dfrac{\sqrt{10}}{10} \cdot \dfrac{25}{4} = \dfrac{5\sqrt{10}}{8}
\end{align}
をとる．この時の$P(p,q)$の座標は$P\left(-\dfrac{3}{2}, \dfrac{7}{4}\right)$である．よって
\begin{align}
  p = -\dfrac{3}{2}
\end{align}
である．

題意の直線は$AB$と傾きが同じだから $y = 3x + \alpha$ とおける ($\alpha \in \mathbb{R}$). これと放物線$y=4-x^2$の交点の $x$ 座標は
\begin{align}
  x^2 + 3x + \alpha - 4 = 0
\end{align}
の2解であり, $x = \dfrac{1}{2}\left(-3 \pm \sqrt{25 - 4\alpha}\right)$ だから, $CD$ の中点 $M$ の$x$ 座標は $x = -\dfrac{3}{2}$ となる. したがって(1)から, 線分 $CD$ は $x = p$ で2等分される. よって題意は示された．

上図のように，$S$のうち$x \le p, p \le x$の部分の面積をそれぞれ$S_1, S_2$とおく．
まず全体の面積$S$は
\begin{align}
  S = \int_{-4}^{1} (4 - x^2 - 3x) dx = \dfrac{1}{6} 5^3 \label{eq:2}
\end{align}
であり，$S_1$は
\begin{align}
  S_1
  & = \int_{-4}^{-\frac{3}{2}} (4 - x^2 - 3x) dx  \\
  & = -\dfrac{1}{3}\left(\dfrac{5}{2}\right)^3 + \dfrac{5}{2}\left(\dfrac{5}{2}\right)^2 \\
  & = \dfrac{1}{12} 5^3 \label{eq:3}
\end{align}
である．よって\cref{eq:2,eq:3}より
\begin{align}
  S_2 = S-S_1 = \dfrac{1}{6} 5^3 - \dfrac{1}{12} 5^3 = \dfrac{1}{12} 5^3
\end{align}
だから$S_1 = S_2$ となる．
