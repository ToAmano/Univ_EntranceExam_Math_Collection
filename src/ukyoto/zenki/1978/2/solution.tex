\paragraph{(1)}

点Xに対し $\overrightarrow{OX} = \vec{x}$ とおく．
$O,A,B$が三角形を成すから$\vec{a}$ と $\vec{b}$ は一次独立である．$G, P, Q$の位置ベクトルは題意より
\begin{align}
  \begin{cases}
    \vec{g} = \dfrac{1}{3}(\vec{a} + \vec{b}) \\
    \vec{p} = h\vec{a} \\
    \vec{q} = k\vec{b}
  \end{cases} \label{eq:1}
\end{align}
である．

従って直線$PQ$上の点$X$は $t \in \mathbb{R}$ として
\begin{align}
  \vec{x} = t\vec{p} + (1-t)\vec{q} = t h\vec{a} + (1-t) k\vec{b}
\end{align}
とおける．これが重心$G$を通るので，\cref{eq:1}で係数比較して
\begin{align}
  th = (1-t)k = \dfrac{1}{3}
\end{align}
となる．$h,k \neq 0$だから
\begin{align}
  t = \dfrac{1}{3h}, 1-t=\dfrac{1}{3k}
\end{align}
となり，辺々足して
\begin{align}
  \dfrac{1}{h} + \dfrac{1}{k} = 3 \label{eq:2}
\end{align}
となる．

\paragraph{(2)}

\cref{eq:1}より，$\triangle OAB, \triangle OPQ$の面積比は$1:hk$だから
\begin{align}
  T = hkS \label{eq:3}
\end{align}
である．\cref{eq:2}より$h+k=3hk$だから代入して
\begin{align}
  h+k = \dfrac{3T}{S} \label{eq:4}
\end{align}
である．よって\cref{eq:3,eq:4}が$hk$平面上に共有点をもてば良い．
$0<h,k\le 1$と合わせて$hk$平面に図示すると以下のようになる．

よってこれらが共有点を持つ条件は
\begin{align}
  & \dfrac{2}{3} + \dfrac{2}{3} \le \dfrac{3T}{S} \le 1 + \dfrac{1}{2} \\
  & \dfrac{4}{3} \le \dfrac{3T}{S} \le \dfrac{3}{2} \\
  \therefore
  & \dfrac{4}{9}S \le T \le \dfrac{1}{2}S
\end{align}
となり，題意の不等式は示された．
