{\bf [解答]}

与えられた関数
\begin{align}
  f(x) = x^3 + mx^2 + nx + 2 \label{eq:1}
\end{align}
について考える．

\paragraph{(1)}

$f(x)=0$の三つの整数解を $\alpha, \beta, \gamma \in \mathbb{Z} (\alpha \le \beta \le \gamma)$ とすると，解と係数の関係より
\begin{align}
  \begin{cases}
    m = -(\alpha + \beta + \gamma) \\
    n = \beta\gamma + \gamma\alpha + \alpha\beta \\
    2 = -\alpha\beta\gamma
  \end{cases}
\end{align}
である．第三式を満たすのは
\begin{align}
  (\alpha, \beta, \gamma) = (-2, -1, -1), (-2, 1, 1), (-1, 1, 2)
\end{align}
であり，この時第一式，第二式に代入して
\begin{align}
  (m, n) = (4, 5), (0, -3), (2, -1)
\end{align}
である．

\paragraph{(2)}

\cref{eq:1}が$k \in \mathbb{Z}$ を解に持つ時，代入して
\begin{align}
  k(k^2 + mk + n) = -2 \label{eq:2}
\end{align}
である．$k, k^2 + mk + n \in \mathbb{Z}$ から
\begin{align}
  (k, k^2 + mk + n) = (-2, 1), (2, -1), (1, -2), (-1, 2) \label{eq:3}
\end{align}
であるから，それぞれ
\begin{align}
  \begin{cases}
    k = -2, 3 - 2m + n = 0 \\
    k = 2, 5 + 2m + n = 0 \\
    k = 1, 3 + m + n = 0 \\
    k = -1, -1 - m + n = 0
  \end{cases} \label{eq:4}
\end{align}
となる．逆にこの時 \cref{eq:2} がみたされるから十分である．

\paragraph{(3)}

\cref{eq:4}から条件は
\begin{align}
  \begin{cases}
    n = 2m - 3, n = -2m - 5, n = -m - 3, n = m + 1 \\
    |m|, |n| \le 5
  \end{cases}
\end{align}
だから，図示すると下図である．

よって $(m, n)$ の組数は
\begin{align}
  10 + 8 + 6 + 6 - 4 = 26 \text{個}
\end{align}
である．
