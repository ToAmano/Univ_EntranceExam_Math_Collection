点$X$に対し $\overrightarrow{OX} = \vec{x}$とすると
$\vec{a}, \vec{b}, \vec{c}$ は1次独立である．
題意より
\begin{align}
  \begin{cases}
    \vec{p}_1 = k\vec{a} \\
    \vec{p}_2 = l\vec{a} + (1-l)\vec{b} \\
    \vec{p}_3 = (1-m)\vec{b} + m\vec{c} \\
    \vec{p}_4 = n\vec{c}
  \end{cases} \label{eq:1}
\end{align}
である．$\square P_1P_2P_3P_4$が平行四辺形だから$\overrightarrow{P_1P_2} = \overrightarrow{P_4P_3}$ なので，\cref{eq:1}より
\begin{align}
  & (l-k)\vec{a} + (1-l)\vec{b} = (1-m)\vec{b} + (m-n)\vec{c} \\
  & l-k=0, \quad m-n=0, \quad 1-l=1-m \\
  \therefore
  & k = l = m = n \quad \text{(答)}
\end{align}
である．

(1)から $k = l = m = n \equiv \alpha$ とおく．
対角線の交点は $P_1P_3$の中点だから，この点$X$として
\begin{align}
  \vec{x}
  = \dfrac{1}{2}(\vec{p}_1+\vec{p}_3)
  = \dfrac{1}{2} \left( \alpha\vec{a} + (1-\alpha)\vec{b} + \alpha\vec{c} \right) \label{eq:2}
\end{align}
である．

一方で$OB, AC$の中点$Y, Z$とすると
\begin{align}
  \vec{y} = \dfrac{1}{2}\vec{b}, \quad
  \vec{z} = \dfrac{1}{2}(\vec{a}+\vec{c})
\end{align}
だから線分$YZ$上の点$W$はパラメータ$t$を用いて
\begin{align}
  \vec{w} = \dfrac{1}{2} \{t(\vec{a}+\vec{c}) + (1-t)\vec{b}\} \quad (0 \le t \le 1) \label{eq:3}
\end{align}
の形でかける．$t = \alpha$ とすると ($0 < \alpha < 1$) \cref{eq:2}から $\vec{w} = \vec{x}$ となるから題意は示された．
