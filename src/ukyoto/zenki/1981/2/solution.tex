[解] 点$X$に対し $\overrightarrow{OX} = \vec{x}$とすると
$\vec{a}, \vec{b}, \vec{c}$ は1次独立であり $\cdots \text{①}$
\begin{align}
  \vec{p_1} &= k\vec{a} \\
  \vec{p_2} &= l\vec{a} + (1-l)\vec{b} \\
  \vec{p_3} &= (1-m)\vec{b} + m\vec{c} \\
  \vec{p_4} &= n\vec{c}
\end{align}

\paragraph{(1)}

$\overrightarrow{P_1P_2} = \overrightarrow{P_4P_3}$ だから
\[ (l-k)\vec{a} + (1-l)\vec{b} = (1-m)\vec{b} + (m-n)\vec{c} \]
①から
\[ l-k=0, \quad m-n=0, \quad 1-l=1-m \]
\[ \therefore k = l = m = n \quad \text{(答)} \]

\paragraph{(2)}

(1)から $k = l = m = n \equiv \alpha$ とおく．
対角線の交点は，$P_1P_3$の中点だから，この点$X$として
\[ \vec{x} = \dfrac{1}{2} \left( \alpha\vec{a} + (1-\alpha)\vec{b} + \alpha\vec{c} \right) \cdots \text{②} \]
一方，$OB, AC$の中点$Y, Z$とすると
\[ \vec{y} = \dfrac{1}{2}\vec{b}, \quad \vec{z} = \dfrac{1}{2}(\vec{a}+\vec{c}) \]
だから，線分$YZ$上の点$W$は
\[ \vec{w} = \dfrac{1}{2} \{t(\vec{a}+\vec{c}) + (1-t)\vec{b}\} \quad (0 \le t \le 1) \]
の形でかける．$t = \alpha$ とすると ($0 < \alpha < 1$) ②から $\vec{w} = \vec{x}$ となるから，
題意は示された．(証明終)
