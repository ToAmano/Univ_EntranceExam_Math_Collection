3辺の長さ $a, b, c$ ($a \leqq b \leqq c$) とすると, 三角不等式から
\begin{align}
  c < a + b \label{eq:1}
\end{align}
が成り立つ. 与えられた長さの中で最大のものは$36$，最小のものは$20$だから，これらを用いて$(a,b,c)=(20,20,36)$とするのが\cref{eq:1}を成立させるのに最も厳しい条件だが
\begin{align}
  a + b - c \geqq 20 + 20 - 36 \geqq 0
\end{align}
となって成立する．従って 問題文の中にある長さのうち任意に3つ持ってくると,三角形を合同で重複することなくつくることができる. 9つの辺の長さから3つをえらぶ方法を考えると
\begin{itemize}
  \item[$1^\circ$] 3辺とも違う長さ $\dots {}_9\mathrm{C}_3 = 84$ 通り
  \item[$2^\circ$] 2等辺三角形 $\dots 2 \cdot {}_9\mathrm{C}_2 = 72$ 通り
  \item[$3^\circ$] 正三角形 $\dots 9$ 通り
\end{itemize}
となる．よって求める場合の数は
\begin{align}
  84 + 72 + 9 = 165 \text{ 通り}
\end{align}
である．
