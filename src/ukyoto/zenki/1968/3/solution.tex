与えられた条件は$y=x$の直線と$y=x^2$の放物線に対して，
\begin{align}
  m \le x \le l \implies m \le x^2 \le l \label{eq:1}
\end{align}
となるような領域である．$x=l$での\cref{eq:1}の成立が必要だから，
\begin{align}
  l^2 \le l
  \quad \therefore
  l(l-1) \le 0
  \quad \therefore
  0 \le l \le 1
\end{align}
が必要である．よって示された．

\paragraph{(2)}

(1)と同様に，$x=m$での\cref{eq:1}の成立が必要だから
\begin{align}
  m \le m^2 \le l^2 \le 1
\end{align}
が必要である．ただし(1)より$0 \le l \le 1$ であることを用いた．
よって
\begin{align}
  \begin{cases}
    m(m-1) \ge 0 \\
    m^2 \le 1
  \end{cases}
  \quad \therefore
  \begin{cases}
    m \le 0, 1 \le m \\
    -1 \le m \le 1
  \end{cases}
  \quad \therefore
  m \le 0 \text{or} m=1
\end{align}
である．よって示された．

\paragraph{(3)}

$m=1$の時，$m \le l$と$0 \le l \le 1$より$l=1$が従うから，
\begin{align}
  S = \{1\}
\end{align}
である．

$m \neq 1$の時(3)より$m < 0$ である．
$m \leqq x \leqq l$ の全ての $x$ で $m \leqq x^2 \leqq l$ となるような $m$ を求める. この時$x^2$のとりうる値は
\begin{align}
  0 \le x^2 \le \max\{m^2, l^2\}
\end{align}
だから，$l^2 \le l$は(1)ですでに満たされていることより，
$m^2 \le l$であることが必要十分である．よってこれを解いて求める条件は
\begin{align}
  -\sqrt{l} \leqq m \leqq 0
\end{align}
である.
