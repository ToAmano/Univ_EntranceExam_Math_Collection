与えられた関数
\begin{align}
  f(x) = x^3 + ax^2 + bx + c \label{eq:1}
\end{align}
について考える．一階微分は
\begin{align}
  f'(x) = 3x^2+2ax+b
\end{align}
である．3次関数では接点と接線が一対一対応するので，$f'(x)=m$となる$x$の数を求めれば良い．よって$f'(x)-m=0$ の判別式$D$として求める個数は
\begin{align}
  \begin{cases}
    D>0 \iff a^2-3(b-m)>0 \text{の時 } 2\text{個} \\
    D=0 \iff a^2-3(b-m)=0 \text{の時 } 1\text{個} \\
    D<0 \iff a^2-3(b-m)<0 \text{の時 } 0\text{個}
  \end{cases}
\end{align}
である．

\paragraph{(2)}

$P_1, P_2$の$x$座標を $p_1, p_2$ とおく ($p_1 < p_2$としてよい)とこれらは(1)より
\begin{align}
  f'(x)-m = 0 \quad \therefore 3x^2+2ax+b-m = 0 \label{eq:2}
\end{align}
の異なる二つの実数解である．

$l_1 : y=l_1(x), l_2 : y=l_2(x)$，$Q_1, Q_2$の$x$座標$q_1, q_2$とすると題意より
\begin{align}
  \begin{cases}
    f(x) - l_1(x) = (x-p_1)^2 (x-q_1)  \\
    f(x) - l_2(x) = (x-p_2)^2 (x-q_2)
  \end{cases} \label{eq:3}
\end{align}
である．$f(x)$は3次，$l_1(x), l_2(x)$は1次だから2次の係数を比較して
\begin{align}
  a = -2p_1 - q_1 = -2p_2 - q_2 \label{eq:4}
\end{align}
である．一方で\cref{eq:2}で解と係数の関係より
\begin{align}
  a = -\dfrac{3}{2}(p_1+p_2) \label{eq:5}
\end{align}
だから，\cref{eq:4}を辺々たして\cref{eq:5}を代入すると
\begin{align}
  & 2a = -2(p_1+p_2) - (q_1+q_2) \\
  & -3(p_1+p_2) = -2(p_1+p_2) - (q_1+q_2) \\
  & p_1+p_2 = q_1+q_2 \\
  \therefore
  & |p_1-q_1| = |q_2-p_2|
\end{align}
を得る．
従って$P_1, Q_1$の$x$座標の差と $P_2, Q_2$のそれが等しく，さらに$P_1Q_1, P_2Q_2$の傾きも等しいので，$|P_1Q_1| = |P_2Q_2|$ である．\quad $\blacksquare$

{\bf [別解]}

    \node[above left] at (2,4) {$Q_1$};
    \node[below right] at (-2,-4) {$Q_2$};
    \node[circle, fill=red!75!black, inner sep=1.5pt] at (0,0) {};
    \node[below left] at (0,0) {$M$};
  \end{tikzpicture}
  \caption{平行な2本の接線と曲線の交点．}
\end{figure}

$P_1(p_1, f(p_1)), P_2(p_2, f(p_2))$ の中点$M(p,q)$とすると
\begin{align}
  \begin{cases}
    p = \dfrac{p_1+p_2}{2} \\
    q = \dfrac{f(p_1)+f(p_2)}{2}
  \end{cases}
\end{align}
\cref{eq:2}において解と係数の関係から
\begin{align}
  a = -\dfrac{3}{2}(p_1+p_2),
  \quad
  b = 3p_1p_2
\end{align}
だから
\begin{align}
  q &= \dfrac{1}{2}(p_1^3+p_2^3) + \dfrac{a}{2}(p_1^2+p_2^2) + \dfrac{b}{2}(p_1+p_2) + c \\
  &= \dfrac{2}{27}a^3 - \dfrac{ab}{3} + c
\end{align}
および
\begin{align}
  f(p)
  &= \left(\dfrac{p_1+p_2}{2}\right)^3 + \dfrac{a}{2}\left(\dfrac{p_1+p_2}{2}\right)^2 + b\left(\dfrac{p_1+p_2}{2}\right) + c \\
  & = \dfrac{2}{27}a^3 - \dfrac{ab}{3} + c \\
  & = q
\end{align}
より，$M$は曲線上の点である．次に$M$が原点になるように$f(x)$を平行移動すると
\begin{align}
  Y = X^3 + \left(b-\dfrac{a^2}{3}\right)X
\end{align}
であり，これは奇関数だから原点対称である．よって$M$に関する対称性により$P_2, Q_2$を$P_1, Q_1$に重ねあわせることができるから$|P_1Q_1| = |P_2Q_2|$である． \quad $\blacksquare$
