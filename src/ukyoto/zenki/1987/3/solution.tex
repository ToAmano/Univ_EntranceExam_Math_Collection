{\bf [解答]}

与えられた不等式
\begin{align}
  a\cos 2\theta + b\cos\theta < 1 \label{eq:1}
\end{align}
について，倍角公式より
\begin{align}
  & a(2\cos^2\theta - 1) + b\cos\theta - 1 < 0 \\
  \therefore
  & f(\cos\theta) = 2a\cos^2\theta + b\cos\theta - (a+1) < 0 \label{eq:2}
\end{align}
とかける．そこで$f(x)<0 \ (-1 \le x \le 1)$となる条件を調べる．$a$の大きさで$f(x)$の挙動が変わるため場合分けして考える．

\subparagraph{$1^\circ \ a=0$の時}

この時は\cref{eq:2}より
\begin{align}
  f(x) = bx - 1
\end{align}
でこれは高々$1$次式だから，$[-1,1]$で$f(x)<0$となる条件は両端点で$f(x)<0$であることで，
\begin{align}
  f(1) < 0 \land f(-1) < 0  \iff  -1 < b < 1 \label{eq:3}
\end{align}
である．

\subparagraph{$2^\circ \ 0<a$の時}

この場合は$f(x)$は下に凸の放物線だから，$[-1,1]$での最大値は端点でとる．
従って$f(x)<0$を満たすには端点で$f(x)<0$ならばよく，
\begin{align}
  f(1) < 0 \land f(-1) < 0
  \iff  a+b-1 < 0 \land a-b-1 < 0 \label{eq:4}
\end{align}
である．

この場合は$f(x)$は上に凸の放物線だから，軸$x=\dfrac{-b}{4a}$と端点の位置関係によって条件は
\begin{align}
  &
  \begin{cases}
    -1 \le -\dfrac{b}{4a} \le 1 \text{の時} \quad f(-\dfrac{b}{4a}) < 0 \\
    -\dfrac{b}{4a} \le -1 \text{の時} \quad f(-1) < 0 \\
    -\dfrac{b}{4a} \ge 1 \text{の時} \quad f(1) < 0
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    -1 \le -\dfrac{b}{4a} \le 1 \text{の時} \quad \dfrac{(a+\dfrac{1}{2})^2}{1/4} + \dfrac{b^2}{2} < 1  \\
    -\dfrac{b}{4a} \le -1 \text{の時} \quad a-b-1 < 0 \\
    -\dfrac{b}{4a} \ge 1 \text{の時} \quad a+b-1 < 0
  \end{cases} \label{eq:5}
\end{align}
である．
\casesend

以上\cref{eq:3,eq:4,eq:5}をまとめて
\begin{align}
  \begin{cases}
    a \ge 0 \land a-1 < b < 1-a \\
    4a \le b \le -4a \land a < 0 \land \dfrac{(a+\dfrac{1}{2})^2}{1/4} + \dfrac{b^2}{2} < 1 \\
    4a \ge b \land a < 0 \land a-1 < b \\
    -4a \le b \land a < 0 \land b < -a+1
  \end{cases}
\end{align}
である．これを図示して下図(境界含まず)である．
