{\bf [解答]}

与えられた等式
\begin{align}
  \int_x^{x+1}f(t)dt=cf(x) \label{eq:1}
\end{align}
について考える．

題意を背理法で示す．$f(x)$ が1次以上だと仮定する．
この時$f(x)$ の原始関数の1つを $F(x)$ として，
\begin{align}
  F(x) = \sum_{k=0}^n a_k x^k \quad (a_n \neq 0, n \in \mathbb{N}, n \ge 2) \label{eq:2}
\end{align}
とおける．\cref{eq:2}を\cref{eq:1}に代入して
\begin{align}
  (\text{左辺})
  &= F(x+1)-F(x) \\
  &= a_n(x+1)^n + a_{n-1}(x+1)^{n-1} - a_n x^n - a_{n-1} x^{n-1} + \cdots \\
  &= n \cdot a_n x^{n-1} + \{ (n-1)a_{n-1} + {}_nC_2 \cdot a_n \} x^{n-2} + \cdots \\
  (\text{右辺})
  & = c F'(x) &= c n a_n x^{n-1} + (n-1) \cdot c a_{n-1} x^{n-2} + \cdots
\end{align}
だから，$n-1, n-2$ 次の項を比較して，
\begin{align}
  \begin{cases}
    n a_n = c n a_n  \\
    (n-1)a_{n-1} + \dfrac{1}{2}n(n-1)a_n = c(n-1)a_{n-1}
  \end{cases} \label{eq:3}
\end{align}
である．$a_n, n \neq 0$だから第一式で$c=1$だが，第二式に代入すると$n(n-1)a_n = 0$となり，$n \ge 2, a_n \neq 0$ に矛盾する．よって背理法によって $F(x)$ は1次以下，つまり $f(x)$ は定数である．
