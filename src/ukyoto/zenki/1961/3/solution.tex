$M$ を原点，$AB$ を $x$ 軸，$MP$ を $y$ 軸とする図のような座標をとる．
すると$A(-r,0), B(r,0), P(0,a)$となる．
対称性から $Q$ が第 1 象限にあるとしてよく，
題意より$\angle PMQ=\theta$だからその座標は
\begin{align}
  Q\left(a \cos\left(\dfrac{\pi}{2}-\theta\right), a \sin\left(\dfrac{\pi}{2}-\theta\right)\right)
  = Q(a \sin\theta, a \cos\theta)
\end{align}
となる．

\paragraph{(1)}

$\triangle APM$に注目すると，$|AM|=r,|PM|=a,\angle APM=\dfrac{\alpha}{2}$だから，
\begin{align}
  \tan\dfrac{\alpha}{2} = \dfrac{r}{a}
\end{align}
なので，$\tan$の倍角公式から
\begin{align}
  \tan \alpha
  = \dfrac{2\tan(\alpha/2)}{1-\tan^2(\alpha/2)}
  = \dfrac{2(r/a)}{1-(r/a)^2}
  = \dfrac{2ra}{a^2-r^2} \label{eq:1}
\end{align}
である．

\paragraph{(2)}

$\tan\beta$を計算する．
\begin{align}
  \tan \beta
  &= \dfrac{\sin\beta}{\cos\beta} \\
  &= \dfrac{|QA||QB| \sin\beta|}{|QA||QB|\cos\beta} \\
  &= \dfrac{2\triangle ABQ}{\overrightarrow{QA}\cdot\overrightarrow{QB}} \label{eq:2}
\end{align}
だから，この分母分子を計算すれば良い．

$\overrightarrow{QA} =
\begin{pmatrix} -r - a \sin\theta \\ -a \cos\theta
\end{pmatrix}$, $\overrightarrow{QB} =
\begin{pmatrix} r - a \sin\theta \\ -a \cos\theta
\end{pmatrix}$
だから，個別に評価すると
\begin{align}
  \overrightarrow{QA}\cdot\overrightarrow{QB}
  = (r - a s)(-r - a s) + a^2 c^2
  = a^2-r^2 \label{eq:3}
\end{align}
および，$Q$から$x$軸に下ろした垂足を$H$として
\begin{align}
  2\triangle ABQ = |AB||QH| = 2r\cdot a\cos\theta = 2ra\cos\theta \label{eq:4}
\end{align}
である．\cref{eq:3,eq:4}を\cref{eq:2}に代入して
\begin{align}
  \tan \beta = \dfrac{2ra\cos\theta}{a^2 - r^2}  \label{eq:5}
\end{align}
である．一方\cref{eq:1}から$\tan\alpha\cos\theta$を計算すると
\begin{align}
  \tan\alpha\cos\theta = \dfrac{2ra\cos\theta}{a^2-r^2} \label{eq:6}
\end{align}
である．\cref{eq:5,eq:6}より
\begin{align}
  \tan \alpha \cos\theta = \tan \beta
\end{align}
だから題意は示された．
