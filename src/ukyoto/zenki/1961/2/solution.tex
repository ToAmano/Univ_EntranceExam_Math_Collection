$AD=1$ として一般性を失わない．A を原点とし，AD を $x$ 軸とする上図のような座標平面をとり，
\begin{align}
  B(\alpha, \alpha \tan \theta) \quad
  C(\beta, -\beta \tan \theta) \quad
  \left(0 < \theta < \dfrac{\pi}{2}, \alpha \neq \beta, \alpha, \beta > 0\right) \label{eq:1}
\end{align}
とおく．

直線$BC$の方程式は
\begin{align}
  BC:
  &(\beta + \alpha)\tan \theta \cdot (x - \alpha) + (\beta - \alpha)(y - \alpha \tan \theta) = 0 \\
  &(\beta + \alpha)\tan \theta \cdot x + (\beta - \alpha)y - 2\alpha\beta \tan \theta = 0 \label{eq:2}
\end{align}
である．題意よりこれが $D(1,0)$ を通るので
\begin{align}
  (\beta + \alpha)\tan \theta = 2\alpha\beta \tan \theta
\end{align}
で，\cref{eq:1}より $\tan \theta \neq 0$ で両辺わって
\begin{align}
  \alpha + \beta = 2\alpha\beta \label{eq:3}
\end{align}
を得る．

$\triangle ABC$ の外心 $O'(X,Y)$ とすると，外心の定義から$|O'A| = |O'B| = |O'C|$ であり，\cref{eq:1}より
\begin{align}
  X^2 + Y^2 = (X-\alpha)^2 + (Y-\alpha \tan \theta)^2 = (X-\beta)^2 + (Y+\beta \tan \theta)^2
\end{align}
である．各辺から$X^2+Y^2$を引くと
\begin{align}
  \begin{cases}
    -2\alpha X - 2\alpha\tan\theta Y +\alpha^2(1+\tan^2\theta) = 0 \\
    -2\beta  X + 2\beta\tan\theta  Y +\beta^2(1+\tan^2\theta) = 0
  \end{cases} \label{eq:4}
\end{align}
である．第一式に$\beta$をかけたものと第二式に$\alpha$をかけたものを辺々足し引きして
\begin{align}
  &
  \begin{cases}
    -4\alpha\beta X + \alpha\beta(1+\tan^2\theta)(\alpha+\beta) = 0 \\
    -4 \alpha\beta\tan\theta Y + \alpha\beta(1+\tan^2\theta)(\alpha-\beta) = 0
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    X = \dfrac{1}{4} (\tan^2\theta + 1)(\alpha + \beta) \\
    Y = \dfrac{1}{4} (\tan^2\theta + 1)(\alpha - \beta)
  \end{cases} \label{eq:5}
\end{align}
を得る．ただし$\alpha\beta \neq 0$であることを用いた．

従って外接円は $C: (x-X)^2 + (y-Y)^2 = X^2 + Y^2$ となり，
点 A での接線 $l$ は
\begin{align}
  l: &Xx + Yy = 0 \\
  \therefore
  l: &(\alpha + \beta)\tan\theta x + (\alpha - \beta)y = 0 \label{eq:6}
\end{align}
である．これと線分$BC$との交点$P(p,q)$ は\cref{eq:2}より
\begin{align}
  p = \dfrac{1}{2}, \quad q = \dfrac{\alpha + \beta}{\beta - \alpha} \dfrac{\tan\theta}{2}
\end{align}
よって P は定直線 $x = \dfrac{1}{2}$ 上にあるから題意は示された．

    \node[teal!80!black, font=\footnotesize, right=3pt] at ($(P)!0.5!(B)$) {$\gamma$};
  \end{tikzpicture}
  \caption{別解で用いる線分 $AP,AB,BP$ と二等辺三角形 $APD$}
  \label{fig:1961_2_synthetic}
\end{figure}

$|AP| = \alpha$, $|AB| = \beta$, $|BP| = \gamma$ とおく．
接弦定理より$\angle PAB = \angle PCA \quad (\angle CAP)$だから$\triangle ABP \sim \triangle CAP$ であり，
\begin{align}
  |AC| = \dfrac{\alpha}{\gamma}\beta \label{eq:7}
\end{align}
および，
\begin{align}
  \alpha^2 = \gamma \cdot |PC| \quad
  \therefore
  PC = \dfrac{\alpha^2}{\gamma} \label{eq:8}
\end{align}
を得る．

また，$\angle BAC$を線分$AD$が二等分するから，
\begin{align}
  |BD| : |DC| = |AB| : |AC|
\end{align}
が成り立ち，
\begin{align}
  |BD|
  &= |BC| \cdot \dfrac{|AB|}{|AB|+|AC|} \\
  &= (|PC|-|PB|) \dfrac{|AB|}{|AB|+|AC|} \\
  & = \left(\dfrac{\alpha^2}{\gamma} - \gamma\right) \dfrac{\beta}{\beta + \dfrac{\alpha}{\gamma}\beta} \quad (\because\text{\cref{eq:7,eq:8}})\\
  &= \alpha - \gamma
\end{align}
となる．
従って
\begin{align}
  |DP| = |PB| + |BD| = \gamma + (\alpha - \gamma) = \alpha
\end{align}
だから$\triangle APD$ は 2 等辺三角形であり，P は AD の垂直2等分線上にある．
