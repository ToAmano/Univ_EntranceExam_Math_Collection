{\bf [解答]}

\paragraph{(1)}

与えられた方程式$x^2+2bx+c=0$において題意より判別式$D=b^2-c<0$だから，これは虚数解$\alpha,\beta$を持つ．$b, c \in \mathbb{R}$ であるからこの時，$\beta = \overline{\alpha}$ となるので，解と係数の関係より
\begin{align}
  \begin{cases}
    \alpha + \beta = -2b \quad (\neq 0) \\
    \alpha - \beta = 2id \quad (d \in \mathbb{R} \neq 0)
  \end{cases}
\end{align}
とおける．したがって，$\gamma = v + iw$ とすると ($v, w \in \mathbb{R}$)
\begin{align}
  \gamma
  & = \dfrac{v}{2b}(\alpha + \beta) + \dfrac{w}{2d}(\alpha - \beta)  \\
  & = \left( -\dfrac{v}{2b} + \dfrac{w}{2d} \right) \alpha + \left( -\dfrac{v}{2b} - \dfrac{w}{2d} \right) \beta
\end{align}
と表せる．よって題意は示された．

\paragraph{(2)}

与えられた方程式
\begin{align}
  f(x) = x^2 + 2(b-1)x + 5-c
\end{align}
について考える．

(1)の条件$b^2-c<0,b\neq 0$が成り立つとすると，実数$t,u$に対して
\begin{align}
  \gamma = t\alpha + u\beta
\end{align}
が任意の複素数を動くから，$f(x)=0$の解もとりえて題意の条件を満たさずに不適である．従って$b^2 - c \ge 0$ 又は $b = 0$ が必要である．以下個別に考える．

\subparagraph{(ア) $b^2 - c \ge 0$ の時}

この時は(1)から$\alpha, \beta$ は実数である．$b = c = 0 \iff \alpha = \beta = 0$ に注意する．

まず$(b,c)=(0,0)$の時は$\gamma=0$だから$f(\gamma)=5 \neq 0$となり題意の条件を満たす．それ以外の時は$b \neq 0$ または $c \neq 0$だから$\gamma$は任意の実数値を取る．従って常に$f(\gamma)\neq 0$となるのは$f(x)=0$が実数解を持たない時で，判別式$D'$として
\begin{align}
  D' < 0 \iff (b-1)^2 - 5 + c < 0 \iff c < -(b-1)^2 + 5 \label{eq:1}
\end{align}
である．

\subparagraph{(イ) $b = 0$ かつ $b^2 - c < 0$ の時}

この時は$\alpha, \beta$ は純虚数であるから，$t\alpha + u\beta$ は任意の $ki$ ($k \in \mathbb{R}$) の形の値をとる．よってこの時
\begin{align}
  f(ki) = (-k^2 - c + 5) - 2ki = 0 \iff k = 0 \text{ かつ } c = 5
\end{align}
である．よって$c \neq 5$ であれば条件をみたす．
\casesend

以上の場合分けより求める条件は
\begin{align}
  \begin{cases}
    b^2 - c \ge 0 \text{かつ} c < -(b-1)^2 + 5 \\
    b=c=0 \\
    b = 0 \text{かつ} b^2 - c < 0 \text{かつ} c \neq 5
  \end{cases}
\end{align}
である．これを図示すると下図斜線部(境界は実線のみ含む)となる．
