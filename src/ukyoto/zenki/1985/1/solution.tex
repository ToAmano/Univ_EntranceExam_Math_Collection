$|AB|=b, |AC|=c$ とおくと，三角不等式から
\begin{align}
  b, c >0, |b-c| < q < b+c \label{eq:1}
\end{align}
である．$\triangle ABC$に余弦定理を用いると
\begin{align}
  & |BC|^2 = |AB|^2 + |AC|^2 - 2\overrightarrow{AB}\cdot\overrightarrow{AC} \\
  \therefore
  &  q^2 = b^2 + c^2 - 2p \label{eq:2}
\end{align}
である．新しく
\begin{align}
  b+c = \alpha, bc = \beta \label{eq:3}
\end{align}
とおくと，$b,c$は$t$の2次式 $t^2 - \alpha t + \beta = 0$ の\cref{eq:1}を満たす2つの正の実数解である．このような$b,c$が存在する$p,q$の条件を求めれば良い．

このような条件は，判別式を$D$として
\begin{align}
  \begin{cases}
    \text{判別式}: D \ge 0 \\
    \text{軸}: \dfrac{\alpha}{2} > 0 \\
    \text{端点(t=0)}: \beta > 0
  \end{cases} \iff
  \begin{cases}
    \alpha^2 - 4\beta \ge 0  \\
    \alpha > 0 \\
    \beta > 0
  \end{cases} \label{eq:4}
\end{align}
である．このもとで$b,c = \dfrac{\alpha\pm \sqrt{\alpha^2-4\beta}}{2}$だから，\cref{eq:1,eq:2}を$\alpha,\beta$で表して
\begin{align}
  \begin{cases}
    \sqrt{\alpha^2-4\beta} < q < \alpha \\
    \alpha^2 - 2\beta = 2p + q^2
  \end{cases} \label{eq:5}
\end{align}
第二式より $\beta = \dfrac{1}{2}(\alpha^2 - 2p - q^2)$ だから\cref{eq:4,eq:5}に代入して，
\begin{align}
  &
  \begin{cases}
    \alpha^2 - 2(\alpha^2 - 2p - q^2) \ge 0  \\
    \alpha > 0 \\
    \alpha^2 - 2p - q^2 > 0 \\
    \sqrt{\alpha^2-2(\alpha^2 - 2p - q^2)} < q < \alpha
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    2p+q^2 < \alpha^2 \le 4p + 2q^2 \\
    \alpha > 0 \\
    -\alpha^2 + 4p + 2q^2 < q^2 < \alpha^2
  \end{cases} \\
  \therefore
  &
  \begin{cases}
    2p+q^2 < \alpha^2 \le 4p + 2q^2 \\
    q^2 < \alpha^2 \\
    4p + q^2 < \alpha^2 \\
    0 < \alpha
  \end{cases} \label{eq:6}
\end{align}
である．これを満たす$\alpha$が存在するためには不等号の左右に注目して
\begin{align}
  \begin{cases}
    2p+q^2 <  4p + 2q^2 \\
    q^2 < 4p + 2q^2 \\
    4p + q^2 < 4p + 2q^2
  \end{cases}
  \therefore
  \begin{cases}
    0 < 2p + q^2 \\
    0 < 4p + q^2 \\
    0 < q^2
  \end{cases}
  \therefore
  0 < 4p + q^2 \label{eq:7}
\end{align}
である．

逆に\cref{eq:7}が満たされる時，$b^2 + c^2 = 2p + q^2$ となる $b, c \in \mathbb{R}_{>0}$ をとることができて， $\alpha = b+c$, $\beta = bc$ とおくと
\begin{align}
  \alpha^2 - 2\beta = 2p + q^2 \label{eq:8}
\end{align}
であり，$b, c$ は $t$ の2次式 $t^2 - \alpha t + \beta = 0$ の2正実解である．
よって$b,c$が正の実数解だから\cref{eq:4}と同様に
\begin{align}
  \alpha^2 - 4\beta \ge 0, \alpha, \beta > 0
\end{align}
となり，\cref{eq:8}を代入して
\begin{align}
  &
  \begin{cases}
    \alpha^2 - 2(\alpha^2 - 2p - q^2) \ge 0 \\
    \alpha > 0 \\
    \alpha^2 - 2p - q^2 > 0
  \end{cases} \\
  \therefore
  & 2p + q^2 < \alpha^2 \le 4p + 2q^2
\end{align}
となる．ここで\cref{eq:7}より$4p + 2q^2 - q^2 > 0 \therefore q^2 < 4p + 2q^2$ なので，$\alpha = b+c > q > \sqrt{4\beta} = |b-c|$ をみたすような $(b, c)$ が存在して十分である．

以上から求める必要十分条件は\cref{eq:7}で
\begin{align}
  4p + q^2 > 0
\end{align}
である．

{\bf [別解]}

ベクトルをそのまま扱うことでよりエレガントに解けるので紹介しよう．
方針としてはB, Cを固定し，Aを動かして考える．この時Aがあるような$p, q$をもとめると考えて，$\vec{a}$についての存在条件を考える．

点Xに対し，$\overrightarrow{OX} = \vec{x}$ とおくと，題意の条件は
\begin{align}
  \overrightarrow{AB}\cdot\overrightarrow{AC} = p
  \quad \therefore
  (\vec{b} - \vec{a}) \cdot (\vec{c} - \vec{a}) = p
\end{align}
だから，同値変形して
\begin{align}
  & |\vec{a}|^2 - (\vec{b} + \vec{c}) \cdot \vec{a} + \vec{b} \cdot \vec{c} - p = 0 \\
  \iff
  & \left| \vec{a} - \dfrac{\vec{b} + \vec{c}}{2} \right|^2
  = \left| \dfrac{\vec{b} - \vec{c}}{2} \right|^2 + p
  = \dfrac{q^2}{4} + p
\end{align}
だから，このような$\vec{a}$が存在する必要十分条件は右辺が正であることで
\begin{align}
  \dfrac{q^2}{4} + p > 0
\end{align}
である．この時BC上にないAがとれて十分である．
