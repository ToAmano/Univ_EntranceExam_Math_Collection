{\bf [解答]}

与えられた二つの曲線を
\begin{align}
  \begin{cases}
    A: y = f(x) = x^3+3ax^2+3bx \\
    B: y = c
  \end{cases} \label{eq:1}
\end{align}
とおく．$f(x)$の一階微分は
\begin{align}
  f'(x)=3x^2+6ax+3b=3(x^2+2ax+b) \label{eq:2}
\end{align}
である．$A$，$B$が相異なる3交点を持つには，$f(x)=c$が異なる3実解を持つ，つまり$f$が極大・極小を持ちその間に$c$がある必要がある．そのためには$f'(x)=0$が異なる2実解を持つことが必要だから$f'(x)=0$の判別式$D$として
\begin{align}
  \dfrac{1}{3}\dfrac{D}{4}=a^2-b>0\iff a^2>b
\end{align}
が必要である．

このもとで，$f'(x)=0$の2実解を$\alpha,\beta$（$\alpha<\beta$）とおくと，
\begin{align}
  \alpha=-a-\sqrt{a^2-b},\quad\beta=-a+\sqrt{a^2-b} \label{eq:3}
\end{align}
である．ここで$y=f(x)$のグラフにおいて
\begin{align}
  f(\alpha) = f\left(\dfrac{3\beta-\alpha}{2}\right),
  \quad
  f(\beta) = f\left(\dfrac{3\alpha-\beta}{2}\right)
\end{align}
だから，求める条件は$f(x)=c$の解を$x_1,x_2,x_3$として
\begin{align}
  \dfrac{3\alpha-\beta}{2} < x_1,x_2,x_3 < \dfrac{3\beta-\alpha}{2}
\end{align}
である．\cref{eq:3}を代入して
\begin{align}
  -a - 2\sqrt{a^2-b} < x_1,x_2,x_3 < -a + 2\sqrt{a^2-b}
\end{align}
である．よって題意は示された．
