(イ) $\vec{AP} = p \vec{c}$ と定めると $\vec{a}, \vec{c}$ では次の通り．
$\vec{a}, \vec{c}$ を用いて表して
\[
  \begin{cases}
    \vec{Q} = k [(1-p)\vec{a} + p\vec{c}] = (1-t)\vec{a} + t \dfrac{1}{3}\vec{c} \\
    \vec{R} = K [(1-p)\vec{a} + p\vec{c}] = (1-t')\vec{a} + t' \dfrac{2}{3}\vec{c}
  \end{cases}
\]
これをといて，$k = \dfrac{1}{2p+1}$, $K = \dfrac{2}{p+2}$ だから
\[
  \begin{aligned}
    |BQ| : |QR| : |RP| &= \dfrac{1}{2p+1} : \dfrac{2}{p+2} - \dfrac{1}{2p+1} : 1 - \dfrac{2}{p+2} \\
    &= p+2 : 3p : p(2p+1)
  \end{aligned}
\]

これと右のグラフから $0 \leqq p \leqq 1$ のとき
\[
  p(2p+1) \leqq 3p \leqq p+2
\]
\[
  \therefore |RP| \leqq |QR| \leqq |BQ| \quad (\text{等号成立は } p=0 \text{ 又は } p=1 (\text{この時一括右は成立}))
\]

(ロ) 3辺の長さ $a = p+2$, $b = 3p$, $c = 2p^2+p$ としてもよい．(イ)から $a \geqq b \geqq c$ だから，$a, b, c$ を3辺に持つ三角形の存在条件は
\[
  \begin{aligned}
    a < b+c &\iff p+2 < 2p^2 + 4p \\
    &\iff (2p-1)(p+2) > 0 \\
    &\iff \dfrac{1}{2} < p \leqq 1 \quad (\because 0 \leqq p \leqq 1)
  \end{aligned}
\]
