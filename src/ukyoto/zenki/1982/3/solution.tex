原点$O$とし，点$X$の位置ベクトルを$\vec{x}$とする．
題意の四辺形の構成方法から
\begin{align}
  \begin{cases}
    \vec{a}_{n+1} = (\vec{b}_n + \vec{c}_n + \vec{d}_n) / 3 \\
    \vec{b}_{n+1} = (\vec{a}_n + \vec{c}_n + \vec{d}_n) / 3 \\
    \vec{c}_{n+1} = (\vec{a}_n + \vec{b}_n + \vec{d}_n) / 3  \\
    \vec{d}_{n+1} = (\vec{a}_n + \vec{b}_n + \vec{c}_n) / 3
  \end{cases} \label{eq:1}
\end{align}
である．この時帰納的に
\begin{align}
  \vec{a}_n + \vec{b}_n + \vec{c}_n + \vec{d}_n = \vec{a} + \vec{b} + \vec{c} + \vec{d} \label{eq:2}
\end{align}
である．

\paragraph{(1)}

線分$AA_1, BB_1, CC_1, DD_1$上の点は各々 $0 \le t, s, u, v \le 1$として
\begin{align}
  \begin{cases}
    t \vec{a}_1 + (1-t) \vec{a} \\
    s \vec{b}_1 + (1-s) \vec{b} \\
    u \vec{c}_1 + (1-u) \vec{c} \\
    v \vec{d}_1 + (1-v) \vec{d}
  \end{cases}
\end{align}
で表される．$t=s=u=v=\dfrac{3}{4}$とすれば，\cref{eq:1}からいずれも
\begin{align}
  \dfrac{1}{4} (\vec{a} + \vec{b} + \vec{c} + \vec{d})
\end{align}
を通るから，これが$P$である．

\paragraph{(2)}

$A_1 A_2, A_3 \cdots$が直線$AA_1$上にあることを数学的帰納法で示す．
$AA_1$上の点$X$は$t \in \mathbb{R}$として
\begin{align}
  \vec{x}
  & = t\vec{a}_1 + (1-t)\vec{a} \\
  & = \dfrac{t}{3} (\vec{b} + \vec{c} + \vec{d}) + (1-t) \vec{a} \label{eq:3}
\end{align}
と表される．$n=1$の時は明らかだから，$n=k$での成立を仮定して$n=k+1$の時を考える．

\cref{eq:1,eq:2}から，$a_k$についての漸化式
\begin{align}
  \vec{a}_{k+1} = \dfrac{1}{3} (\vec{a} + \vec{b} + \vec{c} + \vec{d} - \vec{a}_k) \label{eq:4}
\end{align}
を得る．仮定から\cref{eq:3}で$\vec{a}_k$に対応する$t$が存在するからこれを$t_k$とおくと\cref{eq:4}に代入して
\begin{align}
  \vec{a}_{k+1}
  &= \dfrac{1}{3} \left[ \vec{a} + \vec{b} + \vec{c} + \vec{d} - \dfrac{t_k}{3} (\vec{b} + \vec{c} + \vec{d}) - (1-t_k) \vec{a} \right] \\
  &= \dfrac{1}{3} \left[ \left(1-\dfrac{t_k}{3}\right) (\vec{b} + \vec{c} + \vec{d}) + t_k \vec{a} \right]
\end{align}
である．これは\cref{eq:3}で
\begin{align}
  t = 1 - \dfrac{t_k}{3} \label{eq:5}
\end{align}
としたものにひとしく，$A_{k+1}$も$AA_1$上にある．よって$n=k+1$でも成立する．

以上から数学的帰納法により$A_k$が全て直線$AA_1$上にあることが示された．

\paragraph{(3)}

\cref{eq:5}から点$A_n$に対応する$t$を$t_n$とおくと
\begin{align}
  \begin{cases}
    t_{n+1} = 1 - \dfrac{t_n}{3} \\
    t_1 = 1
  \end{cases}
\end{align}
である．等比数列の公式を用いてこれをとくと
\begin{align}
  t_n = \left(-\dfrac{1}{3}\right)^{n-1} \left(1-\dfrac{3}{4}\right) + \dfrac{3}{4}
\end{align}
である．従って$n\to\infty$の極限は
\begin{align}
  \lim_{n\to\infty} t_n = \dfrac{3}{4}
\end{align}
だから，(1)より
\begin{align}
  \lim_{n\to\infty}A_n = P
\end{align}
となり
\begin{align}
  \lim_{n \to \infty} |\overrightarrow{A_n P}| = 0
\end{align}
である．
