{\bf [解答]}

与えられた方程式
\begin{align}
  f(t) = t^2-2at+3a-2 = 0 \label{eq:1}
\end{align}
が2つの実解を持つ時，判別式$D$として$D \ge 0$だから
\begin{align}
  a^2 - 3a + 2 \ge 0 \iff a \le 1, 2 \le a \label{eq:2}
\end{align}
である．

以下
\begin{align}
  ay = 3(x-\beta) \label{eq:3}
\end{align}
について考える．この直線は定点$(\beta,0)$を通るから，題意の領域が三角形を成すには$\beta>0$が必要である．$\beta \le \alpha$より，\cref{eq:1}が二つの正の解を持つから，\cref{eq:2}のもとで
\begin{align}
  \begin{cases}
    \text{端点} f(0) > 0 \\
    \text{軸}  a > 0
  \end{cases}
  \iff
  \begin{cases}
    3a-2 > 0
    \\ a > 0
  \end{cases}
  \iff a > \dfrac{2}{3} \label{eq:4}
\end{align}
である．よって$a \neq 0$だから\cref{eq:3}は
\begin{align}
  y = \dfrac{3}{a}(x-\beta)
\end{align}
となり，傾き$\dfrac{3}{a} (>0)$の直線である．よってこれが$-x \le y \le x$と三角形をなす条件は$y=x$よりも傾きが大きいことで
\begin{align}
  \dfrac{3}{a} > 1 \iff 3 > a \label{eq:5}
\end{align}
である．

\cref{eq:2,eq:4,eq:5}から求める$a$の条件は
\begin{align}
  \dfrac{2}{3} < a \le 1, \quad 2 \le a < 3
\end{align}
である．
