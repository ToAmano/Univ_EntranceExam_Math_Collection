与えられた条件より$\overrightarrow{OP},\overrightarrow{OQ}$は
\begin{align}
  \overrightarrow{OP} &= (1-s)\overrightarrow{OA} + s\overrightarrow{OE} \\
  \overrightarrow{OQ} &= (1-t)\overrightarrow{OC} + t\overrightarrow{OG}
\end{align}
と表せるから，成分表示すると
\begin{align}
  \overrightarrow{OP}&=(1-s)
  \begin{pmatrix}3\\0\\0
  \end{pmatrix}
  +s
  \begin{pmatrix}3\\0\\4
  \end{pmatrix}
  =
  \begin{pmatrix}3\\0\\0
  \end{pmatrix}+s
  \begin{pmatrix}0\\0\\4
  \end{pmatrix} \label{eq:1}\\
  \overrightarrow{OQ}&=(1-t)
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}
  +t
  \begin{pmatrix}0\\2\\4
  \end{pmatrix}
  =
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}+t
  \begin{pmatrix}0\\0\\4
  \end{pmatrix} \label{eq:2}
\end{align}
と表せる．

また，$AC$上の点$R$は
\begin{align}
  \overrightarrow{OR} = \alpha \overrightarrow{OA}+(1-\alpha)\overrightarrow{OC} \quad (0 \le \alpha \le 1)
\end{align}
だから成分表示して
\begin{align}
  \overrightarrow{OR}=\alpha
  \begin{pmatrix}3\\0\\0
  \end{pmatrix}
  +(1-\alpha)
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}
  =
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}+\alpha
  \begin{pmatrix}3\\-2\\0
  \end{pmatrix}
  \quad(0\leqq\alpha\leqq1) \label{eq:3}
\end{align}
と表せる．

題意の条件は，直線$DR$が平面$OPQ$の垂線になっていること，つまり
\begin{align}
  DR\perp OP, \quad DR\perp OQ \quad \therefore
  \overrightarrow{DR}\cdot\overrightarrow{OP} = \overrightarrow{DR}\cdot\overrightarrow{OQ} = 0 \label{eq:4}
\end{align}
なる$\alpha$が存在することである．
\cref{eq:3}より$\overrightarrow{DR}$を計算すると
\begin{align}
  \overrightarrow{DR}=
  \begin{pmatrix}0\\2\\-4
  \end{pmatrix}
  +\alpha
  \begin{pmatrix}3\\-2\\0
  \end{pmatrix}
\end{align}
だから，\cref{eq:4}に成分を代入して
\begin{align}
  \overrightarrow{OP}\cdot\overrightarrow{DR}
  &=
  \begin{pmatrix}3\\0\\4s
  \end{pmatrix}\cdot
  \begin{pmatrix}3\alpha\\2-2\alpha\\-4
  \end{pmatrix}=0,\\
  \overrightarrow{OQ}\cdot\overrightarrow{DR}
  &=
  \begin{pmatrix}0\\2\\4t
  \end{pmatrix}\cdot
  \begin{pmatrix}3\alpha\\2-2\alpha\\-4
  \end{pmatrix}=0
\end{align}
すなわち
\begin{align}
  & 9\alpha-16s=0,\qquad 1-\alpha=4t \\
  & \alpha=\dfrac{16}{9}s=1-4t
\end{align}
となる．$0<s<1$，$0<t<1$に注意して，$0<\alpha<1$となるような条件は
\begin{align}
  0 < s <\dfrac{9}{16}, \quad
  0< t < \dfrac{1}{4}
\end{align}
である．以上から$\alpha$が存在するような$s,t$の存在条件は
\begin{align}
  \dfrac{16}{9}s+4t=1, \quad
  0 < s <\dfrac{9}{16}, \quad
  0< t < \dfrac{1}{4}
\end{align}
である．
