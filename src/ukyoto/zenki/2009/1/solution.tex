{\bf [解]}
\begin{align}
  \overrightarrow{OP}&=(1-s)
  \begin{pmatrix}3\\0\\0
  \end{pmatrix}
  +s
  \begin{pmatrix}3\\0\\4
  \end{pmatrix}
  =
  \begin{pmatrix}3\\0\\0
  \end{pmatrix}+s
  \begin{pmatrix}0\\0\\4
  \end{pmatrix},\\
  \overrightarrow{OQ}&=(1-t)
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}
  +t
  \begin{pmatrix}0\\2\\4
  \end{pmatrix}
  =
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}+t
  \begin{pmatrix}0\\0\\4
  \end{pmatrix}.
\end{align}
だから，$AC$上の点$R$を
\begin{align}
  \overrightarrow{OR}=\alpha
  \begin{pmatrix}3\\0\\0
  \end{pmatrix}
  +(1-\alpha)
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}
  =
  \begin{pmatrix}0\\2\\0
  \end{pmatrix}+\alpha
  \begin{pmatrix}3\\-2\\0
  \end{pmatrix}
  \quad(0\leqq\alpha\leqq1)
\end{align}
で定めて，$DR\perp OP$かつ$DR\perp OQ$なる$\alpha$の存在条件をもとめれば良い．

\begin{align}
  \overrightarrow{DR}=
  \begin{pmatrix}0\\2\\-4
  \end{pmatrix}
  +\alpha
  \begin{pmatrix}3\\-2\\0
  \end{pmatrix}
\end{align}
から
\begin{align}
  \overrightarrow{DR}\cdot\overrightarrow{OP}
  &=
  \begin{pmatrix}3\\0\\4s
  \end{pmatrix}\cdot
  \begin{pmatrix}3\alpha\\2-2\alpha\\-4
  \end{pmatrix}=0,\\
  \overrightarrow{DR}\cdot\overrightarrow{OQ}
  &=
  \begin{pmatrix}0\\2\\4t
  \end{pmatrix}\cdot
  \begin{pmatrix}3\alpha\\2-2\alpha\\-4
  \end{pmatrix}=0.
\end{align}
よって
\begin{align}9\alpha-16s=0,\qquad1-\alpha=4t.
\end{align}
だから$\alpha=\dfrac{16}{9}s=1-4t$であり，$0<s<1$，$0<t<1$から，この時常に$0<\alpha<1$となるので，
\begin{align}\dfrac{16}{9}s+4t=1.
\end{align}
