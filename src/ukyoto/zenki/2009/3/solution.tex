題意のように$n$回目の試行の後に番号$n$のカードが一番上にきているのは以下のいずれかである．
\begin{itemize}
\item $n$回目に$n$のカードを引いて一番上に戻す．\\
\item $n$回目に1つ上におかれているカードを引いて，$n$より下に戻す．
\end{itemize}
これらは排反な事象だから，それぞれの場合の確率を求めて足し合わせれば良い．
以下個別に考える．

\subparagraph{$1^{\circ}$ $n$回目に$n$のカードを引く時}

$1$から$n-1$回目の試行で引いたカードを$n$のカードより下の位置におけばよく，この確率は
\begin{align}
\dfrac{1}{n}\cdot\dfrac{2}{n}\cdot\dfrac{3}{n}\cdots\dfrac{n-1}{n}
\end{align}
である．さらに$n$回目の試行で引いた$n$のカードは1番上に戻るので，この確率は$\dfrac{1}{n}$だから，
全体での確率は
\begin{align}
\dfrac{1}{n}\cdot\dfrac{2}{n}\cdots\dfrac{n-1}{n}\cdot\dfrac{1}{n}
=\dfrac{(n-1)!}{n^n} \label{eq:1}
\end{align}
である．

\subparagraph{$2^{\circ}$ $n$回目に$n$の1つ上におかれたカードを引く時}

$1$〜$n-1$回目の試行のうち1回だけ，$n$の上にカードをおく．これを$k$回目の試行とすると，
このような確率は
\begin{align}
\dfrac{1}{n}\cdot\dfrac{2}{n}\cdots\dfrac{k-1}{n}\cdot\dfrac{n-k}{n}
\cdot\dfrac{k}{n}\cdots\dfrac{n-2}{n}
\end{align}
である．さらに$n$回目に引いたカードは$n$のカードの下におくので，確率は$\dfrac{n-1}{n}$で，
全体での確率は
\begin{align}
\dfrac{1}{n}\cdot\dfrac{2}{n}\cdots\dfrac{k-1}{n}\cdot\dfrac{n-k}{n}
\cdot\dfrac{k}{n}\cdots\dfrac{n-2}{n}\cdot\dfrac{n-1}{n}
=\dfrac{(n-1)!(n-k)}{n^n}
\end{align}
である．これを$k=1,2,\cdots,n-1$について足し合わせれば$2^{\circ}$の場合の確率は
\begin{align}
\dfrac{(n-1)!}{n^n}\sum_{k=1}^{n-1}(n-k)
=\dfrac{(n-1)!}{n^n}\sum_{k=1}^{n-1}k
=\dfrac{(n-1)!}{n^n}\cdot\dfrac{1}{2}n(n-1) \label{eq:2}
\end{align}
である．
\casesend

以上\cref{eq:1,eq:2}を足し合わせて，求める確率は
\begin{align}
\dfrac{(n-1)!\left\{1+\dfrac{1}{2}n^2-\dfrac{1}{2}n\right\}}{n^n}
=\dfrac{(n-1)!(n^2-n+2)}{2n^n}
\end{align}
である．
