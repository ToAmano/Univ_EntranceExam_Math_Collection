$A$ を原点，$B(2,0), C(0,2)$ とする $xy$ 平面で考える．
又題意の円$T$の中心を$O(t,t)\ (0 < t)$ とおく．すると直線$BC$，円$T$の方程式は
\begin{align}
  \begin{cases}
    T : (x-t)^2 + (y-t)^2 = 1 \\
    BC : x+y = 2
  \end{cases} \label{eq:1}
\end{align}
となる．

\paragraph{(i)}

円$T$と各辺の交点は，それぞれの方程式を連立した解で与えられるから，
\begin{itemize}
  \item $T$ と $AB$ ($x$軸) の交点は $f(x)=x^2 - 2tx + 2t^2 - 1 = 0$ の2実解 \\
  \item $T$ と $AC$ ($y$軸) の交点は $f(y)=y^2 - 2ty + 2t^2 - 1 = 0$ の2実解 \\
  \item $T$ と $BC$ の交点は $g(x)=2x^2 - 4x + 2t^2 - 4t + 3 = 0$ の2実解
\end{itemize}
である．
よってこれらが $0 \le x \le 2, 0 \le y \le 2$ に2実解を持つ条件を考えれば良い．
$T$ と $AB$，$T$ と $AC$の交点は$x,y$を入れ替えただけで全く同じだから，前者だけ考える．
すると求める条件は
\begin{align}
  &
  \begin{cases}
    \text{軸}: 0 < t < 2 \\
    \text{端}: f(0) \ge 0, \ f(2) \ge 0 \\
    \text{判}: t^2 - (2t^2 - 1) > 0
  \end{cases}
  \quad \wedge \quad
  \begin{cases}
    \text{軸}: 0 < 1 < 2 \\
    \text{端}: g(0) \ge 0, \ g(2) \ge 0 \\
    \text{判}: 4 - 2(2t^2 - 4t + 3) > 0
  \end{cases}
  \\
  &\iff
  \begin{cases}
    \text{軸}: 0 < t < 2 \\
    \text{端}: 2t^2 - 1 \ge 0, \ 2t^2 - 4t + 3 \ge 0 \\
    \text{判}: t^2 - (2t^2 - 1) > 0
  \end{cases}
  \quad \wedge \quad
  \begin{cases}
    \text{軸}: 0 < 1 < 2 \\
    \text{端}: 2t^2 - 4t + 3 \ge 0, \ 2t^2 - 4t + 3 \ge 0 \\
    \text{判}: 4 - 2(2t^2 - 4t + 3) > 0
  \end{cases}
  \\
  &\iff
  \begin{cases}
    0 < t < 2 \\
    \dfrac{\sqrt{2}}{2} \le t < 1 \\
    2 - \sqrt{2} < t < 2 + \sqrt{2} \\
  \end{cases} \\
  &\iff \dfrac{\sqrt{2}}{2} \le t < 1
\end{align}
である．$|OA|=x$とおくと$x=\sqrt{2}t$だから求める条件は
\begin{align}
  1 \le x < \sqrt{2}
\end{align}
である．

上図のように，求める面積$S$は円$T$の面積$\pi$から$AB,BC,CA$で切り取られる弓形の面積を取り除けば良い．$T$ の中心と $x, y$ 軸，$BC$ との距離は各々
\begin{align}
  t, \quad t, \quad |\sqrt{2} - \sqrt{2}t|
\end{align}
である．

ここで$F(t)$ が上図斜線部の面積を表すことから，3つの弓形の面積は$F\left(\dfrac{x}{\sqrt{2}}\right), F(\sqrt{2} - x)$なので求める面積$S$は
\begin{align}
  S = \pi - 2F\left(\dfrac{x}{\sqrt{2}}\right) - F(\sqrt{2} - x) \label{eq:2}
\end{align}
である．

\paragraph{(iii)}

\cref{eq:2}の両辺を$x$で微分して
\begin{align}
  \dfrac{dS}{dx}
  &= -4 \sqrt{1 - \dfrac{x^2}{2}} \cdot \dfrac{1}{\sqrt{2}} - 2\sqrt{1 - (\sqrt{2}-x)^2} \\
  &= 2 \left[ \sqrt{2 - x^2} - \sqrt{1 - (\sqrt{2}-x)^2} \right] \\
  &= 2 \dfrac{-2\sqrt{2}x + 3}{\sqrt{2-x^2} + \sqrt{1 - (\sqrt{2}-x)^2}}
\end{align}
から$S$の増減表は以下のようになる．
