{\bf [解答]}

与えられた数列
\begin{align}
  \begin{cases}
    2 \le a_1 \le a_2 \le \dots \le a_n  \\
    S = n-2 - \displaystyle\sum_{i=1}^n \dfrac{1}{a_i} > 0
  \end{cases} \label{eq:1}
\end{align}
について考える．

\paragraph{(1)}

$n=3$ の時\cref{eq:1}より
\begin{align}
  S = 1 - \left( \dfrac{1}{a_1} + \dfrac{1}{a_2} + \dfrac{1}{a_3} \right) > 0 \label{eq:2}
\end{align}
だから $S > 0$ をみたすうちで逆数和を最大にするような $(a_1,a_2,a_3)$ の組をもとめれば良い．
$\dfrac{1}{x}$ は $2 \le x$ で単調減少なことからしらみつぶしで考える．

$a_1=2$を\cref{eq:2}に代入して
\begin{align}
  \dfrac{1}{a_2} + \dfrac{1}{a_3} < \dfrac{1}{2} \label{eq:3}
\end{align}
を満たすうちで左辺を最大にする$a_2,a_3$を求めれば良い．
\cref{eq:1}より$a_3 \ge a_2 \ge 2$ だから，\cref{eq:3}の両辺に$a_2a_3$をかけて
\begin{align}
  (a_2-2)(a_3-2) > 4 \label{eq:4}
\end{align}
だから$a_2=3,4,\cdots$として順に代入すると
\begin{align}
  (a_2, a_3) = (3, 7), (4, 5) \text{ 又は } a_2 \ge 5
\end{align}
なので，これらの逆数和を計算すると
\begin{align}
  \begin{cases}
    \dfrac{1}{3}+\dfrac{1}{7} = \dfrac{10}{21} \\
    \dfrac{1}{4}+\dfrac{1}{5} = \dfrac{9}{20} \\
    \dfrac{1}{a_2}+\dfrac{1}{a_3} \le \dfrac{1}{5}+\dfrac{1}{5}=\dfrac{2}{5}  & (a_2 \ge 5 \text{の時})
  \end{cases}
\end{align}
だから，このうち最大のものを選んで，
\begin{align}
  (a_1, a_2, a_3) = (2, 3, 7) \label{eq:5}
\end{align}
である．この時$S$の値は
\begin{align}
  S =  1 - \left( \dfrac{1}{2} + \dfrac{1}{3} + \dfrac{1}{7} \right) = \dfrac{1}{42} \label{eq:6}
\end{align}
である．

\subparagraph{$2^\circ$ $a_1 \ge 3$ の時}

$a_1 \ge 3$の時は\cref{eq:2}に代入して
\begin{align}
  \dfrac{1}{a_2} + \dfrac{1}{a_3} < 1-\dfrac{1}{a_3} \le \dfrac{2}{3}
\end{align}
だから，これを満たす逆数和が最小の$(a_2,a_3)$の組は$(a_2,a_3)=(3,4)$である．
この時$a_1=3$で，$S$は
\begin{align}
  S = 1 - \left( \dfrac{1}{3} + \dfrac{1}{3} + \dfrac{1}{4} \right) = \dfrac{1}{12}
\end{align}
となり，これは$a_1=2$の時の最小値\cref{eq:6}よりも大きい．よって$a_1 \ge 3$の時は$a_1=2$の時より$S$を小さくできない．
\casesend

以上の場合分けと\cref{eq:6}からもとめるのは
\begin{align}
  (a_1, a_2, a_3) = (2, 3, 7)
\end{align}
である．

\paragraph{(2)}

$n \ge 5$ の時を考えると，\cref{eq:1}において
\begin{align}
  S
  & =  n-2 - \sum_{i=1}^n \dfrac{1}{a_i} \\
  &\ge n-2 - \sum_{i=1}^n \dfrac{1}{2} \\
  & =  n-2 - \dfrac{n}{2} = \dfrac{1}{2}(n-4) > 0 \label{eq:7}
\end{align}
となって $S$ は $a_i = 2\ (i=1, 2, \dots, n)$ とすることで最小値をとる．
\cref{eq:7}において$n$ をうごかした時は $n=5$ で最小値をとる．従って$n \ge 5$の時の$S$の最小値は
\begin{align}
  S = \dfrac{1}{2}(5-4) = \dfrac{1}{2} \label{eq:8}
\end{align}
である．

そこで以下 $n \le 4$ として考える．$n=1,2$ の時は
\begin{align}
  \begin{cases}
    S = -1-\dfrac{1}{a_1}< 0 & (n=1) \\
    S = -\dfrac{1}{a_1}-\dfrac{1}{a_2}< 0 & (n=2)
  \end{cases}
\end{align}
だから不適である．$n=3$の時は(1)で調べたので，残り$n=4$の時を考える．
$\dfrac{1}{x}$ が $2 \le x$ で単調増加なことと $2 = a_1 = a_2 = a_3 = a_4=2$ の時 $S=0$ であることから，$S$を最小にするのは$a_1 = a_2 = a_3 = 2, a_4 = 3$ の時の
\begin{align}
  \min S = 2 - \left(\dfrac{1}{2} + \dfrac{1}{2} + \dfrac{1}{2} + \dfrac{1}{3}\right) = \dfrac{1}{6}\ (>0) \label{eq:9}
\end{align}
である．

以上から，
\begin{align}
  \begin{cases}
    n \ge 5 \text{ の時 } n=5, a_i=2 \text{ で } \min S = \dfrac{1}{2} \\
    n = 4 \text{ の時 } a_1=a_2=a_3=2, a_4=3 \text{ で } \min S = \dfrac{1}{6} \\
    n = 3 \text{ の時 } (a_1, a_2, a_3)=(2,3,7) \text{ で } \min S = \dfrac{1}{42}
  \end{cases}
\end{align}
となり，$S$ を最小にするのは
\begin{align}
  n=3, \quad (a_1, a_2, a_3) = (2, 3, 7)
\end{align}
の時である．
