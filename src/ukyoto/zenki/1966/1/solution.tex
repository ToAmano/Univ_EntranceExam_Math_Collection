\paragraph{(1)}

与えられた関数を
\begin{align}
  f(x) = x^3 + x - 8 \label{eq:1}
\end{align}
とおくと，一階微分は
\begin{align}
  f'(x) = 3x^2 + 1 > 0
\end{align}
だから，$f(x)$は単調増加である．

\paragraph{(2)}

根を $\alpha$ とおくと\cref{eq:1}に代入して
\begin{align}
  \alpha^3 + \alpha - 8 = 0 \label{eq:2}
\end{align}
である．題意を背理法で示す．
$\alpha$ が有理数だと仮定すると，$\alpha = \dfrac{b}{a}\ (a, b \in \mathbb{N})$ とおける($(a, b)$ は互いに素)．
\cref{eq:2}に代入して整理して
\begin{align}
  b^3 = 8a^3 - b a^2 = a^2(8a - b)
\end{align}
だから，$b^3$ が $a^2$ で割り切れることが必要だが，$a, b$ は互いに素だからそのようなことはない．よって矛盾するから，$\alpha \notin \mathbb{Q}$ であり，題意は示された．
