上図のように，$A(0,0)$を原点として$AB$を$x$軸とするような座標平面を考える．
すると$B(a,0)$であり，$P,Q$はそれぞれ$A,B$を中心とする半径$1$上の円上を動く．
題意からこれらの座標は
\begin{align}
  \overrightarrow{AP} =
  \begin{pmatrix} \cos 2\theta \\ \sin 2\theta
  \end{pmatrix}, \quad
  \overrightarrow{AQ} =
  \begin{pmatrix} a \\ 0
  \end{pmatrix} +
  \begin{pmatrix} \cos(-\theta) \\ \sin(-\theta)
  \end{pmatrix}
\end{align}
とおけるから
\begin{align}
  \overrightarrow{PQ} =
  \begin{pmatrix} a + \cos\theta - \cos 2\theta \\ -\sin\theta - \sin 2\theta
  \end{pmatrix} \label{eq:1}
\end{align}
である．

$|\overrightarrow{PQ}| \ge 0$ から，$|\overrightarrow{PQ}|^2$ が最大の時に$|\overrightarrow{PQ}|$ も最大になる．具体的に計算すると
\begin{align}
  |\overrightarrow{PQ}|^2
  &= \{ a + \cos\theta - \cos 2\theta \}^2 + (-\sin\theta - \sin 2\theta)^2 \\
  &= \{ a + \cos\theta - (2\cos^2\theta - 1) \}^2 + (-\sin\theta - 2\cos\theta\sin\theta)^2 \\
  &= (-2\cos^2\theta + \cos\theta + a + 1)^2 + \sin^2\theta(1 + 2\cos\theta)^2 \\
  &= 4\cos^4\theta - 4\cos^3\theta - (4a + 3)\cos^2\theta + 2(a + 1)\cos\theta + (a + 1)^2 + (1 - \cos^2\theta)(4\cos^2\theta + 4\cos\theta + 1) \\
  &= -4a\cos^2\theta + 2(a - 1)\cos\theta + (a^2 + 2a + 2)
\end{align}
となる．これを$f(\cos\theta)$とおいて：
\begin{align}
  f(c) = -4ac^2 + 2(a - 1)c + (a^2 + 2a + 2)
\end{align}
最大値を求めれば良い．
$a>0$より$f(c)$は下に凸な二次式だから，軸$c=\dfrac{a-1}{4a}$と両端点$c=\pm 1$の大きさで場合分けする．

\subparagraph{$1^\circ$ $0 < a \le \dfrac{1}{5}$ の時}

この時は$f(c)$は$c=-1 \therefore \theta=\pi$の時に最大となり，
その最大値は
\begin{align}
  \max f(c) = f(-1) = (a - 2)^2
\end{align}
である．

\subparagraph{$2^\circ$ $\dfrac{1}{5} \le a$ の時}

この時は$f(c)$は軸$c=\dfrac{a-1}{4a}$の時に最大となり，
その最大値は
\begin{align}
  \max f(c) = f\left(\dfrac{a-1}{4a}\right) = a^2 + \dfrac{9}{4}a + \dfrac{3}{2} + \dfrac{1}{4a}
\end{align}
である．
\casesend

以上をまとめて求める最大値は
\begin{align}
  \begin{cases}
    0 < a \le \dfrac{1}{5} \text{の時} & 2 - a \\
    \dfrac{1}{5} \le a \text{の時} & \sqrt{a^2 + \dfrac{9}{4}a + \dfrac{3}{2} + \dfrac{1}{4a}}
  \end{cases}
\end{align}
である．
