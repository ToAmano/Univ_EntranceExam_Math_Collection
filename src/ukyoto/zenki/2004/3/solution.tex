{\bf [解答]}

与えられた関係式
\begin{align}
  x^{2n}
  & =P_n(x) \left( x^2-x+\dfrac{n-1}{n^2} \right) +a_nx+b_n \\
  & =P_n(x) \left(x-\dfrac{1}{n}\right)\left(x-\dfrac{n-1}{n}\right) +a_nx+b_n \label{eq:1}
\end{align}
について考える．
$x=\dfrac{1}{n},\dfrac{n-1}{n}$を代入して
\begin{align}
  \begin{cases}
    \left(\dfrac{1}{n}\right)^{2n}&=a_n\left(\dfrac{1}{n}\right)+b_n\\
    \left(\dfrac{n-1}{n}\right)^{2n}&=a_n\left(\dfrac{n-1}{n}\right)+b_n
  \end{cases} \label{eq:2}
\end{align}
である．$n\to\infty$の時を考えるので，$n\ne 2$として良い．辺々引いて，
\begin{align}
  a_n = \dfrac{n}{2-n}\left[\left(\dfrac{1}{n}\right)^{2n}-\left(\dfrac{n-1}{n}\right)^{2n}\right]
\end{align}
だから$n\to\infty$の極限をとって
\begin{align}
  a_n=\dfrac{1}{\dfrac{2}{n}-1}\left\{\left(\dfrac{1}{n}\right)^{2n}-\left(1-\dfrac{1}{n}\right)^{-n(-2)}\right\}\xrightarrow{n\to\infty} e^{-2}
\end{align}
だから，\cref{eq:2}より
\begin{align}
  b_n=\left(\dfrac{1}{n}\right)^{2n}-\dfrac{1}{n}\cdot a_n\xrightarrow{n\to\infty} 0 \quad(\because a_n\to e^{-2})
\end{align}
である．以上まとめて
\begin{align}
  \lim_{n\to\infty}a_n = e^{-2}, \quad
  \lim_{n\to\infty}b_n = 0
\end{align}
である．
