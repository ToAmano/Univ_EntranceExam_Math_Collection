{\bf [解]}
$f(x)=x^2-x+\dfrac{n-1}{n^2}$とおくと，$f(x)=\left(x-\dfrac{1}{n}\right)\left(x-\dfrac{n-1}{n}\right)$である．したがって，$x=\dfrac{1}{n},\dfrac{n-1}{n}$として，
\begin{align}
\left(\dfrac{1}{n}\right)^{2n}&=a_n\left(\dfrac{1}{n}\right)+b_n\\
\left(\dfrac{n-1}{n}\right)^{2n}&=a_n\left(\dfrac{n-1}{n}\right)+b_n
\end{align}
である．$n\to\infty$の時を考えるので，$n\ne2$として良い．辺々引いて，
\begin{align}
\dfrac{2-n}{n}a_n=\left(\dfrac{1}{n}\right)^{2n}-\left(\dfrac{n-1}{n}\right)^{2n}\quad\cdots①
\end{align}

①から，$n\to\infty$の時
\begin{align}
a_n=\dfrac{1}{\dfrac{1}{n}-1}\left\{\left(\dfrac{1}{n}\right)^{2n}-\left(1-\dfrac{1}{n}\right)^n\left(\dfrac{n-1}{n}\right)^n\right\}\longrightarrow e^{-2}
\end{align}
\begin{align}
b_n=\left(\dfrac{1}{n}\right)^{2n}-\dfrac{1}{n}\cdot a_n\longrightarrow0\quad(\because a_n\to e^{-2})．
\end{align}
