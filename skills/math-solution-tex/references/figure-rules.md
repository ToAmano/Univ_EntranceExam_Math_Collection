# 数学の図の作図規約（TikZ）

数学の答案・教材に載せる図を TikZ で描くときの規約の正本。
節番号（§）で引けるようにしてあり、検査の指摘や作業の工程に応じて必要な節だけを読めばよい。

「（このリポジトリ固有）」と付いた項は、汎用のスキルとして切り出すときに `local/` へ移す。

---

## 0. 基本方針

### 0.1 何を読ませる図かを先に決める
- 本文と原稿を照合し、図で示すべき点・線・交点・境界・隠れた辺・移動方向・数値を列挙してから描く。
- 本文に出てこない補助線や注釈を足して、主題を埋もれさせない。
- 色や装飾のために、形状・位置関係・開閉端点を変えない。

### 0.2 幾何は座標で管理する
- 主要点は `\coordinate (P) at (...);` で命名する。派生点は `$(P)!0.5!(Q)$` や `\pgfmathsetmacro` で求め、手で近似した座標を置かない。
- 具体値を選んで描く場合は、問題の条件（長さ・角度・接する・直交する・点が線上にある、など）を満たす値にし、値の意味をコメントに残す。
- 曲線は正しい式と定義域で描く。

### 0.3 1ページに収める調整はしない
- 図を不自然に縮める、行間を詰める、といった紙面合わせはしない。可読性を優先する。

### 0.4 コンパイラ
- `lualatex`（luatexja）でコンパイルする。`pdflatex` では日本語が通らない。

## 1. 図の置き方

### 1.1 環境
- `tikzpicture` は必ず `figure` の中に置き、`\centering` で中央に寄せる（`center` 環境は使わない）。
- 例外：数式の中で面積の分解などを表す小さな図形アイコンは、`align` の中に直接置いてよい（§5.3）。

### 1.2 配置指定
- 2段組（`multicols`）の中では `[H]` を使う。2段組の中の浮動体は消えたり位置がずれたりする。
- それ以外は `[htb]`。

### 1.3 caption と label
- すべての `figure` に `\caption{...}` を付け、何を表す図かを一言で書く。
- 参照する図には `\label{fig:...}` を付け、本文からは `\cref` で参照する。

### 1.4 複数の図を並べる
- `subfigure` は使わず、`subcaptionblock`（または `minipage`）で並べる。
- 各パネルの軸・色の意味をそろえる。1つの `tikzpicture` の中で並べる場合は `scope[shift=...]` で分ける。

### 1.5 作図予定の図（TODO）
- 図の TODO は、`figure` 環境の中に書く。図を描くときは、この `figure` の中身だけを置き換える。

  ```latex
  \begin{figure}[htb]
    \centering
    % TODO: 左から三角形 OO_nP_n, OO_{n+1}P_{n+1}, O_nO_{n+1}Q_{n+1} と辺の長さ
    \caption{（作図予定）ピタゴラスの定理を用いる3つの直角三角形}
  \end{figure}
  ```
- 本文中に裸の `% TODO` を置かない（図だけを直したことを差分で検証できなくなる）。
- （このリポジトリ固有）`tikzpicture` を含まない `figure` は、現状の `tex_to_md.py` では Web 側に生の TeX として出る。作図予定の図を残したまま公開する場合は注意する。

## 2. 大きさ・縮尺

- 縮尺は図ごとに決める。固定の `scale` は定めない。
- 目安：仕上がりの幅が本文幅（2段組なら段の幅）の6〜9割、`\small` の文字が読める大きさ。
- 縦横比を変えたいときは `x=..cm, y=..cm` または `xscale`/`yscale` を使う（点の描き方は §4.1）。
- 小さすぎる図にしない。特に目盛り・添字付きのラベルが潰れていないかを §11 で確かめる。

---

## 3. 線の役割・色・太さ

### 3.1 役割ごとの指定

| 役割 | 指定 |
|---|---|
| 座標軸 | `->, thick, gray!80!black` |
| 主曲線・主輪郭 | `blue!85!black`、`line width=1.2pt`〜`1.4pt` |
| 比較対象の曲線・線 | `teal!85!black`、`orange!90!black` |
| 強調（結論に直結する点・線・答え） | `red!85!black`。赤は強調専用で、比較用の線には使わない |
| 補助線・座標軸への垂線・寸法の補助 | `densely dotted, thick, gray!70!black` |
| 隠れ線（立体の奥の稜線） | **輪郭と同じ色**の `dashed`（§7.3） |
| 漸近線・参考線 | `dotted` または `densely dotted`、`gray!70!black` |

- 線種の役割を混ぜない。**破線（`dashed`）は隠れ線専用**、点線（`dotted` 系）は補助線・垂線・漸近線。
- 同じ対象の線・点・ラベルは同じ色にそろえる。

### 3.2 灰色の濃さ
- 線・文字に使う灰色は `gray!60!black` 以上の濃さにする。`gray!30`〜`gray!50` のような薄い灰色は、印刷や SVG 化でかすれるので使わない。
- 斜線パターンの色も同じ基準にする（`pattern color=gray!40!white` などは不可）。

## 4. 点・ラベル

### 4.1 点
- 点は `circle` パスではなく `\node[circle, ...]` で打つ。`xscale` と `yscale` が違う図で `circle` パスを使うと楕円に潰れる。
  - 塗りつぶし点：`\node[circle, fill, inner sep=1.2pt] at (P) {};`（色付きは `fill=red!85!black` など）
  - 白抜きの端点（開区間の端点など）：`\node[circle, draw=blue!85!black, thick, fill=white, inner sep=1.4pt] at (P) {};`
  - 確率過程・木構造のノード：白抜きの丸 `\node[circle, draw, thick, fill=white, inner sep=2.0pt]`
- 図形としての円・円板（`\draw (O) circle (\r);`）は従来どおり `circle` を使う。
- 区間の端点は、含むなら塗りつぶし、含まないなら白抜きで描き分ける。

### 4.2 ラベル
- フォントは `every node/.style={font=\small}` を基本に、目盛り・補助説明は `\scriptsize`〜`\footnotesize`。
- ラベルは `above right=2pt` などで点・線から離す。近いラベルは別方向に振る。
- 重なりを避けられないときは引き出し線（`\draw[<-, thin, ...] (target) -- ++(...) node[...] {...};`）か白地のノードを使う。
- 分数は `\dfrac` ではなく `\frac` を使う（縮小表示で間延びするため）。

### 4.3 注釈ボックス
- グラフ上の重要な注釈は、白地に枠線のノードで背景と重ならないように置く。

  ```latex
  \node[draw=blue!85!black, fill=white, rounded corners=2pt, inner sep=2.5pt,
        font=\footnotesize, align=center] at (x, y) {注釈};
  ```

## 5. 塗り

### 5.1 平面の領域
- 面積・不等式の領域・積分区間など、平面の領域は**斜線パターン必須**。淡いベタ塗りだけにしない。

  ```latex
  \fill[pattern=north east lines, pattern color=blue!60!black] ...;
  ```
- 複数の領域を比べるときはパターンの向き・種類（`north east lines`／`north west lines`／`horizontal lines`）と色で区別する。
- 境界線と文字が読めることを優先する。

### 5.2 立体の面
- 立体の面（断面・側面・切り口など）は、薄いベタ塗りを許す（例：`fill=blue!15`、`opacity=0.5`〜`0.75`）。
- 面の輪郭線は必ず描く。体積や面積として読ませたい面は、平面の領域と同じく斜線にしてもよい。

### 5.3 数式中の図形アイコン
- `align` の中で面積の分解を表す小さな図形アイコン（§1.1 の例外）は、`gray!20` 程度のベタ塗りでよい。

### 5.4 くり抜いた領域
- 円環など内側をくり抜く領域は `even odd rule` で塗る。

## 6. 2D のグラフ・領域

### 6.1 座標軸への垂線
- 代表点・交点・極値・端点からは、原則として座標軸へ垂線（§3.1 の補助線）を下ろし、軸上の値をラベルで示す。
- 図が煩雑になる場合は、本文で座標を示していれば省略してよい。

### 6.2 交点・折れ点
- 境界が切り替わる点や交点の座標は計算して置く（目分量で置かない）。

### 6.3 曲線と領域
- 曲線は `plot[domain=..., samples=...]` で描き、急変する部分は `samples` を増やす。
- 領域の閉路は `plot` と `-- cycle` で確実に閉じる。

### 6.4 pgfmath の注意
- 三角関数にラジアンを渡すときは `sin(\x r)` のように `r` を付ける。
- `\x^2` は負の値で符号を誤るので `(\x)^2` または `(\x*\x)` と書く。

## 7. 3D の図

### 7.1 視点
- `tikz-3dplot` を使い、視点は **`figure` の中、`\begin{tikzpicture}` の直前**で指定する。

  ```latex
  \begin{figure}[htb]
    \centering
    \tdplotsetmaincoords{65}{115}
    \begin{tikzpicture}[tdplot_main_coords, scale=1.5]
      ...
  ```
- 標準の視点は **`{65}{115}`**。方位角を 120° などのきれいな角度にすると、問題の設定によっては稜線どうしが重なって隠れやすい。重なる場合は数度ずらす。
- 図ごとに視点を変えてよい（`figure` の中で指定すれば、その図だけに効く）。
- 投影ベクトルの直接指定（`x={(..)}, y={(..)}, z={(..)}`）は、斜投影で描きたい図に限って使う。

### 7.2 座標
- 点は3成分の `\coordinate (A) at (x,y,z);` で置き、§0.2 と同じく条件を満たす値を使う。

### 7.3 見える線と隠れ線
- 手前の稜線は実線、奥の稜線は**輪郭と同じ色の `dashed`**。
- 平面の奥を通る直線など、途中から隠れる線は、隠れ始める位置を計算して実線と破線に分ける（視線方向と面の位置関係から求める）。
- 描く順は、奥の線 → 面の塗り → 手前の線 → 点とラベル。

### 7.4 記号
- 中点・等長の記号は、線分の方向に合わせた短い2本線で描く。
- 面と直線の直交を表す直角記号は、単位方向ベクトルから立体的に整合する形で描く。

## 8. 遷移図・状態図（漸化式・確率）

漸化式や確率の問題で、状態とその移り変わりを示す図。

### 8.1 状態ノード
- 状態は円のノードで描き、ノードの中に本文と同じ名前を書く（`$P$`、`$x$`、`$a_n$`、`状態 $k$` など）。
- 書式は図の中で統一し、`\tikzset` でスタイルにまとめる（付録 C）。輪郭は §3.1 の色、塗りは同じ色の `!10` 程度の薄い色、`line width=1.2pt`。大きさは `minimum size` でそろえる。
- 注目している状態（漸化式の左辺など）だけを強調色にしてよい。
- 吸収状態・終了状態は二重丸（`double`）で区別する。

### 8.2 配置
- 1次元の推移（`x-1 → x → x+1` など）は横一列に等間隔で並べる。
- 対称な状態（3部屋・正多角形の頂点など）は、その対称性が見える配置にする（正三角形・正方形の頂点など）。
- 2つの量で決まる状態（格子上の点 `(k,l)` など）は格子として配置し、座標軸は §3.1 の座標軸の書式にする。
- 無限に続く状態は、両端または途中に `\cdots` のノードを置いて省略を示す。

### 8.3 矢印とラベル
- 遷移は `->` の矢印で描く。往復する2本は `bend left=15` 程度で曲げて重ならないようにする。自分自身への遷移は `loop above` などのループ（または `out=..., in=..., looseness=...`）で描く。
- 矢印には確率・係数・条件をラベルで付ける。分数は `\frac`、`font=\footnotesize`。ラベルは曲線の外側に置き、`auto` か位置指定で向きをそろえる。
- 矢印の色は、遷移元の状態の色にそろえるか、全体を1色にする。漸化式に使う遷移だけを強調色にしてもよい。
- 本文で使わない参考の遷移を描く場合は、`densely dotted, gray!70!black` にする（破線は隠れ線専用、§3.1）。

### 8.4 樹形図・分岐フロー
- 樹形図は左から右へ段ごとに等間隔で枝分かれさせ、枝に事象と確率を書く。
- 葉の右側に、各経路の確率や番号を列としてそろえて書く。区切りが必要なら縦の補助線（§3.1）を引く。
- 手順の分岐（取り出す → 戻す、など）を箱で描く場合は、角を丸めた白地の箱（§4.3）を使い、矢印に条件を書く。

### 8.5 照合すること
- 各状態から出る遷移の確率の和が1になっているか（ループを含む）。
- 本文の漸化式の項と、図の矢印・ラベルが1対1で対応しているか（係数・添字・向き）。
- 状態の名前・番号が本文と一致しているか。
- 樹形図の葉の確率の積と、本文の各場合の確率が一致しているか。

## 9. 概要図（整数・証明・論証の状況説明）

整数や証明の問題で、場合分け・配置・帰納法の構造などの状況を説明する図。正確な形よりも、論証の構造が読み取れることを優先する。

### 9.1 数値
- 長さ・角度は正確でなくてよいが、目盛りや座標などの数値を書く場合は、その値は正確にする。

### 9.2 よく使う型
- **数直線・区間**：区間の端点は、含むなら塗りつぶし、含まないなら白抜き（§4.1）。区間は太線か、端点を持つ括弧で示し、範囲の名前・不等式をラベルにする。
- **格子点・整数の組**：格子点は小さな点、条件を満たす点だけを強調色の点にする。数える対象の個数が本文と一致するようにする。
- **場合分け・集合**：場合ごとの範囲を区切って並べ、本文と同じ番号・名前（`(i)`、`$1^\circ$` など）を付ける。重なりを示すときは §5.1 の斜線で区別する。
- **点の並び・円周上の配置**：等間隔なら等間隔に置き、番号の付け方（時計回り・反時計回り）を本文と一致させる。
- **帰納法・操作の流れ**：`n` の段階と `n+1` の段階を箱や図で並べ、間を矢印で結んで、何が変わるか（増える項・移る点）を強調色で示す。
- 余りや値の一覧のように、表で示せるものは `tikzpicture` ではなく `table` / `tabular` にする。

### 9.3 省略
- 一般の個数を描くときは、途中を `\cdots` のノードで省略し、省略していることが分かるようにする。描いた個数を本文の具体的な個数と取り違えない。

### 9.4 照合すること
- 図中の名前・添字・番号が本文と一致しているか（`P_n` と `P_{n+1}` の取り違え、回転の向きなど）。
- 点・場合・区間の個数が本文と一致しているか。
- 開いた端点と閉じた端点が本文の不等号（`<` と `≦`）と一致しているか。

## 10. 幾何の整合の確認

描いた図が問題の条件を満たしているかを、座標から確かめる。目視で合って見えても、条件を満たしていない例が多い。

- 点が直線・円の上にあるか（例：直線 `ℓ` が点 `A` を通るか）。
- 接するはずの直線・円が交わっていないか（中心からの距離と半径を比べる）。
- 長さ・角度の条件（`AB=1`、120° など）を満たしているか。
- 直角記号を付けた角が実際に直角か。
- 展開図・立体の辺の長さが整合しているか。

## 11. 確認手順

1. lint（このリポジトリ固有：`python3 scratch/lint_latex_style.py <file>`）。
2. 図だけを直した場合は、図以外に差分がないことを確かめる（このリポジトリ固有：`python3 scratch/check_figure_only_diff.py <file>`）。
3. 一時コピーで `lualatex` でコンパイルし、PDF の**全ページ**を画像にして目視する。
4. Web 用の SVG も目視する（このリポジトリ固有：`python3 scratch/tex_to_md.py <file>` で生成し、`rsvg-convert` などで画像にする）。PDF だけでは視点のずれなど SVG 側の不具合が分からない。
5. 見るところ：
   - ラベル同士・ラベルと線の重なり
   - 図・caption の切れ、段からのはみ出し
   - 縮小時の可読性（目盛り・添字）
   - 線の前後関係（隠れ線・塗りの順）
   - §10 の幾何の整合
   - 遷移図・概要図では §8.5・§9.4 の照合

## 付録 A. 2D の図の雛形

```latex
\begin{figure}[htb]
  \centering
  \begin{tikzpicture}[x=2.2cm, y=1.4cm, >=stealth, every node/.style={font=\small}]
    \coordinate (O) at (0, 0);
    \coordinate (P) at (1, 1);
    % 領域は斜線パターンで、軸・輪郭より先に描く
    \draw[->, thick, gray!80!black] (-0.2, 0) -- (1.6, 0) node[right] {$x$};
    \draw[->, thick, gray!80!black] (0, -0.2) -- (0, 1.6) node[above] {$y$};
    \draw[line width=1.4pt, blue!85!black] (O) -- (P);
    % 代表点から座標軸へ垂線
    \draw[densely dotted, thick, gray!70!black] (P) -- (1, 0) node[below] {$1$};
    \draw[densely dotted, thick, gray!70!black] (P) -- (0, 1) node[left] {$1$};
    \node[circle, fill=red!85!black, inner sep=1.4pt] at (P) {};
    \node[above right=2pt, font=\footnotesize] at (P) {$P$};
  \end{tikzpicture}
  \caption{図が表す内容を一言で記す}
  \label{fig:descriptive_name}
\end{figure}
```

## 付録 C. 遷移図の雛形

```latex
\begin{figure}[htb]
  \centering
  \begin{tikzpicture}[>=stealth, every node/.style={font=\small},
      state/.style={circle, line width=1.2pt, minimum size=1.1cm, inner sep=1pt},
      edge label/.style={font=\footnotesize}]
    \node[state, draw=blue!85!black, fill=blue!10] (A) at (0, 0) {$x-1$};
    \node[state, draw=red!85!black, fill=red!10] (B) at (3, 0) {$x$};
    \node[state, draw=blue!85!black, fill=blue!10] (C) at (6, 0) {$x+1$};
    % 往復する遷移は曲げて重ならないようにする
    \draw[->, thick, red!85!black] (B) to[bend left=15]
      node[edge label, below] {$q$} (A);
    \draw[->, thick, red!85!black] (B) to[bend left=15]
```
