# label付き旧丸数字の削除可能性（東工大前期）

結論：綺麗に削除できる。レビュー済みの `definition / existing` **78ファイル・128行**に限定すれば、既存label・式本体・参照文を保持して旧番号の表示だけ取り除く方針が取れる。ただし「labelが同じファイルにあれば無条件に丸数字を消す」という判定は不可。「丸文字1字だけ」では `\text{}`、`\tag{}`、点線、余分な `\quad` が残るので、**番号注記の構文単位**を取り除く必要がある。

`docs/issues/reports/2026-10-22-circled-equation-labels/titech-reviewed.json` の全88ファイルについて現ファイルSHA-256一致を確認。以下は読取・メモ上のパターン照合のみ。原稿変更・コード実装・ビルド・GitHub書込は未実施。

## 128行の内訳（現ファイルに対する読取パターン照合）

117行は単純な「末尾注記＋label/行区切り」の限定パターンで拾える。残り11行も上の明示的な型別処理で対応可能。従って **117行は最小の保守的な自動化候補、128行全部も確認済みの個別型を含めれば実装可能**。実装・ビルドをしていないので「128行の変更後の表示まで検証済み」とは言わない。

## 実例

- 1967/3:13：`... ] \quad \dots \text{①} \label{eq:2}` → `... ] \label{eq:2}`。丸数字①とlabelの数字2は一致しないので番号値からlabelを生成・推測しない。
- 1970/4:85：`... \qquad \dots \text{\textcircled{1}} \label{eq:2}` → `... \label{eq:2}`。入れ子のtextを含めて除去する。
- 1982/1:50：`... \quad \cdots \text{②}\ (\because n>0) \label{eq:3}` → `... \ (\because n>0) \label{eq:3}`。番号後の理由を巻き込まない。
- 2012/4:10：`...\qquad(k=1,2,\dots).\tag{①}` → `...\qquad(k=1,2,\dots).`。数学的な省略記号の `\dots` は対象外。

## 誤変更を防ぐ安全基準

1. 対象はレビューJSONの `kind=definition` かつ `label_status=existing` のファイル・行のみ。実行前にSHA-256と元行を照合し、変化したものは止める。全ファイルへの丸数字の一括置換は行わない。
2. labelは既存の名前・位置・対応する式を保持。同一行とは限らず、128行中18行はlabelが別行。近隣labelの検索だけで安全判定しない。
3. cases/split全体に一つのlabelがある式群はそのまま維持。1976/1の②③や1987/5の①②のためにlabelを分割・増設しない。既存本文の「第一式・第二式」や参照を変更しない。
4. 別解にある同じ番号やlabelを対応候補にしない。レビュー済み1989/5・2001/3・2002/4の対象は主解。図2004/3の4行と場合分け1979/2の5行は対象外。
5. 変更差分を「許可された注記以外に変化なし」「label一覧・cref一覧不変」「空のtext/tag、注記専用quad・点線なし」で確認し、影響する解答をビルドして表示・参照解決を確認。tag除去で通常の式番号表示に戻ることも確認する。

## 保留との境界

本文・数式中に丸数字の直接参照が残る1987/3、1999/3、2007/3、2013/2の4問・12行は、定義がすべてlabelなし。**128行を含む78ファイルと、この4ファイルの共通部分は0**。既存label付き128行だけの削除は、この参照移行4問を巻き込まず独立して扱える。

`definition / ambiguous` の3行（1969/3:17、1981/3:66、1996/3:34）は保留。既存labelが別の同値式・再掲式・align別行に付いており、番号削除と参照先整理の判断を分ける。`missing` 17行と図4行も今回の128行処理には含めない。

## 2026-10-22 実施結果

上記の対象78ファイル・128行について、古い丸数字の式番号注記を削除した。通常の末尾注記に加え、別行の注記、casesの番号専用列、理由の前の注記、手動tagをそれぞれ処理した。変更箇所と原稿の前後ハッシュは `label-removal-changes.json` に記録している。

全128行で変更は削除のみ。各ファイルの `\\label`・`\\cref`・`\\ref`・`\\eqref` の並びは前後で一致した。対象78ファイルはLuaLaTeXを2回実行して全件成功。局所lintは新たなエラー・警告なし（長い行の既存警告が5件減少）。詳細は `label-removal-lint.json` と `label-removal-build.json`。既存の未解決参照3件（1970/4の1件、1972/3の2件）は今回の変更箇所とは別で、参照トークンは変更していない。曖昧な3行、labelのない17行、図の4行、および丸数字での直接参照4問はこの削除対象に含めていない。

Web変換は特殊例の1968/1、1976/1、2006/3、2012/4を一時ディレクトリへ個別実行し、4件とも成功。出力Markdownには旧丸数字と手動tagが残っていない。`git diff --check` は今回の78原稿に限定して成功。全体の `git diff --check` には別作業中の東大原稿の既存末尾空白があり、今回の対象とは無関係。
