# 文字起こし不能・要注意箇所の調査記録

更新日: `2026-07-31`

本ファイルは，`docs/status/*.md` 上で「unfinish」のまま残り続ける問題について，
**原稿を実際に確認した上で「なぜ転記できないか／できたか」を記録した証跡**である。
自動生成される status ファイルとは異なり，このファイルは調査時点のスナップショットであり，
手動でのみ更新される。同じ箇所を再調査する時間を省くために参照すること。

再調査が必要になった場合の判断基準:
- 該当年度の `handwritten.pdf` が差し替えられた／ページが追加された場合は，本ファイルの記載は無効なので再確認する。
- `problem.tex` が追加された場合も同様。

## 東大 後期 (utokyo/kouki)

`docs/status/utokyo_kouki.md` 上は54問全問が `finish` で「100%完了」と表示されているが，
2026-08-01にユーザーからの指摘を受けて `src/utokyo/kouki/*/*/solution.tex` の中身を全件精査したところ，
**4件が空のプレースホルダーテンプレートのまま**であることが判明した（分類E）。

### 分類E（`finish`の誤表示）— 4件

| 年度・問題 | ファイル | 備考 |
|---|---|---|
| 1990年 第2問 | `src/utokyo/kouki/1990/2/solution.tex` | 中身が`{\bf[解]}\n$\cdots$(答)\n{\bf[解説]}`のみ |
| 1993年 第1問 | `src/utokyo/kouki/1993/1/solution.tex` | 同上。`\rhead`が「2006年1番」と誤記（実際は1993年） |
| 1998年 第3問 | `src/utokyo/kouki/1998/3/solution.tex` | 同上。`\rhead`が「2006年3番」と誤記（実際は1998年） |
| 2007年 第2問 | `src/utokyo/kouki/2007/2/solution.tex` | 同上。`\rhead`が「2006年2番」と誤記（実際は2007年） |

**検出方法**: 全54件の`solution.tex`について，`{\bf[解]}`〜`{\bf[解説]}`間の本文を正規表現で抽出し，
空白・`\vspace{}`を除いた実質文字数が40文字未満のものを機械的に洗い出した（ヒット数4件，false positiveなし）。

3件で`\rhead`が実際の年度と異なる「2006年」を指しており，2006年のファイルをテンプレートとしてコピーした後，
本文を書き換えないまま放置された可能性が高い。

**utokyo/koukiの性質について**: `docs/status/utokyo_kouki.md`の「手書き原稿」列は全問「なし」であり，
zenkiと異なりそもそも手書きスキャンからの転記ではなく，問題文のみを元に解答を新規作成する運用になっている。
したがってこの4件は「転記漏れ」ではなく「未着手のまま`finish`ステータスだけが立った」ケースである。

**対応状況（2026-08-01時点）**: ユーザーの判断により，**証跡を残すのみで`solution.tex`本体・statusは未変更**。
実際に解答を作成する，またはstatusを`unfinish`に戻す等の対応は保留中。

---

## 今後の対応方針

- 分類A・Bは，原本自体に転記対象が存在しないため，**原稿の追加スキャンが入手できない限り対応不可**。
- 分類Cは，該当年度の入試が実際に7問・8問構成だったのか，出題ミス・誤番号なのかを一次資料で確認する必要がある。
- 分類Dのような自動判定の誤検知は，`scratch/generate_status_markdowns.py`の`check_file_status()`のキーワードリストが古い形式の解答を拾えないことが原因。同様のケースが他年度に埋もれている可能性があるが，全件の目視確認はコストが高いため未実施。
