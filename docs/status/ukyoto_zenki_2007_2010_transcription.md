## 原稿に残る確認事項（未修正）

| 対象 | 確認事項 |
|---|---|
| 2007-6 解答p.7 | `log((1+y)/(1-y))=2x+C` の直後，原稿は `C=1` と記載．`x=y=0` からは `C=0` となる．次の指数表示とも不整合．原稿通り転記しコメントを付けた． |
| 2008-3 解答p.4 | 一次独立なベクトルと線形結合の添字，係数と `t_i` の対応が不整合．原稿の `ℓ_3=aℓ_1+bℓ_2+cℓ_3` を保持．証明の基底・添字を全体確認する必要がある． |
| 2008-4 解答p.5 | 最後の共有点数の分類に `±2√2/3`，境界 `±√2` が現れ，途中の `±3√2/2`，`±2` と整合しない．最終分類を含む場合分け全体の確認が必要． |
| 2008-5 問題文 | 取り込み元は円柱の高さ条件を `0≤x≤1` と記載．他の記述・解答では `z` 方向の高さとして扱う．問題文原本と照合する必要がある． |
| 2008-6 問題文 | 取り込み元は西へ同一「経度」を進むと記載．緯線上の距離を扱う解答と整合せず，問題文原本の確認が必要． |
| 2010-2 解答p.3 | 冒頭の直線ABを `y=-x/2+1` としているが，問題のA(0,1)，B(0,2)を通る直線は `x=0`．後半のベクトルは問題の座標に対応する．原稿の記述を保持しコメントした． |
| 2010-4 解答p.5 | 負号の解を `b<0` として除外しているが，`√3<a<2` ではその理由が成立しない．鋭角条件も含め証明全体の確認が必要．原稿の除外理由を保持した． |
