# 分野タグ（案）

問題ごとに分野タグを付与し，関連問題リンクの元データとして使うための語彙案。

## 運用ルール

- 1問につき **1〜3個** までタグを付与可能（複合問題を無理に1つへ絞らない）。
- 上限を超えて付けない（タグが薄まって関連度判定に使えなくなるため）。
- 既存の年度サマリ（`src/*/*/*/0/solution.tex`）の「出題テーマ」列は自由記述の要約であり，このタグとは別物。タグ付けの際の参考にはできる。

## タグ一覧（15種）

| タグ | 主な内容の例 |
|---|---|
| 整数 | 整数問題，不定方程式，剰余・約数，二進展開 |
| 方程式・不等式 | 方程式・不等式の解法，恒等式，等号成立条件 |
| 図形と方程式 | 軌跡，領域，座標平面上の図形条件 |
| 平面図形 | 三角形・円などの初等幾何，面積・角の性質 |
| 空間図形 | 立体の体積・切断・投影，空間内の位置関係 |
| 三角関数 | 三角関数の性質・方程式・最大最小 |
| 指数・対数 | 指数関数・対数関数の性質・方程式・不等式 |
| 微分 | 導関数，増減表，極値，接線 |
| 積分 | 定積分の計算，面積，体積，積分方程式 |
| 数列 | 漸化式，一般項，数学的帰納法 |
| 極限 | 数列・関数の極限，はさみうち，区分求積 |
| ベクトル | 平面・空間ベクトル，内積，一次結合 |
| 複素数平面 | 複素数の図形的性質，極形式，ド・モアブル |
| 場合の数・確率 | 場合の数，確率，期待値，漸化式による確率 |
| 行列・一次変換 | 行列の演算，一次変換，不変直線・不変点（旧課程特有） |

## 検討中の論点

- 論証技法（背理法・帰納法など）は cross-cutting なので独立タグにしていない。
